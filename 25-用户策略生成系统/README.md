# 25-用户策略生成系统

> **端口**：8095 | **类型**：Flask 服务
> **定位**：用户意图 → AI 辅助策略生成 → 回测 → 基线对比 → 完整流水线编排

## 功能能力链

1. **用户意图解析** — 接收用户策略需求，转化为结构化意图
2. **AI 辅助策略生成（S1-S5 链）** — 分阶段生成策略代码与参数
3. **策略回测** — 执行回测并输出 metrics_summary
4. **基线对比** — 综合评分 + 推荐最优策略
5. **完整流水线编排** — 端到端策略生成流程

## 依赖

- 26-策略管理模块 — registry 查询基线策略（可选 HTTP 调用）
- 27-策略治理审批系统 — changeset/approval（可选 HTTP 调用）

## 目录结构

```
25-用户策略生成系统/
├── app.py              # Flask 入口

```

## 启动

```bash
python app.py
```

服务监听 `0.0.0.0:8095`。
