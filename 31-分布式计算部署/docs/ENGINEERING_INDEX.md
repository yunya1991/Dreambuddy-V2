# 分布式计算部署 — 工程索引

> **版本**：v1.0 | **更新日期**：2026-10-14
> **模块定位**：线上线下协同部署编排层（三层异构协同：认知聚合 / 竞赛择优 / 协作训练）

## 1. 模块概览

分布式协同部署方案：云端常驻实时交易+前端入口，线下承担训练/优化等重计算，通过任务队列+心跳实现协同与故障降级。
