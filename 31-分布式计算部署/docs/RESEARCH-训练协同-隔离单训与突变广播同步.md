## 0. 问题陈述

### 0.1 用户三层语义（基准口径）

| 层 | 语义 | 对应机制 |
|---|---|---|
| 前端应用层（模型训练） | **堆算力**（两类节点都训练，非二选一） | 隔离单训 + 同步 |
| 子交易系统层 | **择优竞赛** | Competition Mode 打分择优 |
| 广义认知系统层 | **认知聚合型** | 多节点记忆聚合 |

### 0.2 待评估的两个主张

- **主张 1（原方案）**：云端与本地**隔离单训**（各自独立训练，互不阻塞），**定期交互同步**。
- **主张 2（本轮新增·挖矿式）**：每类训练在出现**突变**（较大进步，需定标准/阈值）时**广播一次**（同步交流），其余节点**拉齐**后继续推进。

### 0.3 核心待答问题

1. 隔离单训 + 定期同步是否有理论支撑？（对齐 DiLoCo / Local SGD / FedAvg / Model Soup）
2. "突变才广播"是否成立？阈值怎么定？风险是什么？
3. 同步**同步什么**（权重 delta / 伪梯度 / 认知 / 元数据）、**周期**、**发散监控**、**回滚**如何设计？
4. 与系统已有/待实现编号（N7/N8/N9/N10、O1）如何映射？

## 1. 三方案对比与评分

| 维度（权重） | A 固定周期同步 | B 纯事件触发（突变广播） | **C 混合（周期兜底+突变即时广播）** |
|---|---|---|---|
| 通信量 | 中（周期固定开销） | 低（静默期零通信） | **低（静默期零 + 兜底心跳）** |
| 时效性 | 差（最坏等一个周期） | 好（突变立即传播） | **好** |
| 稳健性 | 高（不会长期静默） | **低**（阈值过高→长期静默、发散不可逆） | **高** |
| 收敛性 | 有保证（Local SGD/FedAvg） | 需 error feedback 才保收敛（Zehtabi 2204.03726） | 有保证（兜底等价周期） |
| 实现复杂度 | 低 | 中 | 中 |
| 与算力悬殊适配 | 中 | 好 | **好** |
| **加权总分** | 7.0 | 6.5 | **8.8** |

> **结论**：主张 2 **不能替代**主张 1，二者是**互补关系**——事件触发负责"快速传播好消息"，周期兜底负责"防止长期静默导致不可逆发散"。推荐 **C 混合**。
> **跨学科类比**：挖矿是"PoW 找到合格块→广播→全网拉齐→继续挖"，其**隐含前提是全节点解同一个难题（同一目标函数）**；我们的两节点若数据/目标不一致（non-IID），"拉齐"更接近 PBT（Population Based Training）的 exploit，会**牺牲种群多样性**，需谨慎（见 §4.3）。

## 2. 理论对齐（AI 训练域）

| 方法 | 同步对象 | 周期 | 对本方案的启示 |
|---|---|---|---|
| **DiLoCo**（DeepMind, [arXiv 2311.08105](https://arxiv.org/pdf/2311.08105)） | **伪梯度 = 内层参数相对外层锚点的增量**（非梯度） | 内层 H 步后 | 低通信(↓500×)隔离训练**有严格先例**；同步的是"参数增量"，契合 N8「权重 delta」；**单机多副本亦适用** |
| **Local SGD / FedAvg** | 模型参数均值 | 每 H 步 | 提供收敛保证与"通信-收敛"权衡；**固定周期次优**（Aperiodic Local SGD, ICPP'22），应允许周期自适应 |
| **事件触发通信**（[Zehtabi 2204.03726](https://arxiv.org/pdf/2204.03726v2.pdf)、He IEEE TSP 2023、[Event-Triggered Gossip](https://arxiv.org/html/2602.19116)） | 本地状态与上次发送值之差 > 阈值才通信 | 事件驱动 | **直接支撑"突变才广播"**；传输可↓50–70%；**但必须配 error feedback / 兜底**，否则掉队节点振荡发散 |
| **PBT**（Jaderberg 2017, [1711.09846](https://arxiv.org/pdf/1711.09846)） | exploit（弱者 copy 强者状态）+ explore | 周期性 | "拉齐"= exploit 的等价物；**但 PBT 同时注入扰动以保多样性** |
| **Model Soup / TIES / DARE / SLERP**（[2111.09832](https://arxiv.org/pdf/2111.09832.pdf)、TIES 2023） | 权重空间插值/合并 | 一次性 | **前提：同架构 + 同初始化（线性模式连通）**；两个"野生"独立 checkpoint 直接平均**有风险**，须先验证 loss |

**关键风险（AI 域）**：异构"野生"权重合并的实证研究（[arXiv 2511.21437](https://arxiv.org/html/2511.21437)）显示，**仅 Task Arithmetic 类稳健获益**，朴素平均可能有害。→ 合并**必须**以验证集 loss 为门禁，劣则退化为"择优不合并"。

## 3. 理论对齐（传统金融域）

| 主题 | 方法 | 对本方案的启示 |
|---|---|---|
| 组合/择优权重 | 等权 1/N、风险平价、BMA、Hedge/指数加权 | 低通信下**首选等权/风险平价兜底**，避免 MVO 估计误差；Hedge regret ≤ √(T·ln d) → 动态加权可逼近事后最优 |
| 择优替换 | champion/challenger + shadow（影子）+ canary | 影子期零风险验证；**最小样本** `n≈(z_{α/2}+z_β)²·2σ²/δ²`；用 MCS 保留候选集而非单冠军 |
| **多重检验校正（最关键）** | **Deflated Sharpe Ratio ≥0.95**、Harvey-Liu **t>3.0**、White RC、Hansen SPA、**BH-BHY FDR**、CPCV、PBO>0.5 | 频繁"比较→择优"会**系统性放大假发现**；每次择优须把**同期含历史版本的全部候选**计入试验计数 N_eff |
| 结构突变 | CUSUM、Bai-Perron、Markov regime switching、PELT | "突变才广播" ≈ **变点触发的再平衡**；须**冷却窗 + 二次确认**防噪声误触 |
| 时序动态权重 | rolling / EWMA / DMA / BPS | "拉齐后继续推进" ≈ warm-start / transfer learning |
| 门禁建议 | DSR≥0.95 或 t>3.0；样本 ≥250 交易日或 ≥1 完整 regime；OOS Sharpe 提升 ≥0.3–0.5 且净收益>成本+滑点 | 三者（统计显著 + 样本 + 经济意义）**同时**满足才广播 |

## 4. 关键设计决策

### 4.1 同步什么（同步物分层）

| 层 | 同步物 | 说明 |
|---|---|---|
| 前端模型层 | **权重 delta / 伪梯度**（DiLoCo 式增量）+ 验证指标元数据 | 只传增量不传原始数据；对应 **N8** |
| 子交易系统层 | **竞赛榜单 + 打分**（Sharpe/Return/MaxDD/WinRate 四元组） | 不传模型本体，只传结果，配合 **N7 版本管理** |
| 认知层 | **认知条目**（按 id 增量） | 现有 10min 双向聚合；可加"突变即时上行" |

### 4.2 突变判据与阈值（"定一个标准"）

统一定义：**相对改善 Δ 超过近期波动 k 倍（z-score），或跨过统计校正门禁**。分三域各自实例化：

| 训练类型 | 判据（"突变"定义） | 初设阈值 |
|---|---|---|
| 前端模型训练 | 验证 loss/perplexity 相对改善 > ε 且 **z>3**（相对近期 EMA 波动的 k 倍） | ε 初设 **1–2%**，k=3 |
| 子交易系统竞赛 | **DSR ≥0.95** 或 Harvey-Liu **t>3.0** | 样本下限：沿用 L0≥30/L1≥50/L2≥100 **且** 建议 ≥250 交易日（两者取严） |
| 认知层聚合 | 置信度增量 / 新增条目数超近期均值 k 倍 | k=3，或即时上行 |

**防误触机制**：
1. **冷却窗**（cooldown）：一次广播后 N 分钟内不再广播（防抖动）；
2. **二次确认**：连续 2 次评估均超阈值才广播（借 CUSUM/变点思路）；
3. **多重检验计数**：把每次比较的候选版本累计进 N_eff，用 DSR/FDR 校正后再判"突变"。

### 4.3 "拉齐"策略（对齐方式）

> **重要修正（跨学科复核后，见 §10）**：用户主张"同源同标(IID)"，但跨学科一致结论是 **"同源≠同构"**——同源数据 + 不同初始权重/随机种子/超参 → **不同收敛 basin**，此时"合并"不成立。**"拉齐"应以"择优(select) + 部分迁移"为先，而非"合并(merge) + 全量覆盖"。**

**禁止**简单"落后者全量覆盖为领先者"（=抹平探索，趋同单一解）。按优先级：

1. **择优 + 部分迁移**（**推荐首选**）：接收端**以领先者检查点做部分迁移/择优注入**（迁移率经验值 1–5%），落后者**保留自身继续训练**（岛屿模型 GA 的 migration 语义）；
2. **合并**（**仅当**同架构+同初始化且通过验证门禁）：SLERP/加权平均/DiLoCo 外层动量累积 → 合并后**必须**在共同验证集评估，劣于领先者则退化为 1；
3. **warm-start**（次选）：落后者以领先者权重初始化继续训练（保效率，接受一定趋同风险）。

**多样性预算（新增护栏）**：设**联合熵下限**——当两端参数余弦 > 0.99（KL 趋近 0）且指标无差异时，**主动注入噪声/换种子/换数据窗口**（PBT explore、岛屿模型 migration 率上调），防止"同步化死亡"（探索熵归零 → 失去集成方差降低收益）。

### 4.4 发散监控与回滚

| 项 | 设计 |
|---|---|
| 发散指标 | 参数/伪梯度 **L2 距离 + 余弦相似度**；验证 loss 差；输出 KL |
| 放弃合并判据 | 参数余弦 < 0.5 或相对 L2 超阈，或合并后验证 loss 无改善 → 择优不合并 |
| 回滚 | 每轮存 checkpoint + **last-known-good** 锚点；复用 **GeneVersionManager** 快照回滚 |
| 兜底心跳 | 固定周期（如 6h / 24h）强制同步一次，**防长期静默** |

## 6. 推荐方案（结论）

> **采纳主张 1 作为基座，把主张 2 作为叠加增强。**

```
隔离单训（两节点各自训练，互不阻塞）
   │
   ├─ 突变检测（MutationDetector）：相对改善 z>k 或过统计门禁
   │        │ 命中
   │        └──► 广播（Redis Pub/Sub）：发布 权重delta + 指标元数据
   │                │
   │                └──► 对端"拉齐"：合并(SLERP)→验证→失败则warm-start→再失败择优覆盖
   │
   └─ 兜底心跳（6h/24h 强制同步）+ 冷却窗 + 二次确认 + last-known-good 回滚
```

**最终评分：8.8 / 10**（原方案 7.0 → 加入突变广播与门禁后 8.8）。

**为什么不是 10**：① 无现成事件触发 FL 库，需自研薄封装；② 两节点数据若 non-IID，"拉齐"存在多样性损失风险；③ 阈值标定需要一段实测数据才能收敛。

## 8. 风险与待确认

| 风险 | 缓解 |
|---|---|
| 阈值过松→通信量与抖动上升 | 冷却窗 + 二次确认 + z>3 |
| 阈值过严→长期静默、不可逆发散 | **兜底心跳**（P0 即生效，不可省） |
| 合并两个野生 checkpoint 有害 | 合并后**强制验证门禁**，劣则降级 |
| 多版本频繁择优→假发现 | **DSR≥0.95 / t>3.0 / FDR(N5)** |
| 两节点趋同为单解 | 多样性护栏 + PBT explore |
| SSH 偶发超时 | 低频通信设计本就契合；广播走 Redis 而非 SSH |

**已确认的决策点**（2026-10-14，用户答复）：
- **Q-5（数据同源）**：用户判断为同源同标(IID)；**跨学科复核修正为"同源异构"**（见 §10），流程为"突变→成果同步→对齐→继续"，但"对齐"方式已按 §4.3 修正为**择优+部分迁移优先**。
- **Q-6（阈值严格度）**：**严格档** —— z>3 且 DSR≥0.95 或 Harvey-Liu t>3.0，+ 冷却窗 + 二次确认。
- **Q-7（兜底心跳）**：**6 小时**。

## 10. 跨学科复核（用户要求："看怎样更好"）

> 方法：`dream-science-cross-disciplinary`（金融交易 ↔ 复杂系统/统计物理/信息论/博弈论/网络科学）。

| 学科 | 理论/模型 | 对本方案的启示 |
|---|---|---|
| 进化计算/生物学 | **岛屿模型 GA**（迁移间隔/迁移率/拓扑）、**间断平衡** | "隔离+择优迁移"与用户流程同构；但"拉齐"=强全互联迁移 → 抹平探索。**迁移率经验 1–5%，应"择优注入"而非全量覆盖** |
| 统计物理/复杂系统 | Kuramoto 同步序参量、**自组织临界 SOC** 雪崩、相变 | "突变广播"≈雪崩触发（自然雪崩是**内生**的，用外设阈值需谨慎）；**阈值过低→过同步耗带宽，过高→漏真临界跃迁**；**拉齐过度 = 同步化死亡** |
| 信息论 | **信息瓶颈 IB**、互信息、KL | "仅当信息增益超阈才传"信息论合理；但"拉齐"≈最小化两端 KL → **降低联合熵 → 集成收益下降**；判据宜增**互信息/转移熵** |
| 博弈论 | 锦标赛理论、搭便车（集体行动逻辑）、机制设计、信号博弈 | 算力悬殊 → **小节点(M3)倾向搭便车**（等云端"出块"），贡献衰减；需机制设计保证双方训练激励；广播=**可信信号** |
| 网络科学 | 领导者-跟随同步、**主稳定函数 MSF** | 2 节点=单边 leader-follower；**未来扩多节点时 ring 拓扑优于全互联**（保多样性） |

### 跨学科修正结论（3 条，重要）

1. **"IID 假设"应改为"同源异构"**：同源数据 ≠ 同分布结果。随机种子/初始权重/超参差异 → 不同收敛 basin；损失面非凸时两端解常互不支配 → **"合并"通常不成立**。
2. **流程非最优**：迁移应 **"择优注入 + 部分迁移"**，并**保留隔离**；"拉齐"应为 **择优(select)** 而非合并(merge)/全量覆盖。
3. **跨学科最优协议（与已定硬约束 z>3 + DSR≥0.95、6h 心跳、混合范式兼容）**：
   ```
   两端各自独立训练
     → 突变只广播"择优检查点（非全模型）"
     → 接收端【择优替换 + 部分迁移(1–5%)】，保留自身变异率（不全量覆盖）
     → 6h 心跳做低幅迁移（rebase）
     → 多样性预算：当 两端 KL < 阈值 即注入噪声/换种子（防同步化死亡）
   ```

> **净结论**：用户"突变→同步→拉齐→继续"的**大方向成立**，但三处需修正：① 前提由 IID 改为**同源异构**；② "拉齐"由合并优先改为**择优+部分迁移优先**；③ 新增**多样性预算**与**反搭便车机制**。
