## 一、3+3 架构总览

```
┌─────────────────────────────────────────────────────────────────┐
│                    对外暴露能力（只读不写）                         │
│   通用 DreamOS (SACG) → DSH → L0 + 交易链（分析/观察，不执行）      │
├─────────────────────────────────────────────────────────────────┤
│  三层能力架构（按「是否依赖生成式 LLM 推理」唯一判据划分）            │
│  L0 基础能力层 │ L1 基础智能层（零token） │ L2 大模型驱动层（token） │
├─────────────────────────────────────────────────────────────────┤
│  三大核心能力链                                                    │
│  ① 交易框架链(49)  ② 模型训练链(34+48)  ③ 产品能力链(3.1/52/6/7/8/53)│
└─────────────────────────────────────────────────────────────────┘
```

**核心结论**：系统对外暴露的核心能力是 **L1（零 token 确定性金融能力）** 和 **L2（大模型驱动推理编排）**，通过 **DreamOS(SACG) → DSH → L0 + 交易链（只读）** 对外提供。内部由三条能力链支撑全部能力。

### 一.1 两种“三链”视角

- **本文的三大能力链**是模块归属视角：交易框架链、模型训练链、产品能力链，回答“模块归属于哪类能力资产”。
- **三大业务闭环链**是业务运行视角：交易链、涌现链、执行链，回答“业务如何完成、结果如何回流、能力如何进化”，由 [三大业务闭环链 SPEC](./SPEC-20261113-THREE-BUSINESS-CLOSED-LOOPS.md) 定义。
- 两者并存且不互相替代；同一模块可以归属于一条能力资产链，同时参与多条业务闭环链。S/C/F 思维链、D/Z/E 开发链、A0—A9 研究链和新 SACG 均不属于这两组分类。

## 二、三层架构定义

| 层 | 定位 | 驱动方式 | 成本 |
|----|------|---------|------|
| **L0 基础能力层** | 数据与事实的存储、采集、结构化 + 经验沉淀 + 工程检验 | 数据库/采集管线/规则/认知记录 | 零 token，独立双向层（fetchContext ⇄ settle） |
| **L1 基础智能层** | 不依赖大模型的金融能力 | 算法/规则/统计/意图识别 | 零 token，秒级响应 |
| **L2 大模型驱动层** | 语义理解、复杂推理、内容生成、跨域综合 | LLM（DreamOS SACG + DSH + 子 Agent） | token 成本 |

**收敛判据**：「确定性 + 本地模型/向量检索」→ L1；「生成式 LLM 推理」→ L2。L0 不直接对外路由，由 L1/L2 在工作前调用（fetchContext）、工作后沉淀（settle）。

**路由逻辑**：前端用户需求先过 L1 → 命中执行意图则直接返回（零 token 秒回）→ 未命中再走 L2。

**唯一判据**（沿用 [SPEC-v1.3-L0L1L2-architecture](../34-前端应用训练系统/SPEC-v1.3-L0L1L2-architecture.md) + [SPEC-L1L2-MCP-PACKAGING v0.1](../47-MCP管理系统/docs/tech/SPEC-L1L2-MCP-PACKAGING-v0.1.md)）：「是否依赖生成式 LLM 推理」——依赖 → L2；不依赖 → L0 或 L1。灰区规则：① 本地模型（FinBERT/嵌入/KNN/贝叶斯）算 L1；② 工具链（pandas/ta-lib/规则引擎）算 L0/L1；③ 混合组件按**主体能力**归层，形态可降级但归属不变；④ 编排 ≠ 生成（GraphExecutor 属机制，Reflector 的 LLM 部分才属 L2）；⑤ 一次 LLM 调用即 L2。

### 二.1 L1 内部三子层

```
L1-A 意图执行层（对外第一跳，in-process，零 token）
  意图注册表(10 意图：data_query/data_insight/contradiction_inference/macro_snapshot/...)
  + 路由器 + 意图执行器 + 案例沉淀(l1_case_store)
        ↓ fetchContext（读 L0）/ settle（写 L0）
L1-B 交易确定性能力层（双决策链的 L1 部分）
  B1 输入分析：9 基本面 / 10 经典指标 / 39 语义(主体L0)
  B2 子交易系统：11 BCRM2.0·BDSM·洗盘·事件套利 / 12 三屏 / 14 马丁 / 17 波浪 / 29 事件驱动
  B3 宏观弹性：40 周期NN / 43 战略承接
  B4 协调：42 协调层（插件总线）
  B5 决策：50 NN主矛盾（NN链出口） / 23 自进化（对照链，L1/L2）
  B6 执行：13 风控 → 16 调控/离场 → 22 执行引擎 → 51 OKX CLI / 11 执行器
        ↓
L1-C 确定性服务层（非交易，被全系统复用）
  15 监控告警 / 36 信号总线 / 26-28 策略管理·治理·信号 / 7 产物中台 / 8 FEISHU
  注：25 的当前生成主路径依赖 LLM，归 L2；其确定性只读元数据可降级暴露
```

### 二.2 L2 内部五子层

```

```

```
  18采集 → 19DAL → 20清洗 → 21特征 → 38数据库
  39金融语义蒸馏 / 9基本面分析
        ↓
【宏观弹性约束层】L1
  40 周期神经网络（长周期结构约束：cycle_state/strategy_mapping/fund_flow/washout）
    → 43 战略承接推演层（五维合成+四档决策+战略指令）
        ↓
【协调层】L1
  42 神经网络交易协调层（插件总线/参数治理/信号归一化/约束分发）
        ↓
【子交易系统层】L1（传感器+候选信号源）
  11-BCRM2.0 / 11-BDSM / 11-洗盘 / 11-事件套利 / 29-事件驱动
  12-三屏趋势 / 14-马丁 / 17-波浪 / 10-经典指标
        ↓
【决策层】L1/L2
  ┌─ NN闭环链: 50-NN主矛盾评估器（新建，复用23架构设计，独立实现）
  └─ 23自进化链（保留不动，作为对照实验）
        ↓
【执行层 EXEC / L1.5】L1（不属于 L0）
  13风控 → 16调控/离场 → 22执行引擎 → 11执行器/51-OKX CLI
  paper: exec.trade.mcp ｜ live: 11 旁路（实盘永不暴露 MCP）
        ↓
【离线反馈与控制面】
  成交/PnL/链路证据 → 48 归因/实验/训练建议
    → 40/50 各自训练门禁 → 采纳或拒绝 → 版本化发布/回滚
```

**关键规则**：
- 40/43 只产弹性约束，不直接出交易信号
- 42 只做汇聚/归一化/参数治理，不做策略判断、不下单
- 23 是矛盾裁决器+唯一最终决策出口（23链）；50 是 NN 链决策出口
- 13 风控优先于一切宏观约束和参数（Fail-Closed）
- L1 在线闭环（信号→决策→执行→反馈）不经过 MCP；离线训练由 34/48 等按门禁执行；L2 对 L1 能力只读，L2 自身训练写工具须 Mandate + 预算 + trace

## 八、归类口径说明

1. **23 自进化系统跨 L1/L2**：矛盾裁决器主体是确定性算法（L1），但做梦部/进化推理含生成式推理（L2）；归为「交易链决策/对照层」。
2. **48 涌现架构跨 L0/L2**：度量基础设施属 L0，涌现推理判定属 L2；归为「训练链」。
3. **认知系统（4/35）和 REA（33）是横切 L0**，但同时深度服务训练链（34/48），标为「横切→训练链」。
4. **原 6-图压缩 已合并入 24-图压缩**（2026-11-13 去重），24 为唯一保留的 TS 图压缩实现。
5. **11-易经推理系统**内部含 BCRM2.0/BDSM/执行器多个子系统，是交易链子系统层的核心承载。
6. **47-MCP管理系统**是纯文档统筹层（L0 能力封装的契约面），壳代码在 `mcp_shells/` 与各域内。
7. **25-用户策略生成系统**的当前生成主路径依赖生成式 LLM，主体归 L2；模板、参数和只读元数据等确定性子集可按 L1 形态降级暴露，但不改变主体归属。
