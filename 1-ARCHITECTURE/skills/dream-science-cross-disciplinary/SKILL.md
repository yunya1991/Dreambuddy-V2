# dream-science-cross-disciplinary — 跨学科调研

> dreambuddy-v2 科研 SKILL 支柱核心能力之一。建立金融交易与复杂系统/统计物理/信息论/博弈论/网络科学的映射关系，发掘跨学科洞察。

## 一、何时调用

满足以下任一条件：
1. 策略研究需要跨学科理论支撑
2. 需要从其他学科借鉴方法解决交易问题
3. 识别跨学科研究空白
4. 整体框架研究需要跨学科视角
5. A1 `dream-strategy-research` 调用本 SKILL 做跨学科调研

## 二、五大学科映射表

### 1. 复杂系统理论（Complex Systems）

| 核心概念 | 金融交易应用 | 可借鉴方法 |
|---------|------------|-----------|
| 涌现（Emergence） | 市场微观行为→宏观价格模式 | Agent-based modeling |
| 自组织临界性（SOC） | 市场崩盘的临界现象 | 幂律分析、沙堆模型 |
| 适应性景观（Fitness Landscape） | 策略参数空间的适应度 | NK 模型、爬山算法 |
| 相变（Phase Transition） | 市场状态转换（趋势/震荡） | 序参量分析、临界指数 |
| 网络效应 | 市场参与者互动结构 | 复杂网络分析 |

### 2. 统计物理（Statistical Physics）

| 核心概念 | 金融交易应用 | 可借鉴方法 |
|---------|------------|-----------|
| 重整化群（RG） | 多时间尺度价格行为 | 多尺度分析 |
| 随机矩阵理论（RMT） | 相关矩阵噪声过滤 | 特征值清洗、Marcenko-Pastur |
| 伊辛模型（Ising） | 交易者羊群行为 | 自旋模型模拟 |
| 最大熵原理 | 市场状态概率分布 | MaxEnt 建模 |
| 勒维飞行 | 价格跳跃分布 | 稳定分布拟合 |

### 3. 信息论（Information Theory）

| 核心概念 | 金融交易应用 | 可借鉴方法 |
|---------|------------|-----------|
| 互信息（Mutual Information） | 因子与收益的非线性关联 | MI 估计、KSG 算法 |
| 转移熵（Transfer Entropy） | 市场间信息流向 | TE 估计、Granger 因果推广 |
| 有效信息（Effective Information） | 策略决策的信息效率 | 信息瓶颈 |
| 科尔莫戈罗夫复杂度 | 价格序列的内在复杂度 | 压缩算法近似 |
| 信息率失真 | 策略信号的信息损失 | Rate-distortion 理论 |

### 复用 asset-research 的美林时钟框架

> **复用来源**: `asset-research` SKILL（美林投资时钟）

宏观周期判定可复用美林时钟框架，将经济周期映射到交易策略：

| 经济周期阶段 | 特征 | 交易策略启示 |
|------------|------|------------|
| 复苏期（Recovery） | GDP↑ 通胀↓ | 成长股/加密货币占优 |
| 过热期（Overheat） | GDP↑ 通胀↑ | 大宗商品占优 |
| 滞胀期（Stagflation） | GDP↓ 通胀↑ | 现金/短债占优 |
| 衰退期（Recession） | GDP↓ 通胀↓ | 长债/黄金占优 |

**应用**: 跨学科调研时，先用美林时钟判定当前经济周期，再选择对应的跨学科理论（如过热期→统计物理的相变理论）。

### 4. 博弈论（Game Theory）

| 核心概念 | 金融交易应用 | 可借鉴方法 |
|---------|------------|-----------|
| 纳什均衡 | 市场参与者策略均衡 | 博弈建模、均衡求解 |
| 演化博弈 | 策略种群的演化动态 | 复制子动态、ESS |
| 机制设计 | 交易规则与市场设计 | 激励兼容设计 |
| 信号博弈 | 信息不对称下的交易 | 信号传递模型 |
| 拍卖理论 | 订单簿价格形成 | 双向拍卖模型 |

### 5. 网络科学（Network Science）

| 核心概念 | 金融交易应用 | 可借鉴方法 |
|---------|------------|-----------|
| 无标度网络 | 市场参与者的连接结构 | 度分布分析、BA 模型 |
| 社区检测 | 板块/资产聚类 | Louvain、谱聚类 |
| 中心性 | 关键资产/节点识别 | 介数中心性、特征向量中心性 |
| 传播动力学 | 风险/情绪在市场中的传播 | SIR 模型、级联故障 |
| 图神经网络 | 资产关系建模 | GCN、GAT |

## 三、跨学科调研流程

### 步骤 1：问题定义
- 明确交易问题（如"如何预测市场状态转换"）
- 拆解问题维度（时间/空间/参与者/机制）

### 步骤 2：学科匹配
- 遍历五大学科映射表
- 识别与问题维度匹配的学科概念
- 输出候选学科清单

### 步骤 3：理论提取
- 深入研究候选学科的核心理论
- 提取关键概念和数学框架
- 评估理论的适用条件

### 步骤 4：应用转化
- 将学科概念映射到交易场景
- 设计可操作的方法（指标/模型/策略）
- 识别潜在的实施挑战

### 步骤 5：综合输出
- 跨学科理论映射表
- 可借鉴方法清单
- 潜在应用场景
- 实施建议

## 四、输出规范

1. **问题定义**：交易问题 + 拆解维度
2. **学科匹配**：候选学科及匹配依据
3. **理论映射**：学科核心概念 → 交易应用场景
4. **可借鉴方法**：具体方法 + 数学框架 + 适用条件
5. **潜在价值**：跨学科洞察可能带来的优势
6. **实施建议**：转化为可操作策略/指标的路径

## 七、金融交易适配

### 适用场景
- 用复杂系统理论解释市场崩盘/泡沫
- 用统计物理方法过滤因子相关性噪声
- 用信息论评估因子的非线性预测能力
- 用博弈论分析市场参与者互动

### 局限性
- 跨学科理论的假设条件在金融市场中常不满足（如均衡假设）
- 物理模型的参数在金融中难以直接校准
- 理论映射可能流于表面，缺乏实际预测力

### 适配建议
- 每个跨学科映射必须有可检验的交易含义
- 优先选择有实证支持的映射（如 RMT 过滤相关性）
- 对映射的适用范围做明确声明

## 八、约束

- 跨学科映射必须有理论依据，不得牵强附会
- 明确标注每个理论的适用条件和局限性
- 坚持 human-in-the-loop：AI 做理论检索和映射，人类判断应用价值
- 不直接搬用其他学科结论，必须经过交易场景的转化验证
