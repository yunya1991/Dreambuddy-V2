# dream-science-uncertainty-reasoning — 不确定性推理

> dreambuddy-v2 科研 SKILL 支柱核心能力之一。量化策略不确定性：市场状态不确定性、参数敏感性、过拟合风险。

## 一、何时调用

满足以下任一条件：
1. 需要量化策略的不确定性
2. 需要评估参数敏感性
3. 需要检测过拟合风险
4. 需要划定风险边界
5. `dream-risk` 调用本 SKILL 做不确定性量化

## 二、贝叶斯推理方法

### 贝叶斯框架
- **先验（Prior）**：参数的初始信念分布
- **似然（Likelihood）**：观测数据的概率
- **后验（Posterior）**：结合数据后的更新信念
- **贝叶斯更新**：Posterior ∝ Likelihood × Prior

### 应用场景
1. **参数不确定性**：策略参数的后验分布而非点估计
2. **状态不确定性**：市场状态的后验概率
3. **模型不确定性**：不同模型的后验概率
4. **预测不确定性**：收益预测的置信区间

### 实现方法
- **MCMC**（马尔可夫链蒙特卡洛）：采样后验分布
- **变分推断**：近似后验分布
- **贝叶斯优化**：在不确定性下寻找最优参数

## 三、敏感性分析

### 局部敏感性
- 对每个参数做小扰动，观察输出变化
- 计算参数的弹性系数

### 全局敏感性
- **Sobol 指数**：分解输出方差到各参数
- **Morris 方法**：筛选重要参数
- **拉丁超立方采样**：高效探索参数空间

### 输出
- 参数重要性排序
- 敏感性热力图
- 参数交互效应

## 四、过拟合风险评估

### 检测方法
1. **样本外验证**：训练集 vs 测试集性能差距
2. **交叉验证**：K-fold / walk-forward
3. **正则化强度**：L1/L2 正则化系数
4. **参数数量 vs 样本量**：自由度检查
5. **夏普比率的偏差校正**：考虑多重检验

### 过拟合信号
- 样本内夏普 >> 样本外夏普
- 参数微调导致性能剧变
- 策略对特定时间段敏感
- 自由度（参数数量）/ 观测值 > 0.1

### 缓解策略
- 增加正则化
- 减少参数数量
- 使用更简单的模型
- 增加样本量
- 使用集成方法

## 五、市场状态不确定性

### Regime Detection 置信度
- 使用 HMM 或聚类识别市场状态
- 输出状态的后验概率而非硬分类
- 当最大状态概率 < 0.6 时，标记为"不确定状态"

### 不确定性来源
1. **状态转换不确定性**：状态边界模糊
2. **观测噪声**：价格数据噪声
3. **模型不确定性**：不同模型给出不同状态判断

## 六、不确定性可视化

1. **置信区间图**：收益预测的上下界
2. **敏感性热力图**：参数空间的性能分布
3. **不确定性瀑布图**：各不确定性来源的贡献
4. **风险边界图**：不同置信水平下的最大损失

## 七、输出规范

1. **不确定性量化**：各来源的不确定性大小
2. **敏感性分析**：参数重要性排序 + 交互效应
3. **过拟合风险**：检测结果 + 缓解建议
4. **风险边界**：不同置信水平下的风险上限
5. **决策建议**：基于不确定性的策略调整建议

## 十、金融交易适配

### 适用场景
- 量化策略的不确定性来源分析（市场/参数/模型）
- 策略参数敏感性评估
- 过拟合风险检测

### 局限性
- 金融市场的不确定性难以完全量化（如黑天鹅事件）
- 贝叶斯先验的选择具有主观性
- 敏感性分析假设参数独立，实际可能存在交互效应

### 适配建议
- 区分"已知未知"（可量化）和"未知未知"（不可量化）
- 对"未知未知"采用压力测试和情景分析
- 过拟合检测结合样本外表现和参数稳定性

## 十一、约束

- 不确定性必须量化，不得模糊表述
- 区分"已知的未知"和"未知的未知"
- 坚持 human-in-the-loop：AI 做量化计算，人类判断风险接受度
