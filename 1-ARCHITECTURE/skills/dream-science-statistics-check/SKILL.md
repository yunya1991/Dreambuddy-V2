# dream-science-statistics-check — 统计审查

> dreambuddy-v2 科研 SKILL 支柱工具集之一。借鉴 nature-skills 的 nature-statistics，审查回测结果的统计严谨性。

## 一、何时调用

满足以下任一条件：
1. 回测完成后需要统计审查
2. 策略报告需要统计学合规性检查
3. 需要发现回测中的统计问题
4. A8 `dream-theory-practice-verify` 调用本 SKILL 做统计审查

## 二、检查清单

### 2.1 实验单位和重复数
- [ ] 实验单位是否明确（交易次数/时间周期）
- [ ] 重复数是否充足（N ≥ 30 或说明理由）
- [ ] 是否使用了独立样本（避免数据泄露）
- [ ] 是否报告了样本量和自由度

### 2.2 p 值审查
- [ ] p 值是否正确计算
- [ ] 是否报告了精确 p 值（而非仅 p < 0.05）
- [ ] 是否使用了正确的检验方法（参数/非参数）
- [ ] 是否考虑了数据分布（正态性检验）
- [ ] 是否存在 p-hacking（多重比较未校正）

### 2.3 效应量审查
- [ ] 是否报告了效应量（Cohen's d / r / 相关系数）
- [ ] 效应量大小是否合理（小/中/大）
- [ ] 效应量是否与 p 值一致
- [ ] 是否区分了统计显著和实际显著

### 2.4 置信区间审查
- [ ] 是否报告了 95% 置信区间
- [ ] 置信区间是否包含 0（影响显著性判断）
- [ ] 置信区间宽度是否合理
- [ ] 是否使用了正确的置信水平

### 2.5 多重比较校正
- [ ] 是否进行了多重比较
- [ ] 是否使用了校正方法（Bonferroni / FDR / Holm）
- [ ] 校正后的显著性是否一致
- [ ] 是否报告了比较次数

### 2.6 跨章节数值一致性
- [ ] 摘要中的数值与正文是否一致
- [ ] 图表中的数值与文字描述是否一致
- [ ] 不同章节引用的同一指标是否一致
- [ ] 百分比计算是否正确

### 2.7 数据可视化审查
- [ ] 图表坐标轴是否有标签和单位
- [ ] 误差棒是否标注类型（SD/SEM/CI）
- [ ] 图表是否有误导性（截断坐标轴、比例不当）
- [ ] 统计学标注是否正确（* / ** / ***）

## 三、常见统计问题与修正

| 问题 | 表现 | 修正方法 |
|------|------|---------|
| 忽略多重比较 | 多个 p 值未校正 | 使用 Bonferroni/FDR 校正 |
| 只报 p 值不报效应量 | "p < 0.05" 无效应量 | 补充 Cohen's d 或 r |
| 样本量不足 | N < 30 且用参数检验 | 改用非参数检验或说明 |
| 数据泄露 | 训练集和测试集有重叠 | 重新分割数据 |
| 前视偏差 | 使用了未来数据 | 检查时间点一致性 |
| 忽略交易成本 | 回测未扣成本 | 加入滑点和手续费 |
| 过拟合 | 样本内远好于样本外 | 增加正则化/减少参数 |

## 四、输出规范

1. **统计问题清单**：按严重程度分级（Critical/Major/Minor）
2. **修正建议**：每个问题的具体修正方法
3. **统计学合规评分**：0-10 分
4. **修正后验证**：修正后的统计结果对比

## 七、金融交易适配

### 适用场景
- 回测报告的统计合规性审查
- 策略对比的统计显著性验证
- 因子研究的多重比较校正

### 局限性
- 金融数据常违反正态性假设，t-test 可能不适用
- 交易数据存在自相关，标准误可能被低估
- 小样本回测（如日内策略）统计功效不足

### 适配建议
- 优先使用非参数检验（Mann-Whitney、Bootstrap）
- 对自相关数据使用 HAC 标准误
- 小样本时报告效应量和置信区间，不仅看 p 值

## 八、约束

- 统计审查必须基于实际数据，不得走过场
- 所有问题必须有明确的修正方法
- 坚持 human-in-the-loop：AI 做统计检查，人类判断问题严重程度
