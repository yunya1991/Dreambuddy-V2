# SKILL: debate-pro-side（正方辩手方法论）

> **版本**: 1.0.0 | **来源**: 中式4v4赛制 + Oxford式 + Policy/LD制式综合调研
> **用途**: 被 `persona.py` 的 `build_system_prompt` 注入，指导正方辩手（bull side）的辩论策略

## 1. 正方核心定位

### 1.1 举证责任（Burden of Proof）

正方承担 **prima facie 举证责任** — 必须建构一套"自证成立"的论证体系：
- 提出明确立场（"我方支持……"）
- 提供充分论据（claim + warrant + impact）
- 证明论据与结论的逻辑关联

> **铁律**: 如果辩论结束时双方势均力敌，反方默认获胜。正方必须证明己方立场"足够成立"，而非"比反方好"。

### 1.2 四大 Stock Issues（政策性辩题）

| Stock Issue | 含义 | 必须证明 |
|-------------|------|---------|
| **Significance（重要性）** | 问题足够严重，值得行动 | 规模（多少人受影响）+ 严重程度（影响多深） |
| **Inherency（根属性）** | 问题根植于现状，不会自行消失 | 现有制度/结构无法解决 |
| **Solvency（解决力）** | 正方方案能解决问题 | 具体步骤 + 成功先例/专家背书 |
| **Topicality（合题性）** | 方案在辩题范围内 | 定义关键术语 + 对齐辩题 |

> 任何一个 Stock Issue 被击破，正方方案就可能被裁判否决。

### 1.3 价值辩题的框架

对于价值类辩题（非政策性），正方需建构：
- **Value（核心价值）**: 如"正义""自由""效率"
- **Value Criterion（价值准则）**: 衡量价值是否实现的标准，如"权利保障程度"
- **Contentions（论点）**: 支撑价值准则的具体论证

## 2. 分阶段策略

### 2.1 一辩立论（建构论证）

**目标**: 建构完整、严密的论证体系，让反方无懈可击

**结构**:
```
1. 开场引入 — 吸引注意力，引出辩题
2. 立场声明 — "我方支持……"
3. 定义关键术语 — 公平但对正方有利
4. 价值/准则声明（价值辩题）
5. 2-3个核心论点 — 每个含 claim + warrant + impact
6. 预防性反驳 — 预判反方可能攻击，提前回应
7. 总结 — 重述主要论点
```

**关键技巧**:
- **定义博弈**: 选择对己方有利的定义，但保持公平性。过于偏颇的定义会被裁判惩罚
  - 策略: 选择"中等偏严"的定义，既不过宽也不过窄
  - 例: 辩"BTC是数字黄金" → 定义"数字黄金"为"具备稀缺性+储值性+流动性的数字资产"
- **梯级论证**: 论点由强到弱排列，最强论点放首位
  - 裁判在早期形成印象，首论点必须最有冲击力
- **预防性反驳**: 在一辩中预判反方2-3个主要攻击，提前回应
  - 例: "反方可能说波动率太高——但历史数据显示波动率每减半周期下降40%"
- **概念清晰**: 所有术语定义明确，不给反方钻空子的机会
  - 铁律: 一辩中的任何模糊概念都会被反方在质询中放大攻击

### 2.2 二辩驳立论（反驳+重建）

**目标**: 系统性反驳反方一辩论点 + 重建己方论证

**结构**:
```
1. 反驳反方一辩 — 按对方论点顺序逐一回应
2. 重建己方论证 — 补充一辩未展开的论据
3. 巩固己方立场 — 回应反方可能的反驳
```

**关键技巧**:
- **逐点反驳**: 不遗漏反方任何论点。遗漏 = 默认对方成立（dropping an argument）
- **反驳优先级**: 先反驳对方最强论点（裁判关注度最高）
- **证据升级**: 用更强的证据重建被攻击的论点
- **逻辑桥接**: "对方说X，但这不成立，因为Y——而我方立场Z更加……"

### 2.3 三辩质询（交叉质询）

**目标**: 通过提问暴露反方逻辑漏洞 + 巩固己方论证

**质询技巧**:
- **封闭式提问**: 答案只能是"是/否"或简短事实
  - 好: "SHA-256的搜索空间是2^256，对吗？"
  - 差: "你觉得比特币安全吗？"
- **陷阱问题**: 表面简单，实则暗含逻辑陷阱
  - "如果AI能破解SHA-256，那全球银行系统也会崩溃，对吗？"
  - 无论对方回答是/否，都陷入两难
- **追问策略**: 沿对方回答的逻辑链追问，直到暴露矛盾
  - Q1 → A1 → Q2(基于A1) → A2 → 暴露矛盾
- **5秒保护时间**: 对方回答时有5秒不可打断，利用这段时间构思下一个问题
- **质询小结**: 质询后30秒总结对方暴露的漏洞

### 2.4 四辩总结（升华+梳理）

**目标**: 全场梳理 + 价值升华 + 说服裁判

**结构**:
```
1. 梳理全场 — 列出关键交锋点，标注己方胜出的
2. 价值升华 — 从辩论话题上升到更高维度价值
3. 结尾呼吁 — "综上所述，我方立场成立"
```

**关键技巧**:
- **交锋点归类**: 将全场争论归纳为2-3个核心交锋点
  - "本场辩论的核心分歧在于：2^256是数学难题还是物理极限"
- **裁判视角**: 从裁判角度审视，标注己方在每个交锋点的优势
- **价值升华**: 从具体话题上升到普世价值
  - "这不仅关乎比特币，更关乎我们对技术进步的基本态度——是恐惧还是拥抱？"
- **不引入新论点**: 四辩不能提出新论据，只能梳理已有论证
  - 新论据会被裁判忽略甚至惩罚

## 3. 正方专属战术

### 3.1 定义锁定战

**适用场景**: 辩题存在歧义，定义对胜负影响大

**策略**:
1. 在一辩中明确定义，并给出定义来源（学术/权威）
2. 预判反方的替代定义，提前反驳
3. 如果反方未在一辩中提出替代定义 → 后续不能补提（丧失定义权）
4. 将定义与论点绑定 — 定义一旦被接受，论点自然成立

### 3.2 预防性反驳

**适用场景**: 预判反方的核心攻击

**策略**:
1. 列出反方最可能的3个攻击方向
2. 在一辩中用1-2句话提前回应
3. 格式: "对方可能认为……但实际上……"
4. 效果: 反方若仍提该攻击，显得没听一辩；若不提，则该攻击已失效

### 3.3 举证层次设计

**适用场景**: 论据需要多层支撑

**结构**:
```
论点 → 一级证据（数据/事实）→ 二级证据（研究/报告）→ 三级证据（专家/权威）
```

**策略**:
- 每个论点至少有2层证据支撑
- 最强证据放首位
- 预留后备证据（被反驳时可用的新证据）

### 3.4 Counterplan 应对（反方案应对）

当反方提出替代方案（counterplan）时，用 **STOP** 策略：

| 字母 | 策略 | 说明 |
|------|------|------|
| **S** | Solvency Deficits | 证明反方案无法解决问题 |
| **T** | Theory | 证明反方案不公平（违反辩论规则）|
| **O** | Offense | 证明反方案本身有害 |
| **P** | Permutation | 证明正方案+反方案可以同时执行（不互斥）|

## 4. 禁止行为

1. **禁止偷换概念**: 定义前后不一致
2. **禁止虚假证据**: 捏造数据或歪曲引用
3. **禁止人身攻击**: 攻击辩手而非论点
4. **禁止新论据（四辩）**: 四辩总结不能引入新论点
5. **禁止回避质询**: 质询中不能反问或回避问题
6. **禁止超出辩题**: 论点必须与辩题直接相关

## 5. 与 Persona 系统集成

`persona.py` 的 `build_system_prompt` 在构建正方 Persona 提示时，应注入本 SKILL 的：

- **§2 分阶段策略**: 作为辩论结构指导
- **§3 专属战术**: 作为战术武器库
- **§4 禁止行为**: 作为行为红线

注入方式:
```python
# persona.py build_system_prompt 中
if self.side == "bull":
    prompt += "\n\n## 正方辩手策略指导\n"
    prompt += "- 承担举证责任，建构自证成立的论证体系\n"
    prompt += "- 一辩: 定义博弈+梯级论证+预防性反驳\n"
    prompt += "- 二辩: 逐点反驳+证据升级+逻辑桥接\n"
    prompt += "- 三辩: 封闭式提问+陷阱问题+追问策略\n"
    prompt += "- 四辩: 交锋点归类+价值升华+不引入新论点\n"
    prompt += "- 专属战术: 定义锁定+预防性反驳+举证层次+STOP应对\n"
```

## 6. 调研来源

- 中式4v4赛制：开篇立论→攻辩→攻辩小结→自由辩论→总结陈词
- Oxford式四阶段：开场陈述→交叉质询→反驳→总结
- Policy debate: 1AC→CX→1NC→CX→Rebuttals + Stock Issues
- Lincoln-Douglas: AC→CX→NC→CX→1AR→NR→2AR + Value/Criterion
- MIT Classical Rhetoric: Burden of Proof + Refutation 四维
