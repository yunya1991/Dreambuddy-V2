# dream-science-hypothesis-verification — 不确定推演论证引擎

> dreambuddy-v2 科研 SKILL 支柱核心能力之一。对交易假设进行科研级论证：可证伪性检验、对照实验设计、统计显著性检验、消融实验、反事实推理。

## 一、何时调用

满足以下任一条件：
1. 策略假设需要科研级验证
2. 回测结果需要统计显著性检验
3. 需要通过消融实验验证因子贡献度
4. 需要反事实推理评估策略因果效应
5. A5 `dream-signal-scoring` 调用本 SKILL 做信号假设验证

## 二、可证伪性检验

### 可证伪性标准
一个交易假设必须满足：
1. **可观测**：假设涉及的变量必须可测量
2. **可反驳**：存在可能的观测结果能推翻假设
3. **可复现**：在相同条件下应得到相同结论

### 检验流程
1. 将假设形式化为可检验的命题
2. 识别反驳条件（什么观测会推翻假设）
3. 评估数据可获得性
4. 输出：可证伪性判定 + 反驳条件清单

### 示例
```
假设: "RSI < 30 时买入，RSI > 70 时卖出，能获得超额收益"
可证伪性: ✅ 可证伪
反驳条件:
  - RSI < 30 买入后收益 ≤ 0
  - 策略夏普比率 ≤ 基准
  - 扣除交易成本后无超额收益
```

## 三、对照实验设计

### 实验设计要素
- **实验组**：使用目标策略/因子
- **控制组**：使用基准策略（如买入持有、随机信号）
- **控制变量**：相同的时间区间、交易成本、风险约束
- **随机化**：随机选择样本（如 bootstrap 抽样）

### 对照实验模板
```
实验名称: <策略名称> 有效性验证
实验组: <目标策略>
控制组: <基准策略，如 buy-and-hold>
控制变量:
  - 时间区间: <开始>-<结束>
  - 交易成本: <bps>
  - 杠杆: <x>
  - 风险约束: <最大回撤上限>
样本量: <N 次 bootstrap>
主要指标: 夏普比率、最大回撤、胜率
次要指标: 卡玛比率、Sortino、盈亏比
```

## 四、统计显著性检验

### 常用检验方法

| 检验方法 | 适用场景 | 假设 |
|---------|---------|------|
| **t-test** | 比较两组均值（正态分布） | H0: 均值无差异 |
| **Mann-Whitney U** | 比较两组分布（非参数） | H0: 分布无差异 |
| **KS-test** | 比较两个分布 | H0: 分布相同 |
| **Bootstrap** | 小样本或分布未知 | 通过重采样估计置信区间 |
| **Permutation test** | 随机化检验 | H0: 标签无关 |

### 显著性判断
- **p < 0.05**：统计显著（*）
- **p < 0.01**：高度显著（**）
- **p < 0.001**：极显著（***）
- **效应量**：不仅看 p 值，还要看效应量大小（Cohen's d / 相关系数）

### 多重比较校正
- 当检验多个假设时，使用 Bonferroni 或 FDR 校正
- 校正后的 p 值阈值 = 原始阈值 / 比较次数

### 复用 dream-strategy-research 的信号充分性评估

> **复用来源**: `dream-strategy-research` §信号充分性评估 (v1.3)

假设验证的证据充分性可复用交易系统的信号充分性评级：

```
证据充分性 = 方向性证据数量 × 证据强度 - 反向证据数量 × 证据强度

方向性证据:
├── HIGH强度: 统计显著(p<0.01) + 效应量大(Cohen's d>0.8) + 样本量充足
├── MODERATE强度: 统计显著(p<0.05) + 效应量中等 + 样本量一般
└── LOW强度: 边缘显著(p<0.1) 或 效应量小 或 样本量不足

评级判定:
├── HIGH: 方向性证据≥3个 且 高强度证据≥1个 且 方向一致
├── MODERATE: 方向性证据≥2个 或 1个高强度+1个中强度
└── LOW: 方向性证据≤1个 或 证据方向冲突
```

**关键规则**: 即使证据混乱，也要给出 MODERATE 评级，禁止"证据不足=不验证"。

## 五、消融实验

### 消融实验目的
验证策略中每个组件的贡献度，识别哪些组件是必需的。

### 消融实验流程
1. 列出策略的所有组件（因子、规则、参数）
2. 逐个移除组件，重新回测
3. 对比完整策略与消融策略的性能差异
4. 量化每个组件的贡献度

### 消融实验模板
```
完整策略: 因子A + 因子B + 因子C + 规则D
消融1: 因子B + 因子C + 规则D (移除因子A)
消融2: 因子A + 因子C + 规则D (移除因子B)
消融3: 因子A + 因子B + 规则D (移除因子C)
消融4: 因子A + 因子B + 因子C (移除规则D)

贡献度 = 完整策略性能 - 消融策略性能
```

## 六、反事实推理

### 反事实问题
"如果不使用这个策略，结果会怎样？"

### 方法
1. **合成控制法**：用其他资产/策略合成反事实路径
2. **双重差分（DID）**：比较处理组和对照组在事件前后的差异
3. **断点回归**：利用临界值附近的随机变化识别因果效应

## 七、结论边界声明

每个验证结论必须声明：
1. **时间边界**：结论适用的时间区间
2. **市场边界**：结论适用的市场/资产
3. **参数边界**：结论适用的参数范围
4. **样本边界**：样本量和统计功效
5. **外推风险**：结论外推到其他场景的风险

## 八、输出规范

1. **假设陈述**：可证伪的命题 + 反驳条件
2. **实验设计**：实验组/控制组/控制变量/样本量
3. **统计检验**：检验方法 + p 值 + 效应量 + 置信区间
4. **消融实验**：各组件贡献度
5. **反事实分析**：因果效应估计
6. **结论**：支持/反驳/不确定 + 结论边界

## 十一、金融交易适配

### 适用场景
- 验证交易因子/策略的统计显著性
- 检验策略改进是否真实有效（对照实验）
- 识别策略中哪些组件是必需的（消融实验）

### 局限性
- 金融数据非平稳，同一假设在不同时期可能结论相反
- 多重检验问题：测试多个策略时，假阳性概率上升
- 可证伪性难以完全实现：市场状态转换可能使历史证伪失效

### 适配建议
- 使用样本外验证（walk-forward）而非仅样本内检验
- 多重比较时使用 Bonferroni 或 FDR 校正
- 声明假设的适用市场状态（趋势/震荡/高波动）

## 十二、约束

- 所有统计检验必须基于实际数据，不得伪造 p 值
- 必须报告效应量，不能只看 p 值
- 多重比较必须校正
- 结论必须声明边界，不得过度外推
- 坚持 human-in-the-loop：AI 做统计计算，人类判断结论的实际意义
