## §2 四角色独立评审

### 2.1 Journal-Fit Reviewer（是否适配目标场景）

**支持**：
- 零 LLM、纯统计、可回溯 `eval_id`，符合 L1 定位；
- R1–R5 覆盖「趋势/形态/周期/惯性/前瞻」，与用户表述一一对应；
- R6 主动挂起（等 FNS），避免用不存在的口径造结论——这是正确的自律。

**意见**：
- **适配缺口（Major-1）**：系统目标是「发现数据-价格关系」，但当前所有指标都是**单资产时序内部**（target = 自身前瞻收益）。跨资产/跨市场传导（例如 DXY → BTC）只能靠 R5 的 CCF，而 16 个包里 R5 只有 2 个包。若目标含跨资产，需补包；若不含，SPEC 应显式声明边界。
- **Minor-1**：`D-K01` 的推荐只给 RankIC/hit，未给「经济含义」（bps）。研究结论若不能换算成可交易幅度，无法进入第 6 步。

### 2.2 方法评审（方法论严谨性）

**支持**：
- 分类法先声明后执行，`method_roles` 20/20 无孤儿，校验脚本能拦 6 类越界；
- 归纳层是**纯函数 + 字节可复现**，方向正确。

**Major 意见**：

- **Major-2（评分 5，致命）「hit_rate ≥ 0.60」不是有效性证据**。命中率无对照基线：若标的无条件上涨概率本身就是 58%，hit 60% 的信息量≈0。必须改为**超额命中率** `hit - base_rate`（或 permutation null 的分位），并报告基线值。
- **Major-3（评分 4）hit 的极值定义未冻结**。「方向命中」依赖「因子处于高位/低位」的阈值；阈值若事后可选（top 10%/20%/30%），hit 可被搜索抬高。必须写死：`|z| ≥ 1.0` 或 `quintile ∈ {1,5}`，且与 discovery_space 一致。
- **Major-4（评分 4）R1–R6 不互斥导致重复计数**。B14 同时映射 R1/R4，同一条 finding 会进入两个族、各自做一次 BH 与 agreement，等于**同一份证据被用两次**。需二选一：① 一条证据只归**主类**（按包绑定），或 ② 在 BH 前对 (eval_id) 去重。
- **Major-5（评分 3）方向多数票掩盖双峰**。`sign_agreement = max(pos,neg)/n` 在「一半强正一半强负」时给出 0.5~0.6 的 candidate，但真实含义是**状态依赖**（子群分化），不是弱效应。应输出 `bimodal` 标记并提示按 regime 拆分，而不是简单降级。

### 2.3 统计评审（合规性）

- **Major-6（评分 5，致命）重叠窗口使 Wilson 区间失效**。n=250、h=20 → 有效独立样本 ≈ 12，Wilson 假设 iid 会**大幅高估精度**（区间过窄）。必须：① 按非重叠窗口计数（`n_eff = floor(n/h)`），或 ② block bootstrap / Newey-West 调整。
- **Major-7（评分 5，致命）跨期多重检验无 α 预算**。BH 只在单期 5000 单元内校正；若每日/每周重跑，假阳性会随期数线性累积（每期 ~250 个 p<0.05 的假阳性）。必须加：跨期复现门（连续 3 期同号 + 同族）或 online-FDR（α spending）。
- **Major-8（评分 4）缺效应量与成本门槛**。hit 60%/RankIC 0.03 可能对应 0.5bps 超额，扣手续费+滑点后为负。门禁必须加 `effect_bps`（超额收益中位数，bps）与 `cost_bps` 对照，`effect_bps > cost_bps` 才可推荐。
- **Minor-2（可证伪性/可复现）**：`patterns.py` 的 `members` 优先取 `eval_id`，缺失时退化为 `series`，会造成同一 series 多行合并成同名成员 → 成员计数虚高。需冻结 findings 字段契约（`eval_id` 必填）。
- **Minor-3（参数不可达，实为缺陷）**：`min_members=3` 与 `alpha=0.05` 组合在数学上**不可达**——n=6 全同向二项 p=0.219，n=3 时 p=0.25。即「3 条就 stable」永远不可能。必须把 `min_members` 提到 **10**（n=10 全同向 p≈0.002），或改用置换检验并如实说明功效。
- **Minor-4（数值一致性）**：`p_adj` 与 `p_value` 在单 pattern 时相等（BH 退化），测试已覆盖；但 SPEC §5 的示例文案写了「p_adj = p × 检验次数」，与实现不符（BH 是秩次缩放），需改文档避免误导。
