## 定位

本目录是 V5.5 LightGBM 机器学习策略的探索工作区，用于：
- 重新设计特征工程解决过拟合问题
- 探索新的标签生成策略
- 探索时序模型（LSTM/Transformer）
- Walk-Forward 验证

## 当前状态

V5.5 ML 副线存在严重的长期过拟合问题：
- 9年回测年化收益仅 4.31%（远低于主线 56.43%）
- 夏普比率 0.3024（远低于主线 1.4112）
- 需重新设计特征工程

## 优化方向

1. **特征工程重设计**：减少特征维度，增加特征稳定性
2. **训练窗口优化**：探索更长的训练窗口（>730天）
3. **标签策略改进**：改进标签生成，减少噪声
4. **时序模型探索**：LSTM/Transformer 替代 LightGBM
5. **多任务学习**：同时预测多个目标

## 晋升条件

副线晋升为主线需同时满足：
- 9年回测年化 ≥ 56.43%
- 夏普 ≥ 1.41
- 最大回撤 ≤ -43.31%
- Walk-Forward 样本外 AUC ≥ 0.60
- 多币种验证均优于主线
