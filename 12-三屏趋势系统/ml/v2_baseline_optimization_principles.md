## 1. 基线策略定位

### 1.1 为什么选择V4作为基线

V4减半周期逃顶策略是在V2/V3基础上，引入**比特币减半周期时间维度**达成的最佳版本。
在9年+历史回测中，综合评分1.592（相对V2提升59.2%），总收益1440%，最大回撤仅53.46%。

V4的核心优势：
- **时间维度加持**：不仅依赖价格指标，还利用减半周期的确定性时间窗口
- **四重逃顶机制**：减半周期 + 越高越卖 + MA128破位 + 反弹卖出，多重保险
- **回撤控制优异**：最大回撤从V2的77.85%降至53.46%，风险大幅降低

### 2.3 四重逃顶机制

V4的核心创新是四重逃顶机制，层层递进：

```
┌─────────────────────────────────────────────────────────┐
│                  V4 四重逃顶机制                          │
│                                                           │
│  ┌─────────────────────────────────────────────────┐     │
│  │ 1️⃣ 减半周期时间锚定（核心）                       │     │
│  │    减半后12-18个月进入顶部区域，强制减仓          │     │
│  │    仓位：100% → 70% → 30% → 0%                  │     │
│  └──────────────────┬──────────────────────────────┘     │
│                     │ 顶部区域内触发                      │
│  ┌──────────────────▼──────────────────────────────┐     │
│  │ 2️⃣ 越高越卖                                     │     │
│  │    价格每创新高5%卖出一档（15%仓位）              │     │
│  │    最高卖出80%仓位                               │     │
│  └──────────────────┬──────────────────────────────┘     │
│                     │ 价格跌破MA128                       │
│  ┌──────────────────▼──────────────────────────────┐     │
│  │ 3️⃣ MA128破位卖出                                │     │
│  │    跌破MA128后每跌5%卖出一档（4档清仓）           │     │
│  └──────────────────┬──────────────────────────────┘     │
│                     │ 下跌中出现反弹                       │
│  ┌──────────────────▼──────────────────────────────┐     │
│  │ 4️⃣ 反弹卖出                                     │     │
│  │    每次反弹3%卖出25%剩余仓位                      │     │
│  │    最高累计卖出80%                               │     │
│  └─────────────────────────────────────────────────┘     │
└─────────────────────────────────────────────────────────┘
```

### 2.4 空头规则（V3优化版，仅BTC）

| 条件组合 | 初始仓位 | 说明 |
|---------|---------|------|
| 跌破MA200 + 5日斜率为负 | 60% | 确认下跌趋势才做空 |
| 跌破MA200 + 5日斜率非负 | 0% | **V3改进：不做空**（V2是30%） |

**关键改进**：V2在"价格跌破MA200但斜率为正"阶段做空（L1=30%），回测发现此阶段未来收益为正，做空是逆势操作。V3/V4移除L1做空，只在斜率明确为负时做空。

| 止盈位 | 盈利比例 | 剩余仓位 | 说明 |

| 第2止盈 | 38.2% | 50% | 主要利润区 |
| 第3止盈 | 50.0% | 25% | 关键心理位 |
| 第4止盈 | 61.8% | 0%（清仓） | 黄金分割位，全部离场 |

### 2.5 小币熊市规则（沿用V2）

| 操作 | 状态 | 原因 |
|------|------|------|
| 做多 | 禁止 | BTC熊市时小币跌势更猛 |
| 做空 | 禁止 | 小币反弹剧烈，趋势不可控，流动性差 |
| 操作 | 空仓 | 观望，等待牛市信号 |

## 7. 版本管理与回退机制

### 7.1 版本命名规则

```
v2              原始基线（牛熊经验法则）
  ↓
v3              做空优化（L1=0, L2=0.6）
  ↓
v4              减半周期逃顶（当前基线）
  ↓
v4.1, v4.2 ...  小版本迭代（参数/特征微调）
  ↓
v5              大版本架构升级（需充分验证）
```

版本号变更规则：
- **参数微调、特征增减** → 次版本号+1（v4.x）
- **架构升级、算法范式变更** → 主版本号+1（v5）

### 7.2 回退触发条件

出现以下任一情况，**必须回退**到V4基线：

| # | 触发条件 | 严重程度 |
|---|---------|---------|
| 1 | 综合评分 ≤ 1.0（相对V4） | 立即回退 |
| 2 | 样本外表现显著劣于样本内（过拟合） | 立即回退 |
| 3 | 最大回撤超过V4的120%（即>64.15%） | 评估后回退 |
| 4 | 实盘/纸交易连续3个月跑输V4 | 评估后回退 |
| 5 | 核心逻辑变更导致可解释性丧失 | 评估 |
| 6 | 减半周期预测失败（2025年10月后BTC未见顶） | 评估后调整 |

### 7.3 回退操作流程

```
1. 标记版本为"探索失败"
   └─ 在配置文件中标记 status: "failed_exploration"
   └─ 记录失败原因和关键发现

2. 策略配置回退到V4基线
   └─ 恢复 HalvingTopExitStrategy 默认参数

3. 分析失败原因
   └─ 是特征问题？模型问题？参数问题？减半周期失效？
   └─ 形成经验教训，避免重蹈覆辙
```
