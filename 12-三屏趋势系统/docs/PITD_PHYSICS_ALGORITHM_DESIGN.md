> **版本**: v1.0 | **创建日期**: 2026-07-19
> **定位**: 三屏趋势系统底层推理算法框架
> **目标**: 将五条核心趋势理论转化为基于物理学定律的数学模型，从经验驱动走向理论驱动
> **母文档**: [TECHNICAL_DESIGN.md](TECHNICAL_DESIGN.md) 第9章

## 1. 算法概述

### 1.1 设计动机

三屏趋势系统经过V2→V5.5的迭代，特征工程已接近瓶颈（28维哲学特征，TOP_EXIT AUC 0.7433）。
进一步突破需要从**经验驱动的特征工程**升级为**理论驱动的物理数学算法**。

五条核心趋势理论提供了物理学映射的基础：
1. 趋势强度强时，大周期驱动小周期（趋势惯性）
2. 趋势强度减弱，小周期底部累积，量变到质变
3. 阈值临界通过方向/速度/加速度计算
4. 市场沿阻力最小方向运动
5. 利用力学定律构建精密算法

### 1.2 核心创新

将K线序列视为**质点运动轨迹**，应用经典力学和变分原理：
- **运动学**：位移/速度/加速度/加加速度（1-3阶导数）
- **动力学**：质量/力/动量/动能（牛顿第二定律）
- **场论**：势能场/梯度/阻力最小方向（最小作用量原理）
- **相变**：能量累积/临界突变/量变到质变

## 2. 五层算法架构

### Layer 1: 运动学层（Kinematics）

**目标**：计算多周期运动学观测量

#### 2.1.1 基础定义

将K线收盘价序列视为质点运动轨迹：

```
位移（路程）: s(t) = ln(P(t) / P(t₀))          # 对数收益，避免量纲
速度:        v(t) = ds/dt ≈ Δs/Δt               # 一阶导数
加速度:      a(t) = dv/dt = d²s/dt²             # 二阶导数
加加速度:    j(t) = da/dt = d³s/dt³             # 三阶导数（突变预警）
```

#### 2.1.2 离散化实现

日线（D）周期，Δt=1日：
```
v_D(t) = ln(P(t)/P(t-1))
a_D(t) = v_D(t) - v_D(t-1)
j_D(t) = a_D(t) - a_D(t-1)
```

周线（W）周期，Δt=7日：
```
v_W(t) = ln(P(t)/P(t-7)) / 7                   # 标准化为日均值
a_W(t) = (v_W(t) - v_W(t-7)) / 7
j_W(t) = (a_W(t) - a_W(t-7)) / 7
```

#### 2.1.3 平滑处理

为降低噪声，对导数进行EMA平滑：
```
v_smooth(t) = EMA(v(t), span=5)
a_smooth(t) = EMA(a(t), span=5)
j_smooth(t) = EMA(j(t), span=3)                 # jerk更敏感，平滑更轻
```

#### 2.1.4 ML特征输出（12维）

| 特征名 | 公式 | 物理含义 |
|--------|------|---------|
| `kin_velocity_D` | EMA(v_D, 5) | 日线速度 |
| `kin_acceleration_D` | EMA(a_D, 5) | 日线加速度 |
| `kin_jerk_D` | EMA(j_D, 3) | 日线加加速度 |
| `kin_velocity_W` | EMA(v_W, 5) | 周线速度 |
| `kin_acceleration_W` | EMA(a_W, 5) | 周线加速度 |
| `kin_jerk_W` | EMA(j_W, 3) | 周线加加速度 |
| `kin_speed_ratio_WD` | \|v_W\|/\|v_D\| | 大小周期速度比 |
| `kin_accel_ratio_WD` | \|a_W\|/\|a_D\| | 大小周期加速度比 |
| `kin_velocity_sign_consistency` | sign(v_W)==sign(v_D) ? 1 : 0 | 方向一致性 |
| `kin_acceleration_sign_consistency` | sign(a_W)==sign(a_D) ? 1 : 0 | 加速度方向一致性 |
| `kin_jerk_abs_D` | \|j_D\| | 日线突变强度 |
| `kin_jerk_abs_W` | \|j_W\| | 周线突变强度 |

### Layer 2: 动力学层（Dynamics）

**目标**：计算力、动量、动能及大小周期动量传递效率

#### 2.2.1 质量定义（修正后方案）

```
m(t) = StableCoin_MarketCap(t) / StableCoin_MarketCap_MA(t)
```

**物理意义**：
- 稳定币总市值代表加密市场整体流动性环境
- 是外生于BTC价格的外生变量（避免与价格共线）
- m增大 = 流动性充裕 = 改变趋势需要更大的力

**数据获取**：
- 主数据源：CoinGecko / DefiLlama API（USDT+USDC+DAI+USDC等总市值）
- 备选方案：若API不可用，使用 `m(t) = 1.0`（恒定质量，退化为纯运动学）

#### 2.2.2 力与能量

```
波动幅度（温度）: σ(t) = ATR(t) / P(t)
摩擦系数: μ = 0.1（经验值，可调）

合力: F(t) = m(t) × a(t) - μ × m(t) × σ(t)
动量: P(t) = m(t) × v(t)
动能: E_k(t) = ½ × m(t) × v(t)²
```

#### 2.2.3 动量传递效率（理论1实现）

```
η(t) = corr(v_W, v_D, window=20) × |v_W| / (|v_W| + |v_D| + ε)

当 η > 0.6（趋势强）: 大周期驱动小周期 → 顺势信号
当 η < 0.3（趋势弱）: 小周期独立运动 → 累积/反转信号
```

#### 2.2.4 ML特征输出（约8维）

| 特征名 | 公式 | 物理含义 |
|--------|------|---------|
| `dyn_force_net` | m×a - μ×m×σ | 合力 |
| `dyn_momentum` | m×v | 动量 |
| `dyn_kinetic_energy` | ½×m×v² | 动能 |
| `dyn_force_W` | m×a_W - μ×m×σ_W | 周线合力 |
| `dyn_momentum_W` | m×v_W | 周线动量 |
| `dyn_coupling_eta` | corr(v_W,v_D)×\|v_W\|/(...) | 动量传递效率 |
| `dyn_force_ratio_WD` | F_W / (F_D + ε) | 大小周期力比 |
| `dyn_friction_ratio` | μ×m×σ / (m×a + ε) | 摩擦力占比 |

### Layer 3: 势能场层（Potential Field）

**目标**：建模价格空间的势能场，计算阻力最小方向

#### 2.3.1 势能场定义

```
V(s) = Σ w_i × φ(s - s_i)

其中:
  s    = ln(P)（当前价格的对数坐标）
  s_i  = 关键价位的对数坐标
  φ    = 势能核函数（高斯核：exp(-x²/2σ²)）
  w_i  = 该价位的"质量"（成交量/触及次数/重要性权重）
```

#### 2.3.2 四类关键价位

| 价位类型 | 来源 | 权重 w_i | σ |
|---------|------|---------|---|
| 均线密集区 | MA50/128/200汇聚点 | 均线斜率强度 | 0.02 |
| 成交密集区 | 历史成交量分布峰值 | 累积成交量 | 0.015 |
| 前高前低点 | 历史结构高低点（20/50/100日） |触及次数×时间衰减 | 0.02 |
| 斐波那契位 | 0.382/0.5/0.618回撤 | 固定权重1.0 | 0.025 |

#### 2.3.3 阻力最小方向

```
势能梯度: ∇V(s) = dV/ds = Σ w_i × φ'(s - s_i)
阻力最小方向: direction = -∇V(s)
```

#### 2.3.4 ML特征输出（约6维）

| 特征名 | 公式 | 物理含义 |
|--------|------|---------|
| `field_potential` | V(s) | 当前势能 |
| `field_gradient` | -dV/ds | 阻力最小方向 |
| `field_distance_to_minima` | \|s - s_minima\| | 距势能最小点距离 |
| `field_force_support` | -∇V_support | 支撑力 |
| `field_force_resistance` | ∇V_resistance | 阻力 |
| `field_net_force` | -∇V_total | 净场力方向 |

---

### Layer 4: 相变层（Phase Transition）

**目标**：检测小周期能量累积与临界突变

#### 2.4.1 能量累积

```
E_pot(t) = ∫₀ᵗ |a_small(t')| × (1 - |η(t')|) dt'
```

**物理意义**：
- `|a_small|`：小周期加速度（震荡幅度）
- `(1 - |η|)`：大周期脱钩程度（趋势弱时累积更快）
- 积分：累积效应

#### 2.4.2 临界判据

```
E_critical = hist_percentile(E_pot, 80%)  # 历史80分位数

PhaseTransition_Score = w₁ × (E_pot/E_critical)        # 能量饱和度
                      + w₂ × |j_small|/σ_j              # 加加速度异常
                      + w₃ × (1 - |η|)                  # 大周期脱钩程度
                      + w₄ × Volume_Divergence          # 量价背离

当 Score > 0.8 → 相变预警（量变到质变临界）
```

#### 2.4.3 ML特征输出（约5维）

| 特征名 | 公式 | 物理含义 |
|--------|------|---------|
| `phase_energy_accumulated` | ∫\|a_small\|×(1-\|η\|)dt | 累积势能 |
| `phase_critical_ratio` | E_pot/E_critical | 临界饱和度 |
| `phase_jerk_anomaly` | \|j_small\|/σ_j | 加加速度异常 |
| `phase_decoupling` | 1 - \|η\| | 大周期脱钩度 |
| `phase_transition_score` | 多指标融合 | 相变综合得分 |

---

### Layer 5: 最小作用量统一框架（Least Action）

**目标**：统一前四层，基于变分原理进行轨迹预测

#### 2.5.1 拉格朗日量

```
L(s, v, a, t) = E_k(t) - V_total(s)
              = ½ × m(t) × v(t)² - V_total(s)
```

#### 2.5.2 作用量与运动方程

```
作用量: S = ∫ L dt

最小作用量原理: δS = 0

欧拉-拉格朗日方程:
  d/dt(∂L/∂v) - ∂L/∂s = 0
  → m×a = -dV_total/ds    （牛顿第二定律的场论形式）
```

#### 2.5.3 轨迹预测

给定当前状态 (s₀, v₀, a₀)，求解 δS=0 得到未来轨迹 s(t+Δt)：
```
s(t+Δt) ≈ s₀ + v₀×Δt + ½×a₀×Δt² + ⅙×j₀×Δt³
```

其中 a₀ 由 `m×a = -dV/ds` 求解，考虑势能场和摩擦力。

## 6. 探索结论与经验教训（2026-07-19）

### 6.1 Phase 1-3.5 验证结果总览

| Phase | 物理理论验证 | ML AUC提升 | 决策 |
|-------|------------|-----------|------|
| Phase 1 运动学层 | ✅ v/a/j物理意义合理（v符号正确率74.3%，反转点jerk放大3.14x） | ❌ TOP -0.0489, DIP +0.0037 | 回退 |
| Phase 2 动力学层 | ✅ **理论1完美验证**（η随趋势强度2.86x单调递增） | ❌ 全部下降 | 回退 |
| Phase 3 势能场层 | 🟡 理论4接近验证（阻力最小方向正确率50.4%） | ❌ TOP -0.0276, DIP -0.0028 | 回退 |
| Phase 3.5 交互特征 | — | ❌ 21个交互特征0个双场景提升 | 回退 |

### 6.2 核心发现

#### 发现1：物理模型是对的，ML集成是错的

**理论1被完美验证**：动量传递效率η随趋势强度单调递增
- 最弱趋势档：η = 0.077
- 最强趋势档：η = 0.294
- 强弱比：2.86x

物理量的物理意义100%正确：
- 动量方向正确率：100%（sign(P)==sign(v)）
- 动能非负率：100%
- 速度符号正确率：74.3%
- 反转点jerk放大：3.14x

**但所有物理特征直接作为ML输入都导致AUC下降**。

#### 发现2：V5.5已触及LightGBM信息容量上限

V5.5基线状态：
- 特征数：80维（52趋势 + 28哲学）
- 训练集AUC：1.0000（完全拟合）
- 测试集decay：25.7%（TOP）/ 30.7%（DIP）

任何新增特征都会加剧过拟合，即使物理意义正确、即使通过交互工程。
特征重要性排名高（如η排名Top11%）但AUC反而下降，是典型过拟合信号。

#### 发现3：物理量与现有特征的信息重叠无法消除

| 物理量 | 本质 | 冗余来源 |
|--------|------|---------|
| η (耦合效率) | corr(v_W, v_D) | 趋势一致性特征 |
| 势能梯度 | MA偏离度 | MA特征族 |
| 动量 P=mv | 价格变化率×质量 | 动量指标 |
| 加速度 a=dv/dt | 价格二阶导数 | 动量变化率 |

即使构建非线性交互特征（η×drawdown, 梯度×周期相似度等），
底层信息源仍与V5.5重叠，21个交互特征0个有效。

#### 发现4：DIP_BUY场景对物理特征更敏感

所有Phase中，DIP_BUY场景多次出现微弱提升信号：
- Phase 1: DIP +0.0037（运动学12维）
- Phase 2: DIP +0.0059（constant质量模式）
- Phase 3.5: 3个交互特征DIP提升>0.003

抄底场景更依赖阻力支撑/动量变化，逃顶场景已被周期/情绪特征充分覆盖。

### 6.3 经验教训

1. **物理意义正确 ≠ ML有效**：物理模型验证了理论，但ML模型已饱和，无法吸收新信息
2. **特征工程有天花板**：80维特征+LightGBM已接近信息容量上限，继续添加特征边际收益为负
3. **交互工程不能突破天花板**：V5.5的fed_level_x_cycle_sim成功是在26维时，80维时交互也无效
4. **理论验证与ML集成是两个问题**：物理模型可作为推理引擎/过滤器，但不适合直接作为ML特征

### 6.4 后续方向

#### 方向A：物理约束后置过滤（推荐）
- 物理特征不作为ML输入，而是作为**后置过滤器**
- η < 0.1（趋势弱）时降低ML预测置信度
- η > 0.3（趋势强）时增强ML预测置信度
- 势能梯度方向作为风控约束（逆势减仓）

#### 方向B：模型架构升级
- 从LightGBM升级到更强大的模型（如Transformer/时序CNN）
- 更大模型容量可能突破80维特征天花板
- 但需要更多数据样本（当前仅3202天）

#### 方向C：场景特化建模
- TOP_EXIT和DIP_BUY使用不同特征集
- TOP_EXIT保持V5.5不变
- DIP_BUY探索加入物理特征（DIP场景有提升信号）

#### 方向D：物理推理引擎
- 不依赖ML，直接用物理模型构建推理规则
- η + 势能梯度 + 相变判据 → 直接输出交易信号
- 作为ML的补充而非融合

### 6.5 方向D验证结果（2026-07-19）

实现了完整的物理推理引擎 [pitd_reasoning_engine.py](../ml/pitd_reasoning_engine.py)，
将η/梯度/动量/势能融合为综合物理信号，验证结果：

#### 验证结论：❌ 物理推理引擎作为独立交易信号预测力不足

| 指标 | 物理信号 | V5.5 ML |
|------|---------|---------|
| TOP_EXIT AUC | 0.6075 | 0.7433 |
| DIP_BUY AUC | 0.4693 | 0.6935 |
| 20日方向准确率 | 49.9% | — |
| 最佳相关性(60日) | ρ=+0.047 | — |

#### 根本原因

**物理模型捕捉的是"状态"而非"时机"**：

1. **η判断趋势强弱正确，但不能预测何时反转**
   - 理论1验证成功（η 2.86x单调递增），但η高只表示"当前是强趋势"，不预测"趋势何时结束"
   - 强趋势状态可能持续数月，对20日择时无指导意义

2. **jerk突变检测有效但方向预测失效**
   - jerk在反转点放大3.14x（Phase 1验证），能检测到"突变发生"
   - 但突变后方向不确定：反转准确率仅51.2%（略高于随机）
   - 突变可能是反转、加速、或震荡，物理模型无法区分

3. **势能梯度指示阻力方向，但阻力可能被突破也可能反弹**
   - 阻力最小方向正确率仅50.4%（理论4未被强验证）
   - 阻力位是被突破还是反弹，取决于资金面和情绪，非纯物理量能决定

4. **物理信号是慢变量，不适合短期择时**

### 6.8 方向2: 波浪理论+物理引擎五浪趋势捕捉（2026-07-19）

#### 设计方案

**信号源**: 艾略特波浪识别器（技术指标的波浪理论）
**信号评估器**: 物理置信度评估器（与方向1相同的PhysicsConfidenceScorer）
**仓位**: 3成基础仓位 × 物理调节系数

#### 波浪识别器实现（ml/ewave_recognizer.py）

**识别方法**:
1. ZigZag算法识别转折点（5%阈值，高低点交替）
2. 分形（Fractal）辅助转折点确认（5窗口）
3. 艾略特三大硬规则判定五浪结构
4. 实时状态判断（基于当前价格相对转折点位置）

**实时状态判断（核心创新）**:
- 转折点是事后确认的，单纯依靠ZigZag无法识别"当前所在浪"
- 通过最后一个转折点类型 + 当前价格相对位置推断当前所在浪
- 多头推动浪: LOW-HIGH-LOW-HIGH-LOW-HIGH
  - 当前价 > p2.price（且p2是LOW）= 浪3进行中（HOLD_LONG_W3=入场信号）
  - 当前价 < p5.price（且p5是HIGH）= 浪5结束（EXIT_LONG_W5=离场信号）

**信号类型**:
| 信号 | 含义 | 处理 |
|------|------|------|
| ENTER_LONG_W3 | 浪2结束、浪3启动（最强） | 入场做多 |
| HOLD_LONG_W3 | 浪3进行中（事后确认） | 入场或持有做多 |
| ENTER_LONG_W5 | 浪4结束、浪5启动（次强） | 入场做多 |
| EXIT_LONG_W5 | 浪5结束 | 离场做多 |
| ENTER_SHORT_W3 / HOLD_SHORT_W3 / EXIT_SHORT_W5 | 空头对应 | 同上 |

#### 波浪仓位计算公式

```
wave_position = base_position × wave_confidence × physics_multiplier

其中:
- base_position = 0.3 (3成基础仓位)
- wave_confidence ∈ [0.5, 1.0] (波浪置信度，下限0.5)
- physics_multiplier = position_lower + position_scale × physics_confidence
  = 0.6 + 1.0 × physics_confidence ∈ [0.6, 1.6] (仅在弱趋势η<0.10时启用)
- 最终限制: min(wave_position, max_position=0.5)
```

#### 集成原则

1. **并行运行**：波浪策略独立评估，不干扰V5.5主策略
2. **同向叠加**：V5.5与波浪同向时仓位叠加，上限100%
3. **异向以V5.5为主**：方向冲突时保留V5.5仓位，忽略波浪信号
4. **WAIT时独立入场**：V5.5 WAIT时波浪可独立入场（捕捉V5.5漏掉的趋势）
5. **物理评估器**：弱趋势时启用物理调节，与方向1一致
6. **异常保护**：try/except包裹，异常时保持V5.5原始仓位
7. **可观测性**：wave_strategy字段记录所有波浪策略信息
