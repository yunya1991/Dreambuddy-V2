# 策略Playbook标准

> 桥水式策略标准文档格式，每个策略必须遵循的Playbook规范，确保策略文档在结构、深度、可复现性上统一。

## Playbook定义

Playbook是策略的标准文档格式，将策略从"代码逻辑"升维为"可审计、可复盘、可传承的完整交易方案"。每个Playbook对应一条策略线，Z链规划阶段以Playbook作为策略写入标准格式。

来源：V9-马丁基线、三屏系统架构

### 2. 规则定义（触发条件 / 失效条件 / 决策树）

决策树格式示例（来源：V9-马丁基线 + 三屏系统架构）：

```
IF Screen1方向=LONG AND Screen2信号强度≥50
  → 开仓入场
  ELSE IF 当前持仓且价格回撤≥8%×vol_mult
    → 执行加仓（最多3次）
    ELSE IF 浮盈≥4%×vol_mult
      → 全平止盈
      ELSE IF Screen1方向翻转=BEAR
        → 强制离场
```

- **触发条件**：Screen1方向约束 + Screen2信号强度阈值
- **失效条件**：方向翻转、预设过期（3天）、连续SKIP≥2次触发Sleepwalk
- **决策树**：IF-THEN-ELSE链式逻辑，每步有明确条件与动作

来源：Screen2-日线入场信号、三屏系统架构

### 3. 执行流程

**Pre-trade Checklist**（来源：风控体系、Screen3-监控与离场）：
- [ ] 战略门禁PASS（无排除事件）
- [ ] 评分门禁PASS（各维度≥3，总分≥12）
- [ ] 执行风险门禁PASS（滑点≤60bps，边缘值>0）
- [ ] 账户层门禁PASS（日回撤<10%，杠杆≤2x）
- [ ] 黑窗检查PASS（非宏观数据发布时段）

**开仓步骤**：
1. 读取Screen1方向输出
2. 读取Screen2预设价位（daily-presets.json）
3. 当前价≤预设入场价 → Phase 1-3.5流水线入场
4. 当前价>预设价 → 等待回调，不追高

**加仓步骤**：
1. 价格回撤≥8%×vol_mult（相对于上一仓入场价）
2. 加仓次数≤3次
3. 等额加仓（金额固定）

**平仓步骤**：
1. 价格触及止盈价（入场价×1.04×vol_mult）→ A9 L1止盈
2. 第一性原理趋势反转确认 → A9 L2离场
3. 风险事件触发 → A9 L3离场
4. 最大回撤≥20% → 红线强制平仓

来源：V9-马丁基线、Screen3-监控与离场、风控体系
