# 三链接力协议：状态管理 + Guard 规则

> **规则 0 优先级高于一切规则。任何与 Rule 0 冲突的行为均被视为违规。**
>
> 蒸馏自 `4-PROTOCOL/PROTOCOL.md` + `SPEC.md` + `scripts/chain_guard.py`
> 为三链架构提供**物理约束**，让阶段跳转可追溯、可验证、可拦截。

---

## 0️⃣ 跳步门禁（最高优先级规则 — 高于一切其他规则）

**任何偏离 D→Z→E 严格顺序的行为必须经用户明确授权。未经用户授权的跳步 = 严重违规。**

### 0.1 默认行为

| 用户状态 | 系统行为 |
|:---|---|
| 用户说"跳过""直接执行""授权跳过" | ✅ 可跳过，记录 override |
| 用户说"走完整链""继续下一步" | ✅ 严格按 D→Z→E 执行 |
| **用户沉默了 / 没明确表态 / 说"好"但没说"跳过"** | ❌ **默认走完整链路，不可跳过** |
| 系统推断"这个任务简单，用户肯定想跳" | ❌ **严重违规** |
| 历史任务允许过跳步 | ❌ **每次需要单独授权** |

**一句话原则**：不说不跳，说跳才跳。

### 0.2 授权要求

跳步授权必须是**用户主动、明确、不可否认的**：

- ✅ 有效的明确授权：`"跳过"` `"直接执行"` `"授权跳过"` `"不用Z了直接E"` `"快速通过"`
- ❌ 不算授权：`"好的"` `"嗯"` `"继续"` `"方案可以"` `"确认"`（这些是同意当前步骤，不是授权跳过后续步骤）
- ❌ 不算授权：用户沉默了
- ❌ 不算授权：系统自行推断

### 0.3 选择点

在每段链路的终点，**必须**向用户呈现明确的选择：

| 选择点 | 时机 | 询问方式 |
|:---|---|:---|
| **🔴 选择点1** | D4 Spec 完成 | "D系列完成。继续Z系列规划，还是授权跳过Z直接进入E执行？" |
| **🔴 选择点2** | Z4 验收矩阵完成 | "Z系列完成。继续E系列执行（完整验证），还是授权跳过E2测试直接部署？" |
| **🔴 选择点3** | E2 测试通过 | "E系列执行完成。确认部署到生产环境？" |

**选择点必须逐字呈现选择(a)(b)(c)，不可模糊询问。** 参考各方法论中的「出口」章节。

### 0.4 记录

每次跳步必须在 `chain_state.json` 中以 override 形式记录：
```
from, to, 时间, 用户授权证据（引用用户消息原文）
```

无授权记录的跳步 = 未授权跳步 = 元链治理审计红灯。

## 一、接力协议架构

```
状态文件 (chain_state.json)         ← 唯一权威
    ↓
Guard 脚本 (chain_guard.py)        ← 物理约束
├── init(scope) / check(from,to) / transition(from,to) / override(from,to,reason)
├── approve(phase) / mark_in_progress(phase)
└── CLI: python3 chain_guard.py {init|status|check|transition|override|approve|start}

---

## 二、Guard 规则矩阵

**同链顺序**：D1→D2→D3→D4 / Z1→Z2→Z3→Z4 / E1→E2→E3（跳步/回跳均被拒绝）

**跨链门禁**：仅允许 D4→Z1（调研完成→规划）和 Z4→E1（规划完成→执行）

**跨链跳步**（D4→E1 或 Z4→E3）：**必须满足 Rule 0（用户明确授权），否则禁止**

**Override理由**：`chain_override(from, to, reason, user_auth_evidence)` 记录跳过理由和用户授权证据。

## 四、场景决策表（阈值 + 跳步门禁对照）

> ⚠️ **旧版此表有隐含跳步漏洞（<10行直接改/10-100行E链直接执行），现全部修正。**
>
> **所有任务都从 D1 开始。差异在于 D 链的速度，而非是否跳过。**

| 场景 | 行数 | 走什么链 | 是否允许跳步 |
|:---|---|:---|:---:|
| 极小改动 | <10行（修注释/改配置名） | D1快速调研(1min) + 选择点1 | ⚠️ 需用户授权 |
| 简单问题 | — | D1→D2快速分析 + 选择点1 | ⚠️ 需用户授权 |
| 小任务 | 10–100行 | D1→D2 + 选择点1 | ⚠️ 需用户授权 |
| 中等需求 | 100–500行 | 完整三链 + 所有选择点 | ⚠️ 需用户授权 |
| 复杂需求 | >500行 | 完整三链 + 每步门禁 | ⚠️ 需用户授权 |
| 不确定 | — | 完整三链 + 所有选择点 | ⚠️ 需用户授权 |

行数是估算，关键是**影响面**。
