# 飞书集成指南

> 飞书（Lark）API 调用方法、lark-cli 用法、Base/OKR/审批/文档/IM 操作命令与已知陷阱。

## 环境配置

```bash
# lark-cli 初始化
lark-cli config init --new

# 认证身份切换
lark-cli --as bot       # 应用身份（自动，无需login）
lark-cli --as user      # 用户身份（需 auth login）
```

当前系统 `strict-mode = bot`，仅 bot 身份命令可用。

## 飞书多维表格 (Base)

```bash
# 查询 Base 信息
lark-cli base +base-get --base-token <token>

# 列出所有表
lark-cli base +table-list --base-token <token>

# 查询记录（表格输出）
lark-cli base +record-list --base-token <token> --table-id <表名> --limit 50

# 查询记录（JSON 格式）
lark-cli base +record-list --base-token <token> --table-id <表名> --limit 50 --format json

# 批量创建记录（columns+rows 格式）
lark-cli base +record-batch-create --base-token <token> --table-id <表名> \
  --json '{"fields":["字段1","字段2"],"rows":[["值1","值2"]]}'

# 单条写入（不包装 fields）
lark-cli base +record-upsert --base-token <token> --table-id <表名> \
  --json '{"字段名":"值"}'
```

**⚠️ 关键陷阱**：
- 表 ID 可能漂移：用表名而非 `tblXxx` 做 `--table-id`
- `+record-list --format json` 返回位置数组而非键值对
- select 字段值永远是数组格式：`["有INDEX"]`
- `+record-batch-create` 不接受 `[{fields:{}}]` 格式，必须是 `{fields:[], rows:[]}`
- REST API 直调用字段中文名作为 key，日期用毫秒时间戳

## 飞书 OKR

```bash
# 列出用户周期
lark-cli okr +cycle-list

# 获取周期详情（含目标+关键结果）
lark-cli okr +cycle-detail --cycle-id <cycle_id>

# 创建关键结果（原生 API）
lark-cli okr objective.key_results create \
  --params '{"objective_id":"目标ID"}' \
  --data '{"content":{"blocks":[...]}}'

# 创建进展记录
lark-cli okr +progress-create \
  --target-id <目标ID> \
  --target-type objective \
  --progress-percent 60 \
  --content '{"blocks":[...]}'
```

**⚠️ 陷阱**：`open_id cross app` 错误时用裸 API 绕过。

## 飞书审批

```bash
# 获取审批模板表单结构
lark-cli api GET /open-apis/approval/v4/approvals/{approval_code} --format json

# 创建审批实例（CLI 无 shortcut，需裸 API）
lark-cli api POST /open-apis/approval/v4/instances \
  --data '{"approval_code":"CODE","open_id":"ou_xxx","form":"[{\"id\":\"w1\",\"type\":\"input\",\"value\":\"文本\"}]","title":"标题"}'
```

## 飞书云文档

```bash
# 创建文档（注意 Shell 转义，建议用 Python subprocess）
lark-cli docs +create --api-version v2 --content '<title>标题</title><p>内容</p>'

# 追加内容
lark-cli docs +update --api-version v2 --doc {doc_token} --command append \
  --content '<h1>新章节</h1><p>内容</p>'

# 授予权限（bot 创建文档需手动授权）
lark-cli api POST /open-apis/drive/v1/permissions/{doc_token}/members \
  --params '{"type":"docx"}' \
  --data '{"member_type":"openid","member_id":"ou_xxx","perm":"full_access","type":"user"}'
```

## 飞书 IM

```bash
lark-cli im send --chat-id oc_xxx --msg-type text --content "消息内容"
```

## 认证分步流程

需要用户授权时：

```bash
# Step 1: 发起授权（立即返回 URL）
lark-cli auth login --scope "需要的作用域" --no-wait --json

# Step 2: 用户完成后，由 Agent 完成授权
lark-cli auth login --device-code <device_code>
```

## 同步纪律

每次修改后需同步飞书四组件：
- [ ] 多维表格 (Base) — 更新对应记录
- [ ] OKR — 创建进展记录
- [ ] 云文档 (Wiki) — 同步变更文档
- [ ] 审批 — 结果已落地
