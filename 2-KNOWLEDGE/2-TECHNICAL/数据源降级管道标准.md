# 数据源降级管道标准

> **目的**: 定义标准化的数据采集降级策略，确保在外部API不可用时代理仍能产生有效输出。

---

## 一、数据源可及性状态（当前）

| 数据源 | 用途 | 状态 | 说明 |
|--------|------|:----:|------|
| **Tavily/web_search** | 通用搜索、新闻、行情概览 | ✅ 可用 | 首选数据源，HTTP 200，响应<2s |
| **web_extract** | 抓取特定网页内容 | ✅ 可用 | 搭配Tavily使用，抓取Coindesk等 |
| **GitHub API** | 代码仓库操作 | ✅ 可用 | HTTP 200 |
| **飞书Lark API** | 推送、文档、审批 | ✅ 可用 | cron交付正常 |
| **本地文件系统** | 所有读写操作 | ✅ 可用 | 永久可用 |
| **Yahoo Finance** | OHLCV历史数据 | ⚠️ 429限流 | 仅限低频使用（单次/天） |
| **OKX API/CLI** | 行情、账户、交易 | ❌ 超时 | 完全不可达 |
| **CoinGecko** | 行情、链上数据 | ❌ 超时 | 完全不可达 |
| **Google/DuckDuckGo** | 搜索备选 | ❌ 超时 | 完全不可达 |
| **Odaily** | 链上/ETF数据 | ❌ 超时 | 完全不可达 |

## 二、标准降级优先级

所有涉及外部数据采集的任务必须按以下优先级执行：

### 趋势行情数据（价格、涨跌、成交量）

```
P1: web_search("BTC price today site:coindesk.com OR site:coinmarketcap.com")
    ↓ 提取价格 → 记录来源URL
P2: web_extract("https://www.coindesk.com/price/bitcoin")
    ↓ 解析结构化表格
P3: web_search("bitcoin BTC USD price") [通用搜索]
```

### 新闻/宏观/地缘政治

```
P1: web_search("BTC bitcoin latest news 2026") → Tavily结构化摘要
P2: web_search("BTC news today") [备用关键词]
```

### 资金费率/链上数据（原OKX依赖）

```
P1: web_search("BTC funding rate perpetual")
P2: web_search("bitcoin open interest")
P3: 无法获取 → 标记"数据源不可用"，使用上次已知值或行业默认值
```

### FGI恐慌指数

```
P1: web_search("fear and greed index crypto today")
P2: web_extract("https://alternative.me/crypto/fear-and-greed-index/")
P3: 估计值（基于当前市场表现推算）
```

### 持仓/账户数据（原OKX CLI依赖）

```
无法降级 — 没有其他公开API可查询OKX账户。
处理方式：标记"OKX_ACCOUNT_UNAVAILABLE"，基于本地meta.json缓存数据
```

## 三、技能级别降级规范

### 有Tavily可正常运行的（降级覆盖度 80%+）

| 技能 | 原依赖 | 降级方案 | 降级后能力 |
|------|--------|---------|-----------|
| **A1 调研** | OKX行情 + Tavily搜索 | 全部用Tavily+web_extract | 可获取行情、新闻、宏观、情绪（缺K线细节） |
| **A2 战略解析** | OKX费率 + 本地YAML | 费率用Tavily搜索估计，YAML本地 | 可完成Regime判定和策略组合 |
| **A3 战略制定** | OKX宏观资产 + Tavily | 宏观资产用Tavily搜索替代 | 可获取宏观资产走势概述（缺精确价格） |
| **Screen2** | OKX/脚本 + 降级路径已有 | 已有降级路径（web_search） | 可完成日线分析 |

### 无替代数据源的（降级覆盖度 < 30%）

| 技能 | 原依赖 | 降级方案 | 降级后能力 |
|------|--------|---------|-----------|
| **A4 验证** | OKX CLI下单验证 | ❌ 无法下单 | 仅能做分析报告，不做实盘验证 |
| **A5 执行** | OKX CLI下单 | ❌ 无法下单 | 仅输出分析报告和指令，标注[DRY_RUN] |
| **A6 监控** | OKX CLI行情+持仓 | 行情用Tavily+web_extract替代 | 可获取行情概览，无法查账户/持仓 |
| **A9 离场** | OKX CLI离场 | ❌ 无法执行离场 | 仅做离场分析和建议 |

## 四、具体降级实现模板

### 获取行情数据（Tavily路径）

```
-- 替换 OKX market ticker 命令 --
web_search("BTC USD price today 2026")
→ 从结果中提取：价格、24h涨跌、24h高低

web_extract("https://www.coindesk.com/price/bitcoin")
→ 解析结构化表格：价格 $XX,XXX，24h涨跌 X.XX%
```

### 获取日线/K线数据

```
web_extract("https://www.coindesk.com/price/bitcoin")
→ 获取实时价格（无法获取历史K线）

若需要历史趋势：
web_search("BTC weekly trend analysis June 2026")
→ 获取分析师/媒体对趋势的描述性判断
```

### 获取宏观资产价格（原OKX跨资产监控）

```
web_search("gold price today XAU")
web_search("S&P 500 today")
web_search("Treasury yield today")
→ 分别获取各资产当前报价和趋势
```

### 获取市场情绪

```
web_search("crypto fear greed index")
web_search("BTC funding rate perpetual")
web_search("bitcoin long short ratio")
→ 从搜索结果提取情绪指标
```

## 六、降级标记规范

所有使用降级数据源的输出必须包含明确的降级标记：

```markdown
> ⚠️ [DEGRADED] 数据源降级说明：
> - 原依赖: OKX API/CLI（行情数据）
> - 降级来源: web_search(Tavily) / web_extract(Coindesk)
> - 数据完整性: MODERATE（缺K线历史/链上细节）
> - 最后正常时间: 2026-06-04
```

### 降级等级定义

| 等级 | 标记 | 含义 |
|:----:|------|------|
| 🟢 FULL | `[FULL_DATA]` | 所有数据源正常工作 |
| 🟡 MODERATE | `[DEGRADED_MODERATE]` | 核心数据可用（Tavily），部分细节缺失 |
| 🔴 DEGRADED | `[DEGRADED_LIMITED]` | 仅可输出分析报告 |
| ⚫ DRY_RUN | `[DRY_RUN]` | 无法执行实盘操作，仅输出建议 |
