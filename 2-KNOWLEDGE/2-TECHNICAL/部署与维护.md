## GitHub 同步

项目代码通过 GitHub 仓库同步维护：

```bash
# 检查仓库状态
cd ~/archives/Dreambuddy-V2-main
git status
git log --oneline -5

# 拉取最新代码
git pull origin main

# 提交本地修改
git add -A
git commit -m "描述变更"
git push origin main
```

**注意事项**：
- `.env` 和 `config.yaml` 中的敏感密钥不提交到 Git（应在 `.gitignore` 中排除）
- `cron/jobs.json` 中的 cron 状态（next_run_at、last_run_at）是运行时生成的，不要提交
- 远程仓库 URL：确认 `git remote -v` 指向正确的 origin

## 进程管理

```bash

ps aux | grep hermes | grep -v grep

# 启动/重启 Gateway
cd ~/.hermes/hermes-agent
python -m hermes_agent.gateway

# 查看后台进程（cron 调度由 Gateway 内部管理，无需额外启动）
```

## 日常维护检查清单

```bash

# 4. 系统负载

# 5. 飞书审批 Webhook 健康
curl http://localhost:8645/health
```

## 常见问题

| 问题 | 原因 | 解决 |
|:---|:---|:---|
| cron 任务排程但不执行 | model/provider 缺失 | 更新 cron 加上 model 和 provider |
| Broken pipe 错误 | SSE 流中断 | 转为 no_agent 脚本模式运行 |
| 飞书消息收不到 | deliver=local 或 chat_id 错误 | 更新 deliver 为正确群 ID |
| OKX CLI 403 | Cloudflare 防护 | 使用 OKX CLI 而非 Python 请求 |
| 脚本被阻止 | 路径不在 `~/.hermes/scripts/` | 复制脚本到 scripts 目录 |
