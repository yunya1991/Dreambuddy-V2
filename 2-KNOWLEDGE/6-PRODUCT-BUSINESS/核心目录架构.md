# 核心目录架构

> DreamBuddy-V2 由 1个文档元层 + 7个顶层模块 + 7个交易子系统 + 6个辅助模块 组成。

## 文档元层

| 目录 | 职责 |
|------|------|
| `0-系统文档管理/` | 文档的文档 — 在哪找、怎么写、怎么管 |

## 顶层模块

| 目录 | 职责 |
|------|------|
| `1-ARCHITECTURE/` | 架构SSoT v3.0，系统架构总览文档 |
| `2-GOVERNANCE/` | 治理合规 |
| `2-KNOWLEDGE/` | 跨域知识库（本目录） |
| `3-FRONTEND/` | 前端系统（Vite+React，端口3456） |
| `4-MEMORY/` | 认知记忆系统（贝叶斯置信度进化） |
| `5-BUSINESS/` | 业务管理 |
| `6-TRADING/` | 交易研究（A0-A9九步决策流水线） |

## 交易子系统

| 目录 | 职责 | 主入口 |
|------|------|--------|
| `10-经典指标系统/` | 核心交易决策引擎 | ml_trade_service.py |
| `11-易经推理系统/` | BCRM + 易经推理 | polling_trader.py |
| `12-三屏趋势系统/` | V4+波浪趋势策略 | — |
| `13-通用风控模块/` | 三层风控体系 | — |
| `14-V15经典马丁策略/` | 马丁格尔策略（文档标杆） | — |
| `16-调控系统/` | 宏观离场调控 | — |
| `17-v4-wave-strategy/` | V4减半周期+艾略特波浪 | — |

## 辅助模块

| 目录 | 职责 |
|------|------|
| `3-EVOLUTION/` | 进化引擎（实验） |
| `6-图结构上下文压缩/` | 图压缩（实验） |
| `7-产物中台/` | 产物管理 |
| `15-监控告警系统/` | 监控告警 |
| `experiments/` | AB交易实验、监控页面 |

## 数据存储

| 路径 | 说明 |
|------|------|
| `11-易经推理系统/scripts/runtime/` | 运行时数据（SQLite、JSONL审计日志） |
| `4-MEMORY/data/cognitive_memory.db` | 认知记忆数据库 |
| `11-易经推理系统/data_center.db` | 交易数据中心SQLite |
