# 风控体系工作流

> 多层风控的触发和执行流程。

## 三层风控架构

```
┌─────────────────────────────────────────────────┐
│  战略层风控（五计庙算）                          │
│  道30% + 天15% + 地25% + 将15% + 法15%          │
│  总分<50 → war_state=FREEZE → 全禁交易           │
│  总分50-59 → 轻仓防守 → cap≤20%                 │
│  总分60-74 → 防御 → cap≤50%                     │
│  总分≥75 → 进攻 → cap≤100%                      │
└───────────────────────┬─────────────────────────┘
                        │ war_state/cap/mask
                        ▼
┌─────────────────────────────────────────────────┐
│  策略层风控（BCRM2.0）                           │
│  方案C 8个开关（SW-C1至SW-C8）全部默认启用       │
│  CBR建库 + Elder-ray + 三层权重 + ElasticGate3L  │
│  BCRM连续性 + BTC自反 + WinProb + 组合熔断       │
│  开仓必经所有风控链路                            │
└───────────────────────┬─────────────────────────┘
                        │ 交易信号+置信度
                        ▼
┌─────────────────────────────────────────────────┐
│  通用风控（三层门禁）                            │
│  ① 仓位限制：单币种+组合上限                     │
│  ② 单笔风险：SL/TP空间下限保护                  │
│  ③ 组合熔断：可用金额亏损>20%触发                │
└─────────────────────────────────────────────────┘
```

## 维度否决规则

| 维度 | 阈值 | 限制 |
|------|------|------|
| 道（情绪） | <40 | 仓位≤30% |
| 将（技术） | <40 | 仓位≤30% |
| 法（风控） | <40 | 不开新仓 |
| 地+天 | 均<40 | 只允许对冲或空仓 |

## war_state解冻/回冻机制

| 状态 | 触发条件 | 效果 |
|------|---------|------|
| FREEZE | 总分<50 | 全禁交易 |
| 解冻中 | 连续3日总分≥60 | 允许轻仓 |
| ACTIVE | 解冻完成 | 正常交易 |
| 回冻 | 总分<58 | 中断解冻，回到FREEZE |

**资产类隔离**: crypto_usdt/us_stock/precious_metal 三类war_state独立计算，互不影响。

## SL/TP保护机制

| 仓位类型 | SL下限 | TP下限 | 说明 |
|---------|--------|--------|------|
| 常规仓 | ≥1.5% | ≥3.0% | 防止ATR极低时被扫损 |
| 轻仓试错 | ≥2.0% | ≥4.0% | 给足空间验证逻辑 |

**爆仓安全约束**: SL必须严格位于爆仓价+0.3%安全缓冲的安全侧，确保先触发止损再爆仓。当间距下限与爆仓安全冲突时，**爆仓安全优先**。

## 离场保护期

| 时段 | 规则 |
|------|------|
| 开仓后6小时内 | 仅硬离场（EV强制）生效，其他信号忽略 |
| 6小时后 | 所有离场信号正常生效 |

## 组合熔断

- **触发条件**: 可用金额亏损超过20%
- **执行动作**: 暂停开新仓，仅允许平仓
- **恢复条件**: 人工确认或亏损回撤至10%以内
