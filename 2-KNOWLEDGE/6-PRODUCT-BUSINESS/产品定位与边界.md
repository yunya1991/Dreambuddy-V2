# 产品定位与边界

> **一句话：** AI驱动的加密货币交易决策系统（多智能体架构）

## 产品是什么

DreamBuddy-V2 是一套**AI驱动的量化交易决策系统**，核心特征：

1. **多智能体协作** — 不是单一策略机器人，而是多子系统（经典指标/易经推理/三屏趋势/V15马丁）各司其职、协同决策
2. **认知记忆驱动** — 接入认知记忆系统（4-MEMORY），具备"越用越聪明"的贝叶斯置信度进化能力
3. **多层风控体系** — 战略层（五计庙算）→ 策略层（BCRM推理）→ 通用风控（三层门禁），逐级过滤
4. **全资产类覆盖** — 支持加密货币（crypto_usdt）、美股（us_stock）、贵金属（precious_metal）三类资产

## 产品做什么

| 能力 | 说明 |
|------|------|
| 信号生成 | 经典指标+易经BCRM推理+三屏趋势+V4波浪，多源信号融合 |
| 风控门禁 | 战略层五计庙算+策略层BCRM+通用风控三层过滤 |
| 交易执行 | OKX交易所API自动下单，支持做多/做空 |
| 持仓管理 | 实时持仓同步、离场信号检测、EV雷达监控 |
| 自我进化 | CBR案例库+认知记忆+AB基线评估+参数自动调优 |

## 产品不做什么

| 边界 | 说明 |
|------|------|
| 不做高频交易 | 轮询间隔5分钟-1小时，非毫秒级 |
| 不做衍生品 | 仅现货交易，不支持期权/期货 |
| 不做资产配置 | 不提供理财建议，仅执行量化策略 |
| 不保证盈利 | 量化系统有风险，历史表现不预示未来 |
