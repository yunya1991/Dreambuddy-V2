## 一、哲学基础 — 三源蒸馏

### 1.1 《矛盾论》（毛泽东）— 主框架

| 原理 | 核心要义 | 交易映射 |
|:-----|:---------|:---------|
| **矛盾普遍性** | 矛盾存在于一切事物中 | **利好利空永远共存**，信号不足≠等待 |
| **矛盾特殊性** | 每个矛盾结构不同 | 必须具体分析，不可套模板 |
| **主要矛盾** | 一个矛盾起主导作用 | **只需主要矛盾方向明确即可行动** |
| **矛盾的主要方面** | 一方居于支配地位 | 优势方即方向，量化力量对比 |
| **矛盾转化** | 一定条件下相互转化 | 设定转化监控点，触发则调整 |

### 1.2 《孙子兵法》— 策略维度

| 原理 | 交易映射 |
|:-----|:---------|
| **知己知彼** | 量化系统偏差+市场信号 |
| **避实击虚** | 共识过强→警惕（实）；被忽视方向→机会（虚） |
| **顺势而为** | 主要矛盾方向=势，逆势操作需极强证据 |
| **灵活应变** | 矛盾转化时不可拘泥旧判断 |

### 1.3 《战争论》（克劳塞维茨）— 对抗维度

| 原理 | 交易映射 |
|:-----|:---------|
| **摩擦** | 滑点、延迟、情绪干扰，必须留安全边际 |
| **重心** | 主要矛盾=市场重心，**所有分析资源集中于此** |
| **战争迷雾** | 信息永远不完整，接受不确定性 |
| **防守优势** | 止损就是防守，宁可多设也不逆势硬扛 |

## 三、A0 三步法

### Step 1：发现矛盾（A1 集成）

遍历 C1-C8 维度，对每个维度列举具体矛盾对。**禁止输出「无矛盾」** — 矛盾永远存在，至少找到 2 个。

### Step 2：抓住矛盾（A2 集成）

**4 维评分法识别主要矛盾：**

| 维度 | 计算方式 |
|:-----|:---------|
| 力量对比 | \|证据A×质量A - 证据B×质量B\| |
| 时间紧迫性 | 短期3分 / 中期2分 / 长期1分 |
| 证据一致性 | 同向信号占比（0-1） |
| 市场影响权重 | 宏观0.3+资金0.25+技术0.2+情绪0.15+其他0.1 |

**输出规则：** 必须给出 UP/DOWN 方向，禁止「无方向」。势均力敌时取基本面权重更高的一方（重心原则）。

### Step 3：利用矛盾（A3 集成）

- 主要矛盾方向=UP → 战略倾向做多
- 矛盾清晰度决定仓位：清晰→标准仓，模糊→半仓
- 转化条件就是止损/止盈条件
- **禁止**「矛盾未消解=观望」→ 必须输出方向+小仓试探建议
