# 第一性原理 — 交易系统哲学根基

> **核心定位：** 基于「市场总是沿着阻力最小方向运行」和「趋势具有延续性」两大公理，为 A1/A2/A3 提供不可动摇的底层判断基准。
> **来源：** dream-first-principles SKILL v2.6.2

---

## 一、两大公理

### 公理1：阻力最小路径（Least Resistance Path）

> 市场如同流水，总是从阻力最小的地方通过。

**阻力来源分解：**

| 阻力类型 | 量化指标 | 信号含义 |
|:---------|:---------|:---------|
| 成本摩擦 | 手续费率、滑点 | 交易成本过高时抑制方向性交易 |
| 流动性摩擦 | 订单簿深度、买卖价差 | 深度不足时价格易被操纵 |
| 拥挤摩擦 | 资金费率、OI变化率 | 资金费率极值预示反转风险 |
| 波动摩擦 | ATR、波动率Regime | 波动率压缩后必放大 |

**路径判定（v2.3重构）：**

```
阻力评分 < 40  → UP方向
阻力评分 > 60  → DOWN方向
40 <= 评分 <= 60 → NEUTRAL（仅占20%区间）
```

### 公理2：趋势延续性（Trend Continuation）

> 趋势一旦形成，会延续直到遇到足够的反向阻力。

**趋势生命周期：**
```
启动期 → 加速期 → 衰竭期 → 逆转/盘整
```

**核心规则：**
- 趋势方向由 EMA20/60/120 多头/空头排列确认
- 趋势强度由 MA 斜率变化率 + 历史标准差判定
- 趋势衰竭识别：RSI 背离、成交量萎缩、波动率放大

## 二、双维度分析框架

### 维度一：基本面分析

| 层级 | 核心问题 | 关键指标 |
|:-----|:---------|:---------|
| L1 宏观流动性 | 全球资金是否充裕？ | DXY、美联储政策、央行利率 |
| L2 中观资金流 | 资金在买还是卖？ | ETF净流入、OI变化、链上净流入 |
| L3 微观流动性 | 执行环境如何？ | 订单簿深度、买卖价差 |

**情绪指标辅助：**
- FGI < 25 且资金费率≈零 → 空头力竭（逆向买入机会）
- FGI > 75 且资金费率≈零 → 多头力竭（逆向卖出机会）
- 资金费率 > 0.05% → 多头拥挤，反转风险
- 资金费率 < -0.05% → 空头拥挤，轧空风险

### 维度二：技术面分析

| 指标类型 | 核心参数 | 信号逻辑 |
|:---------|:---------|:---------|
| 趋势指标 | EMA20/60/120 | 多头排列做多，空头排列做空 |
| 动量指标 | RSI(14)、MACD(12/26/9) | RSI>70超买、<30超卖；MACD金叉/死叉 |
| 波动指标 | ATR(14)、Bollinger(20/2) | 压缩→放大突破 |
| 支撑阻力 | 关键心理位、EMA50/120 | 历史高低点、整数关口 |

## 三、左右脑辩证统一

| 处理器 | 输入 | 输出 | 适用场景 |
|:-------|:-----|:-----|:---------|
| 左脑（确定性） | 硬数据：价格、资金流、技术指标 | 精确得分0-100、方向UP/DOWN | 数据驱动决策 |
| 右脑（模糊性） | 软信息：新闻语气、K线形态、共识 | 方向偏好+置信区间 | 模式识别判断 |

**统一规则：**
- 三者一致（左+右+A0）→ 高置信，标准仓位
- 左右一致但与A0相反 → 取A0（全面维度分析）
- 左右分歧 → 取A0方向 + 降低置信度
- **禁止**因矛盾输出「等待方向明确」→ 必须输出小仓试探建议
