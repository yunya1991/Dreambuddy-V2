## §2 Q1：通信层通信什么（4 类 payload + 单一核心对象）

### 2.1 4 类标准化 payload（按生命周期顺序）

| # | Payload 类型 | 谁发 | 谁收 | 格式 | 例子 |
|---|---|---|---|---|---|
| **P1** | **域内信号快照** | 每个域自己的 verify/PSI/confidence 检测器 | AgentMail observe() 旁路 + L1 NeuralSDE 输入 | `{domain, signal_type, value, timestamp, drift_level}` | `{domain:"rea", signal_type:"investigate_psi", value:0.15, drift_level:"medium", ts:"14:30"}` |
| **P2** | **跨域关系图边** | L1 DomainCouplingHead 推理 | AgentMail 建议层 + TRAIN-BASE TB3 | `{from_domain, to_domain, coupling_weight, lags_min, psi_corr}` | `{from:"cognition", to:"rea", coupling:0.72, lags_min:30}` |
| **P3** | **叠加印证假设** | AgentMail 建议层（消费 P1+P2 后生成） | 跨域组合验证沙箱（§4） | **这是核心对象，见 §2.2 详细 schema** | |
| **P4** | **验证回执** | 沙箱/回测/REA 做梦器 | 所有域的 verify + TRAIN-BASE TB5 GRPO | `{hypothesis_id, result, pnl_delta, shapere_ratio, trace_id}` | `{hyp:"H-20261103-007", result:"valid", pnl_delta:+8.2%, sharpe:+0.14}` |

### 2.2 P3 叠加印证假设 schema（核心对象）

> 这是通信层**最核心的 payload**——其他 3 类 payload 最终都流向这里。

```json
{
  "hypothesis_id": "H-{date}-{counter}",
  "timestamp": "2026-11-03T14:30:00",
  
  // 假设的触发条件（来自 P1 域内信号快照 + P2 跨域关系图边）
  "trigger": {
    "conditions": [
      {"domain": "cognition", "signal": "verify_confidence", "op": ">=", "value": 0.8},
      {"domain": "rea", "signal": "dreamer_V", "op": ">=", "value": 0.75},
      {"domain": "data", "signal": "drift", "op": ">", "value": "medium"}
    ],
    "cross_domain_coupling": {
      "from": "rea", "to": "semantic", "min_coupling": 0.55
    },
    "regime_context": "bull_consolidation"
  },
  
  // 假设预测的效果（L1 DomainCouplingHead 推理 + REA 做梦器建议）
  "prediction": {
    "signal_combination": ["rea_investigate", "semantic_entity_resolve", "cognitive_verify"],
    "combined_effect": {

    "expected_delta": {

      "sharpe_delta": 0.14,

    }
  },

  "validation_plan": {
    "backtest_window": {"start": "2025-01-01", "end": "2026-10-31"},
    "control_group": ["rea_only", "semantic_only", "cognition_only"],  // 单域 baseline
    "treatment": "rea+semantic+cognition",  // 跨域组合
    "alpha_test": true,  // 用 CounterfactualEvaluator 区分 alpha vs beta
    "min_trades": 50     // 至少 50 笔交易才接受验证结果
  },
  
  "source": {
    "l1_inference": "l1-infer-<sha256>",
    "rea_dreamer_trace": "dreamer-<sha256>",
    "psi_correlation": 0.72
  },
  
  "status": "pending_validation"  // pending → validated / rejected / partially_valid
}
```

### 2.3 通信不是"域 A 说 X 域 B 说 Y"，是"域 A 信号 + 域 B 信号 + 跨域耦合 = 叠加印证假设"

| 错误理解 | 正确理解 |
|---|---|
| "rea 域告诉我 sem 域有新实体" | "rea 域的 investigate_psi=0.15 (medium) + sem 域的 verify_confidence=0.78 + 两域 coupling_weight=0.72 + regime=bull_consolidation → **假设 H-20261103-007：这组叠加印证应该提升方向预测准确率**" |
| "认知域 recall hit 了" | "认知域 recall_hit_rate 上升 + rea 域 dreamer_V 上升 + 跨域 coupling 矩阵在 bull_consolidation 时更强 → **这组信号叠加后在历史回测里 Sharpe 提升多少？**" |

## §3 Q2：价值增量怎么量化（TB3 AlphaPareto 第七维 + P4 回执驱动 GRPO）

### 3.1 补 TB3 AlphaPareto 第七维：`pnl_delta_score`

**现有 6 维（全结构指标）**：
1. `p_verify_success` — verify 成功率
2. `p_recall_hit` — recall 命中率
3. `psi_stability` — PSI 漂移稳定性
4. `citation_diversity` — PoE 引用多样性
5. `process_reward` — 过程奖励
6. `transition_smoothness` — 路径平滑度

**新增第 7 维（实盘价值）**：
7. **`pnl_delta_score`** — 跨域组合 vs 单域 baseline 的回测 Alpha 提升

```python
# TRAIN-BASE TB3 compute_reward 新增分量（伪代码）
def compute_reward(self, trajectory: dict, counterfactual_result: dict | None) -> dict:
    rewards = super().compute_reward(trajectory)  # 原有 6 维
    
    # 新增第七维：pnl_delta_score
    if counterfactual_result is not None:
        treatment_alpha = counterfactual_result.get("treatment_alpha", 0.0)
        control_alpha   = counterfactual_result.get("control_group_alpha_mean", 0.0)
        alpha_delta     = treatment_alpha - control_alpha
        
        # 归一化到 [0, 1]（alpha_delta 在回测里通常 -0.05 ~ +0.2）
        rewards["pnl_delta_score"] = np.clip((alpha_delta + 0.05) / 0.25, 0.0, 1.0)
    else:
        rewards["pnl_delta_score"] = 0.5  # 无沙箱验证时中性（FAIL-OPEN）
    
    return rewards  # 7 维
```

### 3.2 TRAIN-BASE TB5 GRPO 用 P4 回执驱动策略进化

```python
# TB5 evolve_step 新增：用沙箱验证回执做奖励
def evolve_step(self, trajectories: list[dict], p4_receipts: list[dict]) -> dict:
    # 原有：hypervolume V 函数
    v = self._compute_hypervolume_v(trajectories)
    
    # 新增：P4 回执做加权
    validated_alpha_delta = np.mean([r["pnl_delta"] for r in p4_receipts if r["result"] == "validated"])
    v_adjusted = v + validated_alpha_delta * self.alpha_weight  # alpha_weight 默认 0.2
    
    return {"v": v, "v_adjusted": v_adjusted, ...}
```

### 3.3 REA 做梦器 V(π, T) 也要吃 P4 回执

```python
# REA 做梦器 Dream-RSI V 函数调整
V_new(π, T) = hypervolume(结构指标, λ_parallelism=0.1) 
              + α * mean([h.prediction.expected_delta.pnl_delta_pct for h in T.hypotheses if h.status == "validated"])
              # α 默认 0.1，防止 alpha 分量覆盖结构优化
```

### 4.3 沙箱核心 TDD 验收（7 条）

| # | 验收项 | 标准 | 硬约束 |
|---|---|---|---|
| 1 | **alpha vs beta 归因正确** | 合成控制法 treatment_alpha = 真实 PnL - 合成反事实，误差 < 0.05 | H2 无权重微调（CounterfactualEvaluator 是统计方法，不训练） |
| 2 | **影子验证不泄漏实盘** | 历史窗口严格 ≤ 假设生成时间点（t_start ≤ t_generation），无未来函数 | 量化黄金标准 |
| 3 | **min_trades ≥ 50** | 任何假设 < 50 笔回测自动降级为 `partially_valid` | 统计显著性硬约束 |
| 4 | **FAIL-OPEN** | 沙箱任何异常 → 假设 status 保持 pending，不阻塞主流程 | H4 |
| 5 | **反事实评估可追溯** | 每条 P4 回执带 trace_id，关联 CounterfactualResult 完整 JSON | H3 可审计 |
| 6 | **regime context 对齐** | hypothesis.trigger.regime_context 必须能在 sector_transmission.json 历史中找到 | SPEC-Shadow 放量门禁 |
| 7 | **零 GPU** | CPU 4C16G 单假设回测 ≤ 5 分钟 | — |
