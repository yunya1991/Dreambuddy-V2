## §1 Executive Summary

### 1.1 核心发现

**我们的认知系统已经在做贝叶斯训练**（4-MEMORY verify 置信度更新 + 动态蒸馏 + FOK/JOL 元认知 harness + ReflectionNode 反思回环 + PoE Evidence Ledger），**只是没有叫 "Agent 训练"**。

本次评估把"训练"从模糊的"让 Agent 变聪明"聚焦为**三件可拆解的事**：

| 训练维度 | 回答什么 | 我们已有的 | 需要补什么 |
|---|---|---|---|
| **学习范式**（Algorithm） | Agent 用什么算法从经验里"学"？ | ✅ 贝叶斯置信度更新 + EWMA 衰减 + 幂律遗忘 + PoE 证据链 | ⚠️ 缺 RL 方向（GRPO/EvolveR 自我进化闭环） + 缺 regime 感知切换 |
| **数据底座**（Infrastructure） | Agent "从哪里学"、"学完存哪"？ | ✅ Replay Buffer + 贝叶斯在线学习 S 层 + CUSUM/EWMA 漂移检测 + DynamicDistillEngine | ⚠️ 缺 PSI 漂移监控（小团队友好型，比 CUSUM 更简） + 缺 per-edge 置信度标注 |
| **治理约束**（Governance） | Agent "学歪了"谁来拦？ | ✅ Mandate 写门控 + FAIL-OPEN + trace_id 全链路 | ⚠️ 缺 EU AI Act / SR 11-7 对齐的风险管理框架 + 贝叶斯 VaR 回测 |

### 1.3 核心结论：**不引入神经网络微调**

SPEC v0.5 明确"不修改 5 层训练循环的核心算法逻辑（TF-IDF/路径挖掘/CBR/图映射/Prompt聚类）"、"不引入深度学习（不引入神经网络权重微调）"、"不修改认知系统后端"。

本评估结论与之一致：
- **贝叶斯在线学习**（`Prior_today = Posterior_yesterday`）是金融领域首选持续学习范式，天然防遗忘、小样本友好、单服务器可跑
- **GRPO** 是 PPO 的金融友好替代（无 critic、训练快、无神经网络权重微调——"奖励函数设计"是关键，权重冻结只调策略输出格式）
- **EvolveR 自我进化闭环**（自蒸馏→策略原则库→在线检索→RL policy evolution）的核心在"策略原则库"而非"神经网络权重"——这正是我们 4-MEMORY 记忆库 + PoE 证据链的天然载体

## §2 外部调研核心发现（与我们架构的映射）

### 2.1 RLHF for Finance：GRPO 替代 PPO，市场反馈替代人类偏好

| 发现 | 来源 | 我们的映射 |
|---|---|---|
| **GRPO 无 critic、训练快、小团队单 GPU 可跑** | arXiv 2507 (Alpha-R1) | **完美匹配**我们的单服务器约束。GRPO 的核心是"不用训练 critic 网络，直接用奖励相对值优化"——奖励函数可接我们 PoE evidence 的 quality_level 评分（S=1.0, A=0.7, B=0.4, C=0.2），权重冻结只调策略输出格式 |
| **Alpha-R1 验证：市场客观反馈（股价/收益率）可替代人类偏好** | arXiv 2507 | **可迁移**。我们的"市场反馈"= verify success/failure + 数据漂移检测 + 回测 PnL——客观、可自动收集、零人工标注成本 |
| **GIFT 框架：LLM 引导的状态-奖励接口** | arXiv 2506 | **参考**。GIFT 的可解释性惩罚（reward shaping 中惩罚复杂度）可直接入我们 PoE evidence 的 known_gaps 字段——known_gaps 越多奖励越低 |

### 2.2 贝叶斯强化学习：ADTS 应对 regime shift

| 发现 | 来源 | 我们的映射 |
|---|---|---|
| **ADTS 自适应折扣 Thompson Sampling** | arXiv 2502 | **可迁移**。Thompson Sampling 是贝叶斯 RL 最简单的形式——不用 POMDP 变分推断，直接对每个 arm 维持 Beta 分布（对应我们 verify 的置信度更新），regime shift 时重置先验。适合 **40-周期神经网络 的 regime gate**（美林时钟四段 = 四个 arm） |
| **RL-BHRP：贝叶斯前端稳定化 + RL 后端分配权重** | arXiv 2503 | **架构参考**。贝叶斯前端（我们已有 verify）输出置信度分布，RL 后端分配模型权重——与我们 34 持续训练的 ensemble 思路一致 |

### 2.3 多目标训练：AlphaPareto 四维向量奖励替代手动权重

| 发现 | 来源 | 我们的映射 |
|---|---|---|
| **AlphaPareto 四维奖励**（预测力/时间稳定性/扰动鲁棒性/多样性） | arXiv 2504 | **直接套用**。我们可以定义：<br>`Reward = (P_verify_success, P_recall_hit, Stability(psi_drift), Diversity(citation_count))`<br>用 MAP（Manifold-Aware Policy）沿 Pareto 前沿优化——无需手动权重调优 |
| **PSI 漂移监控**（Population Stability Index） | 工业标准 | **比 CUSUM 更适合小团队**。PSI 只需"分布直方图对比"，实现 20 行代码；CUSUM 需要累积统计量和动态阈值 |

### 2.4 自我进化闭环：EvolveR 是小团队最优范式

| 发现 | 来源 | 我们的映射 |
|---|---|---|
| **EvolveR 闭环**：自蒸馏 → 策略原则库 → 在线检索 → RL policy evolution | arXiv 2505 | **完美匹配**我们已有的四件套：<br>自蒸馏 = DynamicDistillEngine ✅<br>策略原则库 = 4-MEMORY 记忆库 ✅<br>在线检索 = recall ✅<br>RL policy evolution = GRPO 调策略输出格式 → **待补** |
| **RETROFORMER 回顾性 + replay buffer** | arXiv 2506 | **参考**。回顾性（retrospective reasoning）= 执行后反思 + 教训提取——这正是 ReflectionNode ✅。Replay buffer = 34 持续训练 SPEC v0.5 的 Replay Buffer ✅ |

### 2.5 风控合规：EU AI Act 2026.8 生效 + 贝叶斯 VaR

| 发现 | 来源 | 我们的映射 |
|---|---|---|
| **EU AI Act 2026.8 生效**：信贷评分/保险定价需满足风险管理+数据治理+可解释性+人工监督+日志 | 监管 | **我们实盘风控域（11/yijing）永不暴露 MCP，合规压力在 Agent 训练输出端**。输出必须满足：可追溯（trace_id）、可解释（PoE evidence）、可审计（receipt_hash） |
| **贝叶斯 VaR 回测**（95% exceedance ~4.8%，优于传统交通灯测试） | SR 11-7 | **可迁移**。用 verify 的置信度分布计算 Agent 决策的 VaR——置信度 < 0.5 的决策自动降为建议、置信度 < 0.3 的决策拦截 |
| **PSMA SAFR**（唯一针对 Agent 系统的运行时治理框架） | MAS | **参考**。Safeguard + Filter + Audit + Recourse 四件套——与我们 Mandate + FAIL-OPEN + trace_id + reflect 一一对应 |

| 增量 | 算法 | 位置 | 壳侧改动 |
|---|---|---|---|
| PSI 漂移监控 | Population Stability Index（分布直方图对比） | `4-MEMORY/9-工具与接口/` 新增 drift_detector.py | 壳只加 `params.enable_psi_drift=true` 透传 |
| per-edge 置信度 | 记忆库内每条记忆关联的引用链上标注置信度 | `cognitive_loop_entry.py` record 末尾追加 evidence_entries | 零改 |

| GRPO 轻量 RL 进化 | 奖励函数 = `α·verify_success + β·recall_hit + γ·(1-psi_drift)`，权重冻结只调策略输出格式 | agent 内部 loop，每次 record/verify 后跑一轮 GRPO update | 零改 |

**PSI 实现（20 行 Python）**：
```python
def psi(expected: list[float], actual: list[float], bins=10) -> float:
    """Population Stability Index — 漂移监控"""
    exp_hist = np.histogram(expected, bins=bins, density=True)[0]
    act_hist = np.histogram(actual, bins=bins, density=True)[0]
    exp_hist = np.clip(exp_hist / exp_hist.sum(), 1e-6, None)
    act_hist = np.clip(act_hist / act_hist.sum(), 1e-6, None)
    return float(np.sum((act_hist - exp_hist) * np.log(act_hist / exp_hist)))
# psi < 0.1: 稳定 ｜ 0.1-0.25: 轻微漂移 ｜ > 0.25: 严重漂移
```

| C 评测 | OOD 漂移自动告警 + 建议 retrain 准确率 ≥ 80% | PSI > 0.25 告警 → 建议 retrain → 人工确认 retrain → 漂移消除比例 |
| D 语义 | 别名蒸馏人类确认通过率 ≥ 60% | Mandate 授权 → 人类标注 → 入库 → 后续实体解析 recall 命中 |
| E 数据 | 数据质量漂移告警 P50 < 10min | PSI 接入后，漂移事件 → 告警 → 人类发现耗时 ≤ 10min |

## §6 单服务器算力预算

**约束**：云端 4C16G + macOS M3 本地，**零 GPU**（除非后续购置）

| 训练环节 | 算力需求 | 实现方式 |
|---|---|---|
| PSI 漂移监控 | O(N) 直方图对比，毫秒级 | Python 原生 numpy，零依赖 |
| Beta 分布 verify 升级 | O(1) 分布更新，纳秒级 | math.beta_inv 函数，零依赖 |
| AlphaPareto 四维奖励 | O(1) 向量计算 | Python 原生 tuple |
| GRPO 轻量 RL loop | O(K) K=策略数 × 迭代次数，秒级 | 冻结 LLM 权重，只调策略输出格式（JSON 字段 reorder / known_gaps 调整） |
| 贝叶斯 VaR 回测 | O(N) verify 历史 × 正态分布 CDF | scipy.stats.norm.cdf，秒级 |
| Thompson Sampling | O(K) Beta 分布采样，微秒级 | random.betavariate，零依赖 |
| EvolveR 自蒸馏 | 等价 DynamicDistillEngine ✅ 已落地 | 现有蒸馏引擎 |

**结论**：零 GPU、单 CPU 4C16G 全环节可跑。所有训练算法都是"贝叶斯 + 统计检验 + 策略格式调优"，不涉及梯度下降/神经网络权重更新。

## §7 硬约束（必须记录到认知库）

### 7.1 训练侧

| # | 约束 | 命中关键词 |
|---|---|---|
| H1 | **Agent 训练必须符合壳/agent 分离原则**：所有训练算法迭代在壳后域内实现，壳 envelope.data schema 零变化，壳零感知 agent 内部训练行为 | 必须、零变化、零感知 |
| H2 | **新训练算法不得引入神经网络权重微调**：贝叶斯在线学习 / GRPO 轻量 RL（冻结权重）/ 统计检验 / 策略格式调优，是训练算法的唯一合法区 | 不得、唯一、必须 |
| H3 | **Agent 自我进化闭环必须可追溯**：每次训练迭代产出 trace_id + receipt_hash + PoE evidence，可事后审计 | 必须、唯一 |
| H4 | **GRPO RL loop 默认 FAIL-OPEN**：单轮迭代失败不得阻塞主流程，策略输出格式自动回退到上一稳定版本 | 默认、不得、必须 |

### 7.2 治理侧

| # | 约束 | 命中关键词 |
|---|---|---|
| H5 | **实盘风控域（11/yijing/v15/止损）的 agent 训练输出必须通过贝叶斯 VaR 验收**：置信度 < 0.3 的决策自动拦截、< 0.5 降为建议 | 必须、自动、上限 |
| H6 | **数据域 agent 训练只允许 read-only 输出**：任何自动修复/补全/写回数据仓库的行为禁止 | 禁止、必须 |
