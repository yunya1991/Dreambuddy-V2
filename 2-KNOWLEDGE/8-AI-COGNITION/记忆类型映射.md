# 记忆类型映射

> S/A/B/C/D级记忆 → 知识库域的映射关系。

## 质量等级说明

| 等级 | 含义 | 置信度范围 | 对应知识库域 |
|------|------|-----------|-------------|
| **S** | 公理级，多次验证 | ≥0.95 | 1-TRADING / 3-THEORY |
| **A** | 可信级，实践验证 | ≥0.70 | 1-TRADING / 6-PRODUCT-BUSINESS |
| **B** | 待验证级 | ≥0.40 | 6-PRODUCT-BUSINESS / 7-EXTERNAL-RESEARCH |
| **C** | 假设级 | ≥0.20 | 7-EXTERNAL-RESEARCH |
| **D** | 已证伪 | <0.20 | 不归档（标记deprecated） |

## 映射逻辑

### C级 → 7-EXTERNAL-RESEARCH
调研结论在record时标记为C级，同时归档到7-EXTERNAL-RESEARCH对应子类。
知识单元文件路径写入record的tags字段，建立双向链接。

```
record(content="Kalman Filter可用纯numpy实现", quality_level="C",
       tags=["kalman", "numpy", "fallback"])
    ↓ 同步归档
7-EXTERNAL-RESEARCH/finance/quant-methods/kalman-filter-numpy-implementation.md
```

### B级 → 6-PRODUCT-BUSINESS
产品理解、工作流程沉淀为B级，归档到6-PRODUCT-BUSINESS。
verify成功后升级为A级。

### A级 → 1-TRADING
交易知识经实践验证为A级，蒸馏到1-TRADING交易域。

### S级 → 3-THEORY
多次验证的公理级知识，归入3-THEORY哲学理论域。

## 双向链接机制

```
4-MEMORY (cognitive_memory.db)              2-KNOWLEDGE (md文件)
┌─────────────────────────┐               ┌─────────────────────────┐
│ record tags:             │               │ 文件头部:                │
│ ["kalman",               │◄───路径引用───│ "来源: 4-MEMORY record"  │
│  "7-EXTERNAL-RESEARCH/   │               │                          │
│   finance/quant-methods/│               │ 关联记忆:                │
│   kalman-filter.md"]     │───ID引用─────│ "VM-xxx"                 │
└─────────────────────────┘               └─────────────────────────┘
```
