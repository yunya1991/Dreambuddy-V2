# 检索指南

> 如何通过recall检索认知记忆，以及从知识库反查记忆。

## 标准检索流程

### 1. 任务开始前（硬约束）

每个编码/调试/分析任务开始前，必须调用recall：

```python
recall(
    context="当前任务描述或问题关键词",
    top_k=5,
    min_quality="C"  # 确保返回最多结果
)
```

**为什么用C级？** 记忆库98%是C级记忆，用B级阈值会返回空结果。C级记忆虽未验证，但包含有价值线索。

### 2. 检索结果处理

- 按 score 排序，优先看高分记忆
- 即使没有结果，也表明已检查记忆库（闭环起点）
- 检索到相关经验 → 复用已有方案，避免重复踩坑

## 从知识库反查记忆

### 场景：阅读知识库文档时追溯来源

```
1. 在7-EXTERNAL-RESEARCH/finance/quant-methods/kalman-filter.md中
2. 查看文件头部的"关联记忆: VM-xxx"
3. 调用 recall(context="VM-xxx Kalman Filter", top_k=3)
4. 获取完整记忆记录和验证状态
```

### 场景：验证知识库结论是否仍有效

```
1. 查看知识单元的"状态"字段（active/archived/deprecated）
2. 调用 verify(memory_id="VM-xxx", success=true/false)
3. 验证通过→置信度升级，验证失败→标记deprecated
```

## 检索关键词建议

| 任务类型 | 推荐关键词 |
|---------|-----------|
| 交易策略 | 策略名+参数（如"Martin ATR period"） |
| 风控规则 | 规则名+阈值（如"止损 可用金额 20%"） |
| 技术实现 | 模块名+问题（如"force_vector shadow"） |
| 调研复用 | 技术名+应用场景（如"Kalman numpy fallback"） |
| 架构理解 | 模块名+关系（如"五计庙算 BCRM 风控"） |

## 跨域检索示例

```
# 查找力向量相关所有记忆
recall(context="force_vector resistance direction", top_k=10, min_quality="C")

# 查找Shadow模式实现经验
recall(context="shadow mode 字节等价 FAIL-OPEN", top_k=5, min_quality="C")

# 查找传统金融调研结论
recall(context="PCA 共振 IC 信息系数 特征价格关联", top_k=5, min_quality="C")
```

## 认知系统统计

调用 `stats()` 查看当前记忆库状态：

```
stats()
→ 总记忆数、各等级分布、最近更新时间、蒸馏状态
```

调用 `health()` 排查问题：

```
health()
→ 数据库连接、磁盘空间、索引完整性
```
