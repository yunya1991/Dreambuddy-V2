# 认知系统架构

> 4-MEMORY认知记忆系统结构说明。

## 系统定位

4-MEMORY是DreamBuddy-V2的**底层记忆系统**，核心功能：
1. **记忆存储** — 跨session保存核心事实、教训、战略决策、架构说明
2. **意图识别** — 分析用户意图，路由到合适的SKILL
3. **交易路由** — 基于记忆的智能交易决策路由
4. **自我进化** — 贝叶斯置信度更新 + 动态蒸馏

## 架构设计

```
┌─────────────────────────────────────────────────┐
│              记忆输入层                          │
│  (对话/交易结果/系统事件 → record())             │
└───────────────────────┬─────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────┐
│              意图分析层                          │
│  (recall检索 → 意图匹配 → SKILL路由)             │
└───────────────────────┬─────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────┐
│              SKILL路由层                         │
│  (A0-A9九步决策流水线 → 交易执行)                │
└───────────────────────┬─────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────┐
│              记忆存储层                          │
│  (SQLite: cognitive_memory.db + 蒸馏JSONL)      │
└─────────────────────────────────────────────────┘
```

## 记忆分层体系

| 层级 | 定位 | 内容 |
|------|------|------|
| L0 元记忆层 | 记忆的记忆 | 记忆类型定义、存储规范、质量等级 |
| L1 总记忆层 | 跨域通用 | 原则/方法论/架构/文档记忆 |
| L2 应用记忆层 | 领域专用 | 案例/规则/知识图谱/统计/演化记忆 |
| L3 即时记忆层 | 当前会话 | 上下文缓存、临时状态 |

## 5个MCP工具

| 工具 | 何时调用 | 作用 |
|------|---------|------|
| `recall` | **任务开始前**（硬约束） | 检索相关历史经验，避免重复踩坑 |
| `record` | 发现新经验时 | 将经验写入记忆系统 |
| `verify` | 实践验证后 | 贝叶斯置信度更新，触发蒸馏 |
| `stats` | 查看系统状态时 | 记忆统计 |
| `health` | 排查问题时 | 健康检查 |

## 协作流程

```
任务开始 → recall(检索经验) → 编码实现 → record(记录新经验) → verify(验证升级)
```

**硬约束**: 每个任务开始前必须调用recall，即使没有结果也表明已检查记忆库。
