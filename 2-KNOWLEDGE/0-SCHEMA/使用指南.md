# 知识库使用指南 — 按角色导航

> 本文是 L1 元知识层的核心导航文档，帮助不同角色的读者快速找到所需知识。
> 阅读顺序：先确定你的角色 → 按照→跳转路径访问对应文件

---

## 🆕 新用户 / 新AI Agent

**"我想了解6-TRADING系统"**

作为新接触系统的用户或AI Agent，你需要从上到下建立对系统的整体认知。

**→ 跳转路径：**

```
L1 使用指南(本文)
  → L3 1-TRADING/V9-马丁基线.md           # 理解核心交易逻辑
  → L2 5-METHODOLOGY/D-调研方法论.md        # 了解系统是如何被设计和调研的
  → L3 1-TRADING/三屏系统架构.md           # 理解三屏架构全景
  → L3 2-TECHNICAL/Hermes-架构.md          # 理解技术实现
```

**推荐阅读顺序：**
1. 先读本文 — 了解知识库结构
2. 读 L1 [跨域映射.md](./跨域映射.md) — 理解域间关系
3. 进入 L3 1-TRADING/ — 从 V9-马丁基线 开始
4. 如有需要再深入 L2 5-METHODOLOGY/

## 📊 交易员

**"我想优化策略"**

作为交易员，你的核心关注点是交易策略、信号体系和风控。

**→ 跳转路径：**

```
L3 1-TRADING/三屏系统架构.md             # 理解当前系统架构
  → L2 5-METHODOLOGY/Z-规划方法论.md       # 学习如何规划策略优化
  → L3 1-TRADING/风控体系.md              # 理解风控边界
  → L3 1-TRADING/Screen1-七维牛熊评分.md   # 检查方向判定逻辑
  → L3 1-TRADING/Screen2-日线入场信号.md   # 检查入场信号逻辑
  → L3 1-TRADING/信号生成体系.md           # 理解信号分类与组合逻辑
```

**推荐阅读顺序：**
1. 从三屏系统架构开始，定位你要修改的部分
2. 读Z链规划方法论，制定优化计划
3. 回L3查阅具体域文件
4. 优化后通过 L1 [质量标准.md](./质量标准.md) 检查

**"我想修改系统"**

作为开发者，你需要理解技术架构、集成方式和部署运维。

**→ 跳转路径：**

```
L3 2-TECHNICAL/Hermes-架构.md            # 理解系统架构全貌
  → L2 5-METHODOLOGY/E-执行方法论.md       # 学习执行方法论
  → L2 5-METHODOLOGY/三链接力协议.md       # 理解多Agent接力规则
  → L3 2-TECHNICAL/Cron-调度.md           # 理解Cron调度体系
  → L3 2-TECHNICAL/飞书集成指南.md         # 理解飞书集成
  → L3 2-TECHNICAL/部署与维护.md          # 理解部署流程
  → L3 2-TECHNICAL/数据管道.md            # 理解数据源与ETL流程
```

**推荐阅读顺序：**

2. 读 E链方法论 和 三链接力协议，了解开发流程
3. 深入具体技术文件（Cron、飞书、部署）

## 🏛️ 治理者

**"我想了解系统状态"**

作为治理者，你需要掌握知识库的整体状态、质量和治理规则。新增指标包括回测报告是否遵循Playbook标准、数据管道是否标注了新鲜度。

**→ 跳转路径：**

```
L1 0-SCHEMA/跨域映射.md                  # 了解全局域间关系
  → L1 0-SCHEMA/质量标准.md               # 检查质量指标
  → L2 5-METHODOLOGY/知识库管理框架.md     # 了解管理框架
  → L3 4-OPERATIONS/索引体系.md           # 了解索引体系
  → L3 4-OPERATIONS/OKR管理.md            # 了解OKR状态
  → L3 4-OPERATIONS/三段式门禁.md         # 了解门禁规则
```

**推荐阅读顺序：**
1. 从跨域映射开始，建立全局认知
2. 读质量标准，评估知识库健康度
3. 深入管理框架和索引体系
4. 周期性检查 OKR 和门禁状态
