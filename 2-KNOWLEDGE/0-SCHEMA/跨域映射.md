## 各域引用关系

### 1-TRADING（交易领域）

| 方向 | 目标域 | 说明 |
|:---|:---|:---|
| → 引用 | 5-METHODOLOGY | D链调研用到交易知识分析与调研方法；Z链规划用到策略优化方法论；E链执行用到交易执行流程 |
| → 引用 | 3-THEORY | 矛盾分析法用于A系列决策；第一性原理用于策略设计 |
| ← 被引用 | 2-TECHNICAL | 技术域实现交易系统，需要理解交易业务逻辑 |
| ← 被引用 | 4-OPERATIONS | 运营域管理交易系统运行状态 |
| ← 被引用 | 2-TECHNICAL | 信号生成体系.md被数据管道.md引用（数据消费方） |

### 2-TECHNICAL（技术运维领域）

| 方向 | 目标域 | 说明 |
|:---|:---|:---|
| → 引用 | 1-TRADING | 技术实现需要理解交易业务需求 |
| → 引用 | 5-METHODOLOGY | E链执行方法论指导技术开发流程 |
| ← 被引用 | 1-TRADING | 交易域依赖技术实现 |
| ← 被引用 | 4-OPERATIONS | 运营域管理技术运维状态 |
| ← 被引用 | 1-TRADING | 数据管道.md被信号生成体系.md引用（数据消费方） |

### 3-THEORY（哲学/理论领域）

| 方向 | 目标域 | 说明 |

| ← 被引用 | 1-TRADING | 交易策略实践验证理论 |
| ← 被引用 | 5-METHODOLOGY | 三链方法论引用矛盾分析法 |

### 4-OPERATIONS（运营治理领域）

| 方向 | 目标域 | 说明 |
