# 质量标准 — 知识库质量指标与自动校验

> 本文定义知识库的质量指标体系，用于自动化校验和人工审计。
> 所有指标基于知识库三层架构（L1/L2/L3）的实际状态。

## 指标详细说明

### 1. INDEX引用准确率 = 100%

**规则：** 每个INDEX.md中列出的文件路径必须实际存在。

**校验脚本思路：**
```bash
grep -oP '\[\K[^\]]+(?=\])' INDEX.md | while read file; do
  [ -f "$file" ] || echo "MISSING: $file"
done
```

### 2. 文件版本标记率 = 100%

**规则：** 每个.md文件末尾必须包含 `_最后更新：YYYY-MM-DD`。

**校验脚本思路：**
```bash
for f in $(find . -name '*.md' -not -path './_analysis/*'); do
  tail -1 "$f" | grep -q '最后更新' || echo "NO VERSION: $f"
done
```

### 3. 来源标注率 = 100%

**规则：** 每个.md文件末尾必须包含 `来源：<source_name>`。

**校验脚本思路：**
```bash
for f in $(find . -name '*.md' -not -path './_analysis/*'); do
  grep -q '来源：' "$f" || echo "NO SOURCE: $f"
done
```

### 4. 跨域交叉引用覆盖率 ≥ 3条/域

**规则：** 每个域至少引用3个其他域的文件。

**校验方法：** 扫描各域INDEX.md中的跨域路径引用（以 `../` 开头或指向其他域的名称）。

### 5. 文件行数合理率 ≥ 80%

**规则：** 80%以上的内容文件（不含INDEX.md）行数在30-120行之间。

**校验脚本思路：**
```bash
total=$(find . -name '*.md' ! -name 'INDEX.md' -not -path './_analysis/*' | wc -l)
reasonable=$(awk 'BEGIN{c=0} NR>30 && NR<120{c++} END{print c}' \
  $(find . -name '*.md' ! -name 'INDEX.md' -not -path './_analysis/*'))
echo "合理率: $((reasonable * 100 / total))%"
```

### 6. 文件新鲜度 ≥ 70%

**规则：** 70%以上的文件最后更新日期在30天内。

**校验方法：** 提取每个文件的 `最后更新` 日期，与当前日期比较。

### 7. ASCII图完整性

**规则：** 每个ASCII图可被人类正确解析。

**校验方法：** 人工校验。

### 8. 回测报告Playbook合规率 = 100%

**规则：** 所有回测报告必须遵循[策略Playbook标准](../5-METHODOLOGY/策略Playbook标准.md)的格式要求，包含决策树、执行流程、风险约束和复盘指标。

**校验方法：** 扫描回测相关.md文件，校验是否包含Playbook标准中定义的必需字段。

### 9. 数据管道新鲜度标注率 = 100%

**规则：** [数据管道](../2-TECHNICAL/数据管道.md)中列出的每个数据源必须标注最新数据获取时间（新鲜度），确保数据时效性可追溯。

**校验方法：** 扫描数据管道.md中每个数据源条目，校验是否包含时间戳或新鲜度标记。

## 自动校验流程

1. **每日定时执行：** cron（参考 2-TECHNICAL/Cron-调度.md）自动运行校验脚本
2. **校验范围：** 排除 `_analysis/` 目录，校验所有 `.md` 文件
3. **结果输出：** 生成校验报告，标记不达标指标
4. **异常处理：** 连续3日同一指标不达标 → 触发审批工作流（参考 4-OPERATIONS/审批工作流.md）
