# 通用风控三层体系

> **来源：** 13-通用风控模块/core/engine.py + rules/
> **定位：** 通用风控引擎，三层风控体系（事前门禁/仓位管理/事后离场）

## 三层架构

```
┌─────────────────────────────────────────────────┐
│  L1 事前门禁层 (PreTradeGate)                    │
│  ─────────────────                               │
│  pre_trade_check() — 开仓前检查                  │
│  规则：日回撤熔断/杠杆上限/并发仓位/连续亏损/黑窗  │
└───────────────────────┬─────────────────────────┘
                        │ 通过
                        ▼
┌─────────────────────────────────────────────────┐
│  L2 仓位管理层 (PositionSizer)                   │
│  ─────────────────                               │
│  calculate_position() — 计算建议仓位              │
│  规则：置信度调整/波动率调整/最大仓位限制           │
└───────────────────────┬─────────────────────────┘
                        │ 仓位确认
                        ▼
┌─────────────────────────────────────────────────┐
│  L3 事后离场层 (ExitEngine)                      │
│  ─────────────────                               │
│  check_exit() — 持仓期间检查                     │
│  规则：P0硬离场/P1信号反转/P2易经强制/P3提前退出   │
└─────────────────────────────────────────────────┘
```

## 核心组装（engine.py L84-120）

RiskEngine.__init__ 实例化三个组件：
- PreTradeGate（事前门禁）
- PositionSizer（仓位管理）
- ExitEngine（事后离场）

register_default_rules() 注册三类默认规则。

## L1 事前门禁规则（gate_rules.py）

| 规则 | 优先级 | 说明 |
|------|--------|------|
| daily_drawdown_circuit_breaker | 最高 | 日回撤熔断，触发后全天禁止开仓 |
| leverage_cap_check | 高 | 杠杆上限检查 |
| concurrent_position_limit | 高 | 并发仓位数量限制 |
| consecutive_losses_limit | 中 | 连续亏损次数限制 |
| black_window_check | 中 | 黑窗时段检查 |

## L2 仓位管理规则（position_rules.py）

| 规则 | 说明 |
|------|------|
| confidence_adjustment | 置信度调整仓位 |
| volatility_adjustment | 波动率调整仓位 |
| max_position_cap | 单笔最大仓位限制 |

**max_position_cap公式：** `上限 = total_equity × max_position_pct`
超过上限时下调adjusted_risk。

## L3 事后离场规则（exit_engine.py）

| 优先级 | 规则 | 说明 |
|--------|------|------|
| P0 | 硬离场 | EV<-0.35强制离场 |
| P1 | 信号反转 | 入场信号消失或反向 |
| P2 | 行为约束 | 易经卦象变化等 |
| P3 | 安全退出 | P3保护期结束、排名止盈 |

## 与11-易经推理系统的集成

通用风控作为BCRM2.0推理后的最后一道防线：

```
BCRM2.0推理 → 交易信号 → L1事前门禁 → L2仓位管理 → 下单 → L3事后离场
```

**方案C 8开关（SW-C1至SW-C8）** 中的组合熔断（SW-C8）即调用L1的daily_drawdown_circuit_breaker。

## 风控参数

| 参数 | 值 | 说明 |
|------|-----|------|
| POSITION_PROTECTION_HOURS | 6.0 | 保护期时长（小时） |
| EXIT_CONFIRM_REQUIRED | 2 | 离场确认次数 |
| EXIT_CONFIRM_WINDOW_SEC | 300 | 确认窗口（秒） |

## 组合熔断触发条件

- **可用金额亏损超过20%** → 触发熔断
- **执行动作：** 暂停开新仓，仅允许平仓
- **恢复条件：** 人工确认或亏损回撤至10%以内
