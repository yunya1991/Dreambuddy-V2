# 三屏系统架构 — Screen1→Screen2→Screen3

> 三屏交易体系完整架构总览，各屏职责划分与数据流。
> 源：dream-systematic-trading v2.0, dream-screen1-first, dream-screen2-second, dream-screen3-third

## 架构总览

三屏体系覆盖从战略方向到战术执行的完整交易链条：

```
行情数据 → Screen1(周线) → Screen2(日线) → Screen3(实时)
  战略层       战术层             执行层
```

## 各屏职责

### Screen1：第一屏 — 战略层（周线方向判定）

| 项目 | 内容 |
|:---|---|
| **职责** | 判定周线方向（牛/熊），为Screen2提供方向约束 |
| **核心方法** | 七维牛熊评分（技术/减半/矿工/链上/宏观/跨市场/情绪）|
| **方向锚** | MA200三日确认 |
| **调用** | dream-contradiction-theory (A1) → dream-first-principles (A2) → dream-tactical-validator (A3) |
| **输出** | direction (LONG/SHORT), score (0-100), strategy_type |

### Screen2：第二屏 — 战术层（日线入场预设）

| 项目 | 内容 |
|:---|---|
| **职责** | 基于Screen1方向，计算三大预设价位表（入场/加仓/止盈止损） |
| **核心方法** | 日线A1-A3分析 + 回测验证 + 贝叶斯参数优化 |
| **回测依赖** | dream-backtest, dream-bayesian-opt |
| **输出** | 三大预设 + 入场信号强度评估 + 仓位建议 |

### Screen3：第三屏 — 执行层（实时监控与执行）

| 项目 | 内容 |
|:---|---|
| **职责** | 执行入场-加仓-止盈止损-离场完整闭环 |
| **执行周期** | 每工作日09:00检查触发，持仓期持续监控 |
| **内部流水线** | A7门禁 → A4验证 → Gate C门禁 → A5入场 → A6监控 → A9离场 |
| **输出** | 仓位状态 + 执行日志 + 离场结果 |

## 数据流

```
Screen1输出 ──→ Screen2 ──→ Screen3 ──→ A9离场报告
    |             |             |
    | 方向约束     | 预设价位    | 执行日志
    ▼             ▼             ▼
  记忆更新       Episodes      Memory状态
```

## 关键集成点

- Screen1输出方向给Screen2和Screen3做硬性约束
- Screen2预设是Screen3的唯一入场参考
- Screen3不可独立判断方向，方向必须来自Screen1
- A6监控在持仓期持续运行，实时调整止盈止损
- A9四层离场链在满足条件时触发强制离场
