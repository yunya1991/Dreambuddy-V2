# V4波浪策略

> **来源：** 17-v4-wave-strategy/
> **定位：** V4减半周期 + 艾略特波浪互斥融合策略

## 核心理念

**"V4定方向，波浪择时加仓"** — V4减半周期确定大方向，波浪策略择时加仓，两者互斥融合。

## 独立性

V4+波浪策略**完全独立于三屏趋势系统**，不共享代码或数据。

## 主引擎流程（v4_wave_engine.py）

1. V4减半周期策略生成信号并定方向
2. 价值风险评估
3. 物理置信度调节
4. 波浪互斥融合

## V4减半周期

### 逃顶策略（halving_top_exit_strategy.py）

| 阶段 | 说明 |
|------|------|
| normal | 正常交易 |
| warn | 减半后接近顶部，提高警惕 |
| danger | 顶部窗口，越高越卖 |
| peak | MA128破位，反弹卖出 |

**逃顶机制：**
- 减半后12-18个月为顶部窗口
- 越高越卖策略
- MA128破位卖出
- 反弹卖出

## 波浪互斥融合（ewave_strategy_adapter.py）

### WaveConfig最优参数

| 参数 | 值 | 说明 |
|------|-----|------|
| wave_weight | 0.6 | 波浪权重 |
| confirm_threshold | 0.6 | 确认阈值 |
| bottom_position_cap | 0.5 | 底部仓位上限 |

### 融合规则（9年回测验证）

- V4信号定方向（多/空/中性）
- 波浪信号择时加仓
- 互斥融合输出：total_position_pct / final_action / final_direction

## 输出结构

```python
{
    "total_position_pct": float,  # 总仓位百分比
    "final_action": str,          # buy/sell/hold
    "final_direction": str        # long/short/neutral
}
```
