## 一、黄金与 BTC 关键差异

| 维度 | BTC | 黄金（XAUUSD） |
|:---|---|:---:|
| 日均波动率 | 3-5% (高) | 1-2% (中) |
| 交易时间 | 24/7 | 23小时 (周一至周五) |
| 杠杆 | 高 (OKX 1-100x) | 中 (外汇经纪商 1-50x) |
| 趋势持续性 | 短/中周期 | 长周期（月/年级别） |
| 宏观敏感度 | 低（数字黄金叙事） | 极高（避险对冲） |
| 流动性 | 中等 | 极高（全球最活跃商品） |
| 中央对手方 | 无（去中心化） | COMEX/LBMA（中心化） |
| 数据源 | OKX/Binance API | Yahoo Finance/XAUUSD CFDs |

## 二、黄金 2026 年核心驱动力

1. **通胀持续**（美国PPI 6.5% YoY，中东能源冲击）
2. **地缘政治**（伊朗-美国冲突→避险）
3. **央行购金**（去美元化趋势，中国/波兰/印度增持）
4. **美联储政策**（加息预期 vs 降息预期拉锯）
5. **美元指数**（USD走弱→黄金↑，具-0.4~-0.6相关性）

### 入场策略（Screen2 日线级）

- **方向过滤**: 价格连续3日守在MA200之上 = 牛市，之下 = 熊市
- **入场信号**: MA200方向确认 + RSI回撤至40-50区（牛市中）或RSI反弹至50-60（熊市中）
- **马丁参数适配**: vol_mult = 0.8（黄金波动率仅为BTC的1/3-1/2）
- **加仓间隔**: 8% × 0.8 = 6.4%（黄金日线级别）

### 出场策略（Screen3）

- **止盈**: 4% × 0.8 = 3.2% 全仓平
- **止损**: 无固定止损（V9规则），采用移动止损（ATR × 2）
- **最大加仓次数**: 3次（V9基线）

## 四、与现有 BTC 策略的协同

- **风险预算共享**: 总投资组合的 20% 分配给黄金，80% BTC
- **时期选择**: 黄金在BTC熊市时表现优异（避险轮动）
- **对冲机制**: 黄金↑/BTC↓ = 避险模式（C8矛盾），黄金↑/BTC↑ = 通胀预期模式（C3矛盾）
