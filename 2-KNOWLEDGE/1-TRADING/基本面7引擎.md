## S1 情感引擎（FinBERT）

### 三层FAIL-OPEN机制

| 层级 | 触发条件 | 回退行为 |
|------|---------|---------|
| L0 | USE_FINBERT=0 | 直接回退旧规则 |
| L1 | 模型导入/加载失败 | 会话级降级 |
| L2 | 单条推理异常 | 仅本条回退旧规则 |

### 流程（sentiment_engine.py L329-376）

```
L0 env检查 → L1懒加载 → L2 FinBERT推理 → 失败回旧规则 → 归一映射
```

### 输出契约

```python
{
    "score": float,      # [-1.0, 1.0]
    "sentiment": str,    # positive/negative/neutral
    "categories": list,  # 分类标签
    "matches": list       # 匹配关键词
}
```

### 已知问题

- valuesimplex/FinBERT2模型存在HuggingFace 401 Unauthorized
- 需确认正确repo_id或使用公开替代模型

## S2 事件账本引擎

- **输入：** news_list
- **输出：** List[Dict] 事件账本
- **FAIL-OPEN：** ImportError或异常返回空list，不阻断热路径

## S3 新闻合约验证器

- **输入：** 新闻批次
- **输出：** validate_batch结果 + pass_rate
- **FAIL-OPEN：** 依赖或schema异常时pass_rate=0.8，不完全关闭
