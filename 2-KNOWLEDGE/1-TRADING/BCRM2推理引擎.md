# BCRM2.0 推理引擎

> **来源：** 11-易经推理系统/polling_trader.py + bcrm2/ 目录
> **定位：** 二元矛盾推理模型（Binary Contradiction Reasoning Model），11-易经推理系统的策略层核心

## 核心架构

BCRM2.0 是**二元矛盾推理模型**，通过逐层推理识别市场矛盾，最终输出交易信号：

```
K线数据 → L1模型(344个二元推理单元) → L2模型(278个融合模型) → 卦象映射 → 交易信号
```

## 推理链路

### 1. 数据准备（polling_trader.py L10800-10949）
- 加载外部知识/进化配置
- 执行战略层日级打分（五计庙算）
- 组合熔断检查
- MODE-aware 币种筛选

### 2. BCRM2.0严格模式推理（polling_trader.py L3429-3678）
- 获取K线数据
- 走BCRM2.0严格模式（失败不降级）
- 融合八卦引擎、卦象一致性
- 止损止盈计算
- regime/macro特征融合
- 输出：方向/置信度/止盈止损

### 3. CBR影子融合（polling_trader.py L7695-7943）
- 根据推理结果处理持仓/开仓
- 构造CBR查询
- 检索top-3历史案例
- 记录θ_match*融合结果
- 信号修正

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| L1模型数 | 344 | 二元矛盾推理单元 |
| L2模型数 | 278 | 融合模型 |
| CBR θ_match* | 0.71 | 相似度阈值 |
| CBR top-k | 3 | 检索案例数 |
| 推理模式 | 严格模式 | 失败不降级 |

## 卦象映射

易经64卦 → 交易方向/置信度映射。卦象一致性检查确保推理结果的稳定性。

## 方案C 8个开关

BCRM2.0集成方案C的8个风控开关（SW-C1至SW-C8），全部默认启用：

| 开关 | 功能 |
|------|------|
| SW-C1 | CBR建库 |
| SW-C2 | Elder-ray |
| SW-C3 | 三层权重 |
| SW-C4 | ElasticGate3L |
| SW-C5 | BCRM连续性 |
| SW-C6 | BTC自反 |
| SW-C7 | WinProb |
| SW-C8 | 组合熔断 |

**铁律：** 开仓必经所有风控链路。

## 与其他模块的关系

| 模块 | 关系 |
|------|------|
| 五计庙算（战略层） | war_state/cap/mask 作为BCRM推理的约束输入 |
| CBR案例检索 | θ_match*=0.71 top-3案例权重融合（Shadow模式） |
| 通用风控 | BCRM输出信号经三层风控门禁过滤 |
| 7引擎基本面 | S级5引擎注入道/天维度（±0.10），A级2引擎（±0.05） |
