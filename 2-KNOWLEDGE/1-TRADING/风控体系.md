# 风控体系 — 风险评估与预算控制

> 交易前门禁、风险评估、预算控制、日回撤限制的统一规则。
> 源：dream-pretrade-gatekeeper, dream-risk-position-sizing

## 门禁优先级

```
战略门禁(P0) → 杠杆门禁(P0) → 评分门禁 → 执行风险门禁 → 账户层门禁 → 边缘计算
```

各门禁依次执行，任一阻断 = SKIP。

### 战略门禁（最高优先级）

| 条件 | 结果 |
|:---|---|
| 战略排除条件命中 | SKIP + HARD_FAIL_STRATEGY_EXCLUDED |
| 战略指令 = REDUCE | 允许PASS但强制降级（仓位×position_modifier） |
| 战略指令 = WAIT | 允许PASS但输出SOFT_WARN |
| 极端行情无战略匹配 | SKIP + HARD_FAIL_NO_STRATEGY |
| 方向冲突 | SKIP + HARD_FAIL_DIRECTION_MISMATCH |

### 评分门禁

| 条件 | 结果 |
|:---|---|
| 任一评分维度 < min_dim_score(3) | SKIP + FAIL_LOW_DIM |
| 总分 < min_total_score(12) | SKIP + FAIL_LOW_TOTAL |

### 执行风险门禁

| 条件 | 结果 |
|:---|---|
| 最差滑点 > max_worst_slippage(60bps) | SKIP + FAIL_SLIPPAGE |
| 边缘值 ≤ 0 | SKIP + FAIL_NEGATIVE_EDGE |

### 账户层门禁

| 条件 | 结果 |
|:---|---|
| 当日回撤 > 10% | SKIP + 熔断 |
| 杠杆 > 2x（全仓模式） | SKIP + FAIL_LEVERAGE |
| 黑窗时段（宏观数据发布） | SKIP + FAIL_BLACKOUT |

## 日回撤限制（10%硬性）

**日回撤上限：10%** — 当日累计回撤超过10%后全天禁止新开仓。

| 回撤区间 | 措施 |
|:---:|:---|
| < 5% | 正常交易 |
| 5% ~ 8% | 警告，仓位减半 |
| 8% ~ 10% | 仅允许减仓，禁止新开 |
| > 10% | 熔断，全天禁止 |

## 风险预算控制

```
risk_per_trade_usdt = risk_cap × scores_scaling × dream_multiplier
```

- risk_cap = 账户权益固定比例（硬上限）
- Dream Mode激活时 × 0.5
- memory_safety过低时强制压缩

## 理由码体系

| 类别 | 码 | 含义 |
|:---|:---|---|
| 🔴 硬阻断 | HARD_FAIL_MISSING_CORE_DATA | 核心数据缺失 |
| 🔴 硬阻断 | HARD_FAIL_LEVERAGE_EXCEEDS_CAP | 杠杆超限 |
| 🔴 硬阻断 | HARD_FAIL_STRATEGY_EXCLUDED | 战略排除 |
| 🔴 硬阻断 | HARD_FAIL_DRAWDOWN_CIRCUIT_BREAKER | 回撤熔断 |
| 🟡 降级 | DEGRADE_DREAM_MODE | 梦模式降级 |
| 🟡 降级 | DEGRADE_STRATEGY_REDUCED_RISK | 战略降级 |
| 🔵 警告 | SOFT_WARN_STRATEGY_DIRECTS_WAIT | 战略建议等待 |

## Fail-Closed 原则

- 缺失核心数据 → SKIP
- 无法判定风险阈值 → SKIP
- 出现严重冲突 → SKIP
- 任何上游pass=false → 透传为SKIP
