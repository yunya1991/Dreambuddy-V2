# 调控系统

> **来源：** 16-调控系统/core/
> **定位：** 宏观离场调控系统，跨系统宏观战略离场评估

## 核心架构

调控系统通过A9离场决策模块，融合A1/A2/A3战略方向，评估持仓的宏观战略状态：

```
A1/A2/A3战略输入 → A9离场决策 → 四态输出 → 执行器
```

## A9离场决策（a9_exit_decision.py）

### 四态输出

| 状态 | 动作 | 说明 |
|------|------|------|
| CLOSE | 平仓 | 宏观战略恶化，立即平仓 |
| REDUCE | 减仓 | 风险增加，降低仓位 |
| HOLD | 持有 | 战略状态正常 |
| RAISE_TP | 提高止盈 | 趋势强劲，提高目标价 |

### 五层决策链

1. **Layer 1：** A1/A2/A3战略方向融合
2. **Layer 2：** 置信度计算
3. **Layer 3：** 市场状态评估
4. **Layer 4：** 趋势相位判断 → final_score计算
5. **Layer 5：** 资金压力调整

### final_score映射

final_score由A1/A2/A3的战略方向、置信度、市场状态、趋势相位综合计算，映射为四态动作。

## 资金压力调整（Layer 5）

当phase2_enabled且资金压力HIGH时：
- 阻断RAISE_TP
- 降低置信度
- 保守化离场决策

## 资金调控配置（capital_control/component.py）

| 配置 | 说明 |
|------|------|
| 6个交易系统映射 | 系统ID→资金规则映射 |
| 默认启用系统 | 需要资金调控的交易系统 |
| 健康阈值 | 资金健康度判断标准 |
| fallback budget | 降级预算 |
| phase2高压阻断 | 资金压力HIGH时的阻断配置 |

## 离场执行器（exit_executor.py）

- 过滤HOLD/OBSERVE/RAISE_TP
- 限制单周期执行数量
- 调用_execute_single执行单个离场
- 记录执行日志

## 与其他系统的关系

| 系统 | 关系 |
|------|------|
