# 交易参数速查 — vol_mult、仓位、币种参数表

> 马丁V9基线参数速查，所有优化必须在V9之上叠加。
> 源：dream-risk-position-sizing

## 核心马丁参数

| 参数 | 值 | 说明 |
|:---|---:|:---|
| 加仓间隔 | 8% × vol_mult | 复利，每次加仓在上一仓基础上 |
| 止盈 | 4% × vol_mult | 单次全平，不分批出场 |
| 加仓次数 | 最多3次 | 等额加仓，共4层（Level 0-3） |
| 止损 | 无 | 马丁仓位天然无法设定损 |

## vol_mult 系数

| 币种 | vol_mult | 加仓次数 | 说明 |
|:---|:---:|:---:|:---|
| BTC | 1.00 | 3 | 基准配置 |
| ETH | 1.50 | 3 | 2026-06 从1.30提升 |
| SOL | 1.75 | 3 | 波动率更高 |
| 美股代币 | 0.60 | 2 | TSLA/NVDA/AAPL/SPY |

## 仓位约束

| 约束 | 值 | 说明 |
|:---|---:|:---|
| 单笔名义上限 | 150 USDT | 硬约束 |
| 单层级仓位 | ≤ 账户20% | 四等份原则 |
| 累计马丁仓位 | ≤ 账户60% | 预留40%安全垫 |
| 最大回撤 | ≤ 20% | 马丁硬性止损 |

## 加仓计算公式

```
entry_price_n = entry_price_0 × (1 - 0.08 × vol_mult)^n
```

其中 n = 第n次加仓（n=1,2,3）

## 止盈触发价

```
tp_price = current_entry_price × (1 + 0.04 × vol_mult)
```

## 风险预算计算

1. 风险单位定义：止损距离 = 2 × ATR(15m)
2. 风险预算：`risk_per_trade = risk_cap × (scores.total / max_scores)`
3. Dream Mode：`risk_per_trade *= dream_mode_multiplier (0.5)`
4. 反推名义：在 `estimated_stop_loss ≤ risk_per_trade` 前提下最大化名义
5. 杠杆上限：默认2x，极高分才允许提高
