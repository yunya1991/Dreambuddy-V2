# CBR 案例检索系统

> **来源：** 11-易经推理系统/scripts/memory_l4/cbr_sharded_retriever.py
> **定位：** 基于案例的推理（Case-Based Reasoning），历史交易案例检索增强

## 核心机制

CBR通过检索相似历史交易案例，为当前决策提供参考：

```
当前交易特征 → 相似度检索 → top-3历史案例 → 权重融合 → 信号修正
```

## 检索流程（cbr_sharded_retriever.py L111-199）

1. **分片策略：** 按shard策略分阶段检索
2. **相似度计算：** 特征向量距离计算
3. **去重排序：** 去除重复案例，按相似度排序
4. **返回top-k：** k=3，θ_match*=0.71

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| θ_match* | 0.71 | 相似度阈值 |
| top-k | 3 | 检索案例数 |
| 模式 | Shadow | F1红线真参数不变，仅JSONL审计 |

## 双时间点案例闭包

CBR采用双时间点案例闭包机制：

| 时间点 | 快照 | 用途 |
|--------|------|------|
| 入场 | 特征+信号+环境 | 案例匹配输入 |
| 出场 | 盈亏+持有时间 | 案例结果标签 |

**目的：** 积累同regime同事件≥5样本后，RegimeConditionalCalibrator可校准阶段依赖性。

## 与力向量系统的集成

| 集成点 | 说明 |
|--------|------|
| RegimeConditionalCalibrator | E[r\|event,regime_current] vs E[r\|event,all] |
| 矛盾转化检测 | CBR背离检测（案例预期与实际背离→置信度×0.8） |
| StrategicMapper | CBR结果作为力向量输出的辅助验证 |

## 数据存储

- **案例库：** SQLite存储历史交易案例
- **检索索引：** 特征向量分片索引
- **审计日志：** JSONL记录每次检索的查询、结果、融合权重
