# V9 马丁基线

> **此规则不可修改。** 所有优化必须在 V9 之上叠加。

## 核心参数

| 参数 | 值 | 说明 |
|:---|---:|:---|
| 加仓间隔 | 8% × vol_mult | 复利，每次加仓在上一仓基础上 |
| 止盈 | 4% × vol_mult | 单次全平，不分批出场 |
| 加仓次数 | 最多 3 次 | 等额加仓 |
| 止损 | 无 | 马丁仓位无法设定损 |

## vol_mult 系数

| 币种 | vol_mult | 加仓次数 | 说明 |
|:---|:---:|:---:|:---|
| BTC | 1.00 | 3 | 基准配置 |
| ETH | 1.50 | 3 | 2026-06 从 1.30 提升 |
| SOL | 1.75 | 3 | 波动率更高 |
| 美股代币 | 0.60 | 2 | TSLA/NVDA/AAPL/SPY |

## 升版门槛

新策略（如 V10+）须在熊牛双周期同时满足：

- **Sharpe Ratio > V9**
  - BTC: > 1.50
  - SOL: > 1.85
  - ETH: > 2.05
- **MaxDD < V9**（对应币种）

## 规则约束

{% raw %}
1. 加仓计算公式：`entry_price * (1 - 0.08 * vol_mult)^n`，n=第n次加仓
2. 止盈触发价：`current_entry_price * (1 + 0.04 * vol_mult)`
3. 无法设定损——马丁天然没有止损概念
4. 每次加仓金额固定（等额）
{% endraw %}
