## 核心逻辑（一句话）
价格形态是市场心理的图形化记录。反转形态标志趋势结束，持续形态标志趋势休整。所有形态必须成交量确认+收盘价突破才有效，无量突破=假突破。

## 成交量验证总规则
- 形态形成期：成交量应**递减**（多空趋于平衡）
- 突破时：成交量必须**放大≥1.5倍均量**
- 无量突破=诱多/诱空，不交易
- 量价背离（价创新高但量缩）=趋势衰竭

## 一、反转形态

### 1. 头肩顶/底（最可靠）

**结构**：左肩→头（更高/更低）→右肩，颈线连接两肩低点/高点。

| 项 | 头肩顶（看跌） | 头肩底（看涨） |
|:---|:---|:---|
| 左肩量 | 高 | 中 |
| 头量 | 中（低于左肩） | 高 |
| 右肩量 | 低 | 中 |
| 颈线突破 | 放量跌破 | 放量突破 |

**目标计算**：
```
目标 = 颈线价 ± (头到颈线距离)
```

**入场**：
- 头肩顶：收盘跌破颈线→做空，SL右肩上方
- 头肩底：收盘突破颈线→做多，SL右肩下方

**统计**（Bulkowski thepatternsite.com, 2800+笔交易, 2020更新）：
- 成功率 **81%**（失败率19%），平均跌幅16%，回踩率68%
- 在36种看跌形态中排名第9
- **注意**：多数博客引用的96-99%来自单一2014年研究，不可靠
- **加密适配**：加密失败率更高（20-30%），因非交易时段流动性稀薄、交易所插针

---

### 2. 双顶(M)/双底(W)

**结构**：两个峰值/谷值在相近价位，中间有回调。

**目标计算**：
```
目标 = 颈线价 ± (峰值到颈线距离)
```

**确认条件**：
1. 两顶/底价格差<3%
2. 间隔至少2-4周
3. 第二个顶/底成交量低于第一个（动量衰减）
4. 突破颈线时放量

**入场**：
- 双顶：收盘跌破颈线→做空，SL第二顶上方
- 双底：收盘突破颈线→做多，SL第二底下方

**统计**（Bulkowski, 1333个双顶, 317只股票, 1990-2006）：
- 确认后成功率 **75%**（未确认失败率65%！），平均跌幅15%
- 仅64%达到完整测量目标
- 在36种看跌形态中排名第19（中等，非顶级）
- 双底在牛市成功率88%（显著高于双顶）
- **加密适配**：加密双顶更易失败，第二顶常微超第一顶形成多头陷阱，需RSI背离确认

---

### 3. 圆弧顶/底

**结构**：价格缓慢转向，形成弧形。成交量同步变化（顶部量递减→底部量递增）。

**特征**：
- 形成时间长（数周-数月）
- 成交量先减后增
- 突破时确认信号

**入场**：圆弧形成后突破确认入场，止损在弧顶/底外侧

---

### 4. V形反转

**结构**：快速剧烈反转，无过渡。

**特征**：
- 成交量暴增
- 单日/单周大幅反转
- 难预测，只在确认后跟随

**入场**：反转K线出现后入场，止损在极值外侧

---

## 二、持续形态

### 1. 三角形

| 类型 | 上沿 | 下沿 | 方向暗示 |
|:---|:---|:---|:---|
| 对称三角形 | 下降 | 上升 | 不明确，跟随突破方向 |
| 上升三角形 | 水平 | 上升 | 看涨（多头蓄势） |
| 下降三角形 | 下降 | 水平 | 看跌（空头蓄势） |

**目标计算**：
```
目标 = 突破价 ± 三角形最宽处高度
```

**确认**：
- 形成期成交量递减
- 突破时放量
- 通常在三角形2/3处突破

**入场**：突破上/下沿后入场，止损在三角形内侧

---

### 2. 旗形/楔形

**结构**：趋势中的短暂休整，形成平行四边形（旗形）或收敛楔形。

**特征**：
- 与原趋势方向相反（上升趋势中旗形向下倾斜）
- 形成期成交量锐减
- 突破后沿原趋势快速运行

**目标**：
```
目标 = 突破价 ± 旗杆长度（突破前的趋势幅度）
```

**入场**：突破旗形上/下沿+放量→沿原趋势方向入场

---

### 3. 矩形（箱体）

**结构**：价格在水平上下沿之间震荡。

**特征**：
- 上下沿水平，多次测试
- 形成期成交量递减
- 突破方向决定后续方向

**入场**：突破上沿做多/突破下沿做空，止损在箱体内侧

---

### 4. 杯柄形态（Cup & Handle）

**结构**：U形杯底+短柄回调，看涨持续形态。

**特征**：
- 杯底圆弧形，深度12-15%
- 柄是浅回调（杯深的1/3以内）
- 突破柄上沿时放量

**入场**：突破柄上沿→做多，SL柄底下方

**目标**：突破价 + 杯深度

---

## 三、趋势线与通道

### 趋势线规则
1. 上升趋势线：连接两个以上低点，向上倾斜
2. 下降趋势线：连接两个以上高点，向下倾斜
3. 有效突破需**收盘价**确认
4. 触碰次数越多、时间越长→越有效
5. 跌破后原支撑变阻力（角色互换）

### 通道
- 趋势线平行线构成通道
- 通道上沿可减仓，下沿可加仓
- 突破通道=趋势加速

---

## 四、支撑与阻力

### 规则
- 支撑：下跌止跌区域，跌破后变阻力
- 阻力：上涨滞涨区域，突破后变支撑
- 测试次数越多、成交量越大→越强
- 整数关口（如$100、$50000）是心理位
- 前高/前低是技术位

### 突破确认
- 收盘价突破（非盘中）
- 突破幅度≥0.5-1%
- 成交量放大≥1.5倍
- 3日内不回补

## 五、触发条件汇总

| 形态 | 做多信号 | 做空信号 | 止损 |
|:---|:---|:---|:---|
| 头肩底 | 收盘破颈线+放量 | - | 右肩下方 |
| 头肩顶 | - | 收盘破颈线+放量 | 右肩上方 |
| 双底(W) | 收盘破颈线+放量 | - | 第二底下方 |
| 双顶(M) | - | 收盘破颈线+放量 | 第二顶上方 |
| 上升三角 | 破上沿+放量 | - | 下沿 |
| 下降三角 | - | 破下沿+放量 | 上沿 |
| 旗形(上升趋势) | 破上沿+放量 | - | 旗形下沿 |
| 矩形 | 破上沿+放量 | 破下沿+放量 | 对侧沿 |
| 杯柄 | 破柄上沿+放量 | - | 柄底 |

## 失败形态（假突破）
1. **无量突破**：成交量未放大→假突破
2. **盘中突破不收盘**：仅影线触碰→不确认
3. **突破即回补**：3日内跌回→形态失败
4. **形态不完整**：缺少必要要素（如颈线未形成）
5. **量价背离**：价突破但量缩→趋势衰竭

---

## 适用市场状态
- **趋势市**：持续形态（三角形/旗形）高胜率
- **转折市**：反转形态（头肩/双顶）高胜率
- **震荡市**：矩形/支撑阻力高胜率
- **低波动**：等待形态完成，不提前入场

## 实战纪律
1. **等确认**：形态完成+突破确认再入场，不提前预判
2. **看量能**：无量突破一律不做
3. **设止损**：形态失败立即离场
4. **顺势为**：优先做与大趋势一致的形态
5. **不频繁**：形态需要时间形成，不过度交易
