# ICT / Smart Money Concepts 加密货币版（增强版）

> 来源：ICT方法论(Michael Huddleston) + marketcfd.com/ictkillzone.com/bigbeluga.com/pmotive.com 详细教程。蒸馏日期：2026-09-10。

## 核心逻辑（一句话）
市场被机构"操纵"：先清扫散户止损获取流动性，再在真实方向启动趋势。通过识别市场结构、流动性池、订单块(OB)和失衡缺口(FVG)，在机构入场位置跟随交易。

---

## 七大核心概念

### 1. 市场结构（Market Structure）
- **上涨趋势**：更高高点(HH)+更高低点(HL)
- **下跌趋势**：更低低点(LL)+更低高点(LH)
- **BOS（Break of Structure）**：突破前高/前低=趋势延续确认
- **CHoCH（Change of Character）**：突破反向结构=趋势反转信号
- **MSS（Market Structure Shift）**：剧烈位移突破关键摆动点=方向改变确认

### 2. 流动性（Liquidity）
价格只因为两个原因移动：填补失衡(Inefficiency) 或 获取流动性(Liquidity)。

| 流动性类型 | 位置 | 含义 |
|:---|:---|:---|
| 买方流动性(BSL) | 前高上方 | 空头止损+多头突破单 |
| 卖方流动性(SSL) | 前低下方 | 多头止损+空头突破单 |
| 等高/等低(EQH/EQL) | 双顶/双底 | **最高概率**止损池 |
| 前日高/低(PDH/PDL) | 昨日极值 | 日内重点目标 |
| 前周高/低(PWH/PWL) | 上周极值 | 波段重点目标 |

### 3. 订单块（Order Block, OB）
**定义**：强趋势启动前最后一根反向K线。
- **看涨OB**：上涨前最后一根阴线的开盘价区间
- **看跌OB**：下跌前最后一根阳线的开盘价区间
- **标记规则**：H4/H1标记，M15/M5执行
- **有效性**：OB被收盘价穿过=已失效(mitigated)
- **权重**：高周期OB > 低周期OB

### 4. 公允价值缺口（Fair Value Gap, FVG）
**定义**：三根K线中第1根和第3根影线不重叠，中间留下的失衡缺口。
- **看涨FVG**：第1根高点 < 第3根低点（上涨中留下）
- **看跌FVG**：第1根低点 > 第3根高点（下跌中留下）
- **入场位**：FVG的**50%均衡点**是最精确入场点
- **失效**：FVG被完全填补=失衡修复，失去意义
- **规则**：只做**趋势方向**的FVG，逆向FVG是陷阱

### 5. 流动性清扫（Liquidity Sweep）
**定义**：价格短暂突破关键高/低点后快速反向。
- **看涨清扫**：跌破前低→快速收回（扫多头止损后拉升）
- **看跌清扫**：突破前高→快速回落（扫空头止损后下跌）
- **确认**：2根K线内收回 + 成交量放大
- **止损**：清扫极值外侧×(1±0.5%)

### 6. 最优入场（Optimal Trade Entry, OTE）
- ICT版斐波那契回撤：**62%-79%**回撤区
- 流动性清扫+结构改变后，价格回撤到OTE区再启动
- 这是ICT**最高胜率**入场点

### 7. Killzone（交易时段）

| 阶段 | 时段 | 行为 |

## 三大高胜率Setup

### Setup 1：伦敦开盘清扫+反转
1. 标记亚洲区间高/低
2. 伦敦开盘后清扫亚洲高或低
3. 出现位移K线+FVG
4. 在FVG 50%处限价入场
5. 止损在清扫极值外
6. 止盈在对侧流动性池

### Setup 2：清扫+OB回测
1. HTF（H4/Daily）确定方向偏置
2. 等价格清扫对侧流动性
3. 确认结构改变(MSS)
4. 价格回测OB区域
5. M5/M15确认（影线拒绝/吞没K线/微结构BOS）
6. 入场，止损OB外侧

### Setup 3：三步入场法
1. **Step1 HTF偏置**：日线是否朝流动性池（等高/等低）方向
2. **Step2 清扫**：价格突破前高/低（散户以为是突破）
3. **Step3 位移**：大实体反向K线+FVG，在FVG入场

## 触发条件（开仓）

### 做多完整条件
1. HTF结构向上（BOS确认）
2. 价格清扫卖方流动性（跌破前低后收回）
3. 出现看涨MSS+看涨FVG
4. 价格回测看涨OB或FVG 50%
5. 在Killzone时段
6. M5/M15有确认K线

### 做空完整条件
1. HTF结构向下
2. 价格清扫买方流动性（突破前高后回落）
3. 出现看跌MSS+看跌FVG
4. 回测看跌OB或FVG 50%
5. Killzone时段
6. 低周期确认

## 离场规则

### 止损
- 做多：清扫最低点下方0.5%
- 做空：清扫最高点上方0.5%
- 或：OB区外侧

### 止盈
- 第一目标：对侧最近流动性池（等高/等低/前高/前低）
- 第二目标：下一个反向OB
- 移动止损：达到1R后SL移至保本

### 时间止损
- Killzone外不持仓
- 入场后未启动→离场

## 进阶概念：Breaker Block 与 Mitigation Block

### Breaker Block（破坏块）
**定义**：被突破并**反转极性**的失败订单块(OB)。

| 原OB类型 | 失败后变为 | 新角色 |
|:---|:---|:---|
| 看涨OB被跌破 | 看跌Breaker | 阻力位 |
| 看跌OB被突破 | 看涨Breaker | 支撑位 |

**关键确认条件**：
1. 原OB必须是有效的（强位移前最后一根反向K线）
2. OB被**收盘价**完全穿过（位移突破）
3. **必须先有流动性清扫**：价格在反转前创出新高/新低（超越前摆动点）
4. 结构发生改变(MSS)

**交易方法**：
- 价格回测Breaker区域时入场（与原OB方向相反）
- 看涨Breaker：价格回测时做多，SL在Breaker下方
- 看跌Breaker：价格回测时做空，SL在Breaker上方
- **胜率高于Mitigation Block**（因有流动性清扫确认）

### Mitigation Block（缓解块）
**定义**：同样是失败的OB，但**没有流动性清扫**。

**形成过程**：
1. 看涨OB形成，价格上涨但未达到目标流动性池
2. 价格形成**更低高点**（未创新高）
3. 跌破前低，结构转向
4. 机构被套在OB区域，等价格回升时平仓

**与Breaker的核心区别**：

| 特征 | Breaker Block | Mitigation Block |
|:---|:---|:---|
| 流动性清扫 | ✅ 有（先创新高/低） | ❌ 无 |
| 胜率 | 较高 | 较低 |
| 入场位 | OB区域50% | OB区域50% |
| 机构行为 | 主动清扫后反转 | 被套后被动平仓 |

**交易方法**：
- 价格回到原OB区域50%处入场
- 看涨Mitigation：做多（原看跌OB失败后变支撑）
- 看跌Mitigation：做空（原看涨OB失败后变阻力）
- SL在OB影线极值外

### Unicorn Setup（独角兽形态）
- Breaker Block + FVG的组合
- 价格回测Breaker区域时同时存在FVG
- 这是ICT中**最高胜率**的进阶形态之一
- 两个PD阵列共振，机构意图明确

## 失败形态（反向信号）
1. **清扫后不反向**：持续同向运行=真突破
2. **FVG被穿过**：价格不停留=失衡已修复
3. **OB被收盘穿过**：机构已离场
4. **无量清扫**：无成交量=非机构行为
5. **多重FVG重叠**：信号混乱，等待
6. **HTF偏置不符**：逆势FVG是陷阱
