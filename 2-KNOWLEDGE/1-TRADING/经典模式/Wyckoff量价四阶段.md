# Wyckoff 量价五阶段法（增强版）

> 来源：Richard Wyckoff方法论 + stockchartsai.com/journalplus.co/Wyckoff Analytics详细教程。蒸馏日期：2026-09-10。

## 核心逻辑（一句话）
通过价格+成交量识别机构（Composite Man）的吸筹/派发五阶段(A-E)，在Phase C的Spring（假跌破）买入、UTAD（假突破）卖出，跟随机构方向交易。

---

## 三条基本定律

1. **供需定律**：需求>供给→涨；供给>需求→跌（成交量验证）
2. **因果定律**：盘整时间/宽度=因，突破幅度=果（箱体越大，行情越大）
3. **努力与结果定律**：成交量(努力)与价格变动(结果)应匹配，背离=警告

---

## 五阶段模型（A-E）

### 吸筹（Accumulation）九事件序列
```
PS → SC → AR → ST → Spring → Test → SOS → LPS → Markup
```

#### Phase A：高潮（前趋势终结）
| 事件 | 全称 | 特征 |
|:---|:---|:---|
| PS | Preliminary Support 初步支撑 | 下跌中首次放量，不创新低 |
| SC | Selling Climax 抛售高潮 | 放量暴跌（均量3-10倍），恐慌抛售 |
| AR | Automatic Rally 自动反弹 | 空头回补+抄底，反弹30-60%，确立区间上沿 |
| ST | Secondary Test 二次测试 | 缩量回测SC低点，确认卖盘枯竭 |

**关键**：无成交量放大=不是Phase A，只是趋势中的正常回调。

#### Phase B：构建动因（横盘吸筹）
- 最长阶段，可持续数周/数月
- 价格在SC低与AR高之间震荡
- **特征**：上涨至区间上沿时成交量递减（供给被吸收）
- **因果定律**：6个月箱体的行情远大于6周箱体

#### Phase C：测试（最高胜率入场区）
**Spring（弹簧）**：价格跌破SC低点（清扫下方止损）后快速收回区间内。

| Spring等级 | 特征 | 强度 |
|:---|:---|:---|
| #1 终端震仓 | 宽幅K线+放量+收在低点上方 | 最强 |
| #2 标准Spring | 缩量跌破支撑，收回到区间内 | 中等 |
| #3 轻微Spring | 略微跌破，同根K线收回 | 最弱 |

**确认**：收回时成交量放大（机构承接）。

#### Phase D：新趋势初现
| 事件 | 全称 | 特征 |
|:---|:---|:---|
| SOS | Sign of Strength 强势信号 | 放量突破区间上沿 |
| LPS | Last Point of Support 最后支撑 | 缩量回踩上沿不破，最后入场点 |

#### Phase E：拉升（Markup）
- 趋势明确向上，持有待涨
- 回调缩量=健康，上涨放量=健康
- 直到Phase B构建的"因"被消耗完

---

### 派发（Distribution）九事件序列
```
PSY → BC → AR → UT → UTAD → Test → SOW → LPSY → Markdown
```

| 事件 | 全称 | 特征 |
|:---|:---|:---|
| PSY | Preliminary Supply 初步供给 | 上涨中首次放量不创新高 |
| BC | Buying Climax 买入高潮 | 放量暴涨，散户疯狂追高 |
| AR | Automatic Reaction 自动回落 | 快速下跌确立区间下沿 |
| UT | Upthrust 上冲 | 缩量测试区间上沿失败 |
| **UTAD** | **Upthrust After Distribution** | **突破区间上沿后快速回落+放量**（与Spring对应） |
| SOW | Sign of Weakness 弱势信号 | 放量跌破区间下沿 |
| LPSY | Last Point of Supply 最后供给 | 缩量反弹不创新高，最后离场点 |

## 触发条件（开仓）

### 做多：Spring确认入场
1. 已处于吸筹阶段（Phase B：低位横盘+上涨缩量）
2. Phase C出现Spring：跌破SC低点后2根K线内收回
3. 收回时成交量放大（量比>1.5）
4. 站稳SC低点上方
5. **入场**：收回时，止损在Spring最低点下方

### 做空：UTAD确认离场/做空
1. 已处于派发阶段（高位+放量滞涨）
2. 出现UTAD：突破区间上沿后快速回落
3. 回落时成交量放大
4. 回落至区间内
5. **入场**：回落时，止损在UTAD最高点上方

### Phase D跟随入场
- LPS（吸筹）：缩量回踩上沿不破→做多
- LPSY（派发）：缩量反弹不创新高→做空

## 离场规则

### 做多离场
- 止盈：进入派发阶段（放量滞涨/UTAD）
- 止损：Spring最低点下方 / 跌破区间下沿+放量
- 移动止损：拉升阶段SL上移至前一低点

### 做空离场
- 止盈：进入吸筹阶段（缩量止跌）
- 止损：UTAD最高点上方 / 突破区间上沿+放量

## 量价配合速查表

| 价格行为 | 成交量 | 含义 | 操作 |
|:---|:---|:---|:---|
| 上涨 | 放量 | 健康上涨 | 持有/加仓 |
| 上涨 | 缩量 | 上涨乏力 | 警惕/减仓 |
| 下跌 | 放量 | 恐慌抛售 | 不抄底 |
| 下跌 | 缩量 | 动能衰竭 | 观察止跌 |
| 横盘 | 放量 | 机构建仓/出货 | 看位置判断 |
| 横盘 | 缩量 | 多空平衡 | 等待突破 |

## P&F点数图计数法（价格目标计算）

Wyckoff用**点数图(Point & Figure)**量化"因果定律"，计算突破后的目标价格。

### P&F图基本规则
- **X列**：价格上涨，每个X=一个box size
- **O列**：价格下跌，每个O=一个box size
- **无时间轴**：只记录有意义的价格变动，过滤噪音
- **反转量**：通常3个box才开启新列

### 水平计数法（核心公式）
```
垂直投影 = 横盘列数 × box size × 反转量(通常3)
```
- **吸筹目标** = 突破价 + 垂直投影
- **派发目标** = 跌破价 - 垂直投影

### 计数范围
- 起点：SC（抛售高潮）或BC（买入高潮）区域
- 终点：突破点
- 统计这段区间内P&F图的**列数**

### 实例
- Box size = $1，反转量 = 3
- 吸筹区间横盘25列，突破价 = $60
- 垂直投影 = 25 × $1 × 3 = **$75**
- 目标价 = $60 + $75 = **$135**

### 关键说明
- 目标是**预期区间**，非精确价格
- 计数是"因"的量化，行情是"果"
- 大箱体(列数多)=大行情，小箱体=小行情
- 加密适配：box size取ATR的0.5-1倍

## 九项买卖测试

### 买入测试（吸筹确认）
1. 存在明确的抛售高潮(SC)
2. 二次测试(ST)缩量
3. 下跌时成交量递减
4. Spring后收回+放量
5. 上涨时成交量递增
6. SOS放量突破上沿
7. LPS缩量回踩不破
8. 相对强度优于大盘
9. P&F计数目标合理

### 卖出测试（派发确认）
1. 存在明确的买入高潮(BC)
2. 上涨时成交量递减
3. UTAD后回落+放量
4. 创新高但成交量萎缩
5. SOW放量跌破下沿
6. LPSY缩量反弹不创新高
7. 相对强度弱于大盘
8. 跌破关键支撑
9. P&F计数下行目标合理

## 再吸筹 vs 派发（关键区分）

| 特征 | 再吸筹（Re-accumulation） | 派发（Distribution） |
|:---|:---|:---|
| 上涨成交量 | 递减 | 递增 |
| 创新高 | 缩量（健康） | 放量滞涨（危险） |
| 回调深度 | 浅 | 深 |
| 回调成交量 | 缩量 | 放量 |

---

## 失败形态（反向信号）
1. **Spring后无法收回**：跌破后持续放量下跌=真下跌，非Spring
2. **UTAD后持续上涨**：突破后放量上行=真突破，非UTAD
3. **无量Spring/UTAD**：无成交量=非机构行为
4. **Phase B过长**：横盘超正常周期=可能是派发非吸筹
5. **上涨放量但价格不涨**：机构出货，立即离场

## 量化指标对应（对接本系统）

| Wyckoff 规则 | 本系统配置 |
|:---|:---|
| Phase A高潮 | 量比>3 且 价格极端波动 |
| Phase B吸筹 | 低位震荡+上涨时量比<0.8 |
| Spring | 跌破区间下沿后2根K线收回+量比>1.5 |
| UTAD | 突破区间上沿后2根K线回落+量比>1.5 |
| SOS/SOW | 放量突破区间边界 |
| 因果定律 | 盘整N天→目标幅度∝N |
| 再吸筹vs派发 | 上涨量比递减=吸筹，递增=派发 |

## 加密货币适配
1. **24/7市场**：无收盘，用UTC时段区分
2. **波动大**：Spring/UTAD幅度阈值放宽至2%（股票1%）
3. **主流币有效**：BTC/ETH/SOL机构行为明显，小币种可能无效
4. **刷量问题**：成交量可能失真，需结合多交易所验证
5. **事件驱动**：加密货币受消息影响大，Phase B可能被突发事件打破

## 与本系统现有逻辑的关系
- **互补**：Wyckoff提供regime分类(吸筹/拉升/派发/下跌)，EV雷达可据此调整离场灵敏度
- **Spring/UTAD**：与ICT流动性清扫本质相同，可复用检测逻辑
- **量价分析**：补充BCRM2的量能维度判断
- **FAIL-OPEN**：Wyckoff信号检测失败时退回原有开仓逻辑
