## 核心逻辑（一句话）
VWAP（成交量加权平均价）是机构基准，价格偏离VWAP过远后有回归引力。利用布林带/Z-score识别统计极值，在偏离2-3σ时逆向入场，目标回归VWAP，止损设在极值外侧。

## VWAP 基础

### 计算公式
```
VWAP = Σ(典型价 × 成交量) / Σ成交量
典型价 = (High + Low + Close) / 3
```

### VWAP标准差带

| 带 | 公式 | 含义 |
|:---|:---|:---|
| 上带3 | VWAP + 3σ | 极度超买→做空 |
| 上带2 | VWAP + 2σ | 超买警戒 |
| 上带1 | VWAP + 1σ | 阻力位 |
| **VWAP** | 公允价 | 中枢/目标 |
| 下带1 | VWAP - 1σ | 支撑位 |
| 下带2 | VWAP - 2σ | 超卖警戒 |
| 下带3 | VWAP - 3σ | 极度超卖→做多 |

### 加密适配
- 加密24/7交易，VWAP用**滚动**或**锚定**（Anchored VWAP），不日重置
- 零售占比70-80%→情绪化偏离更多→机会更多
- 成交量相对平坦（非U型），VWAP日内更稳定

## Setup 1：VWAP 反弹（均值回归，最高胜率）

### 做多（超卖反弹）
1. 价格触及或刺穿**下带2或下带3**
2. 下跌过程中**成交量递减**（衰竭确认）
3. RSI(14) < 30（超卖确认）
4. 无重大利空消息
5. **入场**：下带处出现拒绝K线（长下影/吞没）
6. **止损**：下带3外侧（或极值×0.995）
7. **目标1**：VWAP（1.6R）
8. **目标2**：上带1（2.9R）

### 做空（超买回落）
1. 价格触及或刺穿**上带2或上带3**
2. 上涨过程中成交量递减
3. RSI(14) > 70
4. 无重大利好
5. 入场：上带处拒绝K线
6. 止损：上带3外侧
7. 目标1：VWAP
8. 目标2：下带1

## Setup 2：RSI(2) 极端反转

### 做多
- 价格跌至4H重要支撑（200EMA或日线成交量节点）
- RSI(2) < **5.0**（绝对恐慌抛售）
- 等RSI(2)重新上穿10再入场（不预测拐点）
- 止损：支撑下方0.7%
- 目标：VWAP或+2.5%

### 做空
- 价格涨至周线重要阻力
- RSI(2) > **95.0**（极度亢奋）
- 等RSI(2)下穿90再入场
- 止损：阻力上方
- 目标：VWAP

**RSI(2)原理**：超短期超敏感振荡器，捕捉极端情绪，适合加密高波动。

## Setup 3：布林带挤压+偏离

### 条件
1. 布林带（20期，**2.5σ**）宽度处于6个月**最低10%**（挤压）
2. 价格收盘价突破上/下带
3. BBW（带宽）仍在低位（非扩张）

### 逻辑
- 低波动环境下的突发突破=流动性清扫/清算级联，非真趋势
- 回归中轨(20SMA)概率极高

### 入场
- 突破后价格收回带内→反向入场
- 止损：极值外侧
- 目标：布林带中轨

## Z-Score 量化入场

```
z_score = (价格 - N日均值) / N日标准差
```

| z_score | 操作 |
|:---|:---|
| > +2.0 | 做空（超买） |
| < -2.0 | 做多（超卖） |
| 回归至0 | 止盈离场 |
| 扩大至±3.0 | 止损 |
| 16小时未回归 | 时间止损 |

## 触发条件（开仓）汇总

| Setup | 做多条件 | 做空条件 |
|:---|:---|:---|
| VWAP反弹 | 价格≤下带2 + 量缩 + RSI<30 | 价格≥上带2 + 量缩 + RSI>70 |
| RSI(2)极端 | RSI(2)<5 + 支撑区 + 上穿10 | RSI(2)>95 + 阻力区 + 下穿90 |
| 布林挤压 | 收破下带 + BBW低位 | 收破上带 + BBW低位 |
| Z-Score | z<-2.0 | z>+2.0 |

**通用过滤**：
- 大趋势不明确（震荡市）时效果最好
- 避免重大消息时段
- 主流币(BTC/ETH/SOL)优先

## 离场规则

### 止盈
- 目标1：VWAP（第一目标，68%概率到达）
- 目标2：对侧1σ带
- 达到1R后SL移至保本

### 止损
- VWAP反弹：极值外侧（下带3/上带3）
- RSI(2)：支撑/阻力外侧0.7%
- Z-Score：偏离扩大至±3.0
- 一般：入场价 ± (1.5-2)×ATR

### 时间止损
- VWAP反弹：4小时未启动→离场
- Z-Score：16小时未回归→离场
- RSI(2)：8小时未反转→离场

---

## 失败形态（反向信号）
1. **放量偏离**：成交量递增=真趋势，非回归
2. **消息驱动**：重大消息打破统计规律
3. **趋势市**：强趋势中均值回归持续亏损
4. **多次失败**：同一带连续3次不回归→趋势改变
5. **BBW扩张**：带宽扩大=突破有效，非回归

---

## 适用市场状态
- **震荡市**：✅✅ 最优，频繁触碰上下带
- **弱趋势**：⚠️ 可用，需缩短持仓时间
- **强趋势**：❌ 禁止，均值回归会被趋势碾压
- **高波动事件**：❌ 跳过（CPI/FOMC/重大公告）
