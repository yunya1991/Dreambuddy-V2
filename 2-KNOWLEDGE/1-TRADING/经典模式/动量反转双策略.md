## 核心逻辑（一句话）
加密货币的"快新陈代谢"导致短期(2-4周)动量效应显著，长期(>1月)反转动量效应。组合时间序列动量(趋势延续)与横截面反转(均值回归)，通过量能过滤和Sharpe加权分配，实现低相关、高风险调整收益。

**学术发现**（HSE University，2000种加密货币，2014-2020）：
- 排序+持有期≤2周→正动量收益（显著）
- 2-4周→不显著
- >4周至2年→显著反转收益
- 切换点约**1个月**（传统股票是1年，加密快约12倍）

## 策略一：时间序列动量（Time-Series Momentum）

### 信号公式
```
signal = tanh( √(short_window) × (ret短期均值 - ret长期均值) / ret长期标准差 )
```
- short_window = 42根4H K线（约1周）
- long_window = 1080根4H K线（约6个月）
- tanh压缩信号至(-1, 1)

### 含义
- signal > 0：近期表现优于长期均值→做多
- signal < 0：近期表现劣于长期均值→做空

### 量能过滤
```
volume_zscore = √(short) × (vol短期均值 - vol长期均值) / vol长期标准差
```
- **动量仅在高量能时激活**（volume_zscore > 0）
- 理由：高量能=知情交易，动量更可靠

## 策略二：横截面反转（Cross-Sectional Reversal）

### 信号构造
1. 对15+种加密货币计算N日收益率
2. 横截面排名（rank）
3. 去均值（减去横截面均值）
4. 归一化（除以绝对权重之和）

```
weight_i = (rank_i - mean(rank)) / Σ|rank_i - mean(rank)|
```

### 交易规则
- **做多排名靠后的币种**（近期弱势→预期反弹）
- **做空排名靠前的币种**（近期强势→预期回落）
- 始终dollar-neutral（多空市值相等）

### 量能过滤
- **反转仅在低量能时激活**（volume_zscore < 0）
- 理由：低量能=流动性驱动的非理性交易，反转概率高

---

## 组合：Sharpe加权分配

```
组合权重 = (策略近期Sharpe / Σ各策略Sharpe)
```
- 哪个策略近期表现好，分配更多资金
- 动量在趋势市表现好（2024-2025牛市3.48x）
- 反转在震荡市表现好（Sharpe 3.68）
- 组合降低波动，Sharpe突破2.0

## 触发条件（开仓）

### 动量做多
1. signal > 0（短期收益 > 长期均值）
2. volume_zscore > 0（放量确认）
3. BTC大趋势向上（Beta低但需避免大熊市）

### 动量做空
1. signal < 0
2. volume_zscore > 0
3. 大趋势向下

### 反转做多
1. 该币在横截面排名**后20%**
2. volume_zscore < 0（缩量）
3. 大环境非单边下跌

### 反转做空
1. 该币在横截面排名**前20%**
2. volume_zscore < 0
3. 大环境非单边上涨

## 加密货币适配（时间压缩）

加密货币波动率是股票的3倍+，365天交易，需压缩周期：

| 传统参数 | 加密适配 |
|:---|:---|
| 200日MA | 50日MA |
| 12个月ROC | 90日ROC |
| +10%突破阈值 | +25%（过滤噪音） |
| MACD(12,26,9) | MACD(6,13,5) on 4H |
| RSI 70/30 | RSI >55 确认风险偏好，不做反转用 |

### 加密特有规则
1. **ATH重测规则**：不买第一次触碰前高，等突破→新高→回调→再收复（双重确认过滤诱多）
2. **BTC主导度过滤**：山寨币创新高+BTC主导度下降=高质量动量
3. **资金费率**：极端费率(>0.1%/8h)往往预示短期反转

## 离场规则

### 动量离场
- signal翻号→平仓
- 或持有1-4周后评估（动量半衰期）
- 硬止损：1.5×ATR

### 反转离场
- 价格回到横截面均值（z-score归零）→止盈
- 或时间止损：16小时未回归→离场
- 硬止损：偏离扩大至1.5倍原偏离

### 通用风控
- 单笔风险≤2%
- 多空对冲降低方向性风险
- 再平衡周期：4小时（加密数据密度高）

---

## 失败形态（反向信号）
1. **动量在低量能时启动**：无基本面/资金支撑，易假突破
2. **反转在高量能时启动**：放量趋势延续，非均值回归
3. **大事件期间**：消息打破统计规律
4. **流动性枯竭**：低市值币种滑点过大
5. **牛市单边**：反转策略持续亏损（应自动降权）

## 与本系统现有逻辑的关系
- **互补**：动量策略提供趋势方向判断，反转策略提供逆势入场
- **量能过滤**：与BCRM2的量能维度判断一致
- **横截面排名**：可用于多币种选币（本系统目前单币种，可扩展）
- **Sharpe加权**：与认知记忆的反哺权重逻辑同构
- **FAIL-OPEN**：信号计算异常时退回单币种BCRM2决策

## 风险提示
1. 回测来自2018-2025年，包含完整牛熊周期，但未来市场结构可能变化
2. 反转策略在强趋势中会持续亏损，需依赖动态降权
3. 横截面策略需要15+币种，单币种系统仅能用时间序列部分
4. 交易成本虽低(0.16%/年)，但4小时再平衡对执行速度要求高
