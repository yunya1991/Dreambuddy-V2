# 链路3 · 执行交付链（E系列）

> **定位**: 回答"怎么把计划落地"——逐任务编程、测试、交付
> **出口**: 可交付的代码变更 + 验收通过
> **不需要每步确认**（传统执行模式）

---

## 流程

```
Z3实施计划 + Z4验收方案（已获用户批准）
    ↓
E1 任务执行 ──── 产出: 代码变更
身份: 工程师         ↓ 用户验收单步
工具: 全工具      ↓
                ↓
E2 测试验证 ──── 产出: 测试报告
身份: 测试员         ↓ 用户验收测试
工具: terminal    ↓
                ↓
E3 部署交付 ──── 产出: 部署确认
身份: 运维           ↓ 用户验收交付
工具: terminal     ↓
                ↓
            交付完成
```

## 执行原则

1. **设定代办** → 逐个执行 → 勾选
2. **单步可回滚** — 每步完成后应有一个可单独回退的 checkpoint
3. **链路3不需要用户每句确认** — 用户在 Z3 批准计划时就同意了这个执行方向
4. **出问题时停止** — 遇到预料外的问题时自动暂停，等待用户判断
