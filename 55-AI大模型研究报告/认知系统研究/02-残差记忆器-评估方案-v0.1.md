# 残差记忆器（RMD）评估方案 v0.1

> **定位**：把 REA、指针、程序型策略与内容记忆组合成一个可测组件
> **上游**：`01-主论文` §3.1/§5.3、`01a-研究协议` P1/P3、`experiments/E1b-REA闭环-v0.2.md`
> **日期**：2026-11-17
> **状态**：设计稿，未运行；阈值均为待预注册的暂定值

---

## 0. 一句话定义

**残差记忆器 = 写入门槛 + 四形态存储 + 读时解码器 + 失败反馈环。**

它不生产知识，只决定"这条信息以什么形态存在，以及下次如何恢复"。

---

## 1. 组件边界（先定接口，再谈评估）

```text
写入：candidate ──► gate ──► { NONE | POINTER | PROCEDURE | CONTENT | REJECT }
读时：query + 认知召回 ──► decode ──► {answer, evidence, confidence, path}
反馈：outcome ──► 失败聚合 ──► 能力缺口 / 降级 / 删除
```

### 1.1 五种写入判定

| 判定 | 条件 | 存储内容 |
|---|---|---|
| NONE | 任一探针在成本阈值内可恢复 | 不存（可选：锚点写进索引） |
| POINTER | 可恢复但定位成本高 | 锚点 + 查询配方（`file:line` / 符号 / 命令模板） |
| PROCEDURE | 不可直接恢复，但存在可复用解法 | 步骤/判据/校验点（程序型记忆） |
| CONTENT | 结构性不可推导（偏好、否决、外部状态、代价教训） | 原文 + 来源 + 适用条件 + 有效期 |
| REJECT | 敏感域（凭证、密钥、越权数据） | 只存"禁止访问"策略，不存事实 |

### 1.2 探针集合（gate 的输入）

| 探针 | 能力 | 成本量级 |
|---|---|---|
| REA pack | 模块→符号→行 | 1 次调用 / 数十 KB |
| REA trace | 调用子图（已修 I1，未修 I2/I3） | 1 次 / ≤28 KB |
| REA dependencies | 项目内依赖边（已修 I4） | 1 次 / 数十 KB |
| grep | 文本精确命中 | 1 次 / ≤1 KB |
| AST/读取 | 函数体、赋值、配置读取 | 1–2 次 / ≤4 KB |

**判定规则**：`gate` 取"最便宜且能给出可验证证据"的探针；单探针失败不算不可恢复，必须 **REA + grep/AST 双通道一致失败** 才进入 CONTENT/PROCEDURE 候选。

## 2. 待验证命题（组件级，可证伪）

| ID | 命题 | 否证条件 |
|---|---|---|
| C1 | 双通道门槛的误存率 ≤10% | 误存 >30%（与 REA-only 无差异） |
| C2 | 漏存率 ≤5%（真正不可推导却没存） | 漏存 >15% |
| C3 | 敏感域拒绝率 = 100% | 任一敏感样本进入 POINTER/CONTENT |
| C4 | decode 正确率 ≥ 内容基线 −5pp | 低于内容基线 10pp 以上 |
| C5 | 单位成功任务成本 ≤ 内容基线 80% | ≥100% |
| C6 | 能力增强后删除安全：删除测试通过率 ≥95% | <85%，或误删致害 >2% |

C1/C2 是核心；C3 是硬门禁（不做统计让步）；C4–C6 决定它能否进主论文。

## 3. 四层评测

### L1：写入门槛（离线，最便宜、最决定性）

- **数据**：300 条候选，人工标注三类真值
  - 可再推导（代码事实）120 条：调用链、字段来源、配置生效点、模块入口、依赖关系
  - 不可再推导 120 条：用户偏好 30、否决决策 30、外部世界状态 30、带代价教训 30
  - 敏感 60 条：凭证位置、权限判定、越权路径
- **对照**：REA-only / 显著性抽取 / 双通道 / 三值+敏感（本方案）
- **指标**：误存率、漏存率、敏感拒绝率、p95 门槛延迟、平均探针调用数
- **通过线**：误存 ≤10%、漏存 ≤5%、敏感 100%、p95 ≤3 s

> 已知参照：E1b 中"REA 解析不出就记"会把 12 条可由 grep 恢复的题全部误存（12/12），这就是 L1 的负基线。

### L2：读时解码（离线回放）

- **题集**：E1 的 20 题扩到 60 题（5 类 × 12），真值仍由人工 + grep/AST 独立确定
- **条件**：A 内容记忆 / B 指针+REA / C 指针+grep / D RMD 级联 / E 零记忆
- **指标**：答案正确率、证据可定位率（必须给 `file:line`）、decode 成本（tokens/调用/时延）、失败类型分布
- **通过线**：D ≥ A −5pp；D 成本 ≤ A 的 80%；证据定位率 ≥80%
- **防自证**：decode 结果必须过锚点校验（命中真值符号/行），否则判失败

### L3：端到端任务流（半真实）

- **规模**：30 个连续任务 × 3 条件（全量捕获 / 显著性 / RMD）× 3 次重复
- **任务构成**：重复缺陷 8、偏好延续 6、负向决策 6、跨会话定位 6、过期信息注入 4（20% 条目由事实源变更造成）
- **指标**：任务成功率、重复错误率、偏好遵守率、过期残留率、误删率、记忆增长率、单位成功任务成本
- **通过线**：成功率不低于基线 −3pp；记忆增长率 ≤50% 基线；过期残留下降 ≥30%

### L4：删除安全（依赖能力增强事件）

- **触发**：以"修 I2/I3"作为一次真实的能力增强
- **流程**：增强前存 20 条相关 CONTENT → 增强后跑删除测试 → 通过才降级为 POINTER → 30 天宽限
- **指标**：删除测试通过率、重学成本、回滚次数、误删致害
- **通过线**：C6

## 4. 执行顺序与 Kill criteria

| 阶段 | 内容 | 成本 | 失败即停 |
|---|---|---|---|
| E2 | L1 门槛离线评测（300 条） | 低 | 误存 >30% 或敏感 <100% → 门槛回炉 |
| E3 | L2 解码回放（60 题 × 5 条件） | 中 | D 低于 A 10pp → "重建替代内容"不成立 |
| E4 | L3 端到端（30×3×3） | 高 | 记忆增长率未下降 → 写放大未解 |
| E5 | L4 删除安全 | 中 | 通过率 <85% → 禁止自动删除 |

E2 不通过就不做 E3/E4；这能把"方案级错误"挡在最低成本处。

---

## 5. 基线公平性与反循环（沿用 E1b 约束）

1. 真值不由 REA 单独裁定；每类抽样 20% 由第二人盲评并报 κ（κ<0.6 先修手册）。
2. 冻结三件套：仪器 md5、目标 commit、snapshot_id；跨阶段不升级。
3. 失败全部计入分母；超时算失败。
4. 敏感域只做拒绝率，不做"召回率"——不鼓励它去解析敏感信息。
5. 不得把 RMD 与外部记忆系统并列排名；外部系统只做机制对照。

---

## 6. MVP 范围（第一版只做三件事）

1. `gate`：REA pack + grep + AST 三探针，输出五值判定 + 证据。
2. `decode`：指针优先 → 探针恢复 → 锚点校验 → 失败回退 CONTENT。
3. `feedback`：记录失败类型，按"事实类"聚合，不自动删除。

**不做**：TTL 调度、图扩散、向量检索、跨项目迁移。这些属于 P2/P3，需等 L1/L2 通过。

## 7. 主要风险

| 风险 | 表现 | 处置 |
|---|---|---|
| 门槛把仪器盲区当残差 | 误存集中在 A/B/C 类 | 双通道 + 类级解析率校准（E1b 已给基线） |
| decode 自证 | 重建"看起来对"但答案错 | 锚点校验 + 人工 20% 盲评 |
| 程序型记忆膨胀 | 每条失败都写一个策略 | 复发阈值（同题 ≥3 次）+ 策略去重 |
| 删除不可逆 | 能力回退后无法恢复 | 宽限期 + 只降级不物理删除 |
| 敏感信息泄漏进记忆 | 凭证位置被存 | 硬拒绝 + 发布前扫描（参考 Claude 路径校验思路） |

## 10. 门槛分层架构（2026-11-17 补记）

> 背景：纯关键词表不可持续（每加一类句式就要加词），需要把"判定"拆成路由与证据两层。
> 原则：**分类器只做路由，探针才是证据**；否则会回到"自己给自己打分"。

| 层 | 机制 | 预期覆盖 | 成本 |
|---|---|---|---|
| L0 快路 | 敏感词 + 明确结构谓语（定义/导入/赋值/读取/依赖） | ~70% | 0 |
| L1 分类器 | 4 类断言分类：代码事实 / 运行状态 / 组织决策 / 敏感 | ~25% | 本地，<1 ms |
| L2 升级 | 置信度低 → 小模型或 LLM 判一次 | <5% | 按次计费，需预算 |
| 证据 | grep / AST / REA 探针 + 锚点校验 | 全部 code_fact 候选 | 每次约 200 ms |

补充约束：

1. **L2 的触发必须记录**，否则无法估计长期成本；升级比例超过 10% 说明 L0/L1 覆盖不足。
2. **防震荡**：同一候选在短窗口内被反复改写时降级为"信任原始判定"，连续 N 次未改写后恢复（借鉴 `jev_gate` 的降级/恢复机制）。
3. **分类器标签体系固定为 4 类**，不按业务扩展；新增句式优先改判据，不新增类别。
4. **L0 命中不等于最终结论**：结构谓语只决定"允许进入探针"，最终仍由探针输出 NONE/CONTENT。

E3 先测 L2 的上限（LLM 判定准确率与置信度分布），再决定是否训练 L1 分类器。
