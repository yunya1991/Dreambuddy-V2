## 2. P1 判定：有条件成立

P1 的三条否证条件逐条对照：

| 否证条件 | 结果 | 判定 |
|---|---|---|
| ① 指针/零记忆成功率比内容组低 ≥10pp | L2b −3pp、L2d 0pp | **不成立** |
| ② 综合成本高于内容组 | 存储 −34%~−49% | **不成立** |
| ③ 重建成功率 < 80% | 纯 grep 80%，恰好压线 | **边界，不判定** |

**结论**：P1 在"准入 + 回退"这一组合下成立——不牺牲准确率，存储降 34%；但**不能**表述为"指针/重建替代了内容记忆"。真正的替代率只有 43%–63%，其余靠"判不准就存内容"。

### 为什么不能更乐观

1. **回退是恒正确的**，所以"全拒绝"就能得到 100%。准确率必须和回退率、存储一起读。
2. **纯重建的上限是 80%**，5 个错误全部是"多个合理文件选错"，属于语义排序问题。
3. **REA 在符号级定位只有 45%**，且 33 次失败全是"看似合理的错文件"，比"无结果"更危险。

## 3. 被证伪/放弃的路线

| 路线 | 结果 | 处置 |
|---|---|---|
| 关键词表判准入 | 对抗集漏存 56% | 已被"默认拒绝 + 谓词白名单"替代，但仍需更强机制 |
| 图结构压缩当门槛 | 仍是 TF-IDF + 关键词加权，目标错位（保上下文 ≠ 判可推导） | 不采用；仅复用其熵/冗余信号 |
| JEV 当决策模型 | 它是纯规则的动作裁决门，不是文本分类器 | 只借用"快路 + 低置信升级 + 防震荡"结构 |
| 语法校验（行内容） | L2c：准确率 92% vs 97%，三指标全降 | **负结果，已回退** |
| LLM 从 top-3 强制选择 | 召回不足时越选越偏（3 次挑错） | 放弃，改用"允许拒绝"的 yes/no |

---

## 4. 可以写进论文的结论

1. 对"可由代码事实源恢复"的信息，**准入 + 指针 + 回退**可在不降准确率的前提下减少 34% 记忆存储（L2d，60 题）。
2. **重建能力不是单一工具的函数**：REA 45%、grep 80%、LLM 语义校验把系统从 97% 推到 100%。级联的价值大于任何单一仪器。
3. **回退机制是必需的**，否则纯度依赖检索质量，而检索质量在自然问句上不足（top-3 召回 78%）。
4. 敏感信息必须走"拒绝"而不是"记下来"，且拒绝规则要独立于能力强弱。

---

## 5. 结论边界（必须随论文一起声明）

1. 全部为**单领域**（Python 代码工程事实），不外推到偏好/世界状态/多模态。
2. 题集 60 题中 40 题为模板化问句；L1 的可推导样本由 AST 生成，与探针同源。
3. 校验器与判定器同模型家族，存在自我一致性偏差；L2d 的 100% 部分来自"拒绝即正确"。
4. 单次运行，无方差；无跨模型复现。
5. H-70 已知被调参污染，需一份全新留出集。
