# 26-策略管理模块

> **端口**：8093 | **类型**：Flask 服务
> **定位**：策略库管理中台 — 双层接口 + 策略发现 + 回测触发代理

## 接口分层

| 层级 | 路径前缀 | 权限 | 说明 |
|------|---------|------|------|
| 中台层 | `/api/v1/lib/*` | 只读 + admin token 写入 | 策略库管理 |
| 用户层 | `/api/v1/user/*` | CRUD | 用户策略空间 |
| 代理层 | `/api/v1/agent/*` | 策略发现 + 回测触发 | AI Agent 调用 |

## 核心能力

- 策略注册与版本管理
- 用户策略空间隔离
- 策略发现与检索
- 回测触发代理（source_zip 下发）

## 目录结构

```
26-策略管理模块/
├── app.py              # Flask 入口
├── strategy_lib/       # 策略库服务
│   └── services/
│       └── registry.py # 策略注册表
└── data/               # 数据
```

## 启动

```bash
python app.py
```

服务监听 `0.0.0.0:8093`，支持 CORS。
