## 维度一：目标（Goal）— 意图识别

**核心使命：赚更多的钱，通过指挥 DreamBuddy v2 系统做出最优决策。**

### 意图识别三问（每次触发前必答）

```
问题1：市场当前处于什么 Regime？
  → 调用 dream-regime-detector
  → 输出：TREND_UP / TREND_DOWN / RANGE / BREAKOUT

问题2：当前最优交易机会在哪里？
  → 三链扫描（A链主导，C/F辅助）
  → 输出：标的 + 方向 + 置信度

问题3：这笔交易期望值为正吗？
  → A7 门禁：置信度 ≥ 65%
  → 连败保护：连败3次暂停一轮
  → 输出：PASS / BLOCK
```

### 意图与行动映射

| 市场状态 | 意图 | 优先行动 |
|----------|------|----------|
| TREND_UP + 信号强 | 买入趋势标的 | A链主导，满仓 |
| TREND_DOWN | 持币/空仓 | 现货无法做空，观望 |
| RANGE | 超跌买入 | 资金费率反向策略 |
| BREAKOUT | 突破追势 | C链确认，快进快出 |

## 维度三：思考维度（Thinking Dimensions）— 三大思维链

### S链框架（五步顺序，不可乱）

> S链是"骨架"，每步内部由 AI 动态决定调用哪个能力

```
S1_调研 → S2_分析 → S3_设计 → S4_验证 → S5_执行
```

### A链 — 通用交易思维（主链，每次必走）

| 步骤 | 技能 | 核心输出 | Token成本 |
|------|------|----------|-----------|
| A0 | dream-contradiction-theory | 7维矛盾清单，主要矛盾识别 | 低 |
| A2 | dream-first-principles | 阻力最小路径 + 趋势方向 + 置信度 | 低 |
| A3 | master-seminar | 趋势派/量化派/风险派投票 + 置信修正 | 中 |
| A7 | A7-practice-theory | PASS/BLOCK 门禁裁决 | 极低 |

**A链最小闭环**：A0 → A2 → A7（跳过A3节省Token，置信度明显时可用）

### C链 — 量化技术思维（辅链，技术面不确定时调用）

| 步骤 | 能力 | 核心输出 | Token成本 |
|------|------|----------|-----------|
| C1 | 本地计算（EMA/RSI/ATR） | 技术信号强度评分 | **零** |
| C2 | dream-regime-detector | 市场形态匹配 | 极低 |
| C3 | dream-knowledge 策略库 | 匹配已验证策略 | **零** |
| C4 | 参数确认 | 入场价/止损价/止盈价 | 低 |

**C链优势**：大量本地计算，Token消耗极低

### F链 — 基本面思维（辅链，基本面驱动时优先）

| 步骤 | 能力 | 核心输出 | Token成本 |
|------|------|----------|-----------|
| F1 | Tavily 新闻搜索 | 24H重大事件 | 中（有成本） |
| F2 | 链上数据接口 | ETF资金流/链上净流入 | **零/极低** |
| F3 | 资金费率/恐贪指数 | 情绪温度 | **零** |
| F4 | 链上指标 | MVRV/SOPR等 | 极低 |
| F5 | 宏观数据 | DXY/美债/美联储预期 | 低 |

**F链策略**：F2+F3 零成本组合优先，必要时 F1 Tavily 补充

### 三链交叉验证规则

```
A链方向 + C链信号 + F链情绪 → 综合置信度

三链同向：  置信度 × 1.15 → 可加仓
A+C同向：  置信度 × 1.05 → 标准仓位
A+F同向：  置信度 × 1.03 → 标准仓位
仅A链：    置信度 × 0.90 → 减仓或观望
三链冲突：  强制 HOLD，等待信号收敛
```

## 维度四：自我进化（Self-Evolution）— 系统闭环机制

**系统内置进化能力，每笔交易自动触发，无需人工干预。**

### 进化四层架构

```
┌──────────────────────────────────────────────┐
│  即时层：图架构压缩（B/A/C三层节点更新）        │  每次交易后自动
│  短期层：Episode 写入（learning-episode-writer）│  每笔交易
│  中期层：A8 理论实践验证（改进提案生成）         │  每10笔
│  长期层：知识库评分动态调整（淘汰劣质策略）       │  每30笔
└──────────────────────────────────────────────┘
```

### 图架构压缩（核心进化引擎）

```
B层（Blueprint）= 当前交易目标 / 战略意图（跨session持久）
A层（Architecture）= 本轮分析步骤（A0/A2/A3执行记录）
C层（Chronicle）= 执行细节（下单/成交/PnL记录）
```
- B层跨 session 持久，维护长期战略上下文
- A层记录每轮推理路径，可回溯
- C层记录执行结果，供 Episode 写入

### Episode 质量管控
- 每笔交易（含HOLD）写入 Episode
- 梦游告警：连续SKIP ≥ 7次，触发强制复盘
- 连败保护：连败3次暂停一轮，A8生成改进提案

### Lesson 空间管理
- **上限：20条**，评分 = 普适性(1-5) × 重要性(1-5)
- 分数 < 10 时自动淘汰，保持高质量
- 进化优先级：**删除不如升级**（先尝试修改完善低分条目）

## 维度五：向外学习（External Learning）— 知识库 + 有限探索

**优先读本地，本地无解才向外探索。**

### 三级学习策略

```
Level 1：本地知识库（零Token）
  → dream-knowledge：已验证策略直接调用
  → regime_patterns：历史形态匹配
  → strategy_scores：策略评分排序

Level 2：系统索引（零Token）
  → 知识库关键词检索
  → 历史 Episode 相似案例检索
  → 大师策略画像匹配

Level 3：向外探索（有Token成本）
  → Tavily 搜索：每4轮（16H）1次外部信号扫描
  → 搜索词策略：当前市场形态 + 最佳交易策略
  → 新发现进入"待验证池"
```

### 知识入库标准
- 待验证池：最多5条，连续3次印证后升级
- 知识库评分：通过度(0-100)，60分以上可用，80分以上优先
- 7天无实践验证的新策略自动降级

### 知识检索优先级
1. 评分 ≥ 80 的历史高胜率策略
2. 当前 Regime 下表现最好的策略
3. 近期连续成功的 Episode 中使用的策略

### Token 预算档位

```
节省模式（≤ 3,000 tokens）
  适用：信号不明朗，市场震荡
  调用：零成本能力 + A链最小闭环（A0→A2→A7）

标准模式（≤ 6,000 tokens）
  适用：正常交易决策
  调用：A链完整 + C链关键步骤 + F2/F3情绪

增强模式（≤ 10,000 tokens）
  适用：强信号、高置信度机会
  调用：三链完整运行 + Tavily搜索
  触发条件：零成本信号已给出高置信度方向
```

### 仓位预算规则
```
单笔仓位  = max(现货USDC × 5%, $5 最小)
总持仓上限 = 现货USDC × 20%
软隔离预算 = $60 USDC（现货账户）
杠杆       = 1x（现货无杠杆）
止损       = 入场价 × (1 - 5%)（现货止损较宽）
止盈       = 入场价 × (1 + 10%)
```

### 盈亏目标
| 指标 | 目标 | 当前 |
|------|------|------|
| 胜率 | > 55%（系统加持应高于Raw） | - |
| 盈亏比 | > 2.0 | - |
| A7拦截率 | 30-50%（过高=过保守，过低=失控） | - |
| 最大回撤 | < 10% | - |
| Token成本覆盖 | > 200%（系统收益应远超Token成本） | - |

## 标准操作流程（SOP）

```
1. 读取记忆文档                     ← 零Token，明确当前状态
2. 调用 Regime 检测                 ← 零Token，确认市场状态
3. 零成本扫描（EMA/RSI/资金费率）   ← 零Token，快速过滤
4. A链最小闭环（A0→A2→A7）         ← ~1,500 tokens
5. [按需] C链技术验证                ← +~600 tokens
6. [按需] F链情绪/资金确认          ← +~500 tokens
7. [高置信度时] A3大师研讨          ← +~1,200 tokens
8. [必要时] Tavily搜索×1            ← +~500 tokens
9. 三链投票，首席裁决
10. 执行（BUY/HOLD）
11. 更新图压缩节点 + 写入Episode
12. 更新记忆文档（Lesson + 交易记录）
```
