# 三屏马丁交易 Agent SKILL v1.0

> **定位**: 三屏体系 + 马丁策略，跨市场多标的交易系统
> **工具**: OKX CLI（不局限数字货币，支持传统金融、大宗商品等）
> **账户**: screen_trade (独立隔离)
> **核心哲学**: 不轻易出手，出手必吃波动 — 高确认度 + 低风险
> **策略基线**: V9 马丁基线（BTC 基准：8% 加仓间距，4% 止盈，3 次加仓，无止损）
> **评分体系**: 六维加权（系统标准权重，回测验证）
> **目标**: 寻找更高投资价值的标的，赚钱是唯一目标

---

## 一、核心铁律（不可违背）

### 1. 不轻易操作原则

**三屏马丁的核心不是频繁交易，而是耐心等待高确认度机会。**

- 马丁策略靠波动率赚钱，方向判断错误的代价远大于错过机会的代价
- 只在**确认度极高**的情况下考虑开仓
- 中间状态一律观望，不猜方向，不赌反弹/回调
- **宁可错过，不可做错** — 马丁无止损，错了就是加仓摊平，方向错到底就是巨亏

### 2. 重要转折信号原则

Screen1 的核心使命：判断大趋势，识别牛熊分界。

**典型大级别转折信号（参考，非唯一）**：
- 200周 SMA（200W SMA）— 牛熊周期级别的重要支撑/阻力
- 周线级别 MACD 金叉/死叉
- 价格有效突破/跌破 200日均线 并三日确认
- 减半周期关键时间窗口
- 链上数据极端值（MVRV、SOPR、NUPL 等）

**注意**：没有任何单一指标是万能的，必须多维度交叉确认。
方向改变必须等**多个重要转折信号共振**，绝不能因为短期波动就轻易反手。

### 3. 六维评分同等重要原则

Screen1 采用六维加权评分（权重来自系统回测验证，非主观设定）：

| 维度 | 权重 | 说明 |
|:---|:---|:---|
| 技术指标 | 40% | MA200、MACD、RSI、ADX、量价等 |
| 减半周期 | 15% | 减半后时间、历史周期位置 |
| 矿工经济 | 15% | 算力、难度、矿工盈亏、哈希价格 |
| 链上估值 | 15% | MVRV、NUPL、SOPR、Realized Price |
| 宏观金融 | 10% | 美元指数、利率、通胀、流动性 |
| 跨市场联动 | 5% | 美股、黄金、风险偏好、相关性 |

**权重来源**：6-TRADING 系统回测验证的标准配置，非主观臆断。

### 4. 三屏共振原则

开仓必须三屏基本同向，矛盾时以 Screen1（战略层）为准：

| 屏幕 | 周期 | 作用 |
|:---|:---|:---|
| **Screen1** | 周线/月线 | 战略方向判断（六维评分） |
| **Screen2** | 日线 | 战术入场时机（V9 马丁预设） |
| **Screen3** | 4h/日内 | 执行层监控 + A6情报 |

**方向以 Screen1 为主，Screen2/3 只做确认和时机选择，不改变大方向。**

### 5. 参数自适应原则（重要）

**V9 马丁的 8% 加仓间距、4% 止盈等参数是 BTC 基准值，不是所有币种通用。**

不同标的波动率差异巨大，参数必须根据标的波动率同比缩放：

| 标的类型 | 波动率对比 | vol_mult 范围 | 加仓间距示例 | 止盈示例 |
|:---|:---|:---|:---|:---|
| BTC（基准） | 1x | 1.0 | 8% | 4% |
| ETH / 主流币 | 1.2-1.5x | 1.2-1.5 | 9.6-12% | 4.8-6% |
| 中小市值价值币 | 2-4x | 2.0-4.0 | 16-32% | 8-16% |
| 低波动标的（黄金等） | 0.2-0.5x | 0.2-0.5 | 1.6-4% | 0.8-2% |

**参数计算原则**：
- 以 BTC 的 ATR 或历史波动率为基准（vol = 1.0）
- 目标标的波动率 / BTC波动率 = vol_scale
- 加仓间距 = 8% × vol_scale
- 止盈 = 4% × vol_scale
- 最大加仓层数保持 3 层不变（风险控制）
- 首仓比例根据市值/流动性调整，小币首仓更小

**为什么重要**：
- 小币如果用 BTC 的参数，可能一天内就把所有加仓层打满
- 低波动标的如果用 BTC 参数，可能永远碰不到止盈
- 参数必须与波动率匹配，马丁策略才能有效发挥作用

### 6. 跨市场选优原则

**交易的目标是赚钱，不是只做数字货币。哪里有更高投资价值，就去哪里。**

工具基础：OKX CLI 支持多种市场（具体以 OKX 支持为准）：
- 加密货币（BTC、ETH、SOL 等）
- 传统金融（指数、股票等，取决于平台支持）
- 大宗商品（黄金、原油等，取决于平台支持）

选优逻辑：
- 对多个候选标的进行 Screen1 六维评分
- 选择评分最高、确认度最高、风险收益比最优的标的
- 不局限于加密货币，只要 OKX CLI 能交易的都在选池内
- 与 Agent A / Agent B 理念一致：哪里有机会就去哪里

**当前候选币种（v1.0）**：

| 币种 | 类型 | 典型 vol_mult | 说明 |
|:---|:---|:---|:---|
| BTC | 大盘基准 | 1.0 | 六维全评分，波动率基准 |
| ETH | 主流币 | 1.2-1.5 | 以太坊，仅次于BTC |
| SOL | 主流币 | 1.4-1.8 | Solana，高波动 |
| UNI | 价值小币 | 1.8-2.2 | DeFi龙头，波动率偏高 |
| HYPE | 价值小币 | 1.5-2.0 | 热门小币，波动率高 |

**非BTC币种评分维度**：
- 技术指标：65%（权重放大，弥补链上/周期/矿工缺失）
- 宏观金融：20%
- 跨市场联动：15%
- 链上/周期/矿工：不适用（权重为0）

**注意**：
- 不同市场的评分维度需要适配（比如股票没有链上数据，需要替换为基本面维度）
- 当前版本以加密货币为主，跨市场能力为扩展方向
- 每次巡检扫描全部候选币种，自动择优入场

## 二、Screen1 — 战略层（六维评分）

**核心问题：现在是牛市还是熊市？该不该入场？**

评分规则：
- 0-30 分：**强熊市** → 只考虑做空或空仓
- 30-50 分：**弱熊市** → 偏空，谨慎试探空单
- 50-70 分：**中性/震荡** → 观望为主，不轻易动手
- 70-100 分：**强牛市** → 考虑做多

**Screen1 结果在一周内不会轻易改变，除非多个大级别转折信号共振出现。**

---

## 三、Screen2 — 战术层（V9 马丁预设）

**核心问题：如果入场，在哪里入场？马丁层级怎么设？**

输入：Screen1 方向 + A1日报
输出：V9 马丁预设价位表

关键参数（V9 基线）：
- 加仓间距：8% × vol_mult
- 止盈：4% × vol_mult
- 最大加仓：3 次（共 4 层）
- 首仓比例：5% 权益

vol_mult 动态调整：
- 强趋势（高确认）：vol_mult 上调（最高 2.0）→ 间距宽，止盈高
- 震荡/低确认：vol_mult 下调（最低 0.3）→ 间距窄，止盈低

**Screen2 不改变 Screen1 的方向，只决定入场价位和节奏。**

---

## 四、Screen3 — 执行层（持仓监控 + A6情报）

**核心问题：现在该加仓吗？该止盈吗？有风险吗？**

监控内容：
- 实时持仓状态（方向、大小、浮盈浮亏）
- 马丁层级进度（第几层，还剩几层）
- A6 情报更新（P0/P1/P2 告警）
- 资金费率变化

执行规则：
- 加仓：价格触达预设价位 → 自动加仓
- 止盈：价格到达止盈价 → 全部平仓
- 风险：A6 出现 P0 告警 → 禁止开新仓，考虑是否提前减仓
- 不加仓：方向与 Screen1 矛盾时，即使触达价位也不加仓

## 五、研报参考体系

| 研报 | 对应屏幕 | 更新频率 | 作用 |
|:---|:---|:---|:---|
| **周报** | Screen1 | 每周一 | 校准战略方向，周线级别判断 |
| **A1日报** | Screen2 | 每日 | 确认战术信号，日线级别 |
| **A6情报** | Screen3 | 每 4h | 监控风险，执行层参考 |

研报使用原则：
- 研报是**参考**，不是指令
- 研报与 Screen1 矛盾时，以 Screen1（六维评分硬指标）为准
- 研报全部同向 → 提高置信度，可加大仓位
- 研报相互矛盾 → 降低置信度，观望或极小仓位

## 六、开仓决策流程

```
开始
  ↓
Screen1 六维评分 → 得出大方向（BULL/BEAR/NEUTRAL）
  ↓
  ├─ NEUTRAL（40-60分） → 观望，不开仓 ─→ 结束
  │
  └─ 有方向 → 进入下一判断
       ↓
  A6有无P0告警？
       ↓
  ├─ 有 → 观望，禁止开仓 ─→ 结束
  │
  └─ 无 → 继续
       ↓
  三屏 + 研报 综合置信度 ≥ 70%？
       ↓
  ├─ 否 → 观望，不开仓 ─→ 结束
  │
  └─ 是 → 开首仓（5%权益）
            ↓
         进入马丁循环（加仓→止盈）
```

**关键门槛：置信度 ≥ 70% 才开仓。**
低于 70% 一律观望，不做"试试"、"碰碰运气"的交易。

## 七、马丁执行规则

### 加仓规则
- 价格到达预设加仓价位 → 等额加仓
- 方向与 Screen1 矛盾时 → 不加仓（即使到价位也不加）
- 达到最大加仓层数（3次）→ 停止加仓，耐心等止盈

### 止盈规则
- 价格到达止盈价 → 全部平仓，一轮完成
- 止盈后不立即反手，等待下一个高确认度机会

### 无止损！重要提醒
- 马丁策略**没有止损**，靠加仓摊平成本
- 风险控制靠：方向判断 + 仓位管理 + 不轻易出手
- 如果大方向判断错误（比如把熊市当成牛市），马丁会越套越深
- **这就是为什么 Screen1 必须准确，为什么不轻易开仓的原因**

---

## 八、风险控制体系

### 第一层：方向风控（Screen1）
- 六维评分正确 → 大方向不错，马丁只是时间问题
- 评分在中性区不操作 → 避免假突破

### 第二层：仓位风控
- 首仓 5%，最大总仓位 ≤ 25% 权益
- 即使 4 层全加满，也只用 20-25% 资金
- 剩下 75% 是安全垫，极端情况也能扛住

### 第三层：信号风控
- P0 告警不开仓
- 研报矛盾不开仓
- 置信度不足不开仓

### 第四层：时间风控
- 持仓时间过长（>7天）且未到止盈 → 评估是否方向判断错误
- 方向错误 → 止损出局（虽然马丁无止损，但极端情况必须砍）

## 九、自我进化记录

每次交易完成后记录：
- 方向判断是否正确
- 马丁层数（用了几层）
- 实际收益率 vs 预期
- 最大浮亏（压力测试）
- 教训总结

**目标：不断提高 Screen1 的方向判断准确率，这是马丁策略的生命线。**

## 十、快速决策检查表

开仓前问自己 5 个问题：

1. **Screen1 几分？** — < 30 或 > 70 才考虑
2. **有 P0 告警吗？** — 有就别动
3. **三屏共振吗？** — 至少两屏同向
4. **研报一致吗？** — 研报矛盾就降权
5. **置信度 ≥ 70% 吗？** — 不够就等

**5 个问题全部 "是" → 可以开仓。任何一个 "否" → 观望。**
