## 架构总览（三大闭环）

```
🔵 执行环 (Execution Loop)  — 正向决策链
   A1 → A2 → A3 → A4 → A5 → A9
   └ A0矛盾Skill内置于A1/A2/A3，不独立调用

🟠 情报环 (Intelligence Loop) — A6每1H运行，5级放射驱动
   L0致命 → A9离场
   L1高   → A4重新验证
   L1.5变 → A2增量更新
   L2中   → 观察
   L3背离 → A1+A3重启

🟣 治理环 (Governance Loop) — A9离场后触发
   A9→A7(实践记录)→A8(知行合一)→gap_score路由→A1/A2/A3修正
   gap高(>0.5) → A1重启  |  gap中(0.3-0.5) → A2更新  |  gap低(<0.3) → A3优化
```

## 二、情报环节点（A6中枢，每1H）

| 触发级别 | 条件 | 驱动目标 | 执行链 |
|----------|------|---------|--------|
| **L0 致命** | 风险事件/黑天鹅/强平风险 | A9立即离场 | A9→A7→A8→A1/A2/A3 |
| **L1 高** | 重大变化/A4验证失败 | A4重新验证 | A4→A5→A9→... |
| **L1.5 变** | Regime切换/趋势反转 | A2增量更新 | A2→A3→A4→A5→... |
| **L2 中** | 异常信号/轻度变化 | 观察记录 | 记录，不触发 |
| **L3 背离** | 理论与实践背离 | A1+A3重启 | A1→A2→A3→A4→A5→... |

**A6 检测维度（零Token，API读取）**：
- 市场状态变化：Regime切换、24H波动率 > 5%
- 价格异动：持仓标的 1H 变动 > 2%（含持仓方向）
- 资金费率突变：变化幅度 > 0.01%/小时
- 宏观事件：Tavily检测（每日1次，有成本）

- 0.5-0.7：中度背离 → A3优化
- < 0.5：严重背离 → A1/A2重启

## 八-B、治理环节点（自我进化的理论-实践闭环）

> ⚠️ 治理环不是监控，是学习进化的驱动引擎
> A9离场后自动触发，gap_score路由到不同修正深度

| 节点 | SKILL | 触发条件 | 功能 | Token成本 |
|------|-------|----------|------|-----------|
| **A7实践记录** | A7-practice-theory | A9离场后立即 | 记录执行过程、提炼经验教训 | 低 |
| **A8知行合一** | A8-theory-practice-verification | A7完成后/每日14:00 | 批判性分析、gap_score计算 | 中 |
| **A1修正** | dream-strategy-research | gap_score > 0.5 | 重启深度调研，修正根本判断 | 高 |
| **A2更新** | dream-first-principles | gap 0.3-0.5 | 增量更新分析框架 | 中 |
| **A3优化** | master-seminar | gap < 0.3 | 策略微调 | 低 |
| **Lesson提炼** | learning-lesson-distiller | A8完成后 | 将episode→可操作规则 | 低 |
| **Proposal生成** | learning-proposal-generator | 重大背离时 | 生成改进提案 | 中 |

**gap_score 路由规则**：
```
0.9-1.0：知行合一 → 继续（不触发修正）
0.7-0.9：轻微背离 → Lesson记录
0.5-0.7：中度背离 → A3优化策略
0.3-0.5：较大背离 → A2更新分析
< 0.3：  严重背离 → A1重启调研（含做梦部辅助）
```

**治理环预算控制**（每次A9离场后）：
- 标准治理（gap < 0.5）：≤ 2,000 tokens（A7+A8+Lesson）
- 深度治理（gap ≥ 0.5）：≤ 5,000 tokens（A7+A8+A1/A2+做梦部）
