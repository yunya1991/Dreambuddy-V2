> 演讲时长：约20分钟（含 Q&A 约40分钟）
> 目标听众：投资人（非技术背景）
> 核心主题：AI 与传统金融融合的历史性机遇

---

## 【开场 · 约1分钟】

各位投资人，大家好。

今天我想用 20 分钟，和大家聊一个正在发生的结构性机会——**AI 和传统金融的融合，正在催生一个全新的金融基础设施**。

我会讲八个部分：为什么做这个、我们的解决方案、市场有多大、做到哪一步了、怎么赚钱、为什么是我们、我们的竞争优势，以及我们需要什么。

## 【第一部分 · 我们为什么做这个 · 约3分钟】

说实话，我们做这个项目的出发点，不是什么宏大的愿景，就是一个很简单的原因——**我自己在用这些工具的时候，觉得特别别扭。**

我是做区块链和交易出身的，每天面对大量信息和决策。我发现现有的工具，每一个单独看都不错，但拼在一起用，到处都是断层：

- **用 AI 分析币价**，信息总是旧的——引用的是几个月前的数据；
- **看媒体新闻**，缺乏数据支撑——消息对市场影响多大，没人告诉我；
- **看数据网站**，又多得没有重点——不知道该看哪个；
- **用交易所工具**，功能太多但没人指引——全靠自己摸索。

还有一个更烦人的问题：**AI 永远不记得我。** 每次聊天都要从头讲一遍我的交易偏好、风险承受能力、对某些币种的看法。它没有记忆，没有经验复盘。

但我自己又很懒。懒得每次重讲，也懒得自己做复盘笔记。

所以我就想：**能不能有一个系统，既懂我，又懂市场，还能把信息、数据、决策、执行串起来？**

这个想法，就是我们做这个项目的出发点。

## 【第二部分 · 我们的解决方案 · 约4分钟】

### 2.1 大模型只有"脑子"，缺了真正能干活的部件

现在的大模型很聪明，但放到金融决策场景里，它只有"脑子"，没有"手脚"、"记忆"和"经验"。

打个比方，它就像一个智商 160、刚毕业的学生——会推理，但没有行业知识、没有实时数据、没有过往经验，也没法自己执行交易。

一个真正能赚钱的交易员，需要六样东西：

| 能力 | 对应系统部件 |
|------|------------|
| 脑子（推理） | 大模型 |
| 书本（知识） | 知识库 |
| 档案柜（数据） | 数据库 |
| 经验（直觉） | 认知记忆系统 |
| 手脚（执行） | 交易执行系统 |
| 目录（索引） | 索引系统 |

**现在 99% 的 AI 应用只有第一样。我们的系统，六样全有。**

### 2.2 我们的金字塔架构

我们的整体架构是一个金字塔，分四层：

```
┌─────────────────────────────────────────┐
│   应用层：媒体 · 数据 · 投研 · 交易        │  ← 面向用户
├─────────────────────────────────────────┤
│   DreamOS 金融操作系统（我们的核心壁垒）    │
│   知识库 · 数据库 · 认知经验 · 索引系统    │
│   策略层 · 风控层 · 执行层                │
├─────────────────────────────────────────┤
│   DeepSeek Harness（通用 Agent 底座）      │  ← 2026年8月刚发布
├─────────────────────────────────────────┤
│   大模型层（DeepSeek V4 / 兼容多模型）     │
└─────────────────────────────────────────┘
```

**底层**是大模型 + DeepSeek Harness。Harness 是 DeepSeek 今年 8 月刚开源的通用 Agent 底座，解决了模型调度、工具调用这些通用问题。虽然还是预览版，但它给了所有人一个均等的起跑线——传统金融机构那些跑了十几年的成熟系统，在新技术面前反而成了负担，它们不敢换；而我们没有包袱，可以直接用最新的。

**中间层 DreamOS** 是我们的核心。建在 Harness 之上，专门解决金融场景的问题——知识库、数据库、认知经验、索引系统，加上策略、风控、执行层。打个比方，Harness 是"水电煤管道"，DreamOS 是管道上盖起来的"金融大厦"。

**最上层**是面向用户的产品：媒体、数据、投研、交易。

**一句话总结：大模型是发动机，Harness 是传动系统，DreamOS 是整车，应用层是座舱。我们不造发动机，我们造最懂金融的那辆车。**

## 【第三部分 · 市场有多大 · 约4分钟】

### 3.1 一个正在发生的历史级融合

这几年，美国在做一件非常重要的事：**把传统金融和区块链打通。**

- **2024 年比特币现货 ETF 通过**——贝莱德、富达把比特币放进了普通投资者的养老金账户；
- **稳定币立法推进**——USDC、USDT 正在纳入金融监管体系；
- **RWA（真实资产代币化）兴起**——贝莱德 CEO 说"下一代金融的基石是代币化"；
- **CME 比特币期货交易量已超过现货市场**。

历史上每一次金融基础设施的大融合，都会诞生巨头：券商线上化诞生了嘉信理财，交易电子化诞生了骑士资本，资管被动化诞生了贝莱德。**这一次，传统金融和区块链的融合，会诞生下一批巨头。**

### 3.2 市场规模（自下而上估算）

我们用自下而上的方式估算市场（具体数字待确认）：

- **TAM（总潜在市场）**：全球加密资产管理规模约 X 万亿美元 + AI 金融工具市场约 Y 亿美元
- **SAM（可服务市场）**：其中专业交易者和机构客户，愿意为 AI 投研和执行工具付费的市场，约 Z 亿美元
- **SOM（可获取市场）**：我们前 3 年能获取的部分，约 W 亿美元

### 3.3 竞争格局

我们用两个维度看竞争：**通用 AI vs 垂直金融**，**纯数据 vs 智能决策**。

| | 纯数据/资讯 | 智能决策/执行 |
|---|---|---|
| **通用 AI** |  ChatGPT、Claude | 通用 Agent（无金融深度） |
| **垂直金融** | 彭博、Wind、CoinGecko | **我们（DreamOS）** |

- 彭博、Wind 强在数据，但缺乏 AI 整合和自动执行；
- 通用 AI 强在推理，但不懂金融规则、没有实时数据、没法执行；
- **我们的位置：垂直金融 + 智能决策，这是目前的空白地带。**

## 【第五部分 · 我们怎么赚钱 · 约3分钟】

我们的商业模式是**两条腿走路**，相辅相成：

### 第一条线：面向市场的通用工具

在 AI 赋能下，传统的金融媒体、数据网站、投研服务会被整合为一个入口。我们做的就是这个**整合入口**——DreamOS。

- 数据服务（行情、链上、财务）
- 媒体与资讯（AI 摘要、深度分析）
- 投研工具（策略回测、信号生成、组合管理）

对 C 端订阅收费、对 B 端按 API 调用或机构版收费。

### 第二条线：自有基金管理

这是更深层能力的延伸，也是对外能力不断增强的基石。

打个比方：我们对外卖"金融操作系统"，同时自己也在用这个系统管钱。**最好的产品，一定是自己天天在用的产品。** 就像万方量化——先把自己的策略跑通赚到钱，再对外提供服务。

**两条线互相增强**：自有基金验证系统有效性，对外服务提供现金流和更多数据反馈。

## 【第六部分 · 为什么是我们 · 约2分钟】

### 我们的核心优势

**第一，行业基因。** 我们深耕区块链多年，既懂 AI，又懂金融，还懂区块链。这种交叉能力是稀缺的——通用 AI 团队不懂金融规则，传统金融团队不懂 AI 工程，区块链团队不懂 TradFi。而我们三者都懂。

**第二，轻装上阵。** DeepSeek Harness 刚发布，所有人同一起跑线。传统金融机构背着十几年的旧系统不敢换，我们没有历史包袱，可以直接用最新技术。**在 AI 这个全新赛道上，轻，就是快。**

**第三，闭环验证。** 我们的系统已经在实盘运行，自有基金在用。这意味着我们的每一次迭代，都有真实交易数据验证，不是闭门造车。

## 【第七部分 · 我们的竞争壁垒 · 约1分钟】

我们的护城河有三层：

1. **交易经验壁垒**：核心团队深耕区块链交易多年，这些真实的交易经验、踩过的坑、验证过的策略，已经沉淀进系统的认知记忆库——不是通用 AI 公司靠调 API 就能快速补齐的；
2. **认知进化壁垒**：系统从每笔实盘交易中学习，策略和风控规则持续进化，越用越聪明。这种"边交易边进化"的闭环，需要真实交易场景才能跑通；
3. **执行闭环壁垒**：从分析到下单的完整链路，包含自研的风控、止损、仓位管理——这需要时间和真金白银砸出来，不是通用 AI 公司能快速补齐的。

**坦白说，我们的数据积累还不够多，这是我们正在补的课。但我们的交易经验是真实的，而且系统每天都在实盘中积累新的数据和经验——这是一个正向循环。**

### 附录 F：投资人 Q&A 准备

**Q1：你们和彭博、Wind 有什么区别？**

A：彭博、Wind 是"数据终端"，我们是"智能操作系统"。彭博给你数据，我们给你"已经分析好、可以直接执行"的结论。就像从"查字典"升级到"有一个 24 小时在线的首席分析师"。

**Q2：大模型公司自己做金融怎么办？**

A：大模型公司是通用能力，金融是垂直领域。就像苹果不会自己做所有 App 一样，大模型公司不会深入到每一个垂直场景的细节里。而金融场景的细节（规则、数据、风控、执行），恰恰是最深的护城河。

**Q3：DeepSeek Harness 还不成熟，风险怎么办？**

A：这是事实，我们不回避。但正因为它刚出来，所有人才在同一起跑线。而且我们的架构设计了多模型兼容能力，如果 Harness 发展不及预期，我们可以切换到其他框架。风险可控。

**Q4：你们的核心壁垒是什么？**

A：三层壁垒。第一层是交易经验——核心团队多年真实交易经验已沉淀进认知记忆库，通用 AI 公司靠调 API 补不齐；第二层是认知进化——系统从每笔实盘交易中学习，越用越聪明；第三层是执行闭环——从分析到下单的完整链路，需要时间和真金白银砸出来。

**Q5：为什么自有基金和对外服务不冲突？**

A：恰恰相反，是互相增强。自有基金验证系统有效性，对外服务提供现金流和更多数据反馈。就像赛百味自己开餐厅验证模式，然后再开放加盟。

**Q6：监管风险怎么应对？**

A：我们密切关注各国政策，优先在合规市场运营。稳定币立法和 ETF 通过说明监管在走向清晰，这对我们是利好而非利空。
