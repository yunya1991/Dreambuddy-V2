# 链上估值理论

## 核心指标

### MVRV Z-Score
- 公式：(市值 - 实现值) / 市值标准差
- ETF时代重新校准：旧阈值 7+ → 新阈值 3.5+
- 当前 ~1 → 低估区域
- 峰值仅 3.5（前几轮 7-12），"亢奋信号"从未出现

### NUPL (Net Unrealized Profit/Loss)
- 情绪周期：Capitulation(<0) → Hope → Optimism → Belief → Euphoria(>0.75)
- 当前 ~22.9 → Hope/Fear边界 → 底部积累阶段
- Q1 2026: Fear；Q2: 回升至 Optimism

### RHODL Ratio
- 1周持币者 / 1-2年持币者 实现价值比
- 当前 4.5 — 仅次于 2015底(5.0) 和 2022底(7.0)
- >4 = 投机者被清洗，长期持有者主导 = 强底部信号

### STH vs LTH 成本
- STH(<155天) 成本 ~$97K → 水下24%
- LTH(>155天) 成本 ~$35K → 盈利110%
- 实现价格(全体平均) ~$61K → BTC $73.5K高于此20%

## 本轮核心矛盾

MVRV说"没到顶" vs 价格结构说"跌了40%+"
RHODL说"底部结构" vs STH成本$97K形成天花板
→ 这是ETF时代第一个"结构性调整"：机构托底，但恢复缓慢
