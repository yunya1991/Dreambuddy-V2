# Screen1 七维牛熊评分架构 v2.0

## 设计原则

- **MA200 为牛熊基线**，月线 RSI+MACD 为早期预警，其余维度做校准
- **更早识别优先**，不确定则回退基线
- 技术指标牛熊检测器为独立模块，只输出方向锚，不占权重分

---

## 一、技术指标牛熊检测器（独立模块）

### 结构

```
第一层：MA200 基线（唯一方向锚）
  价格连续3日收盘 > MA200  →  BULL
  价格连续3日收盘 < MA200  →  BEAR
  价格在 MA200 附近震荡    →  NEUTRAL

第二层：动量预警（只在锚的方向上叠加）
  BULL锚时: 月线RSI<30(+2), Fear<25(+1), 月线MACD金叉(+2)
  BEAR锚时: 月线RSI>70(+2), 月线MACD死叉(+2)

第三层：辅助验证（可信度乘数，不改变方向）
  周线Stoch: 同向×1.2, 矛盾×0.8
  ADX>25: ×1.0, ADX<20: ×0.5
  OBV同向: ×1.0, OBV背离: ×0.7
  CMF同向: ×1.1, CMF矛盾: ×0.9

输出: BULL / BEAR / NEUTRAL（作为Screen1其他维度的方向锚）
```

### 关键设计约束

- MA200 是唯一方向锚——动量指标永远不能翻转 MA200 给出的方向
- RSI>70 在 BULL 锚下 → 不转空，只弱化信号
- RSI<30 在 BEAR 锚下 → 不转多，只弱化信号

## 二、指标时序对比（顶部 vs 底部优势）

| 指标 | 顶部平均偏差 | 底部平均偏差 | 分类 |
|------|------------|------------|------|
| **月线 RSI** | **-1.0月（提前）** | 同步 | **顶部优势** |
| 月线 MACD | +1.3月 | +2.0月 | 确认指标 |
| MA200 三日 | +3.7月 | **+2.0月（最稳）** | **底部优势** |
| 周线 Stoch | ~同步 | ~同步 | 辅助 |
| BTC Dominance | -0.5月 | +0.5月 | 辅助 |
| **Coppock Curve** | +6.8月 | +7.0月 | **排除** |

**结论：顶部靠月线RSI提前预警，底部靠MA200坚实确认。Coppock太慢不适合加密。**

## 三、七维评分体系

### 维度1：MA200基线 + 经典TA早警（权重 40）

```
基线信号 = MA200三日方向锚 (不占分，作为方向底)

动量预警 (在锚的方向上累加):
  月线RSI>70: BEAR+2 | 月线RSI<30: BULL+2
  月线MACD死叉: BEAR+2 | 月线MACD金叉: BULL+2
  Fear&Greed<25: BULL+1

辅助验证 (可信度乘数):
  ADX>25 ×1.0 | ADX<20 ×0.5
  OBV同向 ×1.0 | OBV背离 ×0.7
```

### 维度2：减半库存周期（权重 15）

| 周期阶段 | 分数 | BTC Kitchin 周期映射 |
|---------|------|---------------------|
| 减半后0-6月 | +15 | 供给冲击初期，矿工出清 |
| 减半后6-12月 | +10 | 价格发现期，S2F翻倍 |
| 减半后12-18月 | +5 | 顶部窗口 |
| 减半后18-24月 | -10 | 熊市确认 |
| 减半后24月+ | -15 | 去库存期（当前） |
| 减半前6月 | +5 | 积累期 |

**四次减半数据：**

| 减半 | 日期 | 见顶天数 | 涨幅 |
|------|------|---------|------|
| 2012 | 2012-11-28 | 367天 | ~97x |
| 2016 | 2016-07-09 | 526天 | ~30x |
| 2020 | 2020-05-11 | 548天 | ~7.8x |
| 2024 | 2024-04-20 | 547天 | ~1.94x |

递减规律：每个周期涨幅递减（97x→30x→7.8x→1.94x），因为市值基数指数增长 + ETF 改变价格形成机制。

| BTC形态 | 加密原生 | 代币化美股 | 代币化板块 |

### 代币化美股特殊参数（区别加密原生）

| 参数 | 加密原生 | 代币化美股 |
|------|---------|-----------|
| vol_mult | 1.0-1.75 | 0.6 |
| 加仓间隔 | 8%×vol_mult | 8%×0.6=4.8% |
| 止盈 | 4%×vol_mult | 4%×0.6=2.4% |
| 最大加仓 | 3次 | 2次 |
| 标的 | BTC,ETH,SOL | TSLA,NVDA,AAPL,SPY |
