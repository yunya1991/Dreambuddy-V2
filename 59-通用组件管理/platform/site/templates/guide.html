使用说明

从下载、安装到体检上架，整个流程只需四步。

第 1 步

下载

登录 SkillHub 控制台，在已购/已授权列表下载组件包。

第 2 步

安装

解压到宿主 Skill 目录，保持包内 SKILL.md 与脚本的相对结构不变。

第 3 步

体检

在 免费体检 页上传包或粘贴 SKILL.md，按报告修复阻断项。

第 4 步

上架

体检通过后回控制台提交上架，收费型 Skill 需补齐计费声明与验付配置。

安装与验证

以下路径以常见本地 Skill 目录为例，按你的宿主实际目录替换。

# 1) 解压到 skill 目录
unzip <组件包>.zip -d ~/.skills/

# 2) 确认结构（SKILL.md 必须在包根目录）
ls ~/.skills/<组件名>/SKILL.md

# 3) 认知管家：跑一次工作区体检
python3 ~/.skills/cogsteward/scripts/cm_cli.py scan
python3 ~/.skills/cogsteward/scripts/cm_cli.py index --check

# 4) 数据服务：按资源调用（示例：宏观序列 DGS10）
curl -sS -X POST http://127.0.0.1:8788/api/data \
  -H 'Content-Type: application/json' \
  -H 'Payment-Proof: <已支付凭证>' \
  -d '{"skill":"market-data-pro","cmd":"macro","params":{"series":"DGS10"}}'

常见问题

体检报告说泄露了本机路径

把 /Users/xxx、/home/xxx 换为 ~ 或相对路径，脚本内读取路径改为参数传入。

提示存在阻断项还能上架吗

不能。阻断项对应平台硬性规则，修复重新体检直到结论为「通过」。

免费额度用完怎么办

按次付费获取完整报告；或在控制台订阅后使用已授权组件，额度按账号计算。

付费接口返回 402

这是预期协议：先按返回的订单号完成支付，再用同一 Payment-Proof 重试，服务会自动取回已完成的结果，不会重复扣费。

边界与安全

组件只依赖 contracts/ 声明的对外契约，禁止反向引用交易域私有 Schema、绝对路径与内部数据； 凭据一律从环境变量读取，不写入仓库、不打印到日志。安装后若发现组件尝试访问未声明的外部服务，请立即停用并在控制台反馈。
