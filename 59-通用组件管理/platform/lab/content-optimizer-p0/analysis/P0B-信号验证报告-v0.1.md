### 1.4 因变量标准化

- 同 platform × query 内百分位（0–100，平均秩）：`pct = 100 × (avg_rank − 1) / (n − 1)`。

### 1.5 特征与统计

| 特征 | 口径 |
|---|---|
| `title_len` | CSV 值；缺失时由 title 字符数派生；占位标题行置空 |
| `hashtag_count` | CSV 值；缺失时数 title 中 `#话题` 数量；占位标题行置空 |
| `body_len` | 仅 CSV 值，缺失即不可用 |
| `publish_hour` | 仅 CSV 值（小红书仅 21 点，常量） |
| `rank` | 同 platform × query 内按 CSV 行序 1..n（不可控，不参与 G2 计数） |

- Spearman rho（自实现，并列取平均秩）、bootstrap 1000 次百分位 95% CI、置换 1000 次得 p 值、BH FDR（同 platform × 同目标、含负对照为一个家族）。
- 有效样本阈值：非空样本 <20 或二值单类为空 → `insufficient`。
- G2 的 out-of-sample 操作化：按 `collected_at + 行序` 70/30 切分，留出集 rho 需 `abs(rho) ≥ 0.20` 且与全样本同号。
- 「可控特征」= 排除 `rank` 与负对照后的特征。

## 5 局限性

1. **样本量不足**：去重后公开样本 137 < 300，自有样本 0 < 30，G1 结构性不达标。
2. **单一时间窗**：`collected_at` 全为 2026-11-24，无法做第二时间窗复现（G5 失败）。
3. **排名层仍不完整**：抖音已覆盖 `1-10` / `11-30` / `31-50` 三层，小红书仍全为 `1-10`，跨平台对照不齐。
4. **主目标无可用样本**：去重后小红书 engagement 仅 19（<20 阈值），抖音 0；G2 在客观上无检验对象。
5. **抖音可用字段偏窄**：`likes` 可用 82/103，但 `saves/comments/body_len/publish_hour` 全缺，只能做 likes 敏感性分析。
6. **百分位标准化引入组内依赖**：同 query 内百分位使样本不独立，置换 p 值偏乐观；小红书 engagement 有 3 组退化到平台级。
7. **二值特征极端不平衡**：`pattern_benefit` / `pattern_emotion` 正例仅 1–2 条（小红书），抖音虽提升到 7/5 条，仍偏小。
8. **`title_pattern` 标注与正则不一致**：小红书 12/34，抖音同样存在偏差，未与人工标注校准。
9. **未做多变量模型**：样本量不支撑 ≤8 特征建模，本报告只做单变量。
10. **交互代理不是曝光指标**：公开样本无曝光分母，engagement 不能解释为 CTR 或完播率。

**本次补样只解决可采集性缺口（抖音条数与排名分层），无法修复结构性缺口（小红书无排名分层、无自有样本、无第二时间窗）。** 即使样本继续扩大到 300，时间窗与自有账号两项短板仍会让 G1/G5 无法达标。

## 6 门禁判定与理由

| 门禁 | 判定 | 依据（脚本输出） |
|---|---|---|
| G0 通道可行 | **PASS** | 去重后 34/103 条，两平台均 ≥30；适用覆盖 81.7% ≥70%、63.4% ≥40%；未改生产代码 |
| G1 数据充足 | **FAIL** | 去重后公开 137 < 300；自有 0 < 30；关键字段缺失最高 36.73% ≥30%；原始重复率 21.71%（去重后 0%） |
| G2 信号存在 | **FAIL** | 可控特征达标数 0（需 ≥2）；主目标无任何可检验特征（小红书 n=19<20、抖音 n=0）；likes 侧最接近的抖音 title_len q=0.3866 > 0.10 |
| G3 可行动 | **FAIL** | 无通过 G2 的可控特征，不存在确定性改写规则（严格口径） |
| G4 合规 | **PASS** | `collection_log.jsonl` 4 条记录，违规 0；1 条 timeout 属通道异常 |
| G5 可复现 | **FAIL** | 仅单日单批样本，无第二时间窗/独立赛道复现 |

**判定：`No-Go`。** 理由（与 `go_no_go.json` 的 `verdict_reason` 一致）：

1. G2 未达判据：无 2 个及以上可控特征同时满足 |rho|/CI/q/方向一致率/OOS；主目标在两个平台均无可检验特征。
2. G1 未达标：公开可用样本（去重后）137 < 300；自有样本 0 < 30；关键字段缺失率最高 36.73% ≥ 30%。
3. G5 未通过：仅单日单批快照，无法复现。
4. G0 已恢复通过（抖音 103 ≥ 30），不再构成阻塞；当前瓶颈是 G1 样本量与 G5 时间窗。

补充：按 SPEC §9，「G2 仅有 1 个特征」可给 `Conditional-Go`；本次通过 G2 的可控特征是 **0 个**，连 `Conditional-Go` 的最低条件都不满足，故判定 `No-Go`，不做粉饰。
