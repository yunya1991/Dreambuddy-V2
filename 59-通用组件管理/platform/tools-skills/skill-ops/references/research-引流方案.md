# 免费引流方案（调研 + 设计）

> 调研时间：2026-11-19 ｜ 适用对象：SkillHub 免费 Skill `cogsteward`
> 结论先行：**平台内做"可被检索到"，平台外做"可被转述"。前者决定有没有人看见，后者决定有没有人替你传播。**

---

## 1. 平台机制事实（决定怎么优化）

| 机制 | 事实 | 运营含义 |
|---|---|---|
| 分类体系 | 12 个一级主分类；每个 Skill 归属 1 个一级 + 1–3 个二级类目；另有行业类目 | 二级类目是"能不能被找到"的关键，宁可选准不要选多 |
| 系统标签 | 含"需要 API Key"等标签，回答"我能不能直接用" | 如实标注，降低安装后失望率（影响差评与卸载） |
| 榜单 | 推荐 / 飙升 / 下载 / 最近上新 四种浏览方式 | 新 Skill 先吃"最近上新"，再靠安装与收藏冲"飙升" |
| 精选 | 每月一期的编辑精选 TOP10（TRACE 评测） | 申报与内容质量决定能否入榜，属长期收益 |
| 分发入口 | 搜索、专题合集、大赛、Agent 检索 | 大赛与合集是低成本的额外曝光位 |
| 发布方式 | 网页 / CLI / Agent 三种，版本可追溯 | 迭代内容用 CLI 提版本，成本最低 |

> 来源：腾讯新闻《10万+Skill 背后》、《什么是 SkillHub》（TRACE 月度精选、《SkillHub 首页》榜单模块。

## 2. 平台内四杠杆（按性价比排序）

### 2.1 分类与标签（一次性，收益最长）

- 一级分类：开发者工具 / 效率类（按实际最贴近的选，不要硬蹭热门）
- 二级类目：2 个，覆盖"上下文管理""工作区整理"两类搜索意图
- 标签：`本地运行`、`零依赖`、`不需要 API Key`

**验收**：在分类页按二级类目筛选，第 1 页能出现自己的 Skill。

### 2.2 标题与简介（可迭代，收益立竿见影）

- 标题写"解决什么"，不写技术名词堆砌
- 简介前 60 字必须含：谁、在什么场景、解决什么、怎么验证
- 避免"最强/第一/颠覆"这类词，平台审核与用户信任双输

**验收**：搜索"上下文 治理""工作区 体检""技能 冲突"，至少命中 1 个。

### 2.3 榜单信号（间接，靠真实使用）

榜单按安装与热度排序，无法直接操纵，也不应操纵。可控的只有两件事：

1. 让**第一次使用就成功**（安装后 3 分钟内出体检报告）
2. 让**成功可被看见**（在简介里放一段真实输出样例）

### 2.4 合集 / 大赛 / 精选（低频高杠杆）

- 平台专题合集：按主题投稿，命中一次抵一周自然流量
- 大赛：报名成本低，但注意不要误勾与企业/付费权益冲突的条款
- 月度精选：需要可复现的质量证据（用例、测试、失败边界）

## 3. 平台外渠道对比

| 渠道 | 受众 | 内容形式 | 单篇成本 | 预期 | 风险 |
|---|---|---|---|---|---|
| GitHub 仓库 | 开发者 | README 即落地页 + 可安装命令 | 中 | star→付费 0.5–2%，主要价值是可信度与转介绍 | 需长期维护 issue |
| 公众号 | 已有关系 | 长文案例 + 结尾引导安装 | 中 | 转化最高但涨粉慢 | 更新频率难坚持 |
| 小红书 | 泛职场/效率人群 | 图文 3–6 张，强场景 | 低 | 起号期需高频稳定输出 | 自动批量发会触发风控 |
| 即刻 / 掘金 / V2EX | 开发者与 AI 玩家 | 短帖 + 实测截图 | 低 | 冷启动首个 100 安装常来自这里 | 需要真名实姓的技术表达 |

**取舍**：先做 GitHub（沉淀）+ 小红书（拉新），公众号放在有 3 个真实案例之后。

## 4. 14 天冷启动排期

| 天 | 平台内 | 平台外 | 观测 |
|---|---|---|---|
| D1–D2 | 补分类/标签/简介；放一条输出样例 | 建 GitHub 仓库，README = 安装 + 30 秒演示 | 安装数基线 |
| D3–D5 | 搜索关键词自测，改标题 | 小红书发 2 篇（场景向） | 安装数、收藏数 |
| D6–D7 | 投稿一个专题合集 | 即刻/掘金各 1 帖（实测向） | 首个外部来源 |
| D8–D10 | 按数据改简介前 60 字 | 小红书再发 2 篇（问题向） | 安装转化 |
| D11–D14 | 复盘：哪个入口带来安装 | 选最优渠道加投，停掉无来源渠道 | 渠道 ROI |

**停止条件**：某渠道连续 14 天零新增安装 → 停，把时间移到下一个。

## 5. 三条可直接用的内容公式

1. **场景痛点式**：`我的工作区有 200 个 md，AI 每次都要重新摸一遍 → 我做了个东西先体检再干活` + 体检报告截图
2. **反常识式**：`别人做"记得更多"，我做了个"判断该不该记"` + 四个载体（技能/文档/记忆/会话）示意
3. **可验证式**：`一条命令，30 秒，给你工作区打分` + 完整命令与真实输出
