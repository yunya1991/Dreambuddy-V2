# 每日 / 每周运营清单

> 目标：把"运营"压缩成固定动作，任何一天照做即可，不依赖灵感。

---

## 1. 每日清单（30 分钟）

### D0 采数（10 min）

- [ ] SkillHub 后台 → 我的 Skill：看 `cogsteward` 的下载/收藏/安装
- [ ] SkillPay 后台 → 商品管理：看 `P0806000213874311` 状态（审核中/销售中/被拒）
- [ ] SkillPay 后台 → 订单管理：订单数、销售额、退款
- [ ] 写入 `ops/metrics.csv` 一行；缺失字段写 `null`

```csv
date,sku,exposures,installs,activations,orders,revenue,refunds,note
2026-11-19,cogsteward,null,0,0,null,0,0,审核中
2026-11-19,market-facts-daily,null,0,0,0,0,0,审核中
```

### D1 生产（20 min，三选二）

- [ ] 优化一个商品字段（标题 / 简介前 60 字 / 二级类目 / 标签）
- [ ] 写一条站外内容（3 个公式任选其一，见 `research-引流方案.md §5`）
- [ ] 写一条付费卖点卡（格式见 §3）

### D2 分发（5 min）

- [ ] 发布或提交
- [ ] 记录：渠道、时间、标题、链接

### D3 复盘（5 min）

- [ ] 与 7 日均值对比，写一句带数字的结论
- [ ] 若本周实验到期，写决策（继续/停止/改造）

## 2. 每周清单（周一 40 分钟）

- [ ] 7 日趋势表（安装/激活/订单/收入）
- [ ] 渠道 ROI 排序：每个渠道带来的安装数 ÷ 投入时间
- [ ] 停掉连续 14 天零安装的渠道
- [ ] 定下周唯一主线（只定一个）
- [ ] 检查商品页是否有过期信息（价格、审核状态、失效链接）

### 2.1 同赛道维护（周 30 分钟 + 双周 20 分钟）

- [ ] 从榜单/搜索里挑 1 个竞品，读完它的 SKILL.md
- [ ] 写 1 条"借鉴 / 不借鉴"，必须带理由（哪条指标会因此变化）
- [ ] 双周：跑一次基线对比（首跑成功率 / 首跑耗时 / 诊断准确率 / 周活跃安装）
- [ ] 达标才发版：可复现改进 + 无回归 + 版本号 + CHANGELOG 写"为什么"
- [ ] 发版后第 7 天看复访率，无变化则停止继续追版本

> 细则见 `竞品基线与升级门禁.md`。**禁止为空版本而发版**，也禁止每日发版。

### 3.2 付费卖点卡（一屏内）

```text
市场事实日报 · ¥0.99 买断
输入：标的代码（A股/美股）
输出：1D/5D/20D 涨跌幅、250 日分位、20 日年化波动、250 日最大回撤、60 日均线偏离
```

## 4. 定时任务提示词（每日自动运营）

```text
执行技能：skill-ops 的每日循环。
步骤：
1) 读取 ops/metrics.csv 最近 7 行与两个 SKU 的后台状态（读不到就记 null）；
2) 按 SKILL.md §9 模板生成 ops/YYYY-MM-DD.md；
3) 今日待办必须 3 条，每条带可观测验收标准；
4) 给出 1 条实验建议（假设/变量/指标/窗口）；
5) 若任一商品为"被拒"，优先生成修改清单，其余结论置空。
约束：不得编造数据；不得出现买卖点、目标价、涨跌预测、标的推荐。
```

**降级**：无数据 → 只输出待办与实验建议，并在文件头标注 `数据缺失`。

## 5. 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 一天改多个变量 | 无法归因 | 一天一个 |
| 用"感觉不错"替代数字 | 决策失真 | 写 null，别猜 |
| 免费款藏核心功能 | 差评 + 卸载 | 免费款价值完整 |
| 订阅制做长周期 | 整单全额退，现金流回吐 | 先做买断验证 |
| 自动批量发社媒 | 账号风控 | 人工发布，脚本只做草稿 |
