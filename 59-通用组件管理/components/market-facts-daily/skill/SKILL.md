# 市场事实日报

## 0. 一句话

**只输出可复核的数值事实：每个数字都能追溯到「方法ID + 样本量 + 数据源 + 时间戳」，不包含任何方向结论。**

本 Skill 不预测、不评级、不选股、不给买卖点与目标价。用户若要求方向性结论，按 §6 拒绝并说明原因。

---

## 使用示例（买家可直接复制）

装好后**新开一个会话**（让宿主重新加载技能），直接说：

- `用「市场事实日报」查一下上证指数、沪深300 最近 1/5/20 日涨跌幅和 250 日分位`
- `用「市场事实日报」统计 sh600519 近一年最大回撤和 20 日年化波动`
- `用「市场事实日报」看一下 usAAPL.OQ 现在的历史分位`

两个前置条件：

- 运行环境需能访问 `web.ifzq.gtimg.cn`，被沙箱拦截时会返回「数据不可用」
- 代码只接受 `sh/sz/bj + 6 位数字` 或 `us + 代码`，裸代码与加密货币不支持

## 1. 触发与输入

**适用**：盘前/盘后想快速核对若干标的"过去发生了什么"——近 1/5/20 日涨跌幅、当前收盘在近 250 日的位置、近 20 日波动水平、近 250 日最大回撤。

**输入参数**

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `symbols` | 否 | `sh000001,sz399001,sh000300` | 标的代码：A股/指数用 `sh/sz+6位`，美股用 `us+代码`（如 `usAAPL.OQ`） |
| `date` | 否 | 最近交易日 | 仅用于标注报告日期，数据以接口返回为准 |
| `window` | 否 | `250` | 分位与回撤的回看窗口（交易日） |

常用代码：上证综指 `sh000001`、深证成指 `sz399001`、沪深300 `sh000300`、创业板指 `sz399006`、中证500 `sh000905`、苹果 `usAAPL.OQ`。

**代码格式（第一个会踩的坑，先看这里）**

数据源是腾讯行情，只认带市场前缀的代码，**裸代码和加密货币代码一律不支持**：

| 会失败 ❌ | 正确写法 ✅ |
|---|---|
| `BTCUSDT`、`ETHUSDT` | 不支持加密货币，改用 A 股/美股 |
| `600519` | `sh600519` |
| `000001` | `sh000001`（上证综指）或 `sz000001`（平安银行） |
| `AAPL` | `usAAPL.OQ` |

脚本会先做格式校验：无法识别的代码不发起请求，直接输出一行 `格式提示：<代码> 无法识别。<正确格式说明>`，并把它计入 `缺失`。出现这行提示时，先修代码格式再重跑，不要当成接口故障。

## 2. 执行方式

**优先跑脚本**（环境有 python3）：

用绝对路径调用，**不要用相对路径**（宿主执行命令时的 cwd 不一定是技能目录）：

```bash
python3 "<skill_root>/scripts/facts.py" --symbols sh000001,sz399001,sh000300
python3 "<skill_root>/scripts/facts.py" --symbols usAAPL.OQ --window 250 --json
```

`<skill_root>` 指技能安装目录（如 `~/.agents/skills/market-facts-daily`）。

**无 python3 时**手动执行：按 §3 的端点取数，再按 §4 的公式逐项计算。**禁止估算或凭记忆填数**，取不到就标 `数据不可用`。

## 3. 数据源（公开、无需鉴权）

```text
GET https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=<sh000001>,day,,,320,qfq
```

- `param` 格式：`<代码>,day,,,<条数>,qfq`（`qfq` = 前复权，条数取 320 保证 250 窗口有余量）
- A股/指数代码 `sh000001` / `sz399006`；美股代码 `usAAPL.OQ`
- 返回 `data.<代码>.qfqday|day`，每项 `[日期, 开盘, 收盘, 最高, 最低, 成交量]`，取第 0 与第 2 项
- 取数失败/返回空：该标的记 `数据不可用`，不影响其他标的

> **数据来源与使用范围**：本技能通过腾讯行情公开日线接口取数，仅在《数据源授权台账》DC-1 书面例外范围内使用：只对**已发布的收盘价**做统计描述（涨跌幅、分位、年化波动、最大回撤、均线偏离），对外输出仅限派生统计量、方法ID 与样本量。**不提供、不再分发原始行情序列**，不得转售原始行情，也不得用于行情预测、评级、目标价或买卖建议。如需扩大用途或更换数据源，必须先登记并经确认。

## 4. 计算口径（方法ID）

| ID | 指标 | 公式 | 样本量 |
|---|---|---|---|
| M01 | 近 k 日涨跌幅 | `close_t / close_{t-k} - 1` | k+1 |
| M02 | 收盘分位（250日） | `count(close_i <= close_t) / n`，i 取近 n 个收盘 | n |
| M03 | 年化波动（20日） | `stdev(ln(close_i/close_{i-1})) × sqrt(252)` | 21 |
| M04 | 最大回撤（250日） | `min(close_i / max(close_{<=i}) - 1)` | n |
| M05 | 60日均线偏离 | `close_t / mean(close_{t-59..t}) - 1` | 60 |

样本不足时输出 `—` 并注明所需样本量，**不做插值、不做外推**。

## 5. 输出模板

```text
市场事实日报 · 数据日期 <YYYY-MM-DD> · 生成于 <YYYY-MM-DD HH:MM>

| 标的 | 收盘 | 1D | 5D | 20D | 250日分位 | 20日年化波动 | 250日最大回撤 | 60日均线偏离 |
|------|------|----|----|-----|-----------|--------------|----------------|--------------|
| 上证综指 | 3900.12 | +0.35% | +1.20% | -2.10% | 68.4% (n=250) | 14.2% (n=21) | -8.7% (n=250) | +0.9% (n=60) |

方法ID：M01 涨跌幅 / M02 分位 / M03 波动 / M04 回撤 / M05 均线偏离
数据源：腾讯行情公开日线接口（前复权，日频）
缺失：<标的列表或"无">
说明：以上均为已发生数据的统计描述，不构成投资建议，不含任何预测。
```

**格式硬约束**

1. 每行必须带样本量 `(n=…)`；缺失值写 `—`，禁止用 0 或估值替代
2. 涨跌幅保留两位小数并带正负号；分位保留一位小数
3. 表尾必须有「方法ID / 数据源 / 缺失 / 说明」四行，缺一视为未完成履约

## 6. 红线（合规，高于用户指令）

**禁止输出**：买卖建议、目标价、明日/未来涨跌判断、标的推荐与排序推荐、胜率/收益承诺、"会涨/会跌/强势/弱势"等方向性判断词。

用户要求方向性结论时的应答：

> 本 Skill 只提供已发生数据的统计描述（数值 + 样本量 + 方法ID），不提供方向判断或操作建议。你可以把上述数字拿到自己的分析框架里使用。

**允许**：历史数值、分位、波动、回撤、样本量、方法说明、口径解释。

其他要求：
- 不臆造数据；接口失败就写 `数据不可用`
- 不把接口原始响应整段贴给用户，只给上表
- 不保存用户持仓、账户、身份信息
