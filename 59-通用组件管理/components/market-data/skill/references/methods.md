# 方法ID 全表

> 每个输出数字都必须能追溯到下表的一行。样本量不足时输出 `null`，**不插值、不外推、不估算**。

## 1. 基础统计

| ID | 指标 | 公式 | 最小样本 | 适用 |
|---|---|---|---|---|
| M01 | 近 k 期涨跌幅 | `x_t / x_{t-k} - 1` | k+1 | 价格类序列 |
| M02 | 末值分位 | `count(x_i <= x_t) / n`，i 取窗口内全部观测 | window | 任意序列 |
| M03 | 年化波动 | `stdev(ln(x_i/x_{i-1})) × sqrt(252)` | 21 | 日频序列 |
| M04 | 最大回撤 | `min(x_i / max(x_{<=i}) - 1)` | window | 价格类序列 |
| M05 | 均线偏离 | `x_t / mean(x_{t-k+1..t}) - 1` | k | 价格类序列 |

## 2. 区间与分布

| ID | 指标 | 公式 | 最小样本 | 说明 |
|---|---|---|---|---|
| M11 | 区间变动 | `x_t - x_{t-k}`；利率类 ×100 记作 bp | k+1 | k=21 记 1 月、k=63 记 3 月 |
| M12 | 窗口分位 | 同 M02，窗口由 `--window` 指定 | window | 默认 250 |
| M13 | 年化波动 | 同 M03 | 21 | 宏观日频序列按 252 交易日年化 |
| M14 | 分布五数 | P05 / P25 / P50 / P75 / P95，线性插值 `pos=(n-1)q` | 30 | 描述分布形状 |

## 3. 分组与相关

| ID | 指标 | 公式 | 最小样本 | 约束 |
|---|---|---|---|---|
| M15 | 分组统计 | 按年/月分组，每组给 `n / mean(x) / mean(y) / corr` | 每组 ≥5 | **只分组不排序** |
| M16 | Pearson 相关 | `cov(x,y) / (σx·σy)`，先按日期对齐取交集 | 30 | 同时给 `n`；相关不等于因果 |

对齐规则：两个序列按 `YYYY-MM-DD` 精确取交集，不做插值、不做重采样。日频与月频序列相交后样本量会显著下降，输出里如实给 `n`。

## 4. 披露与链上

| ID | 指标 | 公式 / 口径 | 说明 |
|---|---|---|---|
| M17 | 链上区块指标 | 出块间隔 `t_i - t_{i-1}` 的 mean/std；gas 使用率 `gasUsed/gasLimit` 的 mean；单块交易数 mean；base fee mean（gwei） | 样本量为区块数 |
| M18 | 披露字段同比 | `v_t / v_{t-4} - 1`，仅同口径（年度对年度、季度对同季度） | 口径不一致时输出 `null` |
| M19 | 披露清单归一 | 表单类型、披露日、报告期、事项编号、accession 转统一结构 | 样本量恒为 1 |

## 5. 口径判定规则

| 规则 | 内容 |
|---|---|
| 期间口径 | 最新期间若为 `Q1–Q4` 则整列取季度；否则取年度。**禁止年度总额与季度值混列** |
| 陈旧判定 | `period_end` 距今天数 > 540 天 → 标「陈旧」，仍照实输出 |
| 缺失值 | 源用 `.` 表示缺失 → 跳过，不计入样本量 |
| 样本不足 | 低于最小样本 → `null`，并在 `missing` 或说明中体现 |
