# 合规边界与免责

## 1. 能做什么

- 监控**用户自己账号**可见的余票、号源、可预约时段
- 命中后通知用户，并给出官方页面链接
- 在用户显式签发的一次性 grant 内，跳转到官方下单页并回填目标（P3，且需就绪实验通过）

## 2. 不做什么（硬边界）

| 禁止 | 原因 |
|---|---|
| 代抢、转售、加价 | 违反平台条款，可能触犯法律 |
| 多账号、代理池、验证码破解 | 干扰平台秩序，账号风险 |
| 自动支付、锁座/占座 | 不可逆资金与资源占用 |
| 抓取他人数据、再分发原始页面 | 侵犯隐私与平台权益 |
| 云端部署 / 上传凭据 | 凭据只在本机 Keychain |

## 3. 数据授权

六个平台均按 `contracts/data-sources.yaml` 的 **DC-2 内部例外**登记：`commercial_use: exception`、仅 `reservation-assist` 内部自用、禁止再分发、按平台限速。用途变化必须重新登记。

## 4. 免责

本工具只做监控与官方页面跳转，不保证能买到/约到；不作任何购买建议；用户需自行确认平台条款与实名要求。因平台条款变化、账号风控或网络异常造成的损失，由使用者自行承担。

## 5. 事故处置

- 识别到风控页：该任务冷却 24h 并通知，不重试、不降级
- 提交状态 `unknown`：停止自动提交，`ra reconcile` 人工对账后关闭
- 凭据疑似泄露：`ra doctor --purge`，轮换 Keychain 条目
