# 统计方法登记（T 系列）

> 只有登记在此的 `method_id` 允许出现在输出中（红线 R4）。所有数值必须带 `n`（样本量）。

| ID | 名称 | 公式 | n 的口径 |
|---|---|---|---|
| T01 | 命中次数 | 统计窗口内 `(task_id, fingerprint)` 首次命中条数 | 探测轮次数 |
| T02 | 探测延迟 | 单次 `probe` 的墙钟耗时均值，单位 ms | 成功探测次数 |
| T03 | 通知送达率 | 成功通知次数 / 首次命中次数 | 首次命中次数 |
| T04 | 时钟偏差置信区间 | 对时采样最小 RTT 3 次的 offset 极差，单位 ms | 采样次数 |

## 使用约定

- 样本不足（n < 3）时只报原始计数，不报均值与比率
- 不做趋势外推、不给成功概率
- 报告中的统计量同时给出 `method_id` 与 `n`
