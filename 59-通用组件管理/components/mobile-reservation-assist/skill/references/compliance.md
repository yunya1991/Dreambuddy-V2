# 合规与红线 — mobile-reservation-assist

| 红线 | 落实方式 |
|---|---|
| 不代抢/不转售/不加价 | 只做"命中→到官方下单页并预填"，不替代人工最终下单 |
| 不破解验证码 | 遇验证码回执 `captcha` → 作业 `cooldown`，不重试 |
| 不锁座/占座 | `assert_no_payment` 禁止支付/锁座动作；构建指令即拒绝 |
| 不托管支付 | 动作序列 `stop(before_payment)`，金额/支付一律人工 |
| 凭据最小化 | 不存身份证/手机号全量；日志/事件/报告统一 redact |
| 跨组件边界 | 不 import 上游，仅经其公开 CLI；不写死上游路径（G1/G2） |
| 数据源授权 | 复用上游 DC-2 内部例外登记，不扩大用途、不再分发 |
| 通道失败不静默 | 通知失败重试 2 次后记 missing[]；网关回执异常落事件 |

免责声明：本组件仅做流水线编排与手机端辅助操作，不构成购买建议，不承诺成功率。
