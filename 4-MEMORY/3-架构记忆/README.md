## 架构决策记录（ADR）

### 什么是 ADR？

ADR（Architecture Decision Record）是记录架构决策的轻量级文档。

每个 ADR 记录：
- 决策的背景和问题
- 考虑过的选项
- 最终决策和理由
- 决策的后果和影响
