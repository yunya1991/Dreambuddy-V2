# MU-INF-CORE — 信息记忆单元核心

> 单元: MU-INF | 容量: ≤ 1,000 字符 | 上次压缩: 2026-07-27 | 当前占用: ~40%
> 记忆类型: Procedural (程序记忆) + Semantic (语义记忆)

## 信息管理原则（S级 — 程序记忆）

- 总记忆只存索引，不存内容：内容在应用记忆或传统文档中
- 应用记忆由子系统主动维护：总记忆被动感知，不越权修改
- 蒸馏不复制：上升到总记忆的是提炼的索引，不是原始数据
- 来源可追溯：每条记忆有来源、有时间、有验证状态

## 索引规范（A级 — 语义记忆）

- 记忆ID规范：AM-{SYSTEM_CODE}-{TYPE}-{RAW_ID}
- 应用记忆注册：AM-TRD-001（交易）、AM-RSK-001（风控待建）等
- 路由表：query → 记忆单元 → 应用记忆接口 → 原始数据
- 健康检查：status + last_update + pipeline_connected

## 信息经验（A级 — 情景→语义）

1. 索引断链危害大于内容缺失：指向不存在的路径会导致开发中断
2. 跨子系统引用在目录统一后必须全面检查
3. 总记忆与文档管理的双向引用需要手动维护，容易过期
