# 应用记忆路由表 — Routing Table

> **版本**: v1.0
> **更新日期**: 2026-07-27

---

## 1. 关键词路由

总记忆系统根据查询关键词自动路由到对应应用记忆：

| 关键词模式 | 路由目标 | 示例查询 |
|-----------|---------|---------|
| `交易` / `trade` / `LONG` / `SHORT` / `趋势` | AM-TRD-001 | "趋势向上时LONG胜率如何？" |
| `风控` / `risk` / `回撤` / `爆仓` / `止损` | AM-RSK-001 | "回撤超过10%怎么处理？" |
| `运维` / `ops` / `CPU` / `内存` / `告警` / `部署` | AM-OPS-001 | "CPU告警怎么处理？" |
| `实验` / `experiment` / `AB测试` / `回测` | AM-EXP-001 | "最近的AB测试结果如何？" |

---

## 2. 子系统路由

根据上下文中的子系统标识路由：

| 子系统标识 | 路由目标 |
|-----------|---------|

| `experiments/` | AM-EXP-001 |

---

## 3. 复合查询处理

当查询涉及多个应用记忆时：

```
用户查询: "最近的风控阻断案例和对应的交易情况"
    │
    ├── 1. 路由到 AM-RSK-001，查询 "阻断案例"
    │       返回: [RSK-001, RSK-002, ...]
    │
    ├── 2. 提取案例中的交易上下文（如 system: "11-易经推理"）
    │
    └── 3. 路由到 AM-TRD-001，查询对应系统的交易记忆
            返回: [TRD-xxx, ...]
    
最终聚合返回
```

---

## 4. 默认路由

无法识别的查询，默认路由到：

1. MU-TRD（交易记忆单元）- 先查总记忆
2. 如无结果，广播到所有在线应用记忆
