# 记忆类型定义 — MEMORY TYPES

> **版本**: v1.0
> **更新日期**: 2026-07-26
> **定位**: 元记忆 — 关于记忆的记忆，定义所有记忆类型的分类和规范
> **等级**: S（公理级）

---

## 0. 记忆分层体系

```
L0 元记忆层（Meta-Memory）← 本文件所在层
    关于记忆的记忆：记忆类型、记忆规范、记忆生命周期
    ↓
L1 总记忆层（Global Memory）
    原则记忆 · 方法论记忆 · 架构记忆 · 文档记忆 · 通用经验 · 应用记忆索引
    ↓
L2 应用记忆层（Application Memory）
    交易应用记忆 · 风控应用记忆 · 运维应用记忆 · 实验应用记忆 · ...
    ↓
L3 即时记忆层（Working Memory）
    当前会话上下文 · 当前任务状态 · 短期工作缓存
```

---

## 1. L1 总记忆类型

### 1.1 原则记忆（Principles Memory）

| 属性 | 说明 |
|------|------|
| **定义** | 项目级的工程原则、开发规范、工作流标准 |
| **来源** | 项目决策、架构评审、技术债治理的经验蒸馏 |
| **典型内容** | 三原则、代码规范、测试标准、发布流程 |
| **质量等级** | 通常为 S 或 A 级 |
| **更新频率** | 低（稳定后很少变化） |
| **存储位置** | 4-MEMORY/1-原则记忆/ |
| **参考文件** | [ENGINEERING_PRINCIPLES.md](../1-原则记忆/ENGINEERING_PRINCIPLES.md) |

**子类型**：
- 工程原则：指导所有技术工作的最高原则
- 开发工作流：需求→调研→设计→实现→验证→发布→复盘
- 质量标准：代码质量、文档质量、测试质量的量化标准
- 安全红线：不可触碰的安全/合规底线

---

### 1.2 方法论记忆（Methodology Memory）

| 属性 | 说明 |
|------|------|
| **定义** | 做事的方法和套路，可复用的思考框架 |
| **来源** | A1/A8 等 SKILL 的实践经验蒸馏 |
| **典型内容** | 矛盾论应用法、A1调研方法论、A8理论实践校验法 |
| **质量等级** | 通常为 A 或 B 级 |
| **更新频率** | 中（随实践不断优化） |
| **存储位置** | 4-MEMORY/2-方法论记忆/ |

**子类型**：
- 分析方法论：矛盾论、根因分析、第一性原理
- 调研方法论：A1 调研法、现状分析、影响评估
- 校验方法论：A8 理论实践校验、文档-代码对齐检查
- 诊断方法论：故障排查路径、问题定位框架

---

### 1.3 架构记忆（Architecture Memory）

| 属性 | 说明 |
|------|------|
| **定义** | 系统架构的历史演进、当前状态、决策记录 |
| **来源** | 架构设计文档 + 架构决策记录（ADR） |
| **典型内容** | 当前架构图、演进历史、ADR 列表、模块依赖图 |
| **质量等级** | 通常为 A 级 |
| **更新频率** | 低（架构稳定后变化少） |
| **存储位置** | 4-MEMORY/3-架构记忆/ |

**子类型**：
- 当前架构：系统当前的分层、分模块架构
- 架构演进：从 v1.0 到现在的架构变迁历史
- 架构决策记录（ADR）：每个重要架构决策的背景、选项、理由、后果
- 依赖图：模块间、服务间的依赖关系

---

### 1.4 文档记忆（Doc Memory）

| 属性 | 说明 |
|------|------|
| **定义** | 全项目文档的索引、质量状态、对齐状态 |
| **来源** | 0-系统文档管理/ 的索引同步 |
| **典型内容** | 文档索引、文档债清单、文档-代码对齐状态 |
| **质量等级** | 通常为 B 级（持续更新中） |
| **更新频率** | 高（随文档系统持续更新） |
| **存储位置** | 4-MEMORY/4-文档记忆/ |

**子类型**：
- 文档索引：全项目文档的结构化目录（指向 0-系统文档管理）
- 文档债清单：文档类技术债务清单（指向 DOC_DEBT_INDEX.md）
- 对齐状态：文档与代码的对齐检查结果

**注意**：文档记忆是 0-系统文档管理 的索引和摘要，不重复存储文档内容。

---

### 1.5 通用经验记忆（Lessons Memory）

| 属性 | 说明 |
|------|------|
| **定义** | 从各应用记忆蒸馏上来的跨系统通用经验 |
| **来源** | 各应用记忆的蒸馏候选 + 人工审核 |
| **典型内容** | 技术教训、流程教训、最佳实践、反模式 |
| **质量等级** | A/B/C 级都有，随验证逐步升级 |
| **更新频率** | 中（随经验积累持续增加） |
| **存储位置** | 4-MEMORY/5-通用经验/ |

**子类型**：
- 技术教训：API 踩坑、配置陷阱、性能陷阱
- 流程教训：哪些步骤容易遗漏、哪些环节容易出问题
- 最佳实践：经过验证的高效做法
- 反模式：经过验证的错误做法

**上升路径**：应用记忆中的案例 → 蒸馏候选 → 审核通过 → 通用经验

---

### 1.6 应用记忆索引（App Memory Index）

| 属性 | 说明 |
|------|------|
| **定义** | 所有应用记忆系统的注册表和路由表 |
| **来源** | 各应用记忆系统注册上报 |
| **典型内容** | 注册表、路由表、健康状态 |
| **质量等级** | B 级（持续维护） |
| **更新频率** | 高（心跳上报） |
| **存储位置** | 4-MEMORY/6-应用记忆索引/ |

**子类型**：
- 注册表：所有应用记忆系统的元数据
- 路由表：什么查询应该路由到哪个应用记忆
- 健康状态：各应用记忆的最后心跳、数据新鲜度

## 2. L2 应用记忆类型

应用记忆由各子系统自行管理，但建议包含以下类型：

| 类型 | 说明 | 典型实现 |
|------|------|---------|
| 案例记忆 | 具体的运行案例、交易案例、故障案例 | CBR 案例库、JSON 记录 |
| 规则记忆 | 总结出的规则、策略、阈值 | 规则库、配置快照 |
| 知识图谱 | 实体-关系网络 | KG 三元组、图数据库 |
| 统计记忆 | 统计数据、分布、趋势 | 统计报表、数据快照 |
| 演化记忆 | 参数、策略的演化历史 | 版本历史、进化路径 |

具体内容由各应用记忆系统自行定义，但必须实现统一接口（见 9-工具与接口）。

## 3. 记忆条目格式规范

### 3.1 通用头部

每条记忆（无论类型）都应包含以下元数据：

```yaml
id: MEM-TYPE-001          # 记忆唯一 ID
type: tech_lesson         # 记忆类型
title: 简短标题            # 一句话概括
quality: B                # 质量等级（S/A/B/C/D）
created_at: 2026-07-26    # 创建日期
updated_at: 2026-07-26    # 最后更新日期
source: 11-易经推理系统    # 来源系统
tags: [标签1, 标签2]      # 标签，用于检索
```

### 3.2 正文结构

根据记忆类型不同，正文结构有所差异，但建议包含：

1. **描述**：记忆的核心内容
2. **背景**：产生这条记忆的上下文
3. **验证**：验证情况和证据
4. **适用场景**：什么时候适用
5. **不适用场景**：什么时候不适用（边界条件）
6. **相关记忆**：关联的其他记忆

## 4. 记忆命名规范

### 4.1 ID 命名

```
{前缀}-{类型缩写}-{序号}
```

| 前缀 | 说明 |
|------|------|
| GM | Global Memory — 总记忆 |
| AM-{APP} | Application Memory — 应用记忆（{APP} 是子系统标识） |

| 类型缩写 | 说明 |
|---------|------|
| PRI | 原则记忆 |
| MTD | 方法论记忆 |
| ARC | 架构记忆 |
| DOC | 文档记忆 |
| LSN | 通用经验 |
| IDX | 应用记忆索引 |

**示例**：
- `GM-PRI-001` — 总记忆·原则记忆·第1条
- `GM-MTD-003` — 总记忆·方法论记忆·第3条
- `AM-TRD-CASE-042` — 应用记忆·交易·案例·第42条
