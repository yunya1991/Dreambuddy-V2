## 1. 适用范围

适用: T2 大仓执行前的事前门禁放行 / 持仓期间事中熔断监控 / 交易结束后事后归因分析 / 独立验证自评可信度。
不适用: 行情研判（T1）/ 下单执行与离场判定（T2）。T3 只判定"是否允许、是否熔断、为什么这个结果"。

从原 A7（实践论门禁）+ A4 约束体系精简而来，本身即为 HARD-GATE。

## 2. 核心步骤

1. **事前 5 项门禁**：认识来源充分性（≥2 独立源）/ 验证设计合理性（有模拟盘）/ 风险可控性（仓位限额+止损）/ 反馈机制完整性（四层离场预案）/ 执行纪律（验证前置检查）。
2. **止损必检**：扫描所有持仓，任一无止损=整体 FAIL，禁止"心理止损"。
3. **4h 窗口 episode 检查**：无近期实践=FAIL，有但全失败=FAIL。
4. **仓位限额与风险预算**：总仓位、单标的、跨资产相关性叠加三重校验。
5. **C5 熔断监控**：单次>15% / 24h>25% / 7d>40% / 连续3次亏损，任一触发即平仓+闭环。
6. **独立验证**：从 episode 数据自动验证，不采信自评分，冲突时以数据为准。
7. **事后归因**：实际 vs 预期差异分析，区分"策略有效 / 运气 / 止损有效 / 误判"四类。
8. **episode 沉淀**：每笔交易记 entry/exit/regime/结果/复盘，供未来 recall。

## 3. HARD-GATE

- T3 本身即 HARD-GATE，所有门禁检查项均为硬约束，不存在"软警告后放行"。
- 门禁 FAIL 时禁止执行，必须返回上游（T1/T2）修正后重新过门禁。
- 独立验证结果从 episode 数据自动得出，不受执行者自评影响，自评与数据冲突时以数据为准。
