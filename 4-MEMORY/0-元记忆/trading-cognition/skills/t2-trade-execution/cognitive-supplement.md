## 1. 适用范围

适用: 战术假设落地为真实订单 / 仓位分级决策 / 持仓离场判定 / 亏损熔断处置。
不适用: 纯行情研判与信息收集（走 T1）/ 风控门禁判定本身（走 T3）。

合并自原 A4（战术验证）+ A5（战术执行）+ A9（离场决策），覆盖从验证到离场全生命周期。

## 2. 核心步骤

1. **三层索引**：策略索引（大师→联网→实践）+ 工具索引（Regime→工具匹配）+ 跨资产设计。
2. **Regime×策略工具匹配矩阵**：7 Regime × 5 工具，标注首选/备选/禁忌，仅从首选/备选取策略。
3. **模拟盘验证**：P1 侦察仓 10-15% 跑 ≥2 次，记录 entry/exit/regime/结果。
4. **验证前置检查**：实践≥2 + 同方向盈利≥2 + 无单次亏损>5%，全绿才进大仓。
5. **最佳策略传递**：输出 win_rate / profit_factor / sharpe / max_drawdown 给执行阶段。
6. **仓位分级**：P1 侦察 10-15% / P2 标准 30-40% / P3 加仓 +10-20% / P4 减仓 -10-20%。
7. **C8 强制试探**：每次至少 1 笔试探单，反纸上谈兵。
8. **四层离场链**：Layer1 技术离场 → Layer2 21 风险事件 → Layer3 P0/P1 情报联动 → Layer4 强制审计。

## 3. HARD-GATE

- 大仓执行前必须有 ≥2 次模拟盘验证实践并通过验证前置检查，否则只允许 P1 侦察仓。
- 所有持仓必须有止损，无止损=禁止开仓，止损只能收紧不能放宽。
- C5 熔断（单次>15% / 24h>25% / 7d>40% / 连续3次亏损）触发时必须立即平仓并进入"平仓→反思→重新研判"闭环，禁止补仓摊平。
