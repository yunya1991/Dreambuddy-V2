# Trade Execution (交易执行)

交易执行的统一入口。把原 A 系列的战术验证、大仓执行、离场决策三段合并为一条内部流水线，确保"验证过的策略才能上大仓、有止损才能开仓、有离场预案才能持仓"。

## Overview

本 Skill 负责从"已研判的战术假设"到"实际持仓生命周期结束"的全程。内部三阶段：

1. **验证阶段**（Validate）：用模拟盘 / 小仓试探检验策略有效性，产出最佳策略传递给执行阶段。
2. **执行阶段**（Execute）：基于验证结果做仓位决策分级下单，遵守止损前置与试探铁律。
3. **离场阶段**（Exit）：沿四层离场决策链逐层判定，任何一层命中即离场。

三阶段必须顺序进行，禁止跳过验证直接大仓执行。

## When to Use

- 需要把一个战术假设落地为真实订单时
- 需要决定仓位大小、加仓 / 减仓节奏时
- 持仓期间需要判断是否离场、如何离场时
- 出现亏损接近熔断阈值，需要判定是否强制平仓时
- 触发词命中：战术验证 / 模拟盘 / 试探 / 大仓执行 / 仓位决策 / 止损止盈 / 平仓 / 离场决策 / 四层离场 / 风险事件 / 熔断 / 强制离场 / 移动止损 / 分批离场

不适用：纯行情研判、信息收集（走 T1）、风控门禁判定本身（走 T3，但本 Skill 的 HARD-GATE 与 T3 对齐）。

## The Iron Law (HARD-GATE)

<HARD-GATE>
1. **验证前置**：大仓执行前必须有 ≥2 次模拟盘验证实践，且通过验证前置检查（实践次数≥2 + 同方向盈利≥2 + 无单次亏损>5%）。未通过 = 只允许 P1 侦察仓。
2. **止损必设**：所有持仓必须有止损设置。无止损 = 禁止开仓。止损一经设置不得在持仓中放宽（只能收紧）。
3. **C5 熔断即时闭环**：C5 熔断触发时（单次>15% / 24h>25% / 7d>40% / 连续3次亏损）必须立即平仓并进入"平仓→反思→重新研判"闭环，不得补仓摊平。
4. **C8 强制试探**：每次战术执行至少 1 笔试探单，反纸上谈兵。只分析不下单 = 禁止进入大仓阶段。
</HARD-GATE>

## Core Steps

### 阶段一：验证（Validate）

#### 1. 三层索引体系

在验证前先建立三层索引，定位"该用什么策略、什么工具、是否跨资产"。

- **策略索引**：大师方法论 → 联网检索同 regime 历史策略 → 本地实践库 recall。三者交叉确认后选出候选策略集。
- **工具索引**：当前 Regime → 工具匹配表 → 候选工具集。工具必须与 Regime 匹配，禁止在禁忌格使用。
- **跨资产设计**：是否存在对冲 / 配对 / 链上联动机会？若有，标注相关性并纳入组合验证。

#### 2. Regime × 策略工具匹配矩阵

7 种 Regime × 5 大策略工具（趋势跟踪 / 均值回归 / 突破 / 套利 / 期权对冲）。每个格子标注：首选 / 备选 / 禁忌。验证阶段只能从"首选"或"备选"格取策略，"禁忌"格直接否决。

矩阵要点（完整表见 cognitive-supplement）：
- 强趋势上涨：趋势跟踪首选，均值回归禁忌
- 震荡区间：均值回归首选，趋势跟踪禁忌
- 高波动无方向：期权对冲首选，突破禁忌
- 流动性收缩：套利首选，趋势跟踪备选（减仓）
- 极端反转：禁忌所有方向性策略，仅保留期权对冲

#### 3. 模拟盘验证与小仓试探

- 用模拟盘或 P1 侦察仓（10-15%）对候选策略各跑 ≥2 次。
- 记录每次：entry/exit/regime/结果/复盘。
- 验证前置检查（必须全绿才能进大仓）：
  - 实践次数 ≥2
  - 同方向盈利 ≥2
  - 无单次亏损 >5%

#### 4. 最佳策略传递机制

验证阶段结束后，选出表现最佳策略，连同以下指标传递给执行阶段：
- `win_rate`（胜率）
- `profit_factor`（盈亏比）
- `sharpe`（夏普）
- `max_drawdown`（最大回撤）

传递格式建议：`{strategy_id, regime, win_rate, profit_factor, sharpe, max_drawdown, validated_at}`。执行阶段只能从传递进来的策略中选，不得临时换将。

### 阶段二：执行（Execute）

#### 5. 仓位决策分级

| 级别 | 名称 | 仓位比例 | 触发条件 |
|------|------|----------|----------|
| P1 | 侦察仓 | 10-15% | 验证未通过 / 试探阶段 |
| P2 | 标准仓 | 30-40% | 验证通过 + Regime 匹配首选 |
| P3 | 加仓 | +10-20% | 浮盈且趋势延续确认 |
| P4 | 减仓 | -10-20% | 接近 TP 或 Regime 拐点 |

总仓位不得超过风险预算上限（由 T3 门禁给定）。

#### 6. C8 强制下单试探铁律

每次战术执行至少 1 笔试探单，哪怕只是最小手数。目的：反纸上谈兵，强迫面对真实滑点、流动性、心理反应。只分析不下单 = 禁止进入大仓阶段。

#### 7. 下单与止损设置

- 开仓与设止损必须原子化（同一次操作内完成）。
- 止损位基于结构（前低 / 波动率 / Regime 关键位），不基于"我希望它不跌到这"。
- 止盈可分批：TP1 减仓 1/3，TP2 减仓 1/3，剩余 trailing。

### 阶段三：离场（Exit）

#### 8. 四层离场决策链

持仓期间持续沿四层链判定，任一层命中即触发离场，高层级覆盖低层级。

- **Layer 1 技术离场**：TP / SL / trailing stop 命中 → 机械执行，不犹豫。
- **Layer 2 风险事件离场**：21 类风险事件任一发生（监管、黑天鹅、流动性骤变、对手方风险等）→ 按事件预案离场。
- **Layer 3 情报联动离场**：P0 / P1 级情报（来自 T1）与持仓方向冲突 → 立即离场或对冲。
- **Layer 4 强制审计离场**：触发 C5 熔断 / T3 门禁 FAIL / 持仓超时 → 强制平仓并复盘。

#### 9. C5 亏损熔断

四个条件任一触发即熔断，进入闭环：

| 条件 | 阈值 |
|------|------|
| 单次亏损 | >15% |
| 24h 累计亏损 | >25% |
| 7d 累计亏损 | >40% |
| 连续亏损次数 | ≥3 |

熔断闭环：**平仓 → 反思（记录原因）→ 重新研判（回到 T1）→ 重新验证（回到阶段一）**。熔断期间禁止开新仓。

#### 10. 分批离场与移动止损

- 盈利后逐步上移 trailing stop，锁定利润。
- 分批离场降低择时风险：TP1 / TP2 / 残仓 trailing。
- 离场后立即记录 episode（entry/exit/regime/结果/复盘），供 T3 独立验证与未来 recall。

## Checklist

执行前自查（任一 No = 停止）：

- [ ] 是否已完成三层索引（策略 / 工具 / 跨资产）？
- [ ] 候选策略是否来自矩阵"首选"或"备选"格（非禁忌）？
- [ ] 模拟盘验证是否 ≥2 次且通过验证前置检查？
- [ ] 最佳策略指标（win_rate / profit_factor / sharpe / max_drawdown）是否已传递？
- [ ] 是否已设置止损且止损位基于结构？
- [ ] 是否至少下了 1 笔试探单（C8）？
- [ ] 仓位是否在 T3 风险预算内？
- [ ] 离场预案是否四层齐备（TP/SL、风险事件、情报联动、熔断）？

持仓中自查（持续）：

- [ ] 是否持续监控四层离场信号？
- [ ] trailing stop 是否随盈利上移？
- [ ] C5 四项熔断阈值是否实时监控？
- [ ] 是否每笔离场都记录了 episode？

熔断后自查：

- [ ] 是否已平仓且未补仓摊平？
- [ ] 是否进入反思→重新研判→重新验证闭环？
- [ ] 熔断期间是否禁止开新仓？

## Anti-Pattern

- **纸上谈兵**：只分析不下单，跳过 C8 试探。→ 禁止进大仓。
- **跳过验证直接大仓**：凭"这次不一样"跳过验证前置。→ 只允许 P1。
- **无止损开仓**：认为"盯盘就行"。→ 禁止开仓。
- **补仓摊平**：亏损后加仓拉低均价。→ 违反熔断闭环。
- **临时换将**：执行阶段抛弃验证过的策略，临时换新策略。→ 禁止。
- **放宽止损**：持仓中把止损往下移。→ 只允许收紧。
