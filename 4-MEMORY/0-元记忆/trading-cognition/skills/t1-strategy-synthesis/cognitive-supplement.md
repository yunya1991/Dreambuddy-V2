## 1. 适用范围

适用: T0 市场认知完成后的战略指令生成、多情景推演、应急预案预制、沙盘推演；不适用: T0 未完成时（必须退回 T0）、纯执行层挂单 / 平仓操作、与战略无关的风控参数调整。

## 2. 核心步骤

1. **战略指令合成**：T0 的 Regime + 阻力方向 + 方向 → directive_bias（LONG / SHORT / WAIT / REDUCE / PROBE / DIP_BUY / HEDGE）
2. **历史模式匹配**：从策略库检索相似 Regime + 阻力结构的历史胜率与失败模式，用于校准概率
3. **三情景推演**：S1 基准 / S2 次级 / S3 尾部，每情景含目标价 + 触发条件 + 验证标准 + 证伪条件 + 止损
4. **贝叶斯校准**：先验（历史频率）× 似然（T0 证据支持度）→ 后验，归一化使 S1+S2+S3 = 1.0
5. **沙盘推演**：每个情景执行"假设 → 验证标准 → 响应动作"循环，产出情景—验证—动作映射表
6. **phase7_contingency**：三层应急预案——黑天鹅层 / 极端情景层（S3 实现）/ 概率情景层（S1↔S2 反转）
7. **结构化输出**：移交 `strategy_directive` 给执行层

## 3. HARD-GATE

- S1 + S2 + S3 概率之和必须 = 1.0（贝叶斯校准后，容差 ±0.01），不允许"其他"兜底项
- 每个情景必须给出明确证伪条件 + 止损方案，禁止"看涨就做多"无止损
- directive_bias = WAIT 时必须给出转 LONG / SHORT 的具体触发条件（价格 / 时间 / 信号），禁止无限期等待
