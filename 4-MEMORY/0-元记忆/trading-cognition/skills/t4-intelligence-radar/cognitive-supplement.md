## 1. 适用范围

适用: 持仓期间的持续市场监控；盘前三屏方向一致性检查；盘后信号剧变检测；T2 验证结果回传后的状态更新；分级告警的发出与升级。
不适用: 从零开始的战略研判（走 T0）；单笔止损/止盈执行（走 T2）；仓位规模计算（走 T1）。

## 2. 核心步骤

1. 三屏 MA 趋势监控：周线/日线/小时线方向、斜率、加速度采集；三屏不一致强制 Level 1.5。
2. 宏观资产共振监控：黄金/原油/铜/TSLA/COIN 与 BTC 相关性及信号解读；多资产同向异动升一级。
3. 双轨触发机制：T4 自主检测轨 + T2 主动上报轨；两轨冲突时以更高级别为准。
4. 分级响应：Level 1 增量更新 / Level 1.5 触发 T0 重判 / Level 2 触发 T2 验证 / Level 3 触发 T0→T1 全链路重启。
5. 信号剧变检测：Edge 与 SI_Index 阈值触发；单步跳变超阈值触发 P0/P1。
6. P0/P1 告警分级：P0 零延迟立即触发 T2 离场检查；P1 下个执行窗口响应。
7. 升级规则：低级别未在窗口内响应自动升一档；降级需 T0 确认，T4 不得单方面降级。

## 3. HARD-GATE

- P0 告警必须立即触发 T2 离场检查，零延迟。
- 持仓期间 T4 不得停止运行。
- 三屏方向不一致时必须发出 Level 1.5 告警。
