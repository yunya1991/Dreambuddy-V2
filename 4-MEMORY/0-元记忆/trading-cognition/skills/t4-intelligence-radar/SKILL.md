# Intelligence Radar (情报雷达)

## Overview

**核心职责**：持续监控 + 分级触发。T4 是 A 系列决策链的"前哨雷达"，不直接决策，而是把市场异常翻译成对 T0/T1/T2 的分级唤醒信号。

**来源**：从原 A6（情报监控）精简，剥离执行细节，聚焦"看见 + 分级 + 上报"三件事。

**铁律**：T4 只负责报警和分级，不替 T0/T1/T2 做决策。越权判定 = 违规。

## When to Use

- **持仓期间**：T4 必须常驻运行，禁止停止。
- **盘前**：扫描三屏方向一致性、宏观共振信号是否变化。
- **盘后**：检查信号剧变是否触及分级响应阈值。
- **T2 主动上报**：T2 完成验证后回传结果，T4 据此更新状态。
- **不适用**：从零开始的战略研判（那是 T0 的活）；单笔止损执行（那是 T2 的活）。

## The Iron Law (HARD-GATE)

```
P0 告警必须立即触发 T2 离场检查，零延迟。
持仓期间 T4 不得停止运行。
三屏方向不一致时必须发出 Level 1.5 告警。
```

违反任何一条 = 该次监控周期判定失败，必须重新跑。

## Core Steps

### Step 1 — 三屏 MA 趋势监控

对周线 / 日线 / 小时线三屏分别采集：

| 维度 | 含义 | 监控点 |
|------|------|--------|
| 方向 | MA 上行 / 下行 / 走平 | 三屏方向是否一致 |
| 斜率 | MA 变化速率 | 斜率是否由正转负（或反之） |
| 加速度 | 斜率的变化 | 加速度是否背离价格 |

**判定**：
- 三屏同向 → 趋势确认，维持当前级别。
- 三屏不一致 → **强制 Level 1.5 告警**，触发 T0 重新研判方向/Regime。
- 斜率或加速度背离价格 → 记入异常池，进入 Step 5 信号剧变检测。

### Step 2 — 宏观资产共振监控

监控以下资产与 BTC 的相关性及信号：

| 资产 | 信号解读 |
|------|----------|
| 黄金 | 避险情绪 / 通胀预期 |
| 原油 | 风险偏好 / 宏观需求 |
| 铜 | 工业需求 / 经济周期 |
| TSLA | 美股科技股风险偏好 |
| COIN | 加密行业资金流向先行指标 |

**共振判定**：
- 多资产同向异动 → 共振信号，提升告警级别。
- 单资产异动 → 观察池，不直接升级。
- 相关性断裂（历史正相关资产背离）→ 记入异常池。

### Step 3 — 双轨触发机制

T4 同时接受两条输入：

1. **T4 自主检测轨**：Step 1/2 主动扫描发现的异常。
2. **T2 主动上报轨**：T2 验证完成后的结果回传（验证通过/失败/部分通过）。

两轨汇合后按 Step 4 分级。禁止只信一条轨——T2 上报"安全"但 T4 自检发现 P0 异常时，**以 P0 为准**。

### Step 4 — 分级响应规则

| 级别 | 触发条件 | 动作 |
|------|----------|------|
| **Level 1** | 局部指标变化，未触及方向/Regime | 增量更新分析（不全量重算） |
| **Level 1.5** | 三屏不一致 / 方向或 Regime 可能变更 | 触发 T0 重新研判 |
| **Level 2** | 新信号出现，需要模拟盘验证 | 触发 T2 验证 |
| **Level 3** | 战略环境根本性变更 | 触发 T0→T1 全链路重启 |

**升级规则**：低级别未在窗口内响应，自动升级一档。
**降级规则**：不允许 T4 单方面降级，降级需 T0 确认。

### Step 5 — 信号剧变检测

监控 `Edge` 与 `SI_Index` 两个合成指标：

- `Edge` 跨越阈值 → 触发对应 Level。
- `SI_Index` 单步跳变超阈值 → 触发 P0 或 P1 告警。
- 两者同时触发 → 按更高级别处理。

### Step 6 — P0/P1 告警分级

| 级别 | 含义 | 响应窗口 |
|------|------|----------|
| **P0** | 立即响应 | 零延迟，立即触发 T2 离场检查 |
| **P1** | 下个执行窗口响应 | 下一个执行窗口内处理 |

**P0 判定示例**：
- 三屏方向全部反转 + 宏观共振异动
- SI_Index 跳变超阈值
- T2 验证失败且持仓处于亏损区间

## Checklist

- [ ] 三屏方向、斜率、加速度是否已采集？
- [ ] 三屏方向是否一致？不一致是否已发 Level 1.5？
- [ ] 宏观资产共振是否扫描？是否有相关性断裂？
- [ ] T2 上报轨是否已接收并比对？
- [ ] 当前告警级别是否正确（Level 1/1.5/2/3）？
- [ ] P0 告警是否已零延迟触发 T2 离场检查？
- [ ] P1 告警是否已排入下个执行窗口？
- [ ] T4 是否在持仓期间持续运行（未停止）？
- [ ] 信号剧变（Edge/SI_Index）是否已检测？
- [ ] 升级规则是否执行（低级别未响应是否自动升级）？
- [ ] T4 是否越权决策？（违规项，必须为零）

## 与其他 T 的关系

- **T0**：接收 T4 的 Level 1.5 / Level 3 信号，做方向/Regime 重新研判。
- **T1**：接收 T4 的 Level 3 信号，参与全链路重启。
- **T2**：接收 T4 的 Level 2 / P0 信号，执行验证或离场检查；回传结果给 T4。
- **T3**：不直接交互，但 T4 的告警记录可作为 T5 复盘的输入。

## 反模式（禁止）

- T4 直接下达止损/加仓指令（越权）。
- 持仓期间停止 T4 以"节省资源"。
- 三屏不一致时仅记录不发告警。
- P0 告警拖延到下个窗口处理。
- 只信 T2 上报轨，忽略 T4 自检轨。
- T4 单方面降级告警。
