# T0 市场认知 (Market Cognition)

将多源信息采集、多维度冲突分析、阻力最小路径判定、Regime 分类与方向判定合并为单一认知环节。它是 T1 战略合成的唯一输入源：T0 不出结论，T1 不能开工。

## Overview

T0 的职责是把"市场现在是什么"讲清楚，而不是"该怎么做"。它从 7 个维度采集信息，识别出当前最主要的多维度冲突，计算阻力最小路径，分类市场 Regime，最终给出方向判定（LONG / SHORT / NEUTRAL / UNCERTAIN）。

T0 不生成交易指令，不推演情景，不出应急预案——这些是 T1 的事。T0 的产出是一份结构化的"市场画像"，T1 据此合成战略。

## When to Use

- 开仓前、加仓前、止损前、持仓 Regime 怀疑发生变化时
- 用户提到"深度调研 / 市场分析 / 矛盾分析 / 行情研判 / Regime / 阻力最小路径 / 冲突识别 / 市场认知 / 趋势分析 / 资金面 / 情绪面 / 第一性原理"等触发词时
- T1 战略合成必须以 T0 输出为前置依赖；T0 可独立运行（仅做认知，不出策略）

<HARD-GATE>
1. **双源交叉验证**：任何进入冲突分析的论据必须有 ≥2 个独立信息源交叉验证，单一来源（哪怕权威）不进入主冲突判定。
2. **主冲突唯一性**：主要冲突必须唯一，不允许两个并列主冲突。若确实存在多个高强度冲突，必须按 4 维评分决出第一，其余降级为次级冲突。
3. **方向必须有冲突支撑**：方向判定必须由冲突分析 + 阻力路径推导而来，不允许跳过冲突分析直接看技术面给方向。
</HARD-GATE>

## Core Steps

### Step 1 — 多维度信息采集（7 维）

从以下 7 个维度并行采集，每个维度至少给出 1 条观察 + 1 条证据：

1. **资金面**：主力资金流向、持仓量变化、大户持仓比、ETF 申赎
2. **情绪面**：恐慌贪婪指数、社交媒体热度、期权 PCR、极端情绪标记
3. **技术面**：趋势状态、关键位、量价关系、背离信号
4. **宏观**：利率 / 通胀 / 增长 / 政策周期定位
5. **地缘**：风险事件、供应链冲击、制裁 / 协议
6. **时序**：日历效应、季节性、重要数据时点
7. **隐性**：未公开但可推断的信息（如链上异动、大宗折价、内部人交易）

**输出**：`info_matrix` —— 7 行 × (观察 / 证据 / 来源 / 时间戳) 列。

### Step 2 — 多维度冲突分析

把 Step 1 的信息组织成"对立双方"结构。冲突 = 两组相互矛盾的力量。

每条冲突记录 4 个要素：
- **对立双方**：多方力量 vs 空方力量（如"资金流入 vs 技术顶背离"）
- **强度**：1-5 分
- **证据**：证据数量 + 证据质量（A/B/C 级）
- **时间视角**：短期 / 中期 / 长期

**4 维评分**确定主冲突：
```
冲突得分 = 强度 × 证据数 × 证据质量系数 × 时间视角系数
```
- 证据质量系数：A=1.0，B=0.7，C=0.4
- 时间视角系数：长期=1.2，中期=1.0，短期=0.7

得分最高者为**主冲突（唯一）**，其余为次级冲突。

### Step 3 — 阻力最小路径分析

市场倾向于沿阻力最小方向运动。计算 4 个摩擦分量：

| 分量 | 权重 | 含义 |
|------|------|------|
| 成本摩擦 | 30% | 持仓成本与现价距离、换手成本 |
| 流动性摩擦 | 35% | 盘口深度、大单冲击成本、合约基差 |
| 拥挤度摩擦 | 20% | 多头 / 空头拥挤度、共识度 |
| 波动率摩擦 | 15% | 已实现 vs 隐含波动率、波动率结构 |

```
阻力分数 = Σ(分量得分 × 权重)   # 取值 [-1, 1]，负=向下阻力小，正=向上阻力小
```

**逆向补偿**：当情绪面进入极端区（如恐慌贪婪指数 <10 或 >90），对阻力分数施加补偿调整——极端恐慌时上调向上阻力优势，极端贪婪时下调。补偿幅度 ±0.15 内。

### Step 4 — Regime 分类

基于主冲突 + 阻力分数 + 技术面状态，分类当前 Regime（7 选 1）：

1. `TREND_STRONG` — 强趋势，主冲突单向主导，阻力分数 |·|>0.5
2. `TREND_WEAK` — 弱趋势，主冲突主导但力量衰减
3. `RANGE_BOUND` — 区间震荡，主冲突双方势均
4. `FALSE_BREAKOUT_RISK` — 假突破风险，技术面突破但资金面不确认
5. `REVERSAL_RISK` — 反转风险，主冲突强度骤变 + 极端情绪
6. `LOW_LIQUIDITY` — 低流动性，流动性摩擦 >0.7 主导
7. `CHAOS` — 混乱，多冲突高强度并列、信息严重不足

### Step 5 — 方向判定

综合主冲突方向 + 阻力分数符号 + Regime，给出方向：
- `LONG` — 主冲突多方主导 + 阻力分数 >0.3 + Regime ∈ {TREND_STRONG, TREND_WEAK}
- `SHORT` — 主冲突空方主导 + 阻力分数 <-0.3 + Regime ∈ {TREND_STRONG, TREND_WEAK}
- `NEUTRAL` — 区间内，阻力分数 |·|<0.3 + Regime = RANGE_BOUND
- `UNCERTAIN` — Regime ∈ {CHAOS, LOW_LIQUIDITY} 或信息不足

### Step 6 — 三角准则调研（经验验证）

对当前结论做三重交叉验证：
1. **记忆调研**：检索 L2 历史记忆中类似主冲突的过往结论与结果
2. **历史类似行情**：检索相似 Regime + 相似阻力结构的历史行情走向
3. **主流观点对照**：记录当前主流观点，作为逆向参考（非盲从）

若三角调研与 T0 结论严重背离，必须回到 Step 2 复核冲突评分。

## Output Schema

T0 产出 `market_cognition_report`，包含：
```yaml
info_matrix: {...}           # Step 1
conflicts:
  primary: {parties, score, evidence, timeframe}
  secondary: [...]
resistance:
  score: -1..1
  components: {cost, liquidity, crowding, volatility}
  contrarian_adjustment: 0   # 逆向补偿值
regime: TREND_STRONG|RANGE_BOUND|...
direction: LONG|SHORT|NEUTRAL|UNCERTAIN
triangulation:
  memory: {...}
  historical: {...}
  consensus: {...}
timestamp: ...
```

## Checklist

执行 T0 时按序勾选：

- [ ] 7 维信息采集完成，每维至少 1 观察 + 1 证据
- [ ] 每条进入冲突分析的论据 ≥2 独立源交叉验证
- [ ] 冲突已按 4 维评分排序，主冲突唯一
- [ ] 4 个摩擦分量均已计算，阻力分数已得出
- [ ] 情绪极端时已施加逆向补偿（如适用）
- [ ] Regime 已分类（7 选 1），不允许多选
- [ ] 方向判定有冲突分析 + 阻力路径双支撑，非纯技术面
- [ ] 三角准则调研完成，与结论无严重背离
- [ ] `market_cognition_report` 已结构化输出，移交 T1

## Anti-Patterns

- **跳过冲突直接看技术面**：违反 HARD-GATE 3，是最常见的偷懒路径
- **并列双主冲突**：违反 HARD-GATE 2，本质是冲突评分不彻底
- **单源论据上主冲突**：违反 HARD-GATE 1，易被单一信息源带偏
- **Regime 多选**：Regime 是互斥分类，"TREND_STRONG + FALSE_BREAKOUT_RISK"这种写法意味着 Step 4 没做完
- **阻力分数无分量细节**：只给一个总分不接受，必须展示 4 分量
- **逆向补偿滥用**：非极端区也调整阻力分数，属于主观干预
