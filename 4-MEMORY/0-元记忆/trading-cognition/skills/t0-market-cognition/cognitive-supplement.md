## 1. 适用范围

适用: 开仓 / 加仓 / 止损前的市场认知、行情研判、Regime 判定、冲突识别、阻力最小路径分析；不适用: 已有 T0 报告且 Regime 未变化时的重复调研、纯执行层操作（如已有指令的挂单）。

## 2. 核心步骤

1. **7 维信息采集**：资金面 / 情绪面 / 技术面 / 宏观 / 地缘 / 时序 / 隐性，每维至少 1 观察 + 1 证据
2. **多维度冲突分析**：对立双方 + 4 维评分（强度 × 证据数 × 证据质量 × 时间视角），主冲突唯一
3. **阻力最小路径**：4 摩擦分量加权（成本 30% + 流动性 35% + 拥挤度 20% + 波动率 15%），极端情绪施加逆向补偿
4. **Regime 分类**：7 选 1（TREND_STRONG / TREND_WEAK / RANGE_BOUND / FALSE_BREAKOUT_RISK / REVERSAL_RISK / LOW_LIQUIDITY / CHAOS）
5. **方向判定**：主冲突 + 阻力分数 + Regime 三者综合，输出 LONG / SHORT / NEUTRAL / UNCERTAIN
6. **三角准则调研**：记忆调研 + 历史类似行情 + 主流观点对照，背离时回退复检
7. **结构化输出**：移交 `market_cognition_report` 给 T1

## 3. HARD-GATE

- 任何进入冲突分析的论据必须有 ≥2 个独立信息源交叉验证，单一来源不进入主冲突
- 主要冲突必须唯一，不允许两个并列主冲突；多冲突时按 4 维评分决出第一
- 方向判定必须由冲突分析 + 阻力路径推导而来，禁止跳过冲突分析直接看技术面给方向
