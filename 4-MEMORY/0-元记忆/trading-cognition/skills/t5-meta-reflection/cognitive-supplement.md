## 1. 适用范围

适用: 单笔 episode 结束后的复盘；日/周/月周期性回顾；纸上谈兵检测（T0/T3 是否被实际调用）；改进 lesson 的观察期验证；改进措施上线后的回滚评估。
不适用: 实时决策纠偏（走 T2/T4）；从零设计战略（走 T0）；仓位计算（走 T1）。

## 2. 核心步骤

1. 纸上谈兵检测：检查 use_skill 调用日志，对比"声称集成"vs"实际调用"次数；零调用标记为虚假集成优先修复。
2. 记录：从 episode 数据提取决策依据五要素（为什么进/预期/止损/仓位/信心度）。
3. 对比：实际结果 vs 预期四项（盈亏/持有时间/命中条件/执行偏差）。
4. 归因：识别认知偏差（确认偏误/损失厌恶/过度自信/情绪化执行），必须给出具体证据。
5. 迭代：提炼可复用 lesson，格式为"在 [条件X] 下，应该 [动作Y]，因为 [证据Z]"，必须可执行。
6. 批评可信度评估：自评 + 独立验证加成（+15/项），≥70% 才进入观察期。
7. 观察期验证：认知 lesson 14 天模拟盘 / Bug 修复 7 天；通过后才升级为正式 lesson。
8. 回滚机制：P&L回撤>3% / 知行合一下降>15分 / 认知偏差增加 / 执行速度下降>50% 任一触发即回滚。

## 3. HARD-GATE

- 复盘必须基于实际 episode 数据，不允许凭记忆复盘。
- 认知偏差识别必须给出具体证据（哪笔交易/哪个决策点）。
- 迭代 lesson 必须可执行，不允许"以后要更谨慎"等模糊建议。
