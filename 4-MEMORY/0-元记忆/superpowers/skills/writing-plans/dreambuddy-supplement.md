## 1. 本 Skill 在 Dreambuddy 场景的适用范围

适用: 设计需落地 / ≥ 3 步的任务 / 文档转实施计划；不适用: 一行命令可完成的琐碎任务

## 2. 本土化适配说明

实施计划粒度：0.5-2h/task，若总时长预估 > 10h 视为大型计划，建议拆阶段并每个阶段单独 review checkpoint。

## 3. 常见 Rationalization 反模式

- [ ] 计划 = 标题列表，具体步骤无 0.5-2h 粒度
- [ ] task 写 实现 xxx 不拆文件路径 / 函数名 / Consumes/Produces
- [ ] 计划写得过长（> 40 task），实际执行到第 10 条就失效
