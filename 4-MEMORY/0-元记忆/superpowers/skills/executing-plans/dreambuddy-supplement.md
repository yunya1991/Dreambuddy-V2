## 1. 本 Skill 在 Dreambuddy 场景的适用范围

适用: 已有 plan 的多步执行；不适用: 无 plan 直接上手的探索性任务

## 2. 本土化适配说明

执行中每完成 3 个 task 做 checkpoint 验证（对照 plan 清单），偏离 > 30% 自动触发重写计划子任务（暂停当前执行）。

## 3. 常见 Rationalization 反模式

- [ ] 跳 task 不记录，偷偷插入计划外任务不补 checkpoint
- [ ] 连续 5 步失败还在死磕，不触发重写计划
- [ ] 完成后不对比实际产出 vs 计划差异，直接 claim 全部完成
