## 1. 本 Skill 在 Dreambuddy 场景的适用范围

适用: 3+ 无依赖子任务；不适用: 强前后依赖的串行任务

## 2. 本土化适配说明

同时并发不超过 3 个（终端数限制 5，留给 daemon/交易系统 2 个）；超过 3 个按队列串行。

## 3. 常见 Rationalization 反模式

- [ ] 并发子任务之间共享状态文件，后写者覆盖
- [ ] 并发数超过终端限制，所有任务互相 kill
- [ ] 无依赖的串行任务硬并发，反而增加调度开销
