## 文档记忆是什么？

文档记忆是 0-系统文档管理 在总记忆系统中的**索引和状态镜像**。

- **不存内容**：文档的具体内容在 0-系统文档管理/ 中
- **只存索引**：文档在哪里、属于什么类型、什么状态
- **存状态**：文档质量、与代码对齐状态、债务状态
