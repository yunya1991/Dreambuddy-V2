## 1 · Critical

### C1：去重阈值 0.82 会漏掉多数跨源真重复（已修订）

**问题**：初稿只做「去标点 + 4-gram Jaccard ≥ 0.82」。实测同一快讯被门户转载时带前缀（`财联社11月13日电，` / `金十数据整理：` / `据纽约时报：`）或代码后缀（`英伟达(NVDA.O)`），把真重复的 Jaccard 压到 0.55–0.77。

**实测证据**（最后 400 行 events 源）：

| 标题对 | Jaccard（归一化前） | 真重复？ |
|---|---|---|
| 「美国财政部拍卖四周期国债…」 vs 「财联社11月13日电，美国财政部拍卖…」 | 0.71 | 是 → 会被漏掉 |
| 「法国总统马克龙…de Cos…」 vs 「财联社11月13日电，…De Cos…」 | 0.77 | 是 → 会被漏掉 |
| 「市场消息：黄仁勋聘请 Paul Weiss」 vs 「据纽约时报：黄仁勋聘请…」 | 0.64 | 是 → 会被漏掉 |
| 「戴利：正处于招聘的完美风暴」 vs 「戴利：正处在招聘的完美风暴」 | 0.60 | 是 → 会被漏掉 |
| 「戴利：AI 对通胀推动作用」 vs 「戴利：AI 对劳动力市场影响有限」 | 0.17 | 否 → 安全 |

加上前缀归一化后，同一批真重复升到 0.85–1.00；同句改写 Jaccard 0.60 但 `difflib.ratio` 0.95；不同表态 0.03–0.19，间隔充分。

**修订（已写入 v1.0 §4.2）**：① 先做 boilerplate 归一化（源前缀、`【…】`、证券代码后缀）；② 判定改为 `Jaccard ≥ 0.78` **或** `ratio ≥ 0.90`；③ 增加「同 type + symbols 有交集」守卫；④ §9 增补真实样本回归测试。

## 2 · Major

### M1：`hot_news.json` 未登记 gitignore（已修订）
运行时产物，`.gitignore` L223-L241 已有 39 产物清单但无此项。→ §7 第 7 项。

### M2：前端类型会导致 `tsc` 失败（已修订）
`ModuleDetail.tsx:32-35` 将 `metrics.breakdown` 声明为 `Record<string, number>`；新增 `hot_news_top10`（数组）、`hot_news_summary`（对象）必然类型报错。→ §7 第 6 项 + R-7。

### M3：云端「本地通过」不等于「云端可用」（已修订）
云端为全量部署、39 产物由云端 `datacenter-scheduler` 自产，不来自本地 rsync。若云端未启用 `DC_SEMANTIC_AUTO` 或 39 代码未同步，页面恒为空态。→ §8 A-6 明确「云端实测」+ R-5 改写。

### M4：旧行无新字段，上线首日榜单会稀疏（已修订）
存量 21550 行不重写，只有新行带 `topic/importance`；24h 窗口内老行占绝大多数。→ §4.5 增加「只读补算」（纯函数现场算，标 `recomputed`）。

### M5：无新事件时产物不刷新（已修订）
若写盘绑在「有新增事件」分支，recency 不衰减、`generated_at` 不滚动，前端无法判断新鲜度。→ §7 第 8 项：每轮无条件重写。
