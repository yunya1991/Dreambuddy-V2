## 2. 总体设计

```
NAV_ITEMS（唯一事实源）
  ├─ platform: 基本面 → /dashboard/fundamental   （删除 news tab）
  └─ platform: 新闻   → /dashboard/news          （新增；独立页面）

/dashboard/news  ──> HotNewsPanel（外链增强） + ModuleDetail(module="news")
                         │
                         └─ GET /api/fundamental/news/snapshot（复用，契约不变）
```

三条硬约束：

1. **导航只改 `navigation.ts`**，不在 `layout.tsx` 内联路由（E9）。
2. **接口复用**：新闻页与原 tab 调同一快照端点，因此不新增鉴权/缓存/错误分支。
3. **外链集中在 `HotNewsPanel`**，不做全局"链接可选"抽象（仅此一处消费 `source_url`）。

## 3. 详细设计

### 3.1 导航入口（N-1）

`navigation.ts` 的 `NAV_ITEMS` 中，`fundamental` 之后插入一条：

```ts
{ id: 'news', label: '新闻', href: '/dashboard/news', icon: '📰', section: 'platform' },
```

副作用自动生效：侧栏、折叠态、移动端、⌘K 命令面板、`navItemsToCommands` 单测（断言 `NAV_ITEMS.length`，动态取值，不需改）。

### 3.2 组件迁移（N-2）

`components/features/fundamental/HotNewsPanel.tsx` → `components/features/news/HotNewsPanel.tsx`。

- 仅 1 处 import 需改（`fundamental/page.tsx`）；无其他引用方（已全仓确认）。
- 目录语义归一：`features/news/` 存放新闻域组件，后续新闻页增强不再挂到 `fundamental/` 下。

### 3.3 新闻页（N-3）

新建 `src/app/dashboard/news/page.tsx`（client component）：

```
标题区（新闻监控 / 24h 热点影响力）
  ├─ <HotNewsPanel />
  └─ <ModuleDetail module="news" title="新闻监控" />
```

- 结构与原 tab 分支（fundamental/page.tsx L64-L73）逐字一致，保证 G3。
- 不引入 `useSearchParams` 深链，避免 `Suspense` 边界与额外水合成本（深链列为后续协同项，见 §7 R2）。

### 3.4 基本面瘦身（N-4）

`fundamental/page.tsx`：

1. `tabs` 删除 `{ id: 'news', label: '新闻监控' }`；
2. `tabModules` 删除 `news: 'news'`；
3. 删除 `activeTab === 'news'` 分支与 `HotNewsPanel` import；
4. L84 兜底分支的 `activeTab !== 'news'` 条件同步清理（该条件在删除 tab 后恒真，属死条件）。

### 3.5 头条外链（N-5）

在 `HotNewsPanel` 内新增纯函数守卫 + Top3 卡改造：

```ts
function isHttpUrl(u?: string | null): u is string {
  return typeof u === 'string' && /^https?:\/\//i.test(u.trim());
}
```

- `TitleCell`：现有 `<a>` 改为先用 `isHttpUrl` 判定；非 http(s) 一律降级为 `<span>`（外部源数据属系统边界，需最小校验，避免 `javascript:` 等非预期协议）。
- Top3 卡片（L253-L268）：命中 `isHttpUrl` 时外层换 `<a href target="_blank" rel="noopener noreferrer">`，并加 `onClick={e => e.stopPropagation()}` 与 `title="在新窗口打开来源"`；否则保持 `div`。
- **表格整行不改为跳转**：行点击当前用于展开 `parts` 分项，保留该交互；标题单元格已经承担跳转职责（E5）。移动端同样只作用于标题。
- 视觉：卡片增加 `hover:bg-slate-800/60 transition-colors`，不新增设计 token（复用现有 tailwind 语义）。

### 3.6 数据与接口（不变）

- 端点为 `/api/fundamental/news/snapshot`，内部触发 `fundamental_snapshot.py` 全量聚合（约 0.8s，进程内 60s 缓存）。
- 已知成本：新闻页首屏沿用该耗时，与原 tab 完全一致；**不新增** `?module=` 快路径（列为 P2 优化，见 §8）。
- `source_url` 覆盖率依赖上游源（E7 实测 100%），缺失时按 §3.5 降级，不阻塞渲染。
