## 2. 总体设计

```
消息源（AI SDK UIMessage / 交易域 SSE / PlanCard）
        │  adapter（单向映射，不改上游类型）
        ▼
AgentPart[]  ──►  PartRenderer（注册表）
                    ├─ TextPart / ReasoningPart
                    ├─ ToolCard（4 态）
                    ├─ PlanCardView（schema 驱动）
                    ├─ ArtifactPart / VerificationPart
                    └─ UnknownPart（JSON 折叠 + warn）

会话层：agent-session-store（持久化）+ 交易域 session-store（保持）
输入层：ChatInput ActionBar（模型/技能/附件/草稿/历史）
入口层：GlobalSearchDialog（⌘K，导航 + 会话 + 动作）
```

原则：

1. **适配器单向**：只把旧事件映射为 part，不反向改造 AI SDK 或交易 SSE。
2. **渲染器可插拔**：新增 part 类型只注册 renderer，不改消息列表。
3. **无新重型依赖**：复用 `react-markdown`、`zod`、现有 V3 原语。
4. **渐进迁移**：交易域先“只读并行渲染”，验证一致后再切换。

## 3. 详细设计

### 3.1 设计 token 收口（B-1）

- 在 `src/app/globals.css` 补全并映射：背景/文字/边框/状态/SACG 五组（沿用原 SPEC §2.6 命名）。
- 新增 `src/lib/design-tokens.test.ts`：扫描 `src/**/*.{ts,tsx,css}` 中 `var(--color-*)`，断言全部有定义。
- 禁止在组件内新增硬编码十六进制色值；既有交易域组件不回改。
- 验收：测试通过；抽查 5 个页面无“透明/黑块”异常。

### 3.2 错误边界与反馈（B-2）

- `src/app/error.tsx` + `src/app/global-error.tsx`：错误摘要 + 重试；不展示堆栈。
- `src/components/feedback/ToastProvider.tsx` + `useToast()`：success/error/info 三态；仅新页面与消息内核使用。
- 消息内核的流失败统一走 toast + 消息内错误 part，不静默。
- 验收：人为抛错页面显示错误边界；工具失败有 toast 且可重试（仅协议层）。

### 3.3 AgentPart 与 PartRenderer（B-3）

**新增** `src/types/agent-message.ts`：沿用原 SPEC §2.3 的 `AgentPart` 定义，补充：

```ts
export interface AgentMessage {
  id: string;
  role: 'user' | 'assistant' | 'system';
  parts: AgentPart[];
  createdAt: number;
  status?: 'streaming' | 'done' | 'error';
  traceId?: string;
}
```

**新增** `src/components/features/agent/PartRenderer.tsx`：

- 注册表：`Record<AgentPart['type'], ComponentType<{ part: AgentPart }>>`。
- 未知类型：`UnknownPart`（`<details>` + JSON 美化 + `console.warn`），FAIL-OPEN。
- 文本/推理：复用 `react-markdown`；推理块默认折叠，显示 `durationMs`。
- Artifact：标题 + kind 图标 + 打开链接（本 SPEC 只做只读跳转）。
- Verification：PASS/BLOCK/INCONCLUSIVE 三态徽标 + evidenceRefs 列表（点击跳报告/产物，未找到则提示）。

**新增** `src/lib/adapters/sse-to-parts.ts`：

- 输入：`sse-dispatcher` 现有事件；输出：`AgentPart[]`。
- 映射表（实施时以现有事件名为准并补 fixture）：
  - `thinking` → `reasoning`
  - `progress` → `tool(state=running)`
  - `step_confirm` → `tool(state=pending)` + 确认入口
  - `report` / `done` → `text` 或 `artifact`
  - `error` → `text(error)` + `verification(BLOCK)`（如适用）
- 未识别事件：忽略并计数，不抛错。

### 3.4 ToolCard（B-4）

- 路径：`src/components/features/agent/ToolCard.tsx`。
- 四态样式与交互严格按原 SPEC §2.4；长结果折叠阈值 12 行；复制按钮使用 `navigator.clipboard`（不可用降级提示）。
- 协议层 error 态提供“重试”回调（由调用方注入）；交易域不显示重试。
- 单测覆盖四态与折叠阈值。

### 3.5 PlanCardView（B-5）

- 类型：`src/types/plancard.ts`（zod schema 镜像 JSON Schema，仅运行时校验）。
- 视图：`src/components/features/agent/PlanCardView.tsx`
  - 头部：`intent` + `debate_meta.verdict` 徽标。
  - `plan_steps`：工具名必须显示注册名；未知工具名标红并提示。
  - `risk_flags`：红色分组。
  - `validation.evaluator_refs`：P0 只展示文本引用，可复制。
- 不做类型生成脚本与 CI 漂移校验（归 SPEC-C，避免与 B 重复）。
- 单测：合法 fixture 渲染 + 未知工具名标红 + 缺字段降级。

### 3.6 协议层接入（B-6）

- `/dashboard/agent` 页面改用 `PartRenderer`；`useChat` 的 `UIMessage.parts` 经 `ui-message-to-parts.ts` 映射。
- 新增 `src/lib/adapters/ui-message-to-parts.ts`：`text`/`reasoning`/`tool-*` 直接映射；未知忽略。
- 保持 `/api/agent/chat` 只读，仅做类型对齐，不加写工具。
- 验收：发送消息、工具调用、PlanCard、错误四类场景可完整渲染；刷新后历史仍在（依赖 B-7）。

### 3.7 会话列表、持久化与深链（B-7）

- 新增 `src/stores/agent-session-store.ts`：`sessions`、`activeSessionId`、`create/rename/delete/select`、`messages`。
- 持久化：`localStorage`（key `dreambuddy.agent.sessions.v1`），限 50 会话 / 单会话 500 条；写入节流 500ms。
- 深链：`/dashboard/agent?session=<id>`；无效 id 回退新建。
- 与交易域 `session-store` 解耦，避免业务串扰。
- 验收：刷新、切换、删除、深链分享（本机）均正确。

### 3.8 长会话虚拟化（B-8）

- 阈值：消息 >50 条启用。
- 实现优先级：
  1. 先启用 `content-visibility: auto` + `contain-intrinsic-size`（零依赖）。
  2. 若首屏仍 >100ms，再实现 `useVirtualList`（固定估算高度 + overscan，零依赖）。
- 不做 ChatMiniMap（P2，收益低、成本高）。
- 验收：200 条消息滚动稳定；新增消息自动吸底；用户上滚时不强制吸底。

### 3.9 输入器增强（B-9）

- 在现有 `ChatInput.tsx` 上扩展 ActionBar，不引入 Lexical：
  - 停止生成（调用 `useChat.stop` / A 的 `abortTaskStream`）
  - 重生成、编辑重发
  - 草稿自动保存（sessionStorage）
  - 输入历史（上/下键，最多 50 条）
  - `@` 触发技能/Agent 候选（数据源：现有 skills/agent 列表 API；无 API 时静态清单）
  - 附件引用：仅支持文本文件选择与展示文件名（不做上传），避免新增存储依赖
- 验收：键盘可完成发送/停止/重发/选择技能；不影响交易域现有发送链路。

### 3.10 命令面板（B-10）

- 扩展现有 `src/components/features/search/GlobalSearchDialog.tsx`：
  - ⌘K / Ctrl+K 打开；Esc 关闭；↑↓ 选择，Enter 执行。
  - 数据源：`NAV_ITEMS`（A 交付）+ 最近会话 + 固定动作（新建会话、打开报告、切换交易模式）。
  - 空查询展示分组；查询做大小写不敏感子串匹配；最多 20 条。
- 不引入 cmdk 等依赖。
- 验收：13 个导航项均可跳转；最近会话可恢复；无结果有提示。
