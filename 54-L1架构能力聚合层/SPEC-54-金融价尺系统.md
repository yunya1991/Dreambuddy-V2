## §0 决策摘要（ADR）

| ID | 决策 | 理由 | 代价 |
|---|---|---|---|
| **ADR-F1** | 把"社会必要劳动时间（SNLT）"作为**建模假设**而非真理导入 | 它是唯一能给出"绝对价值尺度"的理论框架；但主流经济学不认，必须可证伪 | 若 H1/H2 检验失败，降级为成本锚框架 |
| **ADR-F2** | 尺子 = **劳动小时**（本体）+ **MELT**（货币换算率）+ **标准商品**（不变尺度），三者并列，禁止只做其一 | 单用 CPI 是"拿会变的尺子量东西"；单用劳动小时缺货币换算；单用标准商品缺高频可得性 | 实现复杂度 ×3，但可交叉校验 |
| **ADR-F3** | 价格分三层：**价值 λ → 生产价格 p\* → 市场价格 p**，禁止跳过 p\* 直接把 p 与 λ 比 | 转型问题（transformation problem）是 LTV 的硬伤，跳过即伪科学 | 需要利润率均等化假设，年频 |
| **ADR-F4** | 所有"劳动含量"类输入按**年/季频**，禁止伪装成日频；日频只用其**代理**（ULC、小时产出）并显式标注 `frequency_mismatch=true` | 投入产出表年度发布，季度 ULC 有修订 | 日频信号只能用代理，精度下降 |
| **ADR-F5** | 输出必带**双状态机 `market_regime`（全局）与 `asset_regime`（单资产）**，UI 只能按 regime 展示对应指标 | 防止"理论没通过检验却照常展示结论"；两者不可互相替代（v1.2，B6） | 前端需读两个 regime |
| **ADR-F6** | 加密资产单独口径：其"社会必要劳动时间"由**协议难度调整**硬编码，属受控实验，不与法币资产混算 | 难度机制使每币算力时间可精确计算 | 需外部能效/电价参数 |
| **ADR-F7** | 纯确定性、无 LLM、无网络、只读库（沿用 SPEC-54 ADR-V15 / ADR-3） | 与全仓一致 | — |
| **ADR-F8** | 方法编号新增 **V 组**（`V01–V23`），能力编号新增 **D-V 组**（`D-V01–D-V07`） | `D-K` 已被评估层（MERS/Discovery）占用；V 语义唯一（Value/价尺） | 需改 `registry.GROUP_CAPACITY` 增 `"V": 23` |
| **ADR-F9** | **资金流是「验证器」，不是「定义器」**：它只参与 `flow_confirm` 交叉验证，**不得进入价值定义、不得改写任一 regime** | 资金流本身会被流动性、风险偏好、杠杆与挤兑污染，用它定义价值等于用价格定义价值（循环论证） | 少一个"独立价值源"，但避免自证 |

## §1 定位与目标

### 1.0 文档定位：探索目标（North Star），不是排期任务

本 SPEC 的**长期目标是提供一把"社会必要劳动时间"的尺子**用于衡量资产价值，并以周期理论承担**一般经验性计算**（库存/朱格拉/长波的位置判断）。它是方向锚，不是当前排期项。

**研究路线（2026-11-15 用户确定）**

| 阶段 | 做什么 | 归属 | 本 SPEC 的地位 |
|---|---|---|---|
| **S1 单资产尺度发现** | **纯统计**：对每一类资产（股/商品/加密/债汇）分别搜索"哪个衡量尺度最稳定、最可复现"（分位稳定性、均值回归半衰期、跨期 IC、结构断点） | L1 统计层（**当前主线**） | 只提供**候选尺度清单**（λ/MELT/成本锚/收益率倒数…），**不预设哪一个是答案** |
| **S2 汇总** | 把 S1 得到的各类尺度做可比化汇总（共同计价、相位对齐） | L1 | §3 的构造在此阶段才被采用 |
| **S3 反思与相变** | 汇总结果的反思、相变识别、跨周期解释 | **反思进化系统 + 未来大模型探索** | 不在本 SPEC 内实现 |

**由此产生的三条硬边界**

1. **禁止从"统一价尺"倒推 S1**：不得先假定 SNLT 就是正确答案，再挑数据去支持它。S1 必须独立做，其结论可以推翻本文档。
2. **L1 只出统计事实**（尺度稳定性、偏离度、相位）；解释与反思不属于 L1。
3. **V01–V23 是候选清单，不是承诺**：若 S1 证明某类资产适用其他尺度，以 S1 结果为准。

**已回退的探索线**：Vision Banana（arXiv:2604.20329）"多视角一致性"借鉴线与配套 P0 实验已于 2026-11-15 回退（判断：金融场景低信噪比、无价值真值，适用性有限）。相关设计文档与脚本已删除，仅将统计学教训（伪迁移）留在认知库。

### 1.1 解决什么

现有 L1 全部方法都在**价格空间**内工作（相关、延续性、分位、协整、带通）。它们回答"价格怎么动"，但无法回答：

> **这个价格，用一把不随行情变化的尺子量，到底贵还是便宜？**

本模块提供这把尺子。它把"价值"从哲学概念转成**四个可计算量**，并用它们重标定一切资产价格、利率与通胀：

| 可计算量 | 一句话 | 频率 |
|---|---|---|
| 劳动含量 λ | 一单位商品凝结多少小时社会必要劳动 | 年（IO 表）/ 季（ULC 代理） |
| MELT | 一劳动小时对应多少货币（货币的刻度） | 季 |
| 标准商品 | 不受分配变动影响的复合计价物 | 年 |
| 成本锚 | 边际生产成本（矿业 AISC / 挖矿成本 / 抬升成本） | 年 / 日（加密） |

### 1.2 目标

| # | 目标 |
|---|---|
| **G0** | **先于一切**：为每类资产产出"合适衡量尺度"的统计证据（稳定性 / 均值回归半衰期 / 跨期 IC / 结构断点），再谈统一尺子 |
| G1 | 输出 23 个确定性方法（V01–V23），全部登记进 `methods/registry`，可反查方法 ID |
| G2 | 任何资产价格可换算为**劳动小时计价序列**，并给出 `n / span / assumptions / caveat` |
| G3 | 给出**通胀二分解**：`d ln P = d ln MELT + d ln λ`（货币因素 vs 价值因素） |
| G4 | 给出**价值偏离度**及其均值回归半衰期，带 ADF 与置信带 |
| G5 | 输出双状态机 `market_regime`（全局）与 `asset_regime`（单资产），并为资金流附 `flow_confirm` |
| G6 | 可复现：同输入同参数字节一致（无随机、无网络） |

### 1.3 非目标（硬边界）

| 不做 | 原因 |
|---|---|
| ❌ 输出"某资产被低估/高估，应买入" | 属 L2 决策；本模块只给偏离度与检验结果 |
| ❌ 用 SNLT 做点预测或择时信号 | 季/年频，天然不适合日频择时 |
| ❌ 宣称"劳动价值论已被证明" | 主流非共识；本模块只做**可证伪检验**，不做立场宣示 |
| ❌ 用二手文献数字充当本项目结论 | 所有数值必须本地实测，禁止引用未复现的 R²/半衰期 |
| ❌ 把长波（康波）当统计结论 | 样本仅 4–5 个周期，只能作背景标注，禁止推断 |
| ❌ 写入生产库 / 依赖 LLM | 沿用全仓纪律 |

### 1.4 层级归属

```
L0 数据层            L1（本模块）                    L2（后续）
价格/宏观/链上  →   价值尺标定 → 偏离度 → 状态机  →  择时/配置（不在本 SPEC）
```

## §2 理论底座（调研结论，本文件内闭合）

### 2.1 为什么"尺子"必须先解决三个理论坎

| 坎 | 问题 | 本模块的处理 |
|---|---|---|
| **可观测性** | SNLT 无法直接读数 | 取第一含义（技术平均）的**直接观测式**：单位产出劳动小时数 = 劳动生产率倒数 |
| **社会平均 vs 个别** | 价值由行业平均决定，个别企业用时更少 | 用行业小时产出的**中位数**作社会平均；分位数差 = 超额剩余价值（可算） |
| **转型问题** | 价格不直接等于价值 | 分三层：λ → 生产价格 p\*（成本+平均利润）→ 市场价格 p（ADR-F3） |

同时须区分 SNLT 的**两种含义**：

- **第一含义**（技术决定）：现行社会生产条件下生产单位商品所需的劳动时间 → 由生产率决定。
- **第二含义**（需求实现）：社会总需求能吸收的产量所对应的劳动时间 → 由库存/产能利用率修正。

两者之差就是"**价值实现失败**"的量，也是库存周期的数学来源（§2.4）。**只算第一含义会得到一条永不下弯的"价值线"，这是本模块最容易犯的错。** 第二含义由 **V23 `snlt2_ratio`** 实现（v1.2 补齐，评审 B1）。

### 2.2 三层价格与各自的统计对象

```
λᵢ  (小时/单位)  ──×MELT(t)──▶  p*ᵢ (货币)  ──供需扰动──▶  pᵢ (市场价)
   价值本体                      生产价格                    市场价格
```

| 层 | 统计对象 | 检验 | 结论性质 |
|---|---|---|---|
| λ | 横截面相对劳动含量 | `log p ~ log(λ·MELT)` 斜率是否≈1 | 价值**形式**（年频） |
| p\* | 利润率均等化 | 部门利润率收敛性 | 长期引力（年频） |
| p | 价格对 p\* 的偏离 | ADF + 半衰期 | 均值回归（季/年） |

**禁止**把 `log p ~ log λ` 的拟合结果宣称"验证了劳动价值论 / 解决了转型问题"——缺失 p\* 层的检验只能说明**价值的货币形式**在横截面上有解释力，不能说明利润率均等化。**允许**的检验是 `log p ~ log(λ·MELT)`（v1.2 修正，评审 B7）：横截面同一时点下，部门间利润率差异被截距吸收，斜率只反映相对价值形式的比例性。

### 2.3 四把尺子及其失效条件

| 尺子 | 定义 | 何时有效 | 何时失效 |
|---|---|---|---|
| 货币（美元） | 名义计价 | 短期 | 长期尺度漂移；跨国不可比 |
| **劳动小时** | 一小时 = 一小时价值（本体定义） | 同一技术/同一货币区内 | 复杂劳动折算靠工资率近似；跨国劳动不可比；非贸易品 |
| **MELT** | 名义增加值 ÷ 总劳动小时 | 有完整国民经济核算 | 需季度数据；口径变更；非正规经济遗漏 |
| **标准商品**（Sraffa） | 投入矩阵主特征向量组合的商品束 | 理论最优：不受工资/利润分配影响 | 需年度投入产出表；现实中不存在该商品束，只能构造 |

> **关键洞察**：劳动小时**天然是不变尺度**（一小时就是一小时价值），变的是"单位商品所含小时数"。所以尺子不需要"锚定物"，只需要"换算率"。这正是 MELT 的作用。

### 2.4 周期理论的统一解释（本模块的立场）

三种周期不是并列的三种理论，而是**同一件事（价值重置）的三个频率**：

| 周期 | 传统解释 | 价值尺解释 | 可算代理 |
|---|---|---|---|
| 基钦 3–5 年 | 库存波动 | **价值实现滞后**（生产时间 vs 实现时间错配） | 存货/销售比、产能利用率、SNLT-II 缺口 |
| 朱格拉 7–11 年 | 设备投资 | **固定资本更新**（资本-产出比波动） | 资本-产出比、设备投资/GDP |
| 库兹涅茨 15–25 年 | 建筑/人口 | 耐用资产重置 | 住宅开工、房价收入比 |
| 康波 45–60 年 | 技术革命 | **价值革命**（技术使 λ 整体下移，旧价值被摧毁） | 全要素生产率长周期（仅背景，禁止推断） |

可算的利润率恒等式（不需要 IO 表，季度可算）：

```
r = 利润份额 × 产能利用率 ÷ 资本-产出比
```

其周期波动即"价值重估节奏"。**美林时钟在本框架下只是"名义相位"**，真实相位须用劳动尺度重算（因为四象限用的是 CPI，而 CPI 本身含价值变化）。

### 2.5 加密资产：SNLT 的受控实验场

比特币难度调整把"每约 10 分钟出块"写死在协议里，等价于**社会必要劳动时间被代码硬编码**；每次减半，每币所需劳动时间阶梯式翻倍。因此：

```
单币劳动成本(USD) = hashrate × 能效(J/TH) × 电价($/kWh) × 单币出块时间(s) ÷ 3.6e6
```

这比任何经济体都干净。但**成本锚不是价值锚**——2022 年已出现价格长期低于挖矿成本，说明在无内在现金流的资产上，"成本"只提供弱支撑。本模块对此**只输出偏离度与分位，不输出"必然回归"**。

### 2.6 立场声明（写入输出 caveat，不可省略）

> 劳动价值论非主流经济学共识。本模块把它当**建模假设**，用 §7 的 H1–H4 四条检验去证伪。若 H1/H2 不通过，系统自动降级为 `cost_anchor_only`，只保留成本锚与 ULC，不宣称价值论成立。**任何输出不得省略此声明。**

## §3 尺子的数学构造

### 3.1 轴① 劳动含量 λ

```
λ = l · (I − A)⁻¹
```

- `l`：直接劳动投入系数向量（各部门劳动小时 ÷ 总产出）
- `A`：投入产出矩阵（BEA 年度 IO 表 / OECD ICIO）
- `(I−A)⁻¹`：Leontief 逆（完全消耗系数）

高频代理（季度，BLS Productivity and Costs）：

```
labor_requirement_i ≈ 1 / 劳动生产率_i = 小时_i / 实际产出_i
ULC_i = (每小时报酬) / (每小时产出) = COMPNFB / OPHNFB
```

**纪律**：λ 与 ULC 不同量纲，禁止相加、禁止混用；每个输出必须带 `measure ∈ {labor_content, unit_labor_cost, labor_requirement}`。

### 3.2 轴② MELT

**同部门口径铁律（v1.2 修正，评审 B2）**：分子与分母必须来自**同一生产部门**，否则相除无会计意义。

```
MELT(t) = 非农企业部门名义增加值(t) / 非农企业部门总劳动小时(t)     [货币/小时]
        = VA_nfb(t) / HOANBS(t)
MELT_proxy(t) = ULCNFB(t)                                          [指数，仅用于增长率]
```

- `VA_nfb`：BEA NIPA 非农企业部门增加值。FRED 候选 `A460RC1Q027SBEA`，**V0 阶段必须实测核验**；若不可得，退化为 `GDP × 非农企业增加值占比`（占比同样需核验），并在输出标 `degraded_numerator=true`。
- **禁止**用全经济 `GDP` 直接除以 `HOANBS`（部门范围不一致，H3 必然失败）。
- H3 恒等式随之修正为：`dln(VA_nfb) − dln(HOANBS) − dln(MELT) ≈ 0`。

**允许的用法**：`d ln MELT`（货币贬值率）。
**禁止的用法**：用 MELT 水平值跨十年直接比较（国民经济核算口径会变）。

复杂劳动折算（reduction problem）：以相对工资率近似

```
复杂小时 = 简单小时 × (该岗位工资率 / 基准岗位工资率)
```

须标注 `reduction_method="relative_wage"`，并承认其为近似。

### 3.3 轴③ 标准商品

```
A·q = λ*·q      （Perron 主特征向量）
R   = (1 − λ*) / λ*    （标准比率 = 最大利润率）
```

以标准商品为计价物时，工资-利润线为直线 `r = R(1 − w)`，**不随分配变动**——这就是 Ricardo 寻找、Sraffa 解决的"不变尺度"。用于交叉校验 MELT 口径下的实际工资与利润率。

### 3.4 三层价格与偏离度

**v1.2 修正（评审 B3）**：λ 是**全劳动含量**（含不变资本的物化劳动），直接乘 `(1+r̄)` 等于对不变资本也计利润，会系统性高估生产价格。必须先按 IO 表拆成 c / v / s 三块：

```
cᵢ = MELT · λ_c,i        物化劳动（中间投入，不变资本消耗）
vᵢ = MELT · λ_v,i        必要劳动（劳动报酬）
sᵢ = MELT · λ_s,i        剩余劳动
λᵢ = λ_c,i + λ_v,i + λ_s,i

p*ᵢ = (cᵢ + vᵢ) · (1 + r̄)     生产价格（成本加成形式）
gapᵢ = ln(pᵢ) − ln(p*ᵢ)        价值偏离度
```

- **禁止** `p* = λ·MELT·(1+r̄)`（B3 错误式，留作反例）。
- `r̄` 为平均利润率，来源见 §5.2。缺 `r̄` 时 V05 直接返回 `gate=missing_rbar`，不得默认取值。
- 若数据只支持总量口径（无法拆 c/v），则 V05 降级为 `gap_total = ln p − ln(λ·MELT)`，输出必须标 `decomposed=false`，且**不得称其为生产价格偏离**。

`gap` 的均值回归检验：先做协整前置（Engle-Granger，见 P1-1），通过后 ADF（含常数/趋势的选择必须显式登记）+ 半衰期 `ln0.5 / ln|φ|`。**半衰期 > 10 年视为"无有效回归"，不得展示回归箭头。**

### 3.5 任意价格的劳动小时标价

```
H(t) = P(t) / MELT(t)           [小时]
```

反直觉但正确：**同一资产用小时标价后，长期涨幅通常显著低于美元标价**，差额即货币贬值。这是本模块对"真实收益"的重新定义。

### 3.6 通胀二分解

```
d ln P_basket = d ln MELT  +  d ln λ_basket
                 ↑货币因素        ↑价值因素（生产率变化）
```

含义：CPI 上涨可能不是"货币变多"，而是"篮子劳动含量变高"（如服务化、复杂度上升）；反之亦然。**这是本模块相对"CPI 平减"的唯一增量，也是必须实测定论的地方（H4）。**

### 3.7 真实利率（劳动尺度）

```
r_labor = i − d ln MELT
```

对比传统 `r_real = i − π_CPI`。两者差值即 §3.6 的价值因素。

### 3.8 轴④ 资金流尺（市场的实时投票，仅作验证）

用户直觉的严格化：**资金流入是"利润率高于平均"的响应，而利润率高于平均的来源正是 `gap>0`（价格高于价值）。** 因此资金流不是第四种价值定义，而是 **`gap` 的滞后响应函数**，可用于交叉验证。

```
Flow_t = f( gap_t , 宏观流动性_t , 风险偏好_t )          # 响应函数，不是价值本身
因果链：gap↑ → 流入↑ → （建设/部署期）→ 产能↑ → λ↓ → gap↓ → 流入↓
```

**必须先纠正一个直觉偏差**（否则因果会反）：资金流入**放缓**不等于"聪明钱认为贵了"，它可能是
(a) 宏观流动性收紧、(b) 风险偏好下降、(c) `gap` 已被定价。只有**剔除宏观与市场共同因子后**的**超额资金流**才有价值判断含义。

四个可计算量（分别对应"流向 / 速度 / 速率 / 承接力"）：

| 量 | 定义 | 读法 |
|---|---|---|
| **流向** | `sign(超额净流入)` | 符号本身信息量最低（与价格同期循环） |
| **速度** | `flow_intensity = 净流入 / 流通市值` 的滚动 z 分位 | 剔除规模偏差，跨资产可比 |
| **速率** | `Δflow`、`Δ²flow` + 符号持续期 | **拐点比水平更有信息**：加速流入 + 价格滞涨 = 派发 |
| **承接力** | `β_lag`：`ΔlnP_t = α + β_lag·flow_intensity_{t−1} + γ·ΔlnP_{t−1} + ε`（滚动回归） | **本尺最有价值的量**：同等资金推动的涨幅下降 = 边际承接力衰减 = 供给扩张/筹码派发先兆。**必须用滞后项识别**（v1.2 修正，评审 B5）：同期回归中价格与流量互为因果，OLS 系数不可解释 |

**背离判定的四象限**（唯一可用的信号形态）：

```
价格 z 高  &  流入速率 z 低/负   →  高估确认（double_confirm=confirmed_overvalued）
价格 z 低  &  流入速率 z 高/正   →  低估确认（confirmed_undervalued）
价格 z 高  &  流入速率 z 高      →  趋势中，无价值信号（neutral）
价格 z 低  &  流入速率 z 低      →  无人问津，无价值信号（neutral）
```

**硬纪律**：
0. **识别纪律（v1.2，B5）**：`β_lag` 只用 `flow_{t−1}` 与 `ΔlnP_{t−1}` 作解释变量；任何同期回归结果只能标 `contemporaneous=true` 且**禁止**称"承接力/先兆"。备选识别：对 BTC 可用 ETF 获批、指数纳入等外生事件做事件研究；或 bivariate VAR 的脉冲响应。
1. 只做**同向确认**，不做反向证伪——`gap` 与流向冲突时输出 `conflict` 并**以 `gap` 为准**（ADR-F9）。
2. 加密的 `TVL(USD)` 变化 = 价格效应 + 真实流入，**必须用币本位 TVL 或剔除价格分量**后再当流量。
3. 稳定币增量 ≈ 场外资金入场代理，但增发≠入场（可能是换手/跨链搬运），须与交易所余额变化交叉验证。
4. 传统行业缺"板块资金流"数据时，`flow_confirm=unavailable`，**禁止用价格×成交量冒充资金流**。

| 杠杆/情绪 | `mm_funding_rate`、`mm_open_interest`、`mm_taker_volume`、`mm_liquidation`、`mm_long_short_ratio` | 杠杆流入 ≠ 配置资金；爆仓是流出的被动实现 |
| 传统行业 | **缺**（需 18 采集：美股行业 ETF 份额变动 / A 股行业主力净流入 / 北向分行业） | 缺数据时 `flow_confirm=unavailable`，禁止替代 |

**口径铁律**：
1. `flow_intensity` 分母必须用**同一时点的流通市值**，禁止用成交量或 AUM 替代。
2. TVL / AUM 类"存量"必须先做`Δ存量 − 价格效应`分解，才可当"流量"。
3. 超额流（V20）的对照组：加密用"全市场净流入 + 稳定币增量"，股票用"宽基 ETF 流"；对照组必须显式登记在 `params.control`。
4. 所有流量数据 `PIT` 要求：日频数据以**数据商更新时间**为准，禁止用事后修订值回填历史信号。

### 6.2 双状态机：`market_regime`（全局）与 `asset_regime`（单资产）

**v1.2 修正（评审 B6）**：H1 是**横截面**检验（≥20 部门，美国经济全局属性），不能作为单资产属性。故拆两个状态机，**资产输出只引用 `asset_regime`**。

#### 6.2.1 `market_regime`（全局，市场/经济体级）

| 状态 | 触发条件 | 允许展示 |
|---|---|---|
| `anchored` | H1 通过（横截面 `log p ~ log(λ·MELT)`，斜率∈[0.7,1.3]、R²≥0.6）**且** H2 通过（半衰期中位 < 5 年） | 全部指标（含 p\* 偏离） |
| `cost_anchor_only` | H1 或 H2 未过，但 V09/V10 通过 | 只展示成本锚类 |
| `uninformative` | 上述均未过 | 只展示原始换算（V04） |
| `insufficient_data` | 未达 §5.5 门禁 | 只展示缺口说明 |

#### 6.2.2 `asset_regime`（单资产：个股 / 商品 / 加密）

| 状态 | 触发条件（只用资产自身可得信息） | 允许展示 |
|---|---|---|
| `anchored_asset` | 该资产 H2 通过（协整 + 半衰期 < 5 年）**且** `market_regime=anchored` | 该资产的 gap / 小时标价 / 结论 |
| `cost_anchor_only` | H2 未过但成本锚可分位 | 只展示成本锚 |
| `uninformative` | 均未过 | 只展示小时标价（V04），禁止"贵/便宜" |
| `insufficient_data` | 未达门禁 | 只展示缺口 |

**引用规则**：单资产输出必须同时带 `market_regime`（作背景）与 `asset_regime`（作结论依据），且**不得以 `market_regime=anchored` 替代 `asset_regime` 判定**。

### 6.2.1 `flow_confirm` 交叉验证维度（ADR-F9：不影响 regime）

| 状态 | 条件 | 展示 |
|---|---|---|
| `confirm` | `double_confirm` 与 `asset_regime` 同向（高估/低估一致） | 显示「资金流同向确认」 |
| `conflict` | 两者相反 | 显示「资金流与价值尺冲突，以价值尺为准」 |
| `neutral` | 背离四象限落在 neutral | 只显示原始强度/速率，不作解读 |
| `unavailable` | 无板块流数据或 n 未达门禁 | 明示缺口，禁止用价格量替代 |

**禁止**：`flow_confirm` 反向改写任一 regime；禁止用 `flow_confirm=confirm` 提升结论强度措辞。
**冲突告警（评审 Devil's Advocate 让步条件）**：`flow_confirm=conflict` 连续 ≥ 4 期时，必须输出 `value_ruler_suspect=true` 告警（提示价值尺可能失效），不得永远让价值尺赢。

**状态转移不可跳级**：`insufficient_data → uninformative → cost_anchor_only → anchored`，每级需重新检验，禁止缓存上次结果。

## §7 验收标准（可证伪，未通过则降级）

### 7.1 四条假设检验（本模块的生死线）

| # | 假设 | 检验 | 通过阈值 | 失败处理 |
|---|---|---|---|---|
| **H1** | 相对价格 ∝ 相对**价值形式** `λ·MELT` | 横截面 `log p ~ log(λ·MELT)`，斜率、R² | 斜率∈[0.7,1.3] 且 R²≥0.6 | 降 `cost_anchor_only` |
| **H2** | 价格/价值比均值回归 | ADF（含常数）p<0.10 + 半衰期 | 半衰期中位 < 5 年 | 降 `cost_anchor_only` |
| **H3** | MELT 会计恒等式自洽（**同部门**） | `dln(VA_nfb) − dln(HOANBS) − dln(MELT)` | 绝对误差 < 1% | 数据口径错误，阻塞发布 |
| **H4** | 换尺子改变结论 | `r_labor − r_cpi` 分布 | 显著非零（\|t\|>2） | 尺子无增量信息，降 `uninformative` |
| **H5a** | 资金流是 gap 的**滞后响应** | `corr(flow_t, gap_{t−k})`，k=0..8 | 存在 k≥1 使相关显著高于 k=0 | 资金流只作描述 |
| **H5b** | 滞后弹性 β_lag 是**先行指标** | `corr(β_lag,t, gap_{t+k})`，k=1..4（BH 校正） | 至少一个 k 的 `p_adj<0.10` 且方向为正 | 关闭 V19 信号语义 |
| **H5c** | 背离有增量信息 | 价格高+流入减速 vs 对照组，未来 h 期收益差 | 分层统计显著（不要求可交易） | 关闭 `flow_confirm` 的 confirm 态 |

**H3 是唯一硬门禁**（会计恒等式，必须成立）；H1/H2/H4 决定 regime 而非阻塞上线。

### 7.2 单元测试（合成数据，必须全绿）

| 用例 | 构造 | 期望 |
|---|---|---|
| 恒等性 | λ 恒定、MELT 恒定、p=p\* | `gap ≡ 0`（误差 <1e-12） |
| 尺子不变性 | 所有价格 ×2 且 MELT ×2 | `hours` 序列不变 |
| 通胀分解 | 构造 P=MELT·λ | `dln_price ≡ dln_melt + dln_lambda` |
| 门禁 | n=39 季 | `gate=insufficient_samples`，无数值输出 |
| 反例 | 白噪声价格 | 不得判 `anchored` |
| 参数缺失 | 不传能效/电价 | `gate=missing_assumptions` |

### 7.3 真实数据验收

| 项 | 数据 | 通过标准 |
|---|---|---|
| 美口径 | 1990Q1–2026Q3，n≈146 | H3 误差 <1%；MELT 增长率与**非农企业增加值/工时**增长手工核算一致 |
