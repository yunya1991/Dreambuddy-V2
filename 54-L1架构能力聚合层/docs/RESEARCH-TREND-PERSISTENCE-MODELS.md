# 54 调研 — 趋势延续性（Trend Persistence）建模与模型选型

- **版本**: v1.2 ｜ **日期**: 2026-11-14 ｜ **状态**: 🟢 调研结论（v1.1 修订排期；v1.2 数据事实改为引用方法库 §15，不再复制点数）
- **触发**: 「已通过数据 + 价格对齐建立相关性矩阵，能否用这套相关性描述 + FinBERT 或线性回归做"趋势延续性预测"，主要以统计学描述规律并输出延续性分析」
- **结论**: **可行，但需要先做三处纠正**——① FinBERT 不是价格趋势模型；② "延续性"不是一件事而是三件事；③ 相关矩阵不能直接喂模型，必须先降维成状态特征。
- **配套**: [METHOD_LIBRARY.md](./METHOD_LIBRARY.md)、[SPEC-54](../SPEC-54-L1架构能力聚合层.md)、[TECHNICAL_DESIGN.md](./TECHNICAL_DESIGN.md)

## §0 结论先行

| # | 结论 | 依据 |
|---|---|---|
| 1 | **FinBERT 不能做趋势延续性预测**。它是文本 3 分类器（正/中/负），输入是新闻句子，不是价格或相关矩阵 | 模型输入域不匹配；见 §2 |
| 2 | **你的目标 90% 不需要"模型"**。用确定性统计量（Hurst / 方差比 / AR(1) 半衰期 / 转移矩阵 / IC 衰减 / 条件前瞻分布）就能完整描述"延续性"，且符合 54 的"同输入同输出"定位 | 全部已在 METHOD_LIBRARY 中（T13/T14/T20/T21/B07/B08/B13–B15/F18/R01/R02/R08） |
| 3 | 真要做"预测"，最值得先上的不是深度模型，而是 **HAR-RV（波动延续）+ Logistic/Ridge（方向延续）+ Markov/HMM（状态延续）** 三个可解释基线 | 样本量仅 1,094 天，深度模型必然过拟合；见 §4 |
| 4 | 当前真正的瓶颈不是模型而是**样本**：1,094 天对 Hurst 与深度模型都偏短，加密域指标仅 14–44 天 | 与 SPEC §17.1.3 实测一致 |
| 5 | 相关性描述的是**同期联动**，不是**时间方向**。高相关 ≠ 趋势会延续，只代表一起动。这是本方案最大的逻辑风险 | 见 §5 |
| 6 | 分层归属：**延续性度量 + 条件分布 → L1**；**训练式预测 → L2**。不得把 L2 输出伪装成 L1 确定性结论 | 与 SPEC ADR-3 / §2.2 非目标一致 |

**一句话建议**：先做「延续性画像」（Tier A，纯确定性，零新依赖），再做「相关状态 → 前瞻分布」的 MERS 网格，最后才考虑 L2 的可解释回归基线。FinBERT 保持在情绪腿，不进入趋势链路。

## §1 问题拆解：三种"延续性"不是一件事

用户表述里的"趋势延续性预测"实际混合了三个层次，必须分开定义、分开评估、分开归属。

| 层 | 名称 | 问题 | 输出形态 | 是否确定性 | 归属 |
|---|---|---|---|---|---|
| **P1** | 延续性度量 | 这段价格有没有记忆？记忆多强？ | `H`、`VR`、`φ`、半衰期、连胜分布 | ✅ D2 | **L1** |
| **P2** | 条件延续分布 | 历史上处于同类状态时，之后 h 日怎么走？ | 均值/中位/胜率/区间 + `n` | ✅ D2 | **L1** |
| **P3** | 延续性预测 | 训练模型输出「延续概率」 | 概率 / 点估计 | ❌ 需训练与样本外 | **L2** |

> 用户想要的"主要以统计学描述规律，并输出延续性分析"= **P1 + P2**。这两层不需要任何机器学习，也不违反 54 的确定性纪律。P3 才需要模型，且必须走 L2 的样本外门禁。

**关键区分**：
- P1 回答「这个序列本身是否可延续」；
- P2 回答「在当前状态下，历史延续概率是多少」；
- P3 回答「下一个 h 日会不会延续」。前两者是**描述**，后者是**预测**。混用会导致结论越界。

## §2 FinBERT 的正确位置（以及为什么它不是答案）

### 2.1 输入域不匹配

| 维度 | FinBERT | 趋势延续性所需 |
|---|---|---|
| 输入 | 自然语言句子 / 研报段落 | 数值时间序列、相关矩阵 |
| 输出 | 3 类情感概率（Positive / Neutral / Negative） | 延续概率 / 前瞻收益分布 |
| 训练目标 | 情感分类（交叉熵） | 时序外推 / 分类 |
| 时间结构 | 无（句级独立） | 必须有（滞后、窗口、状态转移） |

FinBERT 的 BERT 编码器可以对任意文本产出 768 维 embedding，但这仍然只是**文本表征**，不含价格的时间结构。把它直接接到价格上不会得到趋势结论。

### 2.2 它唯一合理的三处用法

| 用法 | 形态 | 落地方式 |
|---|---|---|
| U1 情绪标量腿 | 新闻/研报 → `sentiment_t ∈ {−1,0,+1}` 或概率加权分 | 复用 `18-数据获取中心/models/finbert-tone-chinese` + 9 `sentiment_engine.py`，序列化后进入对齐层，与价格做 P2 条件分布 |
| U2 叙事强度因子 | 新闻 embedding 聚类 → 主题热度 / 分歧度 | 需要先补新闻历史纵深，当前不具备 |
| U3 事件语义标签 | 公告分类（利好/利空/中性） | 属事件研究（R04），依赖 `mm_events` 扩充（现仅 16 行） |

### 2.3 中文场景硬约束（已有认知库条目）

- 现役中文模型是 `yiyanghkust/finbert-tone-chinese`（本地 `18-数据获取中心/models/finbert-tone-chinese`），**不是** `valuesimplex/FinBERT2`（HF 不存在）。
- 标签必须做契约映射：`LABEL_0=Neutral(0) / LABEL_1=Positive(+1) / LABEL_2=Negative(−1)`；缺映射会静默回落规则引擎（表现为情绪恒 0.5）。
- **禁止跨语言回退**：英文 `ProsusAI/finbert` 评中文的 UNK 率约 54%，会产出伪信号。

> 结论：FinBERT 是**输入侧的特征制造者**，不是**输出侧的预测器**。它可以给 P2/P3 提供一条额外特征腿，但不能替代时序模型。

## §3 相关矩阵 → 模型特征的降维契约

### 3.1 为什么不能直接喂

N 个资产的相关矩阵是 N×N 对称矩阵（上三角 N(N−1)/2 维）。当前资产池 8–14 个 → 28–91 维；40 层全量 → 780 维。而样本仅 1,094 天，且相邻日高度自相关（有效样本远小于 1,094）。直接喂入 = 维度灾难 + 过拟合 + 无法解释。

**必须压缩成 8–12 个有金融含义的状态标量**，且每个都能反查回 METHOD_LIBRARY 的方法 ID。

### 3.2 推荐的压缩特征表

| # | 特征 | 含义 | 方法 ID | 输出 | 预期方向 |
|---|---|---|---|---|---|
| F1 | 平均相关度 | 市场一体化程度（危机时趋同） | M07 | `mean_rho` | 越高 → 分散化失效 → 个体趋势更易被系统性冲击打断 |
| F2 | 第一特征值占比 λ1/Σλ | 市场模式（market mode）强度 | M19 | `absorb_ratio` | 越高 → 单一因子主导 → 延续性由大盘决定 |
| F3 | 特征值谱熵 | 相关结构分散度 | M19 扩展 | `spectral_entropy` | 越低 → 结构越集中 |
| F4 | 滚动相关 z-score | 相关突变（regime switch） | M25 | `rho_z` | `|z|>2` → 结构断裂，延续性下降 |
| F5 | 同向率 | 同涨同跌天数占比 | M23 | `co_move_ratio` | 高 → 联动强 |
| F6 | 最优 lead-lag | 谁领先谁（BTC 落后纳指几天） | M11/M12 | `best_lag, ccf` | 领先关系稳定 → 可做领先腿 |
| F7 | Beta（对基准） | 系统性暴露 | M17 | `beta` | — |
| F8 | 相关稳定性 | 滚动相关标准差 | M24 | `rho_stability` | 低 → 环境稳定 → 延续性更可信 |
| F9 | 本资产相关向量 PCA | 该资产在相关网络中的位置 | M19/M20 | `pc1..pc3` | — |
| F10 | 聚类簇结构变化 | 资产分组是否重排 | M21 | `cluster_churn` | 高 → 结构重组 |
| F11 | 趋势斜率 t 值 | 自身趋势强度 | T08/T09 | `slope_t` | 高 → 趋势显著 |
| F12 | 波动率分位 | 波动状态 | I30/S25 | `vol_pct` | 高波动 → 延续性通常下降 |

> **经验先验（供假设，不作结论）**：危机期相关性趋同（F1↑、F2↑）会削弱个体趋势延续性；相关结构稳定期（F4 低、F8 低）趋势延续性通常更强。这两条必须用 P2 条件分布去验证，不能直接写进结论。

### 3.3 前视偏差硬约束

- 所有相关特征必须用 **PIT（point-in-time）滚动窗口**计算，禁止全样本相关矩阵。
- 相关窗口与前瞻窗口不得重叠；重叠时必须 Newey-West 修正或非重叠采样。
- 每个特征必须带 `window`、`n`、`as_of`。

## §4 候选模型清单（按适配度分级）

评分口径：适配度 = 样本可行性 × 可解释性 × 与"延续性"目标的匹配度 × 工程成本。

### Tier A — 确定性延续性度量（L1 可用，零新依赖）★ 最推荐先做

| ID | 方法 | 回答什么 | 输出 | 方法 ID | 门槛 |
|---|---|---|---|---|---|
| A1 | Hurst 指数（R/S 或 DFA） | 长期记忆强度：H>0.5 持续、H=0.5 随机、H<0.5 反持续 | `H, ci` | T13 | **≥2,000 点**才可信；1,094 点只能作参考并标 `low_confidence` |
| A2 | 方差比检验 VR(k) | 多期方差 / 单期方差：>1 趋势、<1 均值回复 | `vr, z, p` | T14 | ≥250 点；k∈{2,5,10,20} |
| A3 | AR(1) / OU 半衰期 | 偏离后回归一半所需时间 | `phi, halflife` | T20/T21 | ≥250 点 |
| A4 | 连胜/连败分布 | 同向连续长度经验分布 | `runlen_dist` | F18 | ≥250 点 |
| A5 | 状态转移矩阵 + 稳态 | 上行/下行之间的转移概率与停留期（**方向态；波动 regime 归 T0.5/T1a**） | `matrix, dwell` | B07/B08/T24 | ≥100 状态点 |
| A6 | 趋势斜率显著性 | 趋势是不是噪音 | `slope, t, r2` | T08/T09 | ≥60 点 |
| A7 | IC / RankIC 衰减曲线 | 信号有效期（延续性的最直接度量） | `ic[k]` | B13–B15 | ≥250 点 |
| A8 | 条件前瞻分布 | 给定状态后 h 日分布 | `mean, median, win_rate, n` | R01/R02/R08 | ≥250 点**（须按每桶非重叠计）**；单资产版 h=1 → **T0.5**，多维版 → **T2** |

> Tier A 的产出就是用户想要的"统计学规律描述"，且**全部可复现、可反查方法 ID、带样本量**。建议作为 P0。

### Tier B — 可解释线性 / 状态模型（L2 候选，低成本）

| ID | 模型 | 适配理由 | 输入 | 输出 | 风险 |
|---|---|---|---|---|---|
| B1 | **Logistic / 有序 Logit** | 最稳的方向延续基线；系数即"统计规律" | F1–F12 + 动量 + 波动 | P(延续/震荡/反转) | 线性假设；需正则化 |
| B2 | **Ridge / Lasso / ElasticNet** | 回归版延续性；Lasso 自动选特征，最接近"可读的统计规律" | 同上 | 前瞻 h 日收益 | 非平稳导致系数漂移 |
| B3 | **HAR-RV**（Corsi 2009） | 波动延续性的学术标准模型；日/周/月三尺度 OLS，极简 | RV_d, RV_w, RV_m | 下一期 RV | 只预测波动不预测方向 |
| B4 | **Markov Regime Switching**（Hamilton 1989）/ HMM | 状态延续 + 状态切换概率；输出期望停留期 | 收益率 / 波动 / 相关特征 | 状态概率、转移矩阵 | 状态数需预先固定（2–3） |
| B5 | **Kalman Filter / 状态空间** | 时变 beta 与相关，平滑估计，无需"训练" | 双序列 | 时变参数 + 置信带 | 线性高斯假设 |
| B6 | **协整 / VECM** | 均值回复型"延续"（价差延续） | 双资产价格 | 误差修正项、半衰期 | 仅适用于有经济联系的资产对 |
| B7 | **分位数回归** | 输出区间而非点，符合 L1 的分布纪律 | 同上 | P10/P50/P90 | 尾部样本稀疏 |

> Tier B 里**优先 B3 与 B1/B2**：实现成本最低、可解释性最强、最容易被 MERS 的 RankIC 体系评估。B4/B5 次之。

### Tier C — 非线性 / 深度学习（L2，样本足够再做）

| ID | 模型 | 适配理由 | 为什么不是现在 |
|---|---|---|---|
| C1 | **梯度提升（LightGBM / XGBoost）** | 表格特征上的事实标准；特征重要性可解释；1k–10k 样本可行 | 需要先有稳定的 Tier A/B 特征与样本外基准；否则无法判断收益来自模型还是特征 |
| C2 | **Temporal Fusion Transformer (TFT)** | 多步 + 静态协变量 + 注意力可解释，适合多资产 | 参数量与 1,094 天严重不匹配；需 ≥10k 样本 |
| C3 | **PatchTST / N-BEATS / DLinear** | 长序列建模；DLinear 常作为"Transformer 是否真有用"的对照 | 金融日频信噪比极低，深度模型优势不稳定 |
| C4 | LSTM / GRU | 通用序列模型 | 实证上常不优于线性基线，不建议投入 |
| C5 | **图神经网络（GNN）** | 把相关矩阵当邻接矩阵，是"用相关性做预测"最自然的深度形态 | 需要大样本 + 稳定图结构；当前样本与指标纵深均不够 |
| C6 | FinBERT | 文本腿特征 | 见 §2，不进入趋势链路 |

> **判断**：C 组在样本回填到 ≥3,000 交易日、且 Tier A/B 已建立样本外基准之前，不建议启动。否则必然出现"回测很好、样本外归零"。

## §5 "延续性"的操作化定义（不定义就无法评估）

必须先把 label 定死，否则模型无法训练、统计无法比较。建议并列评估四种定义，不得混用：

| 定义 | label | 适用 | 评价指标 |
|---|---|---|---|
| D1 方向延续 | `sign(fwd_ret_{t→t+h}) == sign(ret_{t−k→t})` | 动量/反转 | 命中率、AUC、RankIC |
| D2 趋势状态延续 | 当前 `MA20>MA60 且 slope_t>0` → h 日后仍成立 | 趋势跟随 | 转移概率、期望停留期 |
| D3 波动状态延续 | 当前 vol 分位桶 → h 日后同桶 | 波动率交易 | 转移矩阵、Brier |
| D4 相关状态延续 | 当前相关 regime（由 F1/F2/F4 聚类）→ h 日后同 regime | 组合/分散化 | 转移矩阵、簇稳定率 |

**必须回答的前置问题**（否则结论无意义）：
1. h 取多少？（建议 1/5/20 日三档，与 MERS 网格一致）
2. k（回溯窗）取多少？（建议与相关窗口一致，60/90/365）
3. "延续"是相对自身历史，还是相对横截面？（决定用时序动量还是横截面动量）

> 注意：**相关性高 ≠ 趋势延续**。相关矩阵描述同期联动，不含方向信息。D4 只能回答"相关结构是否稳定"，不能直接推出"价格会继续涨"。这是本方案最容易犯的逻辑错误，必须在所有输出中显式隔离。

## §6 统计陷阱与验证协议

| # | 陷阱 | 后果 | 对策 |
|---|---|---|---|
| 1 | 前瞻收益重叠 | t 值虚高 | Newey-West / 非重叠采样 |
| 2 | 全样本相关矩阵 | 前视偏差 | PIT 滚动窗口 |
| 3 | 多重比较 | 假发现 | BH-FDR（H14）强制 |
| 4 | 非平稳 | 全样本一个数无意义 | 分高/低波动两段分别报告 |
| 5 | Hurst 对样本长度极敏感 | 1,094 点估出的 H 不可信 | 标注 `low_confidence`；≥2,000 点才出结论 |
| 6 | 用 holdout 反复调参 | 数据窥探 | 一轮一次 holdout，记录 `holdout_used` |
| 7 | 只用 in-sample IC 排名 | 过拟合 | walk-forward + 样本外 IC（SPEC §14.3 已定义门禁） |
| 8 | 相关矩阵维度灾难 | 过拟合、不可解释 | 先降维到 F1–F12（§3.2） |

**验证协议（所有 Tier B/C 模型必须走）**：

```
① 特征 PIT 化（滚动窗口，禁用全样本）
② 切分：前 70% 训练 / 中段验证 / 末 30% holdout（holdout 只验证一次）
③ walk-forward：滚动重训，记录每折 IC
④ 门禁：n≥250；BH-FDR p_adj<0.05；前后半段 RankIC 同号；holdout 同号；coverage≥0.8
⑤ 负样本：随机序列 + 打乱标签 → 命中率必须≈50%，stable 数量=0
⑥ 与基线对比：必须打败「无条件历史均值」与「纯动量 sign」两个零参数基线
```

> 第 ⑥ 条最关键：如果模型打不过 `sign(过去 20 日收益)`，说明它没有提供任何增量信息。

| 阶段 | 内容 | 产出 | 归属 | 前置 | 门禁 | 不过怎么办 |
|---|---|---|---|---|---|---|
| **T-1**（关键路径） | 日频样本扩充 | 四资产 ≥3,000 日 | 18/19 | — | 缺口<5%；PIT 无修订 | 阻塞 T2/T3 结论，不阻塞 T0.5 |
| **T0** ✅ | A1–A7 确定性度量 | 延续性画像（已交付） | **L1** | 1,093 日 | 全部带 `n/window/caveat`；Hurst 标 `low_confidence` | — |
| **T0.5** | A8 单资产自身状态 → 前瞻分布（h=1，4 分位桶） | 条件分布表 | **L1** | T0 | 每桶非重叠 n≥250；PIT 滚动分位分桶；禁止点预测措辞 | 降为 2 桶并披露 n |
| **T1a** | 自身状态特征 F11/F12 + 波动 regime PIT | 自身状态面板 | **L1** | T0 | 缺失率<5%；每特征带 `as_of` | 阻塞 T3a |
| **T1b** | 跨资产相关特征 F1–F10 PIT | 相关状态面板 | **L1** | T1a + 4 资产对齐 | 滚动窗口；特征窗口与前瞻窗口不重叠；带 `n/window/as_of` | 阻塞 T3b；F6 无稳定 lead-lag 则放弃 T3c |
| **T2** | 多维状态 → 前瞻分布（P2） | 「当前状态下的历史 h 日分布」 | **L1** | T1b + T-1 | **1–2 维**；**每桶非重叠 n≥250**；BH-FDR | 维数降到 1 或等 T-1 |
| **T3a** | HAR-RV + 分位数回归 | 波动腿基准 + 区间 | **L2** | T1a | 打败零参数基线；给区间 | 保留为波动腿基准 |
| **T3b** | Logistic/Ridge + HMM（B1/B2/B3/B4） | 方向腿 walk-forward 报告 + 样本外 IC | **L2** | T2 + MERS 内核 | 打败「无条件历史均值」与 `sign(过去20日收益)` 两个基线；跨 **≥2 个年度 regime** 样本外同号 | 砍方向腿，只留波动腿 |
| **T3c**（可选） | Kalman / VECM | 时变相关 / 价差 | **L2** | T1b 的 F6 显示稳定 lead-lag | 同上 | **默认不做** |
| **T4**（可选） | Tier C（LightGBM → GNN/TFT） | 对照实验报告 | **L2** | 样本 ≥3,000 日且 T3 已建立稳定基准 | 样本外稳定优于 T3 | 不上线 |

### 7.1 为什么 T2 的门禁必须按「每桶非重叠」算

现有 1,093 日，前瞻 h 期的非重叠样本数约为 `1093/h`，再按 4 分位桶切分：

| 前瞻 h | 非重叠样本总数 | 每桶（4 桶） | 过 n≥250？ |
|---|---|---|---|
| h=1 | 1,093 | ≈273 | ✅ 刚好 |
| h=5 | ≈218 | ≈54 | ❌ |
| h=20 | ≈54 | ≈13 | ❌ 差一个数量级 |

结论：**T0.5 只做 h=1**；h≥5 的分桶条件分布必须等 T-1 扩样本，或放宽到「2 桶 + 披露有效 n」。用重叠样本凑够 250 是假的——A7 已实测 h=20 非重叠仅 53 个点。

### 7.2 状态口径分工（避免 A5 与 A8 重复定义）

| 状态维度 | 归属 | 说明 |
|---|---|---|
| 涨/跌方向态 | **A5（已冻结）** | 2×2 转移矩阵，已实现 |
| 波动 regime（高/低） | **T0.5 / T1a** | PIT 滚动分位分桶；A5 不做 |
| 跨资产相关状态 F1–F10 | **T1b / T2** | 需多资产对齐，非单资产 |

**与 SPEC 现有阶段的映射**：
- T0 ≈ S3 的「延续性」子集，S1 完成后即可做（不需要跨资产回填）；
- T0.5/T1a 仍属 L1 自身历史范畴，不依赖跨资产回填；
- T1b/T2 ≈ S2 + S3；
- T3 ≈ S5 的 MERS 下游（复用 `relationship_eval` 表结构，新增 `model` 维度）；
- FinBERT 情绪腿 ≈ 现有 U1 链路，不在本路线关键路径上。

## §9 数据前提与门禁（当前实测）

| 检查项 | 现状 | 对延续性建模的影响 |
|---|---|---|
| 日频价格 | BTC/ETH/SOL/XAU 各 1,094 点（2023-11-15~2026-11-12） | ✅ 支撑 A1–A7 与 T0.5（h=1，4 桶）；❌ 不足支撑 h≥5 的分桶条件分布（每桶非重叠≈13–54）；⚠️ Hurst 偏短 |
| 跨资产龙头 | 28 个已绑定（明细见 METHOD_LIBRARY §15） | ✅ 支撑 F1–F10 |
| 加密域指标 | 14–44 天 | ❌ 不可作为延续性特征腿 |

| 事件表 | 16 行 | ❌ 不可做事件研究 |

**门禁**：
- 单资产延续性（A1–A8）：`n≥250`；Hurst 额外要求 `n≥2000` 否则标 `low_confidence`。
- 相关状态特征（F1–F12）：对齐点 `n≥60`；`n<60` 返回 `insufficient_samples`。
- 任何 Tier B/C 模型：`n≥250` + holdout 同号 + BH-FDR。
- 加密域指标在回填到 ≥250 天之前，不得进入任何延续性模型。

## §10 风险与禁区

| 风险 | 后果 | 对策 |
|---|---|---|
| 把 P2 条件分布说成 P3 预测 | 越界，违反 ADR-3 | 固定模板 + 抽检 20 条；出现「将会/预计」即判失败 |
| 把「相关高」等同于「趋势延续」 | 逻辑错误 | D4 只描述相关结构稳定，不推价格方向 |
| 用 1,094 点做 Hurst 并给强结论 | 伪精确 | 标 `low_confidence`；只给区间不给点 |
| 深度模型在小样本上回测漂亮 | 上线即失效 | 必须先有 Tier B 样本外基准；T4 才允许 |
| 相关矩阵直接喂模型 | 过拟合、不可解释 | 强制走 F1–F12 降维 |
| FinBERT 用于价格 | 无效且误导 | 明确边界：仅文本腿 |

**禁区（沿用 SPEC §15）**：不做因果表述、不做点预测、不做无样本量披露的结论、不做多重比较不校正的批量扫描、不用合成/随机数据参与统计。
