# SPEC-54d 卡片模式「推荐卡片」与动态回测更新

- 版本：v0.1（2026-11-17）
- 关联：SPEC-54（卡片接入）/ SPEC-54c（能力放开）
- 目标：卡片模式默认落地 6–8 张「简单、价格派生、带前瞻统计」的卡，并支持按回测结果动态更新。

## 1. 默认卡片

新增 builtin tab「推荐卡片」（`rec-cards`，默认落地页），离线兜底 6 张：

| 能力 | 卡片 | 口径（触发行情 → 前瞻） |
| --- | --- | --- |
| D-E15 | 趋势跟踪：价格 + EMA26 | 收盘价站上 EMA26 → 后续 5/20 日收益 |
| D-E01 | 20 日动量 → 后续收益 | 20 日动量为正 → 后续收益分布 |
| D-E07 | 状态转移（涨跌延续） | 近 20 日涨态 → 后续 5 日是否延续 |
| D-E02 | 价格分位（高位/低位） | 250 日 80% 分位以上 → 后续 20 日 |
| D-E14 | 相关状态 → 前瞻分布 | 与基准 60 日相关 >0.5 → 后续 20 日 |
| D-G20 | 动量分位胜率（最高档） | 20 日动量最高 20% → 后续 20 日 |

候选池另含 D-G08（12-1 动量）/ D-E10（回撤修复），回测不达标时自动落选。

## 2. 动态更新（可以做到）

- 生产者：`scripts/card_recommender.py`
  - 资产池 BTC/ETH/SOL/US500/XAU，750 日；
  - 每条规则回测触发后 5/20 日收益方向，汇总胜率、Wilson 下界、样本量、前后段稳定性；
  - `score = 0.4*wilson5 + 0.6*wilson20`（n<120 扣 10%）；
  - 入选条件：20 日胜率 ≥50%，最多 8 张（不足 6 张时取得分前 6）；
  - 只写 `artifacts/cards/recommendation.json`，不写库、不改配置。
- 读取：`GET /api/visual/cards/recommend`（只读制品；缺失→空列表→前端静态兜底；
  制品 >7 天标 `stale`）。
- 刷新：`POST /api/visual/cards/recommend` → 重跑脚本后回读；卡片 tab 上「刷新推荐」按钮触发。
- 持久化边界：`rec-cards` tab 不写服务端（避免某一期结果固化成用户配置），
  始终由回测制品驱动；用户可把卡复制到自建 tab 后长期保留。

## 4. 风险

| 风险 | 处置 |
| --- | --- |
| 胜率受样本期影响（近年行情） | 全部披露 n、Wilson 下界、前后段稳定性；标注「历史统计，不代表未来」 |
| 规则过于简单被误读为策略 | 卡片只给统计事实，不给方向/仓位（沿用能力层信封口径） |
| 动态刷新覆盖用户调整 | 推荐 tab 独立于服务端配置；用户调整请落到自建 tab |
