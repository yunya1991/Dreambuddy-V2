## §1 共同交付契约（两个包都必须满足）

| # | 契约 | 具体要求 |
|---|---|---|
| T1 | 零依赖 | 仅 Python 3.8+ 标准库；不得 import 第三方包；单文件可 `python3 script.py` 直跑 |
| T2 | UA 声明 | 所有请求带 `market-data-hub/1.0 (research; contact: ops@neodrm.com)` 或 `event-context/1.0 (...)`；**不得伪装成 Chrome**（实测 SEC 对 Chrome UA 反而不稳定） |
| T3 | 确定性 | 同一输入同一数据日期，输出逐字节稳定；不含随机数、不含当前时间以外的状态 |
| T4 | 失败语义 | 单源失败 → 该项标 `数据不可用` + 原因码，**最多重试 2 次（退避 0.8s / 1.6s）**、不估算、不用旧值填充；不影响同批其他项 |
| T5 | 来源可溯 | 每份输出末尾必须含 `方法ID / 数据源 / 许可 / 缺失 / 说明` 五行（Markdown）或等价 JSON 字段 |
| T6 | 红线可机检 | 输出文本命中禁用词表（§4.3）即视为不合格；`--json` 模式输出 `"limits"` 固定声明字段 |
| T7 | 包体积 | 单文件 ≤512KB，总 ≤3MB，SKILL.md ≤200 行；无二进制、无缓存文件、无 `.pyc` |
| T8 | 无状态 | 不写用户目录、不落盘缓存、不记录调用者身份；只读数据源 + stdout |
| T9 | 版本 | `version: 1.0.0`；`--version` 可打印；SKILL.md 末尾带版本记录表 |
| T10 | 私有信息零外泄 | 代码内不含服务器地址、内网 IP、Token、数据库名（上架包会被完整下载） |
| T11 | 双通道 | 所有取数命令支持 `--endpoint auto/cloud/local`，默认 `auto`：先试云端 3s，失败回退本地；输出标注 `data_route` |

**统一失败原因码**（两包共用，便于验收脚本断言）：

```text
E_NET       网络不可达/超时
E_TLS       TLS 握手失败
E_HTTP_4XX  源返回 4xx（如 403 封禁）
E_SCHEMA    返回结构与预期不符
E_EMPTY     返回成功但无可用观测
E_INPUT     参数格式非法（不发请求）
E_LICENSE   来源未在 licenses.md 登记（拒绝输出）
```

## §2 商品 A：`market-data-hub`

### 2.1 包结构

```text
market-data-hub/
├── SKILL.md

│   ├── macro.py       # D1 海外宏观（已写，待验收）
│   ├── filings.py     # D2 美股披露
│   ├── onchain.py     # D5 链上公开数据（自采 RPC）
│   ├── context.py     # A-2 数据上下文 + A-3 交叉统计
│   └── handoff.py     # 可装配指针清单（与认知管家组合，见 §3.8）
```

`stats.py` 不单独成文件：D3 自算统计的公式全部落在 `macro.py` / `context.py` 内，由 `methods.md` 统一登记，避免同一公式两处实现。

### 2.2 CLI 契约

```bash
# D1 宏观（已实现）
python3 scripts/macro.py --series DGS10,CPIAUCSL,UNRATE [--window 250] [--json]

# D2 美股披露
python3 scripts/filings.py --ticker AAPL [--form 8-K] [--limit 10] [--json]
python3 scripts/filings.py --ticker AAPL --facts Revenue,NetIncomeLoss [--json]

# D5 链上
python3 scripts/onchain.py --chain eth [--blocks 50] [--json]

# A-2 数据上下文（单序列怎么读）
python3 scripts/context.py --describe DGS10 [--window 250] [--json]

# A-3 交叉统计（只分组不排序）
python3 scripts/context.py --cross DGS10,CPIAUCSL [--bucket year|month] [--json]
python3 scripts/context.py --basket DGS10,DGS2,CPIAUCSL,UNRATE [--json]   # 相关矩阵

# 组合：把结果转成可装配指针清单（handoff 契约，见 §3.8）
python3 scripts/handoff.py --series DGS10,CPIAUCSL [--budget 2000] [--json]
```

参数规则：

- `--series` / `--basket` 支持逗号分隔多值，单项失败不拖累整批
- 未知 series 返回 `E_INPUT` 并列出支持清单，不发请求
- `--json` 输出纯 JSON（无前后缀文本），非 `--json` 输出 Markdown
- 所有脚本 `--help` 可用，退出码：`0` 全部成功 / `1` 部分失败 / `2` 参数非法

### 2.3 输出契约

**Markdown 模式**（必须五行尾注）：

```text
海外宏观事实 · 数据日期 2026-11-17 · 生成于 2026-11-19 21:41

| 指标 | 最新值 | 1月变动 | 3月变动 | 250期分位 | 20期波动(年化) | 样本量 |
|---|---|---|---|---|---|---|
| 美国10年期国债收益率(%) | 5.10 | +1.0bp | +38.0bp | 92.0% (n=250) | 20.5% | 16204 |

方法ID：M11 区间变动 / M12 序列分位 / M13 年化波动
数据源：FRED（美联储圣路易斯分行）
许可：FRED / U.S. Federal Reserve Bank of St. Louis · Public Domain
缺失：无
说明：以上均为已发布数据的统计描述，不构成投资建议，不含任何预测。
```

**JSON 模式**（统一外层结构，四个脚本一致）：

```json
{
  "skill": "market-data-hub",
  "version": "1.0.0",
  "generated_at": "2026-11-19T21:41:03",
  "data_date": "2026-11-17",
  "rows": [],
  "missing": [{"key": "DGS2", "code": "E_NET", "detail": "timeout"}],
  "method_ids": ["M11", "M12", "M13"],
  "sources": [{"name": "FRED", "url": "https://fred.stlouisfed.org/", "license": "Public Domain"}],
  "limits": "仅提供已发布数据的统计描述，不含方向判断、预测或建议。"
}
```

字段硬约束：

1. `rows` 每个对象必须含 `n`（样本量）；缺失值用 `null`，禁止 `0`
2. `missing` 不得为空数组以外的自由文本；每项必须有 `code`，取值见 §1
3. `sources[].license` 必须能在 `licenses.md` 中找到同名登记行，否则抛 `E_LICENSE`
4. `limits` 为固定中文声明，不允许按调用改写

### 2.4 方法ID 全表

| ID | 指标 | 公式 / 口径 | 最小样本 |
|---|---|---|---|
| M01 | 近 k 期涨跌幅 | `x_t / x_{t-k} - 1` | k+1 |
| M02 | 收盘/末值分位 | `count(x_i <= x_t)/n` | n |
| M03 | 年化波动 | `stdev(ln(x_i/x_{i-1})) × sqrt(252)` | 21 |
| M04 | 最大回撤 | `min(x_i/max(x_{<=i}) - 1)` | n |
| M05 | 均线偏离 | `x_t/mean(x_{t-k+1..t}) - 1` | k |
| M11 | 区间变动（绝对） | `x_t - x_{t-k}`，利率类报 bp | k+1 |
| M12 | 序列分位（窗口） | 同 M02，窗口可配 | window |
| M13 | 年化波动（日频序列） | 同 M03 | 21 |
| M14 | 分布五数 | P05/P25/P50/P75/P95（线性插值） | 30 |
| M15 | 分组统计 | 按 `bucket` 分组：n / mean / median / std | 每组 ≥5 |
| M16 | Pearson 相关 | 对齐日期后 `corr(x,y)`，同时给 n | 30 |
| M17 | 链上区块指标 | 出块间隔 mean/std、gas 使用率 mean、交易数 mean | blocks |
| M18 | 披露字段同比 | `(v_t/v_{t-4} - 1)`，仅同口径同期 | 5 期 |

样本不足 → 输出 `null` + `insufficient` 标记，**不插值不外推**。

### 2.6 A-2 / A-3 的边界（本商品最容易越界的地方）

**A-2 数据上下文**允许给：定义、单位、频率、样本区间、分布五数、当前值在分布中的位置、同族可比序列及其相关度（含 n）。
**不允许**：解释为"高/低/便宜/贵"、给"合理区间"、给"均值回归"结论。

**A-3 交叉统计**允许给：分组表（每组 n / mean / median）、相关矩阵、条件分布。
**不允许**：按任一指标排序、标"优选/最佳/首选"、给"前 N 名"、给分组结论。

### 3.2 CLI 契约

```bash
# 列出某主体近期事件（归一后的一级事实）
python3 scripts/events.py --subject AAPL [--since 30] [--types 8-K,10-Q] [--json]
python3 scripts/events.py --feed sec-press [--since 7] [--json]
python3 scripts/events.py --feed fed-all [--since 7] [--json]

# 装配五层上下文
python3 scripts/context.py --event-id <id> [--json]
python3 scripts/context.py --subject AAPL --latest [--json]

# 组合：把五层结果转成事件指针清单（handoff 契约，见 §3.8）
```

`--event-id` 由 `events.py` 稳定生成：`{source}:{type}:{accession|guid}` 的 SHA1 前 16 位，**同一事件任何时候调用都一致**（用户可缓存、可复核）。

### 3.3 五层输出（严格 schema）

```json

  "version": "1.0.0",
  "event_id": "3f2a91c4b7de0051",

    "source": "SEC EDGAR",
    "type": "8-K",
    "subject": {"ticker": "AAPL", "cik": "0000320193", "name": "Apple Inc."},
    "headline_facts": ["提交 8-K", "事项编号 2.02", "报告期 2026-09-27"],
    "accession": "0000320193-26-000123",
    "url": "https://www.sec.gov/Archives/edgar/data/320193/..."
  },
  "entities": {
    "tickers": ["AAPL"],
    "sector": {"code": "3571", "label": "Electronic Computers"},
    "supply_chain": [],
    "entity_source": "SEC SIC / company_tickers"
  },
  "analogues": {
    "key": {"source": "SEC EDGAR", "type": "8-K", "item": "2.02"},
    "n": 37,
    "window": "T+5",
    "stat": {"mean": null, "std": null},
    "note": "n 为同类事件次数；收益类统计依赖行情授权，本期未启用"
  },
  "sources": [
    {"title": "8-K - Apple Inc.", "url": "https://www.sec.gov/...", "license": "Public Domain", "retrieved_at": "2026-11-19T21:40:00"}
  ],
  "assembly": {
    "rule_version": "v1",
    "fields_filled": 5,
    "fields_empty": ["supply_chain", "analogues.stat"]
  },
  "limits": "仅装配已发生事实与同类事件次数，不含影响判断、方向判断或建议。"
}
```

层级硬约束：

| 层 | 必须有 | 必须没有 |
|---|---|---|
| event | time / source / type / subject / headline_facts / url | 定性形容词、影响描述 |
| entities | tickers 或 cik 至少一项；sector 可空但需 `entity_source` | 推荐、排序、权重 |
| analogues | `key` / `n` / `window` / `note` | **均值标准差在无行情授权时恒为 `null`**，不得填估算 |
| sources | 每项 title + url + license | 全文转载（`headline_facts` 单条 ≤80 字，总引述 ≤300 字） |
| assembly | 填充统计，供验收断言 | — |

`analogues.n` 的统计口径：同一 `source+type+item` 在**已拉取窗口内**的出现次数，窗口默认 24 个月，且在 `window` 字段写明。**n 是计数不是概率**，不得换算成"上涨概率"。

### 3.4 事件源注册表（本机实测，2026-11-19）

| 源 key | 端点 | 实测 | 许可 | 事件类型 |
|---|---|---|---|---|
| `sec-submissions` | `data.sec.gov/submissions/CIK##########.json` | ✅ 200 / 2.6s | Public Domain | 8-K / 10-K / 10-Q / 4 |
| `sec-press` | `www.sec.gov/news/pressreleases.rss` | ✅ 200 / 1.7s | Public Domain | 监管公告 |
| `fed-all` | `www.federalreserve.gov/feeds/press_all.xml` | ✅ 200 / 3.8s（TLS 偶发抖动，需 1 次重试） | Public Domain | FOMC 声明、纪要、讲话稿 |
| `ecb-press` | `www.ecb.europa.eu/rss/press.html` | ❌ TLS 失败 | 免费需署名 | 本期**不启用**，仅登记 |
| 商业媒体（Reuters/Bloomberg/新浪/东财） | — | — | 禁再分发 | **不接** |

规则：`sources.md` 未登记 → `events.py` 拒绝输出（`E_LICENSE`）。新增源必须先补登记行再过验收。

### 3.5 装配规则（`rule_version: v1`）

1. **事件归一**：所有源映射到统一结构 `{time, source, type, subject, facts[], url, license}`；时间统一转 ISO8601 带时区
2. **实体映射**：ticker→CIK 用 SEC `company_tickers.json` 本地映射（一次拉取，进程内缓存）；sector 取 SEC SIC 描述；**上下游不臆造**，无可靠来源时 `supply_chain: []` 且列入 `fields_empty`
3. **同类检索**：按 `source+type+item` 精确匹配，窗口 24 个月；不足 3 次时 `n` 照实给，并加 `note: "样本不足，仅给次数"`
4. **不评价**：不做情感极性、不做影响程度、不做时间线推演
5. **引述控制**：只取标题 + 结构化字段，不抓正文全文

## §3.8 handoff 组合契约（两包共用，组合卖点）

两个包都不内嵌认知管家（`cognition-manager`）实现，只对齐它的**输入契约**：输出一份「可装配指针清单」。装了认知管家的用户可直接交给 `cm pack`，未安装的用户按普通 JSON 使用，功能不残缺。

**定位纪律**：本契约提供的是「**可装配**」，不是「辅助分析」。商品页、SKILL.md、README 一律不得出现"辅助分析行情 / 辅助判断 / 智能解读"等表述。

### 3.8.1 ID 规则（两包必须逐字一致）

```text
series:<SERIES_ID>            例 series:DGS10
event:<event_id>              例 event:3f2a91c4b7de0051
filing:<CIK>-<accession>      例 filing:0000320193-26-000123
block:<chain>:<height>        例 block:eth:1939659
```

同一对象在任何时候、任何包内生成的 `id` 必须相同（可缓存、可去重、可复核）。

### 3.8.2 输出契约（两包一致）

```json
{
  "handoff_version": "1.0",
  "skill": "market-data-hub",
  "target": "cogsteward/pack",
  "generated_at": "2026-11-19T21:55:00",
  "budget": 2000,
  "items": [
    {"id": "series:DGS10", "kind": "series", "title": "美国10年期国债收益率",
     "license": "Public Domain", "url": "https://fred.stlouisfed.org/series/DGS10",
     "estimated_tokens": 40, "method_ids": ["M02", "M12"], "data_date": "2026-11-17"}
  ],
  "skipped": 0,
  "total_tokens": 40,
  "read_only": true,
  "limits": "仅提供可装配指针，不含判断与建议。"
}
```

### 3.8.3 硬约束

| # | 约束 |
|---|---|
| H1 | `--budget` 默认 2000；贪心入选，`total_tokens <= budget`；放不下的计入 `skipped`，不截断内容 |
| H2 | `estimated_tokens` 用 `max(1, round(bytes/3/1.5))` 估算，与认知管家 `pack` 同一口径 |
| H3 | 纯只读：不发额外请求（复用同一进程内已取数据）、不写文件、不改 `.cm/` |

| H5 | `license` 必须能在 `licenses.md` / `sources.md` 命中，否则 `E_LICENSE` |
| H6 | 取数失败时 `items` 为空并给 `missing`，退出码 1，不编造指针 |
| H7 | `limits` 为固定声明，不得按调用改写 |

|---|---|

| 严格模式 | `--endpoint cloud` 时失败直接返回 `数据不可用`，不静默降级 |
| 环境变量 | `MDH_ENDPOINT` / `EC_ENDPOINT` 可覆盖网关地址 |
| 令牌 | `PARTNER_TOKEN` 或 `PARTNER_TOKEN_FILE`（文件路径）；**令牌不写入包内**，未配置时完全不走云端，直接本地 |

## §3.10 订阅令牌生命周期（按订阅签发）

### 3.10.1 目标模型

购买成功 → 签发令牌；未续费 → 到期自动失效；续费 → 自动续期。

### 3.10.2 平台能力现状（决定自动化程度）

| 能力 | 现状 |
|---|---|
| 设备侧权益查询 | ✅ `POST /api/gateway/invoke`（`queryStatus`），返回 `WAIT_PAY` / `ENTITLED+usable` |
| 服务端订阅状态 / 订单列表 API | ❌ 未见文档化接口 |
| 购买 / 续费 webhook | ❌ 未见配置入口 |

结论：**“购买成功即自动签发”当前无法全自动**，因为平台不主动通知，也没有服务端可拉的订阅状态。

### 3.10.3 分阶段落地

| 阶段 | 方式 | 状态 |
|---|---|---|
| P1 人工签发 | 订单号 → `manage.py issue` 生成令牌 + 到期时间；网关按 `expires_at` 自动拒绝；续费 `renew`、退款 `revoke` | ✅ 已实现 |
| P2 订单号自助兑换 | 买家在包内执行 `activate --order ORD...`，由买家侧登录态校验权益，凭 proof 换令牌 | 🟡 待验证平台接口 |
| P3 事件驱动 | 若平台开放 webhook 或订阅状态 API，改为自动签发 / 自动续期 / 自动吊销 | ⛔ 依赖平台 |

### 3.10.4 P1 实现细节

| 项 | 值 |
|---|---|
| 有效期规则 | 签发 = 订阅周期 + 7 天缓冲（月付 30+7 = **37 天**，季付 90+7 = 97 天，周付 7+7 = 14 天）；到期未续费即硬停，无二次宽限 |
| 续期规则 | 只按订阅周期顺延（月付 +30 天），缓冲不累积；未到期续费不损失剩余天数，已过期从当下起算 |
| 到期展示 | `list` 输出剩余天数，便于续费前提醒 |
| 令牌表 | `/opt/partner-gateway/tokens.json`（0600），按 mtime 热加载，改文件即生效 |
| 令牌格式 | 48 位十六进制，`secrets.token_hex(24)` 服务器本地生成 |
| 记录字段 | `order` / `plan` / `issued_at` / `expires_at` / `revoked` / `renewed_at` |
| 管理命令 | `manage.py issue|renew|revoke|list` |
| 拒绝语义 | `401 token_missing` / `token_unknown` / `token_expired` / `token_revoked`，响应含 `expires_at` |
| 续期语义 | 从当前到期日顺延（未到期续费不损失剩余天数）；已过期的从当下起算 |
| 兼容 | 保留 `PARTNER_TOKEN` 环境变量作为管理员令牌（不落表、不过期），仅供自测 |
