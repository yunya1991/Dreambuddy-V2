## 模块定位

通用风控引擎 — 为所有交易模块提供统一的风控能力。

### 三层风控体系

| 层级 | 名称 | 核心职责 |
|------|------|---------|
| L1 | 事前门禁层 (PreTradeGate) | 战略/杠杆/评分门禁、执行风险/账户层门禁、日回撤熔断、黑窗时段、连续亏损限制（Fail-Closed） |
| L2 | 仓位管理层 (PositionSizer) | 风险预算驱动仓位计算、马丁加仓计算（可插拔） |
| L3 | 事后离场层 (ExitEngine) | 离场决策 |

### 架构

```
┌─────────────────────────────────────┐
│          RiskEngine (统一入口)        │
│  ┌────────┐  ┌────────┐  ┌────────┐ │
│  │ 事前门禁 │  │ 仓位管理 │  │ 事后离场 │ │
│  └────────┘  └────────┘  └────────┘ │
└─────────────────────────────────────┘
                ↓
      RuleRegistry (规则注册表)
                ↓
    RiskContext / StateStore (状态层)
```
