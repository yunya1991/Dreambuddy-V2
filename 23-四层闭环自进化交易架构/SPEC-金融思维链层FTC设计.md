# SPEC: 金融思维链层（FTC Layer）— 经验路径拆解 × 基因组进化 × 知识对齐

> **状态：** Spec（待评审）
> **创建：** 2026-09-06
> **目标：** 将 PathLibrary 的 17 条经验路径拆解为可组合的"金融思维链"（Financial Thinking Chain, FTC）种子，接入 L2 基因组进化闭环；通过金融知识库相似度对齐避免无序探索，先模仿再创新，最终由回测 ESS + 实盘盈亏验证最优路径。
> **约束：** FAIL-OPEN 铁律不可破坏；不破坏现有基因组/回测/反思引擎；inference 步骤不参与执行（仅用于对齐与可解释）。

***

## 零 · 问题总结

### 0.1 当前架构缺口

系统存在**两层割裂**：

| 层               | 现状                                                      | 问题                             |
| :-------------- | :------------------------------------------------------ | :----------------------------- |
| **基因组层**        | condition(CD-*) × action(AC-*) → combination，扁平 `条件→动作` | 无法表达多步因果推理，只有"什么条件做什么"，没有"为什么" |
| **PathLibrary** | 17 条固定路径，独立评估取 top1，P\&L 直接改 score                      | 不可组合、无回测、无 gmax 变异、与基因组完全脱节    |

**核心矛盾**：蓝图要求"最优路径 = 基因组自由组合 + 回测 ESS 筛选 + 盈亏验证"，但 PathLibrary 把经验路径当成了固定最优路径，没有拆解、没有组合、没有回测。

### 0.2 用户核心诉求

1. 经验路径只是**参考种子**，不是固定最优路径
2. 系统应通过**基因组自由组合**探索最优路径
3. 成功标准 = **回测胜率最高**（ESS）
4. 最终验证 = **赚钱**（实盘 P\&L）
5. 初期探索应**对齐金融知识库**，避免闭门造车和无序探索
6. **先模仿（对齐理论），再创新（探索回测）**

### 2.2 基因类型规则

| 类型          | 是否执行  | 作用             | 数据需求                       |
| :---------- | :---- | :------------- | :------------------------- |
| `condition` | ✅ 执行  | 可观测条件判断        | data\_required + threshold |
| `inference` | ❌ 不执行 | 因果推理步骤，编码"为什么" | logic + knowledge\_ref     |
| `action`    | ✅ 执行  | 交易动作           | gene\_ref（AC-\*）           |

**关键约束**：inference 步骤**不参与回测执行**，仅用于：

- 知识相似度对齐

- 人类可读的因果解释

- FTC 组合时的语义约束（如 inference 的 knowledge\_ref 决定可组合的条件类型）

## 四 · 拆解机制（PathLibrary → FTC 种子）

### 4.1 拆解规则

```
PathLibrary 路径
  ├─ trigger 条件 → condition 步骤
  ├─ causal_chain 描述 → inference 步骤（提取因果节点）
  └─ direction 逻辑 → action 步骤
```

**拆解粒度**：按"因果节点"拆，不拆到原子指标。

- ✅ 好：`放量`（condition）→ `注意力上升`（inference）→ `资金流入`（condition）

- ❌ 坏：`vol_5 > vol_20 * 1.3`（太细，失去因果语义）

### 4.2 拆解产物

17 条路径 → 约 50-70 个基因步骤（condition/inference/action），形成初始种子池。

每条经验路径生成 1 个 FTC 种子，同时其步骤可被其他 FTC 组合复用。

## 五 · 相似度裁剪机制

### 5.1 两层相似度计算

**层 1：结构化匹配（0.5 权重）**

- 步骤类型序列模式匹配：如 `condition→inference→condition→action` vs 理论的因果模式

- 数据依赖图同构性

**层 2：语义匹配（0.5 权重）**

- inference 步骤的 `knowledge_ref` 与理论标签匹配

- condition/action 的 `gene_ref` 与理论关联基因匹配

- 关键词匹配（初期用关键词，后续升级 embedding）

### 5.2 裁剪规则（软裁剪 + 探索因子）

**核心原则**：相似度是**优先级信号**，不是**否决票**。低相似度 FTC 不直接丢弃，而是进入"探索池"用小仓位验证——系统具备探索能力，真正的创新往往不匹配旧理论。

| 相似度区间       | 轨道             | 仓位          | 入库门槛                         |
| :---------- | :------------- | :---------- | :--------------------------- |
| ≥ 0.80      | **利用轨道**（高对齐）  | 100% (25U)  | N ≥ 30 快速采纳                  |
| 0.60 – 0.79 | **利用轨道**（中对齐）  | 100% (25U)  | N ≥ 50                       |
| 0.30 – 0.59 | **混合轨道**（低对齐）  | 50% (12.5U) | N ≥ 200                      |
| 0.15 – 0.29 | **探索轨道**（极低对齐） | 20% (5U)    | N ≥ 300 + ESS ≥ 0.5 才能升入利用轨道 |
| < 0.15      | **丢弃**（纯噪音）    | —           | —                            |

**探索因子 ε (epsilon)** — 控制系统探索力度（类 ε-greedy）：

- ε ∈ \[0.2, 0.6]，初始 0.3

- ε 控制"探索轨道"FTC 被选中的概率权重

- 高 ε → 更多探索低相似度组合；低 ε → 更多利用高对齐组合

- **地板 0.2 是结构性底线**：周期相似但不雷同，即使连续盈利也必须保留至少 20% 探索率

**ε 的自适应更新**（由 ReflectionEngine 驱动）：

| 触发条件                | ε 变化              | 逻辑                     |
| :------------------ | :---------------- | :--------------------- |
| CS≥0.7 & TP（判断准且赚）  | ε × 0.95          | 现有策略有效，微降探索（不激进收缩）     |
| CS≤-0.2 & SL（判断错且亏） | ε × 1.2           | 现有策略失效，增加探索（环境可能变化）    |
| 连续 N 轮无 ESS 提升      | ε × 1.15          | 陷入局部最优，强制探索            |
| ε 触及上下限             | clamp \[0.2, 0.6] | 永不低于 20%（周期不雷同），上限 60% |

**生物学依据**：

- 即使适应良好的物种，突变率也永不为零（bet-hedging 策略）

- 细菌 SOS 反应：环境压力下突变率提升 10-100 倍

- 金融类比：Renaissance Medallion 即使现有策略盈利，仍持续投入 10-20% 资源探索新信号

**探索池晋升机制**：

- 探索轨道 FTC 若 ESS ≥ 0.5 且 N ≥ 300 → 自动升入利用轨道

- 升入后重新计算相似度对齐（可能此时发现它其实符合某个未被锚定的理论）

- 若探索轨道 FTC 连续 50 笔 ESS < 0.3 → 降级丢弃

**理由**：

- 高对齐 = 模仿成熟理论，风险低，满仓快速采纳

- 低对齐 = 可能是创新也可能是噪音，小仓探索，用样本量证明自己

- 探索因子让系统在"利用已知有效"和"探索未知可能"之间动态平衡

- 永不丢弃 0.15-0.30 区间的候选——金融创新往往来自此处

### 5.3 两层探索体系（组合探索 + 基因创新）

探索因子分为**两层**，对应生物学的"基因重组"和"基因突变"：

| 层级          | 机制                  | 生物学对应       | 作用             | 控制参数            |
| :---------- | :------------------ | :---------- | :------------- | :-------------- |
| **L1 组合探索** | ε-greedy 选择低相似度 FTC | 基因重组（有性生殖）  | 重组现有基因，发现新组合   | ε ∈ \[0.2, 0.6] |
| **L2 基因创新** | 外研+反思 → 新基因候选       | 基因突变（新等位基因） | 创造现有基因库没有的全新因子 | 涟漪异常 + 反思洞察触发   |

**进化 = 重组(L1) + 突变(L2) + 选择(回测 ESS / 实盘 P\&L)**

#### L2 基因创新流程（基因突变机制）

```
涟漪系统检测到异常模式
  （如：资金流入+放量+但价格不动 — 现有 condition 基因无法表达）
    ↓
反思引擎分析：这种模式是否暗示新的因果条件？
    ↓
生成候选新基因（如 CD-VOL-PRICE-DIVERGENCE 量价背离）
    ↓
挂载到探索轨道 FTC，小仓验证 (5U)
    ↓
N ≥ 100 笔 + ESS ≥ 0.5
    ↓ 验证通过
写入 gene_data/strategy_genes/ 成为正式基因
    ↓
该基因可被所有 FTC 组合复用 → 基因组进化
```

**L2 触发条件**（满足任一即启动基因创新分析）：

- 涟漪检测到现有 condition 基因无法解释的异常模式

- 反思发现连续失败的共同模式（如"放量不涨"反复出现）

- FTC 组合空间饱和（所有组合 ESS 趋同，无差异）

**L2 验证门槛**（比 L1 更严格，因为是新基因）：

- 探索轨道 5U 小仓

- N ≥ 100 笔样本

- ESS ≥ 0.5

- 胜率 H ≥ 0.55

- 通过后写入基因组，所有 FTC 可复用

**与现有架构的三层探索空间**：

| 空间   | 机制            | 现有/新增 |
| :--- | :------------ | :---- |
| 参数空间 | gmax 扰动       | 现有    |
| 组合空间 | ε-greedy (L1) | 新增    |
| 基因空间 | 外研+反思突变 (L2)  | 新增    |

生物学对应：**表观遗传调控 → 基因重组 → 基因突变**，三层完整。

## 八 · 风险与约束

| 风险                       | 缓解                                  |
| :----------------------- | :---------------------------------- |
| 拆解粒度过粗 → 组合空间小           | 按因果节点拆，保持语义完整                       |
| 拆解粒度过细 → 组合爆炸            | inference 步骤约束可组合的条件类型              |
| 相似度计算不准 → 误裁             | 软裁剪+探索池，低相似度不丢弃只降仓位                 |
| 过度探索 → 亏损过多              | 探索轨道仓位仅 5U (20%)，且需 N≥300 才能晋升      |
| 过度利用 → 陷入局部最优            | ε 下限 0.1，连续无 ESS 提升时 ε×1.2          |
| inference 不执行 → FTC 不可执行 | condition+action 必须形成完整执行链          |
| 回测过拟合                    | ESS 含 N 样本量校正，低 N 组合不入库             |
| 与现有基因组冲突                 | FTC 是 condition×action 的超集，向下兼容扁平组合 |
