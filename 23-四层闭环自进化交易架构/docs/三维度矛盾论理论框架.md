## 1. 问题提出与三个典型场景

### 1.1 当前系统的局限

现有 `PrimaryContradictionIdentifier` 是单时间框架的——它从路径列表中识别方向一致性和矛盾强度，但不区分周期层级，也无法处理跨维度矛盾转化。

### 1.2 三个典型场景

**场景 A：形态反复测试，筹码集中**

某币种在某个位置反复测试，日线/周线在此处反复震荡，筹码集中，形成强阻力/支撑。技术面本身形成了中长期矛盾。要突破这个位置，需要基本面或宏观面提供更强的推动力——技术面的中长期矛盾是此处的主要矛盾，直到更强的跨维度力量介入。

**场景 B：加密持续上涨 + 宏观加息预期上升**

加密市场持续上涨，但动能减弱。宏观加息预期上升。技术面支撑在动能减弱下变得脆弱，宏观利空预期升级为主要矛盾，合力方向转为下跌。**主要矛盾从技术面转移到了宏观面**——不是因为维度映射了周期，而是因为宏观面力量增长超过了技术面力量。

**场景 C：UNI 独立行情**

比特币上涨初期，UNI 因基本面改善（如协议收入增长）表现强势，即便 BTC 滞涨依然独立上涨。但随着动能减弱，BTC 和宏观恶化，主要矛盾合力跟随趋势——**基本面矛盾从主要降级为次要，宏观面矛盾升级为主要**。

### 1.3 核心命题

1. **主要矛盾是动态的** — 在技术面、基本面、宏观面之间动态切换，取决于哪个维度的力量在当前时刻最强
2. **矛盾转化是周期驱动的** — 同一维度内不同周期的信号演化导致主导力量转移
3. **弹性约束是跨维度的** — 力量更强的矛盾约束力量较弱的矛盾，不论维度和周期

## 2. 哲学基础

### 2.1 矛盾论核心原理

本理论根植于毛泽东《矛盾论》的四个核心命题：

| 命题 | 含义 | 在交易中的映射 |
|------|------|---------------|
| 矛盾普遍性与特殊性 | 矛盾存在于一切过程中，各有特殊性 | 每个交易对、每个时段都有独特的矛盾结构 |
| **主要矛盾与次要矛盾** | 主要矛盾**规定或影响**其他矛盾的存在和发展 | 当前市场的核心驱动力决定方向——关键是"规定或影响"是**因果性**命题，不是相关性排序 |
| **矛盾的主要方面** | 矛盾双方发展不平衡，主导方面起决定作用 | 多空力量不对称，主导方决定方向 |
| **矛盾的转化** | 量变积累引发质变，主要矛盾和次要矛盾地位转化 | 非主要矛盾持续增强→力量超越→地位翻转 |

### 2.2 因果性 vs 相关性的区分（哲学修正）

v2.0 的缺陷是将"主要矛盾"简化为 `max(strength)` 排序——这是**相关性**，不是矛盾论的**因果性**。

毛泽东说的是：主要矛盾**规定或影响**其他矛盾的存在和发展。这是**因果传导**命题：

- 宏观加息（主矛盾）不只是"力量最强"——它**改变了**技术面的性质（使支撑变脆弱）
- 这不是排序，而是：主矛盾通过**因果传导链**改变其他矛盾的状态

本理论 v3.0 的修正：主要矛盾的识别不仅依赖力量排序，还必须验证其是否通过因果传导链影响其他矛盾。具体方法见 [§5 因果传导建模](#5-因果传导建模)。

### 2.3 量变与质变的严格区分（哲学修正）

辩证唯物主义的"质变"是**系统结构的根本性变换**，不是简单的标签交换。

v2.0 的"质变"定义（`strength_A > strength_B` → A 成为主矛盾）只是**排序变化**，是量变的延续，不是真正的质变。

**v3.0 严格定义**：

- **量变**：矛盾力量的数值变化（增减），系统结构不变
- **质变**：系统结构发生根本性变换，具体表现为以下**任一**结构性断裂：
  - 波动率制度转换（低波↔高波）
  - 相关性结构断裂（BTC 与美股从脱钩→联动）
  - 市场形态转换（趋势态↔震荡态）

仅交换"哪个矛盾排第一"不构成质变。质变必须伴随可检测的结构性转变。具体方法见 [§8 质变的严格定义与检测](#8-质变的严格定义与检测)。

## 3. 理论框架

### 3.1 维度与周期的交叉矩阵

维度（技术面/基本面/宏观面）和周期（短/中/长）是**正交的两个轴**：

| | 短期（h/d） | 中期（w/m） | 长期（m/q/y） |
|---|---|---|---|
| **技术面** | 日线 RSI 超卖反弹 | 周线筹码集中区阻力 | 月线趋势线、大级别头肩顶/底 |
| **基本面** | ETF 单日净流入 | 周度链上活跃度趋势 | 月度盈利预期、季度估值变化 |
| **宏观面** | CPI 公布日的脉冲反应 | 月度利率决议周期 | 季度加息周期预期、年度流动性环境 |

每个单元格都是一个**矛盾候选**。主要矛盾可能是矩阵中的任何一个单元格，不固定在某一行或某一列。

### 3.2 矛盾的数据结构

```python
@dataclass
class ContradictionCandidate:
    dimension: str        # "technical" | "fundamental" | "macro"
    timeframe: str        # "short" | "medium" | "long"
    direction: str        # "BULL" | "BEAR" | "NEUTRAL"
    raw_strength: float   # 原始力量值（外生度量，见 §4）
    normalized_strength: float  # 标准化后力量值 [0,1]（见 §6）
    causal_outflow: float # 因果输出强度（Granger 因果检验值，见 §5）
    shift_signal: bool    # 是否触发了结构性质变（见 §8）
```

## 4. 外生力量度量体系

### 4.1 循环定义问题的修复

v2.0 的根本缺陷：力量如何独立于价格结果来测量？如果没有独立度量，就陷入循环论证：

> 主要矛盾 = 力量最强 → 力量最强 = 推动价格变动最大 → 价格变动是事后可知 → 主矛盾永远事后可解释、事前不可知

**v3.0 修复**：定义**外生力量度量**——在价格变动之前就能测量到的力量，**不依赖价格结果**。

### 4.2 外生力量度量的三个原则

| 原则 | 含义 | 示例 |
|------|------|------|
| **前瞻性** | 度量必须在 t 时刻可得，不依赖 t+1 的价格结果 | ETF 资金净流入量（量，不是价格） |
| **可验证性** | 度量值可以被独立第三方重现 | CPI 实际值-预期差（公开数据） |
| **维度无关性** | 度量方法不因维度不同而失去可比性 | z-score 标准化后所有维度同一标度 |

### 4.3 各维度的外生力量度量

| 维度 | 短期力量（外生度量） | 中期力量 | 长期力量 |
|------|------------|------------|------------|
| 技术面 | RippleEngine RI 信号强度（路径评分，非价格结果） | 周线筹码集中度（UTXO/换手率，链上量，非价格） | 月线趋势线斜率 + 大级别形态完成度（几何结构，非价格变动方向） |
| 基本面 | ETF 日净流入量（份额变动，非价格） | 链上活跃地址周变化率（活跃量，非价格） | 估值偏离均值程度（NVT 或 MVRV Z-Score） |
| 宏观面 | CPI 公布值-预期差（ surprise 项） | 利率决议周期预期（Fed Funds Futures 隐含概率） | 加息/降息周期方向（政策利率趋势） |

**关键**：以上度量都是**非价格量**——它们测量的是市场结构的物理量（资金流、链上活动、政策预期），不是价格变动本身。

### 4.4 Fama-French 类比

传统金融的 Fama-French 因子模型用**回归系数的 t 统计量**来衡量因子力量。本框架借鉴其统计检验思想：

- Fama-French：因子回报 = β × 因子值 + ε，力量 = t(β)
- 本框架：矛盾力量 = 外生度量的**标准化值 × Granger 因果显著性**

这样力量值有了统计学基础，不再是主观打分。

## 5. 因果传导建模

### 5.1 Granger 因果检验

**问题**：v2.0 说"主矛盾影响次矛盾"，但从未验证影响是否真实存在。

**v3.0 修复**：用 Granger 因果检验验证矛盾间的因果传导。

Granger 因果检验的核心思想：如果 X 的过去值能改善对 Y 的预测（在 Y 自身历史的条件下），则 X 是 Y 的 Granger 原因。

```
# 双变量 VAR 模型
Y_t = α + Σ β_i × Y_{t-i} + Σ γ_j × X_{t-j} + ε_t

H0: γ_1 = γ_2 = ... = γ_p = 0  (X 不 Granger-cause Y)
H1: 至少一个 γ_j ≠ 0           (X Granger-causes Y)

F 统计量检验 H0，p < 0.05 则拒绝 H0，X 是 Y 的 Granger 原因
```

### 5.2 矛盾间的因果传导链

场景 B 的因果传导链：

```
宏观加息预期↑ (Granger-cause → 资金成本↑)
    → 资金成本↑ (Granger-cause → ETF 资金流出)
    → ETF 资金流出 (Granger-cause → 技术支撑测试频率↑)
    → 技术支撑测试频率↑ (Granger-cause → 支撑脆弱化)
    → 支撑脆弱化 = 技术面矛盾性质被改变
```

**因果传导链验证了"主要矛盾规定或影响其他矛盾"的哲学命题**。

### 5.3 Per-Regime Granger 因果

传统 Granger 因果检验假设关系是静态的。但研究表明（arXiv:2601.10732），因子间的因果结构会随 regime 变化。

本框架采用 **Per-Regime Granger**：

1. 先用 HMM 或结构断点检测划分 regime
2. 在每个 regime 内独立检验 Granger 因果
3. 如果某矛盾只在特定 regime 内对其他矛盾有 Granger 因果性，则该矛盾在该 regime 内是主矛盾的候选

这比静态 Granger 更贴近现实——矛盾间的因果传导在牛市和熊市中可能完全不同。

## 6. 维度标准化与交互效应

### 6.1 不可通约问题的修复

v2.0 的合力公式 `Σ(direction × strength) / Σ(strength)` 隐含假设所有维度的力量可加、可比。但技术面 RSI 超卖（0.8）和宏观 CPI 超预期（0.7）是**不可通约的**——影响机制完全不同。

**v3.0 修复**：对力量值做**标准化**，使不同维度可比。

#### 6.1.1 Z-Score 标准化

```python
# 每个维度的力量值按其历史分布标准化
z_score = (raw_strength - historical_mean) / historical_std

# 然后转为 percentile rank（均匀分布，消除异常值影响）
normalized_strength = percentile_rank(z_score, historical_distribution) / 100.0
```

标准化后所有维度的力量值都在 [0, 1]，且基于历史分布定位，具有可比性。

### 6.2 交互效应处理

v2.0 忽略了维度间的交互效应——两个矛盾可能非线性叠加（互相增强或互相抵消）。

**v3.0 修复**：引入**交互项**。

```python
# 合力方向计算（含交互项）
合力 = Σ(wi × di × si) + Σ(wij × di × dj × si × sj × Iij)

# 交互项说明:
# di, dj = 矛盾 i, j 的方向值 (+1 BULL, -1 BEAR, 0 NEUTRAL)
# si, sj = 标准化力量值
# wi = 单个矛盾权重
# wij = 交互权重（通过历史回归估计）
# Iij = 交互指示函数（1 if 两个矛盾方向相反且有 Granger 因果关系, 0 otherwise）
```

交互项的含义：如果两个矛盾方向相反**且**存在 Granger 因果传导，它们的交互效应不简单是各自力量的线性叠加，而是有一个**衰减系数** wij（因为因果传导会削弱被影响方的独立力量）。

### 6.3 APT 模型类比

传统金融的 Arbitrage Pricing Theory (APT) 同样面临因子可加性问题，它用**因子回报的协方差矩阵**来处理交互。本框架借鉴此思想，用 Granger 因果矩阵代替协方差矩阵——因为矛盾间的关系是时序因果性的，不是同时刻相关性的。

## 7. 弹性约束模型

### 7.1 核心定义

弹性约束不是"长期约束短期"，而是**力量更强的矛盾约束力量较弱的矛盾**，不论维度和周期。

### 7.2 弹性约束规则（修正版）

```
设定:
  C_primary = {direction: D_p, strength: S_p}    # 当前主要矛盾（标准化力量）
  C_minor = {direction: D_m, strength: S_m}      # 某次要矛盾
  Δp = 价格偏离幅度                                 # 次要矛盾方向上的已偏离幅度
  T_max = 反弹允许上限
  causal_link = Granger因果检验结果                  # 是否存在因果传导

如果 D_p ≠ D_m（方向相反）:
    # 弹性约束：允许次要矛盾方向操作，但有上限
    # T_max 基于历史最大反弹幅度的 percentile 计算，不拍脑袋
    T_max = historical_max_rebound_p75 × (S_p / (S_p + S_m))
    
    if Δp < T_max:
        constraint_force = T_max - Δp
        # sigmoid 衰减（非线性，比 v2.0 线性衰减更合理）
        position_mult = floor + (1.0 - floor) × (1 / (1 + exp(k × (Δp / T_max - 0.5))))
    else:
        resolved_direction = D_p
        position_mult = floor
        shift_signal = True  # 触发质变检测

如果 D_p == D_m（方向一致）:
    # 无约束，加仓
    position_mult = 1.0 + bonus × S_p
```

### 7.3 参数理论约束

v2.0 有 4 个自由参数无任何估计方法。v3.0 给出理论边界：

| 参数 | 理论约束 | 估计方法 |
|------|---------|---------|
| `historical_max_rebound_p75` | 历史反弹幅度的 75 百分位 | 回测统计 |
| `floor` | ≥ 0.05（最低仓位 5%），≤ 0.2 | Kelly Criterion 下界 |
| `bonus` | ≤ 0.3（最大加仓 30%） | 风险预算约束 |
| `k` | sigmoid 斜率，建议 5~10 | 网格搜索 + 交叉验证 |
| `dominance_gap` | ≥ 0.15（15% 力量差距） | 历史质变事件统计 |

### 7.4 与 BDSM direction_constraint 的分层

| 层级 | 机制 | 类型 | 执行位置 |
|------|------|------|---------|
| 基本面层 | BDSM direction_constraint | **刚性 veto** | 开仓前筛选 |
| 协调器层 | 弹性约束 | **弹性** | 路径评分后仓位调整 |

二者分层不冲突：基本面层先做刚性筛选，协调器层对剩余方向做弹性约束。

## 8. 质变的严格定义与检测

### 8.1 质变 vs 量变的严格区分

v2.0 的"质变"仅仅是排序变化（`strength_A > strength_B`），这只是量变的延续。真正的质变是**系统结构的根本性变换**。

**v3.0 严格定义**：

| 类型 | 定义 | 检测方法 |
|------|------|---------|
| **量变** | 矛盾力量数值变化（增减），系统结构不变 | 力量值时间序列的变化 |
| **质变** | 系统结构发生根本性变换 | 以下任一结构性断裂 |

### 8.2 三类结构性断裂

质变必须伴随以下**至少一项**可检测的结构性转变：

#### 8.2.1 波动率制度转换

```python
# 用 Markov-Switching GARCH 检测波动率 regime 转换
# 参考: Multi-Scale MS-GARCH (arXiv:2606.06190)
from statsmodels.tsa.regime_switching.markov_regression import MarkovRegression

# 拟合 2 状态 HMM: 低波 / 高波
model = MarkovRegression(returns, k_regimes=2, trend='c')
result = model.fit()

# 检测 regime 转换概率
transition_matrix = result.regime_transitions
if transition_matrix[0, 1] > threshold:  # 低波→高波概率超阈值
    regime_shift = True
```

#### 8.2.2 相关性结构断裂

```python
# BTC 与美股相关性的结构断点
# 用 Chow Test 或 Bai-Perron 检测
from statsmodels.stats.diagnostic import breaks_cusumolsresid

# 滚动计算 BTC-S&P 500 相关系数
rolling_corr = btc_returns.rolling(60).corr(sp500_returns)

# CUSUM 检测相关性结构断点
cusum_stat, p_value = breaks_cusumolsresid(rolling_corr)
if p_value < 0.05:
    correlation_break = True
```

#### 8.2.3 市场形态转换

```python
# 趋势态 ↔ 震荡态
# 用 Hurst Exponent 检测
from hurst import compute_Hc

H, c, data = compute_Hc(price_series, kind='price')
# H > 0.5: 趋势性 (持久性)
# H < 0.5: 均值回归 (震荡态)
# H ≈ 0.5: 随机游走
if H_prev > 0.5 and H_current < 0.5:
    market_regime_shift = True
```

### 8.3 质变判定规则

```
质变 = 矛盾力量排序变化 AND (波动率制度转换 OR 相关性结构断裂 OR 市场形态转换)

仅排序变化（无结构性断裂）= 量变，不触发质变流程
```

## 9. 矛盾转化检测算法

### 9.1 算法逻辑修正

v2.0 的 `detect_shift` 比较 `current_primary.strength - init_primary.strength`——使用初始时刻的力量值。如果旧主矛盾力量自然衰减，即使没有新矛盾崛起也会误触发。

**v3.0 修正**：比较旧矛盾的**当前**力量 vs 新矛盾的**当前**力量。

```python
class ContradictionShiftAccumulator:
    """跟踪矛盾力量变化，检测主要矛盾转移"""

    def __init__(self):
        self.history = []  # [(ts, [ContradictionCandidate, ...])]

    def record(self, contradictions: list):
        """每次评估记录所有矛盾候选的力量"""
        self.history.append({
            "ts": time.time(),
            "contradictions": contradictions,
        })

    def detect_shift(self, persistence=14, dominance_gap=0.15):
        """
        检测主要矛盾是否发生转移
        
        条件:
        1. 连续 persistence 次评估中，新矛盾当前力量 > 旧矛盾当前力量
        2. 新矛盾当前力量 - 旧矛盾当前力量 > dominance_gap
        3. 新矛盾方向与旧矛盾方向不同
        4. 至少一项结构性断裂检测为 True（质变条件，见 §8）
        """
        if len(self.history) < persistence:
            return None
        
        recent = self.history[-persistence:]
        
        # 找到初始态的主矛盾
        init = recent[0]["contradictions"]
        init_primary = max(init, key=lambda c: c.normalized_strength)
        
        # 追踪旧主矛盾的当前力量（不是初始力量）
        for snapshot in recent[1:]:
            current = snapshot["contradictions"]
            # 找旧主矛盾在当前时刻的力量
            old_current = next(
                (c for c in current 
                 if c.dimension == init_primary.dimension 
                 and c.timeframe == init_primary.timeframe),
                None
            )
            if old_current is None:
                continue
            
            # 找当前力量最强的矛盾
            current_primary = max(current, key=lambda c: c.normalized_strength)
            
            # 检查是否有新矛盾超越旧矛盾（比较的都是当前力量）
            if (current_primary.dimension != init_primary.dimension or
                current_primary.timeframe != init_primary.timeframe):
                
                if (current_primary.normalized_strength - old_current.normalized_strength
                    > dominance_gap and
                    current_primary.direction != init_primary.direction and
                    current_primary.shift_signal):  # 质变条件
                    
                    return {
                        "shifted_from": {
                            "dimension": init_primary.dimension,
                            "timeframe": init_primary.timeframe,
                            "direction": init_primary.direction,
                            "strength": old_current.normalized_strength,  # 当前力量
                        },
                        "shifted_to": {
                            "dimension": current_primary.dimension,
                            "timeframe": current_primary.timeframe,
                            "direction": current_primary.direction,
                            "strength": current_primary.normalized_strength,
                        },
                        "new_direction": current_primary.direction,
                    }
        
        return None
```

### 9.2 三个场景的转化过程

**场景 A（形态反复测试）**：

  → Granger 因果检验: 基本面→技术面（基本面 Granger-cause 技术支撑测试频率）
  → 质变条件: 突破筹码区伴随波动率制度转换（低波→高波）

## 10. 反身性维度

### 10.1 Soros 反身性理论

Soros 的反身性理论核心：**认知影响现实，现实反过来改变认知**。在交易系统中：

> 如果系统判断宏观是主矛盾→做空→做空本身影响 ETF 资金流→改变基本面矛盾→可能改变主矛盾

v2.0 完全缺失这个反馈循环。加密市场尤其严重，因为参与者结构相对集中。

### 10.2 反身性建模

Soros 的反身性模型用两个函数描述：

- **认知函数**（cognitive function）：参与者认知 ← 基本面状态
- **参与函数**（participating function）：基本面状态 ← 参与者行为（交易）

```
认知函数: 认知_t = f(基本面_t-1, 价格_t-1)
参与函数: 基本面_t = g(认知_t, 行为_t)
行为函数: 行为_t = h(认知_t, 系统仓位_t)

反身性循环:
  系统做空 → ETF 资金流出加剧 → 基本面矛盾恶化 → 主矛盾更确认为宏观 → 更多做空 → ...
```

### 10.3 自影响项

在合力方向计算中增加**自影响项**：

```python
# 系统自身仓位方向作为基本面矛盾的输入之一
self_influence = system_position_direction × system_position_size × reflexivity_coefficient

# 修正后的合力
修正合力 = 外生合力 + self_influence

# reflexivity_coefficient 通过历史数据估计：
# 当系统仓位 > 某阈值时，对 ETF 资金流有可检测的 Granger 因果
```

### 10.4 反身性检测

```python
# 检测系统仓位是否 Granger-cause 市场指标
# 如果系统仓位规模足够大，交易行为本身可能改变市场结构
from statsmodels.tsa.stattools import grangercausalitytests

# 检验: 系统仓位 → ETF 资金流
result = grangercausalitytests(
    [system_position_history, etf_flow_history],
    maxlag=5
)
# 如果 p < 0.05，系统仓位 Granger-cause ETF 资金流
# → 反身性存在，需要加入自影响项
```

## 11. 可证伪性与验证框架

### 11.1 可证伪性定义

v2.0 的命题"主要矛盾决定方向"不可证伪——因为主矛盾 = 事后力量最强者，命题永远为真。

**v3.0 修复**：明确预测和检验方法。

### 11.2 前瞻性预测

```
在 t 时刻:
  1. 用外生度量计算各矛盾力量（不使用 t+1 价格信息）
  2. 识别主矛盾（力量最强 + Granger 因果验证）
  3. 输出预测: 合力方向 D_t

在 t+1 时刻:
  4. 检验价格是否沿 D_t 方向移动
  5. 记录命中率

可证伪条件:
  如果命中率不显著优于随机（50%），理论被证伪
  显著性检验: binomial test, H0: p=0.5, α=0.05
```

### 11.3 回测验证框架

```python
def backtest_contradiction_theory(data, contradiction_evaluator, min_samples=100):
    """
    回测验证矛盾论理论
    
    返回:
      hit_rate: 预测方向命中率
      p_value: binomial test p 值
      information_coefficient: 预测方向与实际收益的 Spearman 相关
      ic_p_value: IC 显著性
    """
    predictions = []
    actuals = []
    
    for t in range(len(data) - 1):
        # t 时刻预测（只用 t 及之前的信息）
        contradictions = contradiction_evaluator.evaluate(data[:t])
        predicted_direction = compute_force_direction(contradictions)
        
        # t+1 时刻实际
        actual_return = data[t+1].return - data[t].return
        actual_direction = "BULL" if actual_return > 0 else "BEAR"
        
        predictions.append(predicted_direction)
        actuals.append(actual_direction)
    
    # 命中率
    hits = sum(1 for p, a in zip(predictions, actuals) if p == a)
    hit_rate = hits / len(predictions)
    
    # Binomial test
    from scipy.stats import binom_test
    p_value = binom_test(hits, len(predictions), 0.5)
    
    # Information Coefficient (Spearman)
    from scipy.stats import spearmanr
    pred_values = [1 if p == "BULL" else -1 for p in predictions]
    actual_values = [1 if a == "BULL" else -1 for a in actuals]
    ic, ic_p = spearmanr(pred_values, actual_values)
    
    return {
        "hit_rate": hit_rate,
        "p_value": p_value,
        "information_coefficient": ic,
        "ic_p_value": ic_p,
        "is_falsified": p_value > 0.05,  # 不显著 = 被证伪
        "sample_size": len(predictions),
    }
```

### 11.4 证伪标准

| 检验项 | 通过标准 | 证伪标准 |
|--------|---------|---------|
| 方向命中率 | > 55%（binomial p < 0.05） | ≤ 55%（不显著优于随机） |
| Information Coefficient | IC > 0.03（p < 0.05） | IC ≤ 0.03 |
| Granger 因果验证 | 主矛盾 Granger-cause 次矛盾（p < 0.05） | 无 Granger 因果性 |
| 质变检测准确率 | 结构性断裂检测命中率 > 60% | ≤ 60% |

如果以上任何一项被证伪，理论需要修正而非废弃——指出是力量度量问题、因果链问题还是质变检测问题。

## 13. 与传统金融理论的关系

### 13.1 Dow 理论

Dow 的三趋势层级对应**同一维度（技术面）内不同周期**。本理论扩展为跨维度跨周期：Primary Trend 可以是任何维度+任何周期的矛盾，只要它力量最强且通过 Granger 因果验证。

### 13.2 周期嵌套理论

传统周期嵌套（Kondratieff→Juglar→Kitchin）描述经济周期层级。本理论借鉴嵌套思想但不直接映射：长周期矛盾提供背景约束，短周期矛盾提供交易时机。

### 13.3 多时间框架分析（MTA）

传统 MTA 铁律"高周期优先"是刚性 veto。本理论改为弹性约束——力量更强的约束力量较弱的，但允许有限偏离。

### 13.4 HMM Regime 检测

HMM 回答"当前是什么 regime"，本理论回答"这个 regime 下主要矛盾是什么方向、力量多强、如何转化"。二者互补。

### 13.5 Fama-French 因子模型

Fama-French 用回归系数 t 统计量衡量因子力量。本框架借鉴：力量 = 外生度量的标准化值 × Granger 因果显著性。

### 13.6 Soros 反身性理论

Soros 的认知函数+参与函数描述了价格与基本面的双向反馈。本框架引入自影响项建模系统仓位对矛盾结构的反馈。

### 13.7 分形市场假说

Peters 的分形市场假说认为市场是自馈式非线性自组织系统，不同投资起点的投资者形成分形结构。本理论的多维度多周期矛盾矩阵与分形市场假说的"不同投资起点"概念一致——每个矩阵单元格对应不同投资起点的矛盾。
