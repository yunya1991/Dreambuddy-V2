#### 根因分析：LaunchAgent 配置 Bug

`com.dreambuddy.yijing_trading.plist` 中 `ProgramArguments` 参数序列错误：

```xml
<!-- ❌ 错误：--no-guardian 被当作 python3 参数 -->
<array>
    <string>/opt/anaconda3/bin/python3</string>
    <string>--no-guardian</string>    <!-- ← python3 不识别此参数 -->
    <string>-u</string>
    <string>-m</string>
    ...
</array>
```

正确序列应该是：

```xml
<!-- ✅ 正确：移除 --no-guardian，或作为模块参数 -->
<array>
    <string>/opt/anaconda3/bin/python3</string>
    <string>-u</string>
    <string>-m</string>
    <string>scripts.memory_l4.polling_trader</string>
    ...
</array>
```

**验证**:
```bash
$ launchctl load -w ~/Library/LaunchAgents/com.dreambuddy.yijing_trading.plist
Load failed: 5: Input/output error

$ /opt/anaconda3/bin/python3 --no-guardian -u -c "print(1)"
unknown option --no-guardian
```

`dreambuddy.yijing.polling-trader.plist` 额外标记了 `<key>Disabled</key><true/>`，也不会被加载。
