## 七、发现的问题与修复记录

### [P1] HC-AGI-20 违规：空 kline 时 continuation_score 返回 0.2 而非 0.5

- **严重度**: P1（硬约束违反）
- **根因**: `TrendContinuationScorer.score()` 对空 `kline_data` 仍进入 `_minervini_score` 计算：趋势模板 8 条件全不满足 → 0.0，VCP 无数据 → 0.5，加权得 `0.0×0.6 + 0.5×0.4 = 0.2`。HC-AGI-20 要求"趋势延续性字段缺失取 0.5 中性兜底"。
- **影响**: 当市场数据缺失趋势字段时，路径 `continuation_score` 偏低（0.2 vs 0.5），导致评分公式 `×(0.8+0.4×cont)` 中路径被过度惩罚（×0.88 vs ×1.0）。
- **修复**:
  - `core/trend_continuation.py`: 新增 `TREND_FIELDS` 常量，`score()` 中若 kline 不含任何趋势字段则 `continuation=0.5`，`cause_score`/`effort_result` 仍按各自字段独立计算。
  - `core/contradiction_identifier.py`: `_compute_continuation_score()` 同步增加趋势字段缺失检测，返回 0.5。
- **验证**: 空 kline → 0.5 ✅；全失败（字段存在）→ 0.35（< 0.4，不破坏 `test_minervini_all_fail`）；仅 cause 字段 → cont=0.5, cause=1.0。

### [P2] solve_optimal_path 统一入口未透传 primary_contradiction

- **严重度**: P2（一致性缺口，非主链路断裂）
- **根因**: `hjb_solver.solve_optimal_path()` 函数签名无 `primary_contradiction` 参数，内部调用 `solver.solve()` 时不传。`DeepReasoningEngine.find_min_resistance_path` 使用此统一入口，故其 HJB 求解不享受矛盾强度调制。主 pipeline `_select_optimal_path` 直接调用 `HJBPathSolver.solve()` 已正确传入，环节⑤主链路完整。
- **修复**: `solve_optimal_path` 新增 `primary_contradiction: dict | None = None` 参数，透传给 `solver.solve()`。向后兼容（None 等价旧行为）。
- **验证**: `solve_optimal_path(..., primary_contradiction={...})` → backend=hjb, converged=True。

### 已确认无需修复项

- **基因库 Schema 校验噪音（bad_genes.log 5879 条）**: 属数据质量问题（P3），不影响交易热路径，FAIL-OPEN 铁律未触发。
