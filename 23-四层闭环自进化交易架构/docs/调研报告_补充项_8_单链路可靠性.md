## 摘要

Q4 三级降级模式假设"单链路（仅 Granger 或仅 Attention）输出 primary_dim 与双链路一致"，但理论分析表明：Granger 单链路在结构断点期因平稳性假设违反而功效下降；Attention 单链路因 softmax 饱和与训练数据偏置可能输出错误维度；二者在不同 regime 下可靠性互补但单独使用时一致率预估仅 50-65%。Binomial test 功效分析显示：α=0.05、power=0.80、检测 p1=0.40 偏离需 n=155 次质变事件，BTC 1h 周期约需 4-6 年才能积累；改用 SPRT 序贯检验可降至 ASN≈73 次（2-3 年）。当前数据条件下（质变事件零历史样本、`_history` 内存丢失）无法立即证伪或证实，故建议采用"先验一致率 0.55 + Bayesian 在线更新 + SPRT 序贯监测"过渡方案，并准备 3 个替代方案以备证伪后切换。模式 6 逻辑跳跃问题**部分解决**（理论分析已闭合，实证检验待数据）。

## 任务 1：理论分析单链路可靠性

### 1.1 Granger 单链路输出 primary_dim 的可靠性

Granger 因果检验基于线性 VAR 模型 + F-test 联合显著性，其统计功效依赖三个要素：

| 要素 | 理论要求 | Q4 降级场景实际情况 | 影响 |
|------|---------|---------------------|------|
| 样本量 | ≥ 50 obs/var（bivariate VAR 经验下限），更严谨需 n ≥ 100 | 文档 §10.11.3 已设计 `SAMPLE_COOLDOWN = 2 × persistence`，若 persistence=5 则需 ≥10 期样本 | **临界**——降级期常因样本不足触发 |
| 平稳性 | 严格平稳（ADF p<0.05），否则 F-test 失效（spurious regression） | 质变事件伴随结构性断裂（Hurst/CUSUM/vol_regime），断裂期序列非平稳 | **违反**——降级期正是平稳性最差时刻 |
| Lag order | 通过 AIC/BIC/HQ 选择，过大降功效，过小漏动态 | 文档未指定 Granger lag order；默认 lag=1 在 BTC 上自相关 τ=1 时勉强够用 | **中等** |
| Effect size | Cohen's f² ≥ 0.02（小效应）、≥ 0.15（中效应） | 外生力量对 BTC 收益率的影响通常为弱效应（r 0.05-0.15） | **偏低**——Type II 错误率上升 |

**理论结论**：Granger 单链路在质变降级期（结构断点同时刻）的统计可靠性**显著下降**。文献 Cliff et al. (2021, arXiv:2003.03887) 证明：在非平稳序列上 Granger 检验的 nominal Type I error rate 会从 5% 膨胀到 20-40%，且 cross-correlation 会进一步降低 effective sample size。这意味着 Granger 单链路输出的 `primary_dim` 在质变期有较高假阳性率（误判某因子为主导）。

### 1.2 Attention 单链路输出 primary_dim 的可靠性

Attention 机制基于 softmax 权重聚合 `Attention(Q,K,V) = softmax(QK^T/√d_k)V`，输出是 value 的凸组合（权重和=1）。

| 要素 | 理论特性 | Q4 降级场景实际情况 | 影响 |
|------|---------|---------------------|------|
| 训练数据充分性 | 需足够 regime 覆盖，否则 OOD 输入下 softmax 退化 | 文档 §10.11 标注 NeuralSDE 权重未训练（VM-1791183353813-494f7e6a 确认懒加载），降级时 Attention 输出可能完全无意义 | **致命**——降级常因模型未初始化 |
| Softmax 饱和 | 大 logit 差时退化为 one-hot（attention sink，Bae et al. 2026 arXiv:2602.23057） | 质变期因子编码可能突变，softmax 跳转到新维度 | **中等**——单期输出可能正确但无置信度 |
| 注意力熵 | 高熵=分散（信号弱）；低熵=集中（信号强或饱和） | 降级期常伴随注意力熵骤降（受冲击主导） | **偏置**——易过度自信 |
| 可解释性 | softmax 权重是相关性而非因果性 | 文档 §1.1 已批判"循环论证"风险 | **存在**——单链路无法交叉验证 |

**理论结论**：Attention 单链路在权重已训练的前提下，对极端事件（质变）**敏感但不可靠**——它能迅速捕捉到新维度，但缺乏置信度估计，且 softmax 饱和会导致"硬切换"而非"渐进过渡"。最严重的是文档已确认 NeuralSDE 权重未训练，降级模式启用 Attention 单链路时输出可能是无效值。

### 1.3 不同市场状态下可靠性对比

| Regime | Granger 可靠性 | Attention 可靠性 | 谁更可靠 |
|--------|---------------|-----------------|---------|
| **Trending**（趋势态，Hurst>0.55） | **较高**——线性关系强、平稳性好，F-test 功效接近 nominal | **中等**——softmax 易被趋势因子饱和，可能错过反转信号 | **Granger** |
| **Ranging**（震荡态，Hurst≈0.5） | **低**——信号弱、信噪比差，Type II 错误率高 | **较高**——能捕捉微弱的因子切换，非线性建模优势显现 | **Attention** |
| **High-volatility**（高波态，vol_regime_shift） | **极低**——结构断点违反平稳性假设，F-test 失真 | **低**——softmax 受噪声放大，注意力熵骤升 | **都不可靠**——应回退到完全中性 |
| **Regime transition**（制度转换期） | **低**——重估冷却期未到，旧 Granger 关系失效 | **中**——能感知新因子，但训练分布外 | **Attention**（但置信度低） |

**关键发现**：Granger 与 Attention 在 trending/ranging 上可靠性互补，但在 high-volatility 上**双双失效**——这恰是质变最可能发生的 regime。这意味着 Q4 降级模式在最需要它的场景下恰好最不可靠。

### 1.4 单链路 vs 双链路理论一致率

参考类似多源验证系统的经验数据：

| 类比系统 | 单源 vs 多源一致率 | 来源 |
|---------|---------------------|------|
| Ensemble ML（bagging/random forest） | 65-75%（单棵树 vs 集成） | Breiman 2001 |
| Cross-validation fold | 60-70%（单折 vs 全集） | Kohavi 1995 |
| 多模型预测金融时间序列 | 55-65% | 实证经验 |
| Multi-head attention 单头 vs 多头聚合 | 60-70% | Vaswani 2017 附录 |

**理论估算**：单链路与双链路一致性的期望一致率约 **55-65%**。考虑质变场景下双链路本身可能分歧（这正是质变信号），单链路输出 primary_dim 与"后续质变确认方向"的一致率预估：

- Granger 单链路：**45-55%**（质变期功效下降拖累）
- Attention 单链路：**50-60%**（敏感性高但精度低）
- 加权平均：**50-55%**——**恰好处于 H0 阈值 50% 附近，无法先验断定**

## 任务 2：一致性检验实验设计

### 2.1 假设与检验方法

```
H0: p ≥ 0.50  （降级模式不引入系统性偏差，单链路 primary_dim 与质变方向一致率 ≥ 50%）
H1: p < 0.50  （降级模式引入系统性偏差，应改为完全中性）
```

**检验方法选择**：

| 方法 | 适用场景 | 优点 | 缺点 | 推荐 |
|------|---------|------|------|------|
| **单边 Binomial test** | 固定样本量、已知质变事件总数 | 简单、p-value 明确 | 需等样本量门槛 | 用于事后复盘 |
| **Wilson score interval** | 比例估计、小样本 | 区间估计优于正态近似 | 仅区间，无决策规则 | 用于实时监控 |
| **SPRT 序贯检验** | 在线监测、样本量不定 | 早期停止、ASN 降低 47% | 需指定 p0/p1 | **主推**——用于 Q4 在线决策 |

### 2.2 样本量功效分析

固定样本 Binomial test，α=0.05（单边），power=0.80，p0=0.50：

| 待检测真值 p1 | 效应量 δ=|p0-p1| | 所需样本 n | BTC 1h 累积时间* |
|--------------|----------------|-----------|-------------------|
| 0.45 | 0.05 | **619** | 17-26 年（不可行） |
| 0.40 | 0.10 | **155** | 4-6 年 |
| 0.35 | 0.15 | **69** | 2-3 年 |
| 0.30 | 0.20 | **37** | 1-1.5 年 |

*基于 BTC 1h 周期质变事件频率估算约 2-3 次/月（见任务 3）

**Power=0.70 时样本量**（接受更高 Type II 错误）：

| p1 | n | 累积时间 |
|----|----|---------|
| 0.40 | 121 | 3.5-5 年 |
| 0.35 | 56 | 1.5-2.5 年 |

**SPRT 序贯检验 ASN**（α=β=0.05，p0=0.50 vs p1=0.40）：
- 边界 a = log((1-β)/α) = log(19) ≈ 2.944
- 边界 b = log(β/(1-α)) = -2.944
- 在 H0 真时漂移速率 μ₀ = 0.5×log(0.4/0.5) + 0.5×log(0.6/0.5) ≈ -0.0205
- ASN(H0) = a / (2|μ₀|) ≈ 2.944 / 0.041 ≈ **72**
- ASN(H1) = -b / (2|μ₁|) ≈ **74**
- **期望样本量约 73 次**（相比固定样本 155，节省约 53%）

### 2.3 时间窗口设计

```
质变事件 t_k (降级期 primary_dim 输出)
    │
    │ lag L ∈ [1, persistence × cycle] (待估)
    ↓
质变确认方向 t_k+L (后续双链路重新一致的方向)
```

**Lag L 设计**：
- 下界：1 期（即时一致）
- 上界：`persistence_threshold × cycle_phase`（约 5-10 期，1h 周期约 5-10 小时）
- 推荐主窗口：**L = persistence_threshold**（与质变检测窗口同尺度）
- 敏感性分析：L ∈ {1, 3, 5, 10}（覆盖短期到中期）

### 3.3 数据不足时的过渡方案

在样本量 < 30 期间（约前 9-15 个月），采用 **先验 + Bayesian 在线更新**：

```
# 初始先验（基于任务 1 理论估算）
prior_alpha = 11  # 相当于先验一致率 0.55，先验样本量 20
prior_beta = 9

# 每次质变事件后更新
posterior_alpha = prior_alpha + successes
posterior_beta = prior_beta + failures

# 后验均值
E[p] = posterior_alpha / (posterior_alpha + posterior_beta)

# 95% 可信区间下界
lower_bound = beta_ppf(0.025, posterior_alpha, posterior_beta)
```

**先验选择理由**：
- Beta(11, 9) 中心 0.55，反映理论估算的 50-65% 区间中值
- 先验样本量 20（弱先验），数据累积 30 次后先验权重仅占 40%，后验主要由数据主导
- 50 次质变事件后先验权重降至 28%，可视为数据驱动

**决策规则**：
- 后验下界 > 0.50：维持 Q4 降级模式
- 后验下界 < 0.40：切换替代方案
- 后验下界 ∈ [0.40, 0.50]：维持现状但启用告警

| **可证伪性** | ✓（一致率 binomial test） | ✓（无假设，但失效直接观测） | ✓（缓存值命中率） | ✓（映射准确率） |
| **回退成本** | 中（关 enable_degraded_mode） | 低（已是中性） | 低（清缓存） | 中（移除映射表） |
| **适配文档 §10.11.4 设计** | ✓ 原方案 | 部分（仅双 None 时） | ✗（与"不引入偏差"理念冲突） | ✗（引入新假设） |

### 4.3 推荐组合方案

**主方案**：Q4 原方案 + SPRT 在线监测 + Bayesian 过渡（数据不足期）

**条件回退**（基于任务 2 让步阈值）：
1. SPRT 触发下界 → 切换到 **替代 1（完全中性）** + 告警（最安全）
2. 后验下界 ∈ [0.40, 0.50] → 切换到 **替代 2（缓存）** + 限仓降级
3. high-volatility regime 一致率 < 40% → **替代 3（regime 映射）** 仅在该 regime 应用
4. Granger 单链路 vs Attention 单链路差异 > 20% → 链路差异化（仅保留较可靠链路）

**组合优势**：
- 数据充足前用 Bayesian 过渡，避免早决策
- 数据充足后用 SPRT 实时监测，早期停止
- 多层让步阈值确保安全回退
- 与文档 §10.11.4 原设计兼容，仅新增 `enable_degraded_mode` 的条件触发逻辑

## 综合结论：Q4 降级模式是否可靠？

### 结论分级

| 问题 | 结论 | 置信度 | 证据 |
|------|------|--------|------|
| **理论可靠性** | 单链路在质变期可靠性下降，但**不能先验断定 < 50%** | 中 | 任务 1 分析：Granger 平稳性违反、Attention 训练权重缺失，但二者在 trending/ranging 互补 |
| **实证可靠性** | **未知**——当前零历史样本，无法证实或证伪 | 低 | 数据缺口：`_history` 内存丢失、CrossValidationGate 未实现 |
| **可行性** | SPRT + Bayesian 过渡方案可行，1h 周期约 22-35 月可决策 | 中 | 任务 3 估算与 SPEC §11.3 一致 |
| **替代方案** | 替代 1（完全中性）最安全但放弃 primary_dim；替代 2-3 折中 | 高 | 任务 4 对比矩阵 |

### 总体判定

**Q4 降级模式的"单链路可靠"假设**：
- **理论上不能被先验证实**——单链路在质变期功效下降，但下降幅度未确定
- **理论上也不能被先验证伪**——一致率预估落在 50-65% 区间，包含 50% 阈值附近
- **当前应采取的态度**：**暂不放弃，但启用 SPRT 在线监测 + Bayesian 过渡 + 多层让步阈值**

### 与文档 §10.11.4 原设计的关系

文档原设计："`enable_degraded_mode` 默认 True（单链路可用总比完全中性好）"——此设计在数据不足期是合理的（先验 55% > 50%），但**必须补充**：

1. 在 `compare()` 返回 dict 中新增 `degraded_consistency_lower_bound` 字段（Wilson 区间下界）
2. 当 Wilson 下界 < 0.40 时自动切换到替代方案 1
3. 当 SPRT 触发下界时强制切换并告警
4. 文档 §10.11.4 需补充让步阈值表（任务 2.4）
