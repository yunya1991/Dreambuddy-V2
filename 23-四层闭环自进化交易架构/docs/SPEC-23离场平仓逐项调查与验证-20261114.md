## 1. 调查方法

三源对照，任一源判定为"错误"即列入缺陷：

1. **代码证据**：只采信生产链路可达路径（`polling_trader` → `EvolutionExitLoop.run` → `EvolutionExitEngine.decide`），注释与 docstring 不作为正确性依据。
2. **技术文档对照**：内部硬约束与设计文档。
   - [硬约束总表.md](../../2-KNOWLEDGE/1-TRADING/硬约束总表.md#L57-L61)：SL=4.0~6.0×ATR（下限 4%/上限 15%）；TP=3.0×SL（下限 12%/上限 30%）；盈亏比 ≥2:1
   - [硬约束总表.md](../../2-KNOWLEDGE/1-TRADING/硬约束总表.md#L158-L159)：保本止损、跟踪止盈、分批止盈 +1R→50% / +2R→30% / +3R→trailing 20%
   - [硬约束总表.md](../../2-KNOWLEDGE/1-TRADING/硬约束总表.md#L78-L82)：TP 衰减下限 ≥12%，前 12h 不衰减
   - [投资交易模型构建与实现指南.md](../../2-KNOWLEDGE/1-TRADING/投资交易模型构建与实现指南.md#L713-L728)：保护期、离场确认 2 次/300s
3. **传统金融方法正解**：
   - **Chandelier Exit**（Chuck LeBeau）：多头 `SL = 最高价(22) − 3×ATR(22)`，空头对称；止损锚定**峰值**而非现价。
   - **单调棘轮（monotonic ratchet）**：止损只能朝有利方向移动，禁止反向回退——这是仓位管理的公理级约束。
   - **R 倍数框架**（Van Tharp）：`1R = 入场价 − 初始结构止损`，不是从目标价反算；R 是所有分批/加仓/评价的统一度量。
   - **MFE/MAE 捕获率**：`capture = realized / MFE`，`giveback = 1 − capture`；离场质量的核心归因指标。
   - **Scaling out**：+1R 减 50%、+2R 再减 30%，剩余交给 trailing——与内部硬约束一致。
   - **保本含费**：breakeven 必须覆盖双边手续费 + 滑点，否则"名义保本"实为小亏。

### 5.2 回滚门禁（任一触发即回滚）

3. `规则 4 命中率 = 0` 且已注入 `current_sl_px` → 回滚（说明接线失效）。
4. 单日 `force_close` 笔数超过基线 3σ → 回滚。
