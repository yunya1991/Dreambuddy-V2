## 核心改动 (vs V9/v8.0+v9.0)

| 改动项 | V9 (v8.0+v9.0) | v12.0 |
|--------|----------------|-------|
| L2b Regime对立止链 | 无 | **持仓方向与Regime对立时提前止链** |
| L2c 链均价提前保护 | 仅Level3加满后 | **Level≥1加仓后即启用avg×1.20/×0.80** |
| MEC动能衰竭 (继承v11.0) | 无 | **涨三跌四+BTC MEC评分门控** |
| BLOCKED→FALLBACK (继承v11.0) | BLOCKED阻止入场 | **无MA信号时回退V9正常入场** |

**L2b触发条件**:
- Level=0: SHORT+STRONG_BULL 或 LONG+STRONG_BEAR → 止链
- Level≥1: SHORT+(WEAK/STRONG_BULL) 或 LONG+(WEAK/STRONG_BEAR) → 止链

**L2c触发条件**:
- Level≥1 且未加满: avg_entry × 1.20 (SHORT) / × 0.80 (LONG) → 止链
- 与v9.0 Level3 SL逻辑相同, 提前在Level1生效

## 修复的核心问题

**ETH 2025-05-10 灾难链** (本次修复):
```
修复前: SHORT $1,567 → L1$1,730 → L2$1,910 → 强平$2,583 (损失约-15.8%组合)
修复后: SHORT $1,567 → L1$1,730 → L2$1,910 → L2c avg×1.20 平仓$2,083 (损失约-4.8%组合)
```

**机制**: L2c在第一次加仓(Level=1)后立即为链设置avg×1.20(SHORT)/×0.80(LONG)保护线。
极端反向行情触及保护线时提前止损整条链, 不等信号反转或20%回撤强平。
