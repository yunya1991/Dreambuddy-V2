# 6-TRADING 知识库

## 是什么
从 dream-multiskill-v2 蒸馏的核心交易知识，以**哲学→理论→经验**三分法组织。

## 如何用

| 遇到问题 | 先读 |
|:---|---:|
| "这个决策对不对？" | `0-哲学/宪法.md` 中的6条原理 |
| "当前是什么行情？" | `1-理论/7种Regime定义.md` |
| "该怎么分配风险？" | `1-理论/阻力路径与冲突裁决.md` |
| "哪位大师的风格匹配？" | `2-经验/大师档案/INDEX.md` |
| "以前踩过什么坑？" | `2-经验/实战教训.md` |

## 哲学 → 理论 → 经验的调用路径

```
启动分析:
  1. 先加载 0-哲学/宪法.md 决策原则
  2. 再加载 1-理论/ 选择分析方法
  3. 最后查 2-经验/ 获取实战参数和案例

知识更新:
  新经验产生 → 写入 2-经验/
  方法论迭代 → 更新 1-理论/
  哲学修正 → 更新 0-哲学/（极少发生）
```
