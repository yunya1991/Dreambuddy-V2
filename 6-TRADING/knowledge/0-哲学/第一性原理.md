## 原理一：阻力最小路径 (Least Resistance Path)
> 市场如同流水，总是从阻力最小的地方通过

**阻力来源分解**:
| 阻力类型 | 量化指标 | 来源 |
|:---|:---|:---|
| 成本摩擦 | 手续费+滑点 | 订单簿 |
| 流动性摩擦 | 深度+买卖价差 | 订单簿 |
| 拥挤摩擦 | 资金费率+OI变化 | 合约市场 |
| 波动摩擦 | ATR+波动率 | 技术指标 |

**路径判定**: 阻力评分 < 40=UP方向 | 40~60=中性 | >60=DOWN方向

## 原理二：趋势延续性 (Trend Continuation)
> 趋势一旦形成，会延续直到遇到足够的反向阻力

**趋势阶段**: 启动期 → 加速期 → 衰竭期 → 逆转/盘整

**MA轨迹法核心**:
- 计算MA(5,10,20,60)序列
- 检测MA斜率变化率
- 趋势轨迹 = Σ(MA斜率 × 权重)
- 趋势强度 = |趋势轨迹| / 历史标准差

## 矛盾处理2.0
> 禁止因矛盾导致WAIT — 在冲突中必须找出主导方向

```
冲突强度:
  WEAK: 方向一致但置信差异>30% → 取置信度高者
  MODERATE: 方向相反但一方>60% → 取可靠方
  STRONG: 方向相反双方>50% → 取基本面权重更高者

输出规则:
  ✗ 禁止 direction=NEUTRAL
  ✗ 禁止 "等待方向明确"
  ✓ 必须输出 direction=UP|DOWN + 低置信度(0.3) + 小仓试探
```
