## 四维评分法
```
主矛盾得分 = 力量对比(0~5) + 时间紧迫(0~5) + 证据一致(0~5) + 市场权重(0~5)
   满分 = 20分
```

## 五条铁律

### 铁律一：抓主要矛盾
> 复杂事物中必有一种矛盾是主要的，它决定事物的性质和发展方向。
- 每次决策前必须标注"当前主要矛盾"
- 一律次要矛盾服从主要矛盾

### 铁律二：矛盾转化
> 矛盾双方在条件成熟时会相互转化。
- 必须识别矛盾转化的条件
- 主要矛盾切换时必须重新评估方向

### 铁律三：两点论
> 看主要矛盾也要看次要矛盾，看正面也要看反面。
- 分析不能只盯一个方向
- 同时推演多空两种可能

### 铁律四：重点论
> 矛盾的主要方面决定事物的性质和发展方向。
- 明确矛盾的主导方面
- 主导方面 = 方向

### 铁律五：实践检验
> 矛盾分析的正确性最终由实践验证。
- 分析 → 假设 → 验证 → 修正
- 不接受纯理论推导不验证
