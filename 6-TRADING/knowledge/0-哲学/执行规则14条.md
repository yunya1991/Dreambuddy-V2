# 6-TRADING 核心执行规则
> **审定**: 2026-06-13 — 基于实际系统状态验证
> **类别**: 哲学 — 必须遵守的操作纪律

---

## 一、最高优先级：V9 马丁规则（不可修改）

> 从 dream-multiskill-v2 衍生的系统，但 V9 规则是6-TRADING独立基线的最高约束。
> **任何优化必须在 V9 之上叠加，不得替换 V9 核心公式。**

**V9 基线参数：**
- 加仓间隔 8%×vol_mult（复利）
- 止盈 4%×vol_mult（单次全平）
- 最多 3 次等额加仓
- **无固定止损**（Martin 网格策略特性，非遗漏）

**vol_mult 配置：** BTC=1.0, ETH=1.50, SOL=1.75

## 二、数据纪律

### 规则 A：FAQ 优先
- 遇到问题 → 先搜索 FAQ → 有解执行 → 无解解决后归档
- 踩坑经验永久保留，不可删除

### 规则 B：数据 fallback 强制
- 数据源必须有 4 层回退链（Binance → Tavily/extract → CCXT Gate.io → 本地缓存）
- 上层数据源退化超 2 小时 → 自动切换下层

## 三、决策纪律

### 规则 C：趋势层级
- **MA200 三日确认** 为牛熊分界唯一锚点（非金/死叉）
- 日线维度 > 4H维度 > 1H维度
- MA200 定方向，RSI/MACD 仅加减强度

### 规则 D：证据强制
- 任何决策建议必须附证据清单（数据来源+时间戳）

## 四、风控纪律

### 规则 E：仓位限制
- 多策略并行总仓位 ≤ 20%
- 日回撤 > 10% → 暂停交易

### 规则 F：止损规则
- V9 马丁策略 **无固定止损**
- 若叠加其他策略，止损至少距离当前价 1%（留足波动空间）

## 五、投递纪律

### 规则 G：双通道投递
- A系列产物投递到 `6-TRADING/artifacts/{category}/`
- cron 执行结果自动投递飞书

## 六、时间纪律

### 规则 H：执行间隔
- V15 信号：每小时检查
- A1-A6：按 Hermes cron 排程（状态机驱动）
- 非交易时段不加速

## 七、双轨决策链

### 规则 I：AI 模式
- A1→A2→A3→A4→A5→A6 全链路由 Hermes 状态机管理
- A6 control_decision 决定下一步路由

### 规则 J：基线模式（降级）
- 当 Token ≤ 10% 自动切换
- 关 A1-A8, Screen1/2/3
- A6 只做 Token 监控不交易
