# 风险预算式仓位管理 (理论 — 仓位计算方法论)
> **来源**: dream-multiskill-v2/1-TRADE/dream-risk-position-sizing/SKILL.md
> **类别**: 理论 — 量化仓位计算方法

---

## 核心原则
用"风险预算"替代纯粹"总分档位"，仓位建立在可解释的风险占用上。

## 输入
- `scores`: { total 0-30, trend_strength 0-10, macro_fund_tailwind 0-10, memory_safety 0-10 }
- `vol`: { atr14_15m, atr_pct_15m }
- `risk_limits`: max_notional 150, max_drawdown 8%, risk_per_trade_cap
- `dream_mode`: { enabled, multiplier 0.5 }
- `portfolio_constraints`: 组合层约束

## 核心逻辑（5步）
```
1) 风险单位定义
   stop_distance = 2 × ATR(15m)
   estimated_stop_loss_usdt 随名义与杠杆变化

2) 风险预算
   risk_per_trade_usdt = risk_cap × scores.total / 30 (线性缩放)
   Dream Mode: × dream_mode.multiplier

3) 反向推名义与杠杆
   在 stop_loss <= risk_budget 下取最大 notional ≤ max_notional
   杠杆上限按 scores.total 分档

4) 账户级约束
   日回撤 > max_drawdown → pass=false (HARD_FAIL)
   memory_safety 过低 → 强制压缩风险预算

5) 组合层约束
   若敞口/集中度/因子暴露超限 → 优先降级 → 仍超限则 block
```

## 理由码
- `HARD_FAIL_DRAWDOWN_CIRCUIT_BREAKER` — 日回撤超限
- `HARD_FAIL_RISK_BUDGET_TOO_SMALL` — 风险预算过低
- `HARD_FAIL_PORTFOLIO_NET_EXPOSURE_LIMIT` — 组合净敞口超限
- `SOFT_WARN_DREAM_MODE_ACTIVE` — 梦游模式激活
- `ASSUMPTION_STOPLOSS_MODEL_SIMPLIFIED` — 止损模型简化估算

## 约束
- **不决定方向、不做信号、不负责下单** — 只输出仓位/杠杆建议与风险占用
- 缺少ATR或风险预算上限无法确定 → pass=false
