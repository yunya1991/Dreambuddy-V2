## 三角准则（调研方法论）

> 调研决策的三条独立证据链，不可绕过

### 准则一：记忆调研
- 调取 MEMORY.md、daily logs、episodes 历史
- 提取与当前行情相似的历史 case
- 必须引用具体 episode_id 和时间戳

### 准则二：历史类似行情调研
- 档案中心搜索相似行情
- 外部搜索历史类似走势案例
- 评估维度: 价格形态相似度 + 宏观环境相似度 + 时间周期相似度

### 准则三：类似交易策略调研
- 学习相似情境下的策略应对
- 参考大师库中的匹配策略
- 验证策略在历史类似环境中的表现

```
调查三角模型:
        ┌──────────────────┐
        │   完整调查        │
        │                   │
        │ ┌───┐ ┌───┐ ┌───┐│
        │ │历史│ │外部│ │实际││
        │ │记忆│ │调研│ │数据││
        │ └───┘ └───┘ └───┘│
        │  三者缺一不可      │
        └──────────────────┘
```

## 三层索引体系（策略检索链）

> 按优先序检索，大师策略(最高)→联网搜索(次)→实践经验(兜底)

| 层级 | 检索来源 | 优先级 | 用途 |
|:---|:---|:---:|:---|
| 第一层 | 大师策略库 (master_profiles/) | 最高 | 大师策略匹配当前Regime |
| 第二层 | 联网搜索 (Tavily/Web) | 中等 | 市场最新策略/信号 |
| 第三层 | 实践经验 (历史episodes) | 兜底 | 已知可行策略 |

### 工具索引（第二索引维度）
Regime → 工具匹配矩阵 + OKX命令模板

### 跨资产设计（第三索引维度）
宏观资产池(XAUT/COIN/CL/XCU) + 币种相关性 + 组合方案
