3美林时钟周期判定方法论
3.1 四象限模型

引擎核心基于美林投资时钟（Merrill Lynch Investment Clock），将经济周期划分为四个象限，以增长得分和通胀得分的 50 分中位线为分界：

滞胀期
增长 ↓ · 通胀 ↑
超配：贵金属/现金
过热期
增长 ↑ · 通胀 ↑
超配：商品/周期股
衰退期
增长 ↓ · 通胀 ↓
超配：国债/日元
复苏期
增长 ↑ · 通胀 ↓
超配：科技股/信用债
3.2 增长得分计算逻辑
指标基准/荣枯线映射公式权重
PMI 指数50 为荣枯线min(max((value-40)×5, 0), 100)1.0
GDP 增长率2% 潜在增速min(max(value×20, 0), 100)1.0
失业率5% 自然失业率min(max((5-value)×20+50, 0), 100)0.8

趋势调整：上行 +10 / 下行 -10；新鲜度调整：fresh +5 / stale -10

3.3 通胀得分计算逻辑
指标央行目标映射公式权重
CPI 通胀率2%min(max((value-2)×25+50, 0), 100)1.0
核心 CPI2%min(max((value-2)×25+50, 0), 100)1.1
PPI2%（领先性）min(max((value-1)×15+35, 0), 100)1.2

PPI 因领先性获得最高权重 1.2；核心 CPI 次之 1.1

3.4 置信度计算

置信度由三个维度加权合成：

维度权重计算方式
指标数量50%min(指标数/6, 1) × 0.5，6个指标即满分
数据新鲜度30%fresh=1.0 / acceptable=0.7 / stale=0.4 的平均值
指标一致性20%增长与通胀指标各自趋势的众数占比，取平均
当前置信度 = 95%：6 个指标全部 fresh（满分）+ 趋势一致（GDP/CPI 同向上行），构成高置信判定。
4三版本引擎深度剖析
4.1 V1 美林时钟经典版 — 规则驱动

V1 是纯规则引擎：周期判定 → 固定权重映射表 → 子类偏好分级。无数据时使用偏好分数（1-5分）直接映射配置方向。

周期股票债券商品现金加密
复苏期40%20%15%10%15%
过热期（当前）25%10%35%10%20%
滞胀期10%20%30%30%10%
衰退期15%35%10%30%10%

子类偏好：5分=优先级1(超配) / 4分=优先级2(超配) / 3分=中性 / 2分=低配 / 1分=最低配

V1 优势：逻辑透明、可解释性强、计算量小，适合快速判断和系统降级场景。
4.2 V2 多因子增强版 — 量化评分

V2 在 V1 周期判定的基础上，引入四因子加权评分体系，将子类资产评分量化为 0-100 分：

因子权重数据来源说明
周期因子40%美林时钟偏好映射表22个子类 × 4周期 = 88个偏好值
动量因子25%价格趋势（默认：周期×0.7+噪声+15）无实际数据时基于周期推断
估值因子20%PE/PB等（默认：静态基础估值表）加密类估值偏低（30-40分）
情绪因子15%资金流/舆情（默认：周期×0.6+噪声+20）波动最大，±30噪声
V2 关键设计：评分 ≥65 → 超配 / 35-65 → 标配 / ≤35 → 低配。大类权重 = round(综合得分×0.8+10)，再归一化至100%。
4.3 V3 情景模拟版 — 概率推演

V3 在 V2 因子评分基础上，增加周期预测层：基于马尔可夫链转换概率 + 领先指标调整，输出三情景配置方案。

9系统优势分析
✅ 三版本交叉验证

V1/V2/V3 三引擎并行运行，通过周期一致性（1.0）、配置相关性、Top资产重合度三维度量化对比。当三版本结论一致时，可信度显著提升；当出现分歧时，系统自动检测低置信版本作为回退候选。

✅ 可降级架构

Tavily API 不可用时自动降级为模拟数据；资产调研模块故障时第一屏自动降级为原有模式；置信度过低时明确标注"仅供参考"。三层降级保障系统鲁棒性。

✅ 量化因子体系

V2 的四因子加权体系将主观偏好转化为可量化、可追溯的评分。每个子类资产的推荐理由都包含具体的优势/风险因子描述，如"周期位置有利、动量强劲、市场情绪积极"。

✅ 前瞻性情景推演

V3 的马尔可夫链+领先指标体系不仅给出当前配置，还提供基准/乐观/悲观三情景的未来配置预案，支持季度动态调仓决策。多时间维度展望覆盖短/中/长期。

✅ 低侵入集成

通过 latest.json + Bridge 模式与第一屏解耦，30分钟缓存避免重复读取。资产调研独立运行，结果写文件，不改变原有第一屏逻辑。

✅ 全链路自动化

月度常规调研（每月1号）+ 季度深度报告（首月5号）+ 事件驱动快速调研，配合告警机制（飞书/邮件/Webhook），实现从数据采集到报告推送的全自动闭环。

10局限性与风险提示
⚠️ 已识别风险点
#风险类别描述影响程度
1数据来源单一当前数据源为 example.com/economic-data（占位），实际依赖 Tavily API 或降级模拟数据。模拟数据不含真实趋势，导致动量/情绪因子退化为周期推断+随机噪声高
2指标去重缺陷latest.json 中 GDP/PMI/CPI 各出现两次（重复），导致置信度计算中指标数量虚高（6个而非3个），置信度被人为推高至 95%高
3动量/情绪因子含随机噪声V2 的 getDefaultMomentumScore 和 getDefaultSentimentScore 使用 Math.random()，每次运行结果不同，无法复现中
4估值因子为静态值V2 估值因子使用硬编码 BASE_VALUATION 表，不随市场变化。加密类（30-40分）始终低分，可能系统性低估加密资产估值吸引力中
5PMI 信号矛盾未触发特殊处理PMI 48.4 低于荣枯线但 GDP 上行，系统仍判定为过热期。实际可能是结构性分化（服务业强/制造业弱），需更细化的周期判定中
6美林时钟地域局限美林时钟基于美国 1970-2004 历史数据验证，在非美市场（尤其中国）有效性降低。中国"政策市"特征下周期切换不完全遵循时钟顺时针旋转中
7预测置信度偏低V3 预测置信度仅 46%，低于 50% 参考线。领先指标仅识别到 PMI 一个（其余为模拟），预测可信度有限高
8缺少加密市场特有指标 Fear & Greed Index、资金费率、链上活跃度等加密原生指标未纳入因子体系，加密类配置完全依赖传统宏观周期映射中
最关键问题：当前报告使用的是模拟数据（数据源标记为 example.com），而非真实宏观数据。95% 的高置信度部分来自指标重复计数。在接入真实 Tavily API 数据前，本报告的配置建议仅供框架验证，不构成实际投资参考。
