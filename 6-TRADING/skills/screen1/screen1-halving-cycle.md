## 一、减半供给冲击机制

### 1.1 比特币内置的库存周期

比特币协议将每次减半设计为一次强制性供给冲击，触发可预测的价格发现周期。这不是技术分析，是经济学规律：

```
每隔 ~210,000 个区块（约4年）矿工区块奖励减半：
  第1周期 (2012): 50 → 25 BTC/区块
  第2周期 (2016): 25 → 12.5 BTC/区块
  第3周期 (2020): 12.5 → 6.25 BTC/区块
  第4周期 (2024): 6.25 → 3.125 BTC/区块

减半后供给冲击传导路径:
  日产量骤降 50%
    → 矿工日均 BTC 收入减半（短期成本压力）
    → 市场日均新增抛售压力减少 ~50%
    → 在需求不变的情况下：价格发现上涨
    → 价格上涨 → 吸引新投资者入场
    → 正向反馈循环 → 供给冲击效应持续 ~12-18 个月
```

### 1.2 S2F（库存/流量）比率机制

```
S2F = 现有存量（Stock）÷ 年产量（Flow）
  含义: S2F 越高 = 稀缺性越强 = 价格支撑越高

第3周期 (2020-2024): S2F ≈ 56  (接近黄金 S2F ~60)
第4周期 (2024-2028): S2F ≈ 119 (远超黄金)

理论价格支撑:
  S2F 模型将稀缺性量化为价格 → 每次减半后 S2F 翻倍
  → 历史上价格在减半后 12-18 个月内向新 S2F 对应估值靠拢

注意: S2F 是价格上限的方向性工具，不是精确预测；
     ETF 时代机构采购改变了传导节奏（加快），但方向性依然成立。
```

### 1.3 递减收益规律

每次减半周期 BTC 涨幅在递减，因为市值越大、流动性越高，拉动成本也越高：

| 减半周期 | 时间 | 涨幅（周期峰值/减半价）| 原因 |
|---------|------|---------------------|------|
| 第1周期 | 2012 | **+97x** | 市值极小，散户驱动 |
| 第2周期 | 2016 | **+30x** | 市值增长，但仍散户主导 |
| 第3周期 | 2020 | **+7.8x** | 机构开始入场（MicroStrategy, Grayscale）|
| 第4周期 | 2024 | **预期 +1.94x** | ETF 机构主导，基数大，涨幅收窄 |

> 递减收益是正常的，不代表"减半失效"——绝对涨幅仍然显著，只是倍数在缩小。

| 2 | 供给冲击初期 | 减半后 0~180天 | +15 | BULL | 日产量骤降，供给最紧张期 |

### 2.2 各阶段深度分析

**阶段2：供给冲击初期（最强势阶段）**
```
机制:
  减半日 → 日产量从 900 BTC → 450 BTC
  矿工收入减半 → 无利可图的矿工关机退出
  剩余矿工更谨慎抛售（等待价格回升）
  供给端突然收缩 → 在买盘维持的情况下价格上涨

历史表现:
  2020 减半后 180 天: +165%
  2016 减半后 180 天: +57%
  2024 减半后 180 天: +30%（ETF时代递减）
```

**阶段4：顶部窗口（最难操作阶段）**
```
特征:
  价格仍可能上涨（但上涨斜率放缓）
  链上指标开始预警（MVRV Z > 3.5, NUPL > 0.75）
  矿工开始增加抛售（Puell Multiple > 2.0）
  主流媒体进入（散户情绪顶峰）

操作含义: 分批止盈，减少马丁仓位，不建新仓
```

**阶段6：去库存期（当前阶段，最痛苦但临近转机）**
```
特征:
  价格持续低位
  矿工亏损、被迫抛售（成本压力）
  长期持有者逐渐接盘（RHODL 上升）
  算力下降、难度调整（弱矿工出局）

临近转机信号:
  Hash Ribbon 金叉（30日MA上穿60日MA）
  RHODL > 4（长期持有者主导）
  NUPL < 0（市场整体亏损）→ 历史底部区域

当前 (2026-06): 阶段6 第 772 天，进入去库存期后半段
```

## 三、ETF 时代对减半周期的影响

```
传统减半模式 (2016, 2020):
  减半 → 矿工停产 → 供给减少 → 价格被动上涨
  时间线: 减半后 6-12 个月才开始明显上涨

ETF 时代 (2024+):
  机构提前布局 → ETF 审批预期 → BTC 在减半前已涨
  2024 案例: 1月 ETF 批准后 BTC 已涨 +150% → 减半前已透支部分供给冲击效应

影响评估:
  ✓ 周期结构（7阶段）依然成立
  ✗ 减半日当天价格反应可能"平淡"（提前定价）
  ✓ 阶段2/3 持续时间可能缩短（机构比散户更快布局）
  ✓ 底部绝对价格更高（ETF 托底效应）
  ✗ 周期峰值倍数递减（市值基数大）

结论: 使用周期框架时，重视阶段方向，不迷信具体天数刻度
```

### Step 3 — 六维度周期评估

**维度1：算力/难度调整**
- 算力创历史新高且持续上升 → 矿工看好后市 (+1~+2)
- 算力下降 >15% → 矿工撤出，熊市信号 (-1~-2)
- 难度调整连续下调 3 次+ → 矿工受压 (-1)

**维度2：矿工收入/出矿压力**
- 矿工手续费占比 >20% → 链上活跃，减轻卖压 (+1)
- 矿工 OTC/交易所流入激增 → 抛售压力 (-1~-2)
- 矿工余额减半后 12 个月仍持续下降 → 超常抛售 (-1)

**维度3：S2F 实际偏差**
- 当前价格 > S2F 预测 × 1.2 → 透支估值 (-1~-2)
- 当前价格 < S2F 预测 × 0.5 → 严重低估 (+1~+2)
- 0.5x~1.2x 合理区间 → 不调整 (0)

**维度4：NUPL / 持币者盈亏**
- NUPL > 0.75（极度贪婪）→ 顶部预警 (-1~-2)
- NUPL < 0（多数持币者亏损）→ 底部信号 (+1~+2)
- NUPL 0.25~0.75 → 健康，不调整 (0)

**维度5：机构 ETF 因素（仅第4周期）**
- ETF 净流入持续正值 → 结构性需求 (+1)
- ETF 连续 2 周+ 大额净流出 → 机构撤退 (-1)
- 无明显方向 → (0)

**维度6：宏观周期叠加**
- Fed 降息周期已启动 + BTC 阶段 2/3 → 双重共振 (+1)
- Fed 加息或缩表 + BTC 阶段 5/6 → 双重压力 (-1)
- 宏观中性 → (0)

---

### Step 4 — 计算 stage_adjustment

`stage_adjustment = 各维度得分之和`，限制在 **[-5, +5]** 范围内。

最终评分 = 基线评分 + stage_adjustment

信号重判（仅当调整后分数跨越阈值时）：
- 调整后 ≥ +8 → BULL
- 调整后 ≤ -8 → BEAR
- 其他：维持基线信号

`confidence`：
- 搜索丰富且一致 → 0.85~0.95
- 部分缺失或矛盾 → 0.60~0.80
- 无有效搜索结果 → 0.50（不调整）
