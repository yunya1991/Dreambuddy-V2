## 一、矿工经济底部理论

### 1.1 商品属性定价原理

比特币具备商品属性：**价格不可能长期低于边际生产成本**。这是矿工经济维度的核心公理。

```
商品定价逻辑:
  当价格 < 生产成本 → 生产者亏损 → 停止生产（关机）
  → 供给减少 → 供求重新平衡 → 价格回升至成本线以上

比特币具体路径:
  BTC 价格跌破关机价
    → 效率低矿工关机（高成本矿机先出局）
    → 全网算力下降
    → 协议自动调低挖矿难度（约每 2 周一次）
    → 剩余矿工单位算力收益上升
    → 成本底支撑形成
    → 价格不可能长期维持在关机价以下
```

### 1.2 三层成本结构

| 成本层 | 当前估算（2026-Q1）| 含义 | 历史作用 |
|--------|------------------|------|---------|
| **关机价（Shutdown）** | ~$43,000 | 纯电费，边际成本 | 历史绝对底部支撑 |
| **平均生产成本（Avg）** | ~$82,000 | 含折旧、运营 | 结构性底部，长期不可持续跌破 |
| **全成本（All-in）** | ~$100,000 | 上市矿企含融资、管理成本 | 顶部估值参考（正常应高于此）|

> 成本随算力/能源价格/矿机代际每季度变化，代码模块通过 `COST_MILESTONES` 历史插值自动估算当前成本。

### 1.3 历史底部验证（3/3 精准）

| 周期 | 底部价格 | 与关机价偏差 | 跌破时长 | 后续表现 |
|------|---------|------------|---------|---------|
| 2018 底 | $3,200 | 低于关机价 -47% | ~2 个月 | +2200% (24个月) |
| 2020.3 | $3,800 | 低于关机价 -46% | ~2 周 | +1600% (18个月) |
| 2022 底 | $15,500 | 低于均成本 -23% | ~3 个月 | +350% (18个月) |
| **2026-06（当前）** | ~$73,500 | 低于均成本 ~-10% | 进行中 | 等待确认 |

> 规律：价格跌破均成本后，历史上均在 2-3 个月内触底反弹。跌破时长越短，底部质量越高。

## 二、矿工投降五阶段（Hash Ribbon 机制）

### 2.1 投降周期定义

矿工投降是底部最可靠的先行信号之一，经历五个阶段：

```
阶段1: 利润压缩（Pre-Capitulation）
  价格下跌但仍高于成本 → 矿工收入下降 → 减少卖出，等待反弹
  信号: Puell Multiple 从 >1.0 开始下降

阶段2: 投降开始（Hash Ribbon 死叉）
  价格跌破部分矿工成本 → 高成本矿工开始关机
  算力: 30日MA 下穿 60日MA（死叉）
  信号: Hash Ribbon 出现死叉 → 历史上是"恐慌底"前期

阶段3: 难度下调（Protocol Response）
  算力持续下降 → 协议降低挖矿难度（约每 2 周一次）
  幸存矿工单位算力收益回升
  信号: 难度连续 2+ 次下调

阶段4: 幸存者稳定（Stabilization）
  无利可图矿工已退出 → 剩余矿工成本结构改善
  算力企稳或小幅回升
  信号: 算力企稳，Hash Ribbon 死叉持续但不扩大

阶段5: 价格恢复（Recovery）
  算力 30日MA 开始上穿 60日MA（金叉）
  信号: Hash Ribbon 金叉 = 历史上最可靠的底部确认信号（价格滞后 2-4 个月）
```

### 2.2 Hash Ribbon 原理详解

```
构成:
  Hash Ribbon = 算力 30日移动平均 vs 60日移动平均

为什么有效:
  30日MA 反映近期矿工行为（快速变化）
  60日MA 反映较长期趋势（变化慢）

  死叉（30MA < 60MA）:
    近期算力低于长期趋势 → 矿工正在退出
    → 市场恐慌，卖压最大 → 价格通常已跌透

  金叉（30MA > 60MA）:
    近期算力高于长期趋势 → 幸存矿工开始扩张
    → 投降结束确认 → 历史上价格随后 2-4 个月上涨

历史金叉信号:
  2019-01: 金叉 → BTC 随后 +200%（6个月）
  2020-04: 金叉 → BTC 随后 +400%（6个月）
  2023-02: 金叉 → BTC 随后 +150%（6个月）
  准确率: 历史上金叉后 6 个月内正收益概率 >90%
```

## 三、三大辅助指标详解

### 3.1 Puell Multiple（矿工收入倍数）

```
定义:
  Puell Multiple = 当日矿工收入（美元）÷ 过去 365 天日均矿工收入

含义:
  >1.0: 当日收入高于年均 → 矿工盈利状态
  <1.0: 当日收入低于年均 → 矿工亏损压力
  <0.6: 极端压力区（历史底部区域）
  >4.0: 过热区（历史顶部区域）

历史分布:
  极端低位（<0.5）: 每个周期出现 1-2 次，对应历史底部
  正常范围（0.5-2.0）: 大多数时间
  极端高位（>4.0）: 每个周期出现 1-2 次，对应历史顶部

ETF时代注意:
  减半后矿工日产量仅 450 BTC → 矿工收入占比下降
  ETF 持仓 130 万 BTC → ETF 成为更重要的边际定价者
  Puell 对顶部的预测效果减弱，但底部信号依然有效
```

### 3.2 MPI（矿工持仓指数）

```
定义:
  MPI = 矿工每日链上转移量（BTC）÷ 过去 365 天日均转移量

含义:
  >2.0: 矿工大量抛售（转移到交易所或 OTC）
  -1.0~2.0: 正常持仓行为
  <-1.0: 矿工在积累（减少抛售 or 转入冷钱包）

信号解读:
  MPI > 2.0 = 矿工认为价格高，在抛售 → 偏顶部
  MPI < -1.0 = 矿工认为价格低，在囤币 → 偏底部

当前解读 (2026-06):
  MPI < 0（推测，需Tavily搜索确认）→ 矿工在底部积累
  与 Hash Ribbon 恢复信号一致 → 底部特征
```

### 3.3 各指标组合评分

| 状态组合 | 解读 | 对 BTC 含义 |
|---------|------|-----------|
| Hash Ribbon 死叉 + Puell<0.6 + MPI>2 | 矿工投降顶峰 | 可能是极端底部，但短期仍有下行风险 |
| Hash Ribbon 金叉 + Puell<1.0 + MPI<0 | 投降结束，矿工转积累 | 历史最强底部信号组合 |
| Hash Ribbon 正常 + Puell>1.0 + MPI<0 | 矿工盈利且在囤币 | 健康上涨支撑 |
| Hash Ribbon 正常 + Puell>4.0 + MPI>2 | 矿工在过热区大量抛售 | 顶部预警 |

## 四、ETF 时代对矿工经济的影响

```
传统定价权（ETF前）:
  矿工 = 主要新增供给来源（卖压主力）
  矿工成本 = 价格下限的直接锚定

ETF时代变化:
  减半后矿工日产量: 450 BTC/天 = 约 $3.3B/年（按$73K计）
  ETF管理资产: 约 $60B + 持仓约 130万 BTC
  → ETF持仓变动对价格影响 >> 矿工日产量

结论:
  ✓ 矿工成本仍是"绝对底部"（价格永久低于关机价不可持续）
  ✓ Hash Ribbon 底部信号依然有效（矿工资本退出 → 供给收缩）
  ✗ 矿工顶部信号（Puell>4.0 = 顶部）已大幅弱化
  → 本模块主要用于底部识别，顶部判断交由链上估值维度
```

## 六、评分体系

代码模块先计算 `price_score`，SKILL 在此基础上叠加：

**价格 vs 成本（代码自动计算）**
| 价格位置 | 评分 |
|---------|------|
| 低于关机价 | -15（极端底部，但危险期）|
| 关机价~均成本 | -10（底部区间）|
| 均成本~全成本 | 0（正常范围）|
| 高于均成本 20%+ | +5（健康盈利）|
| 高于全成本 50%+ | +15（强势牛市）|

**Hash Ribbon 覆盖规则（最高优先级）**
| 状态 | 覆盖评分 |
|------|---------|
| 死叉持续中 | -20（覆盖价格分）|
| 金叉 ≤28天（恢复中）| -10（降级警戒）|
| 正常（无覆盖）| 0（使用价格分）|

**Puell Multiple 叠加**
| Puell | 分数 |
|-------|------|
| < 0.6 | -5（极端压力）|
| 0.6~1.0 | 0 |
| > 4.0 | +5（过热，底部分析中参考价值低）|

**MPI 矿工持仓叠加**
| MPI | 分数 |
|-----|------|
| > 2.0 | -5（矿工抛售）|
| -1.0~2.0 | 0 |
| < -1.0 | +5（矿工积累）|

**信号阈值**: score ≥ +5 → BULL | score ≤ -5 → BEAR

### Step 3 — 四维评分

根据搜索结果逐维度打分：

**维度1: Hash Ribbon 覆盖规则**（最高优先级，覆盖价格分）
- 30日MA 低于 60日MA（死叉持续）→ ribbon_override = **-20**
- 30日MA 刚上穿 60日MA（金叉 ≤28天）→ ribbon_override = **-10**
- 正常（无覆盖）→ 0

**维度2: Puell Multiple**
- Puell < 0.6 → **-5** | 0.6~1.0 → 0 | > 4.0 → **+5**

**维度3: MPI**
- MPI > 2.0 → **-5** | -1.0~2.0 → 0 | < -1.0 → **+5**

**维度4: 生产成本更新校准**
- 搜索到成本 >代码默认值 10% → 上调成本 → price_score 下调 1~3 分
- 搜索到成本 <代码默认值 10% → 下调成本 → price_score 上调 1~3 分

---

### Step 4 — 计算 score_adjustment

仅针对**代码无法自动获取的定性因素**（±10）：
- 最新成本数据与代码基线偏差 → ±1~3
- 矿企财报/融资动向（大矿企抛售/增持）→ ±1~2
- 矿工投降程度（交易所矿工净流入创新高）→ -2~0
- 哈希率趋势（连续 2 周新高 vs 连续 2 周下滑）→ ±1~2

`confidence`：
- 4 条搜索均有效且一致 → 0.85~0.95
- 2~3 条有效 → 0.65~0.80
- 0~1 条有效（AI 不可用）→ 0.50，`score_adjustment=0`

## 九、常见误区

| 误区 | 正确认知 |
|------|---------|
| "价格跌破成本 = 立即反弹" | 跌破后可能维持 2-3 个月，Hash Ribbon 金叉才是确认 |
| "矿工顶部信号（Puell>4）很可靠" | ETF 时代顶部信号已钝化，矿工日产量占比<5%，不再主导顶部 |
| "算力创新高 = BTC 涨" | 算力反映矿工信心，不直接决定价格；ETF 资金流影响更大 |
| "看到 Hash Ribbon 死叉马上空" | 死叉通常在价格已大跌后出现（滞后信号），用于确认底部，不用于追空 |
| "Puell <0.6 = 抄底信号" | Puell 极低时价格可能仍在下跌，需结合 Hash Ribbon 金叉才能入场 |
