## 一、核心理论框架：三层宏观传导机制

宏观金融对 BTC 的影响遵循"潮水-引力场-直接管道"三层结构，每一层传导时滞不同，理解这一结构是避免信号混淆的关键。

```
【第一层】全球 M2 ——— BTC 的潮水
  ┌─────────────────────────────────────────────────────────────────┐
  │ 原理: 全球流动性总量决定所有风险资产的估值上限                      │
  │       M2 扩张 → 资本寻找收益 → 风险资产估值抬升                    │
  │ 时滞: 约 13 周（约 3 个月）                                       │
  │ 实证: 2020.3 QE → 6 个月后 BTC +500%                            │
  │       2022 M2 收缩 → 同期 BTC -75%                               │
  │ 当前: M2 +12% YoY (2026-06) → BTC 背离已 6 个月 → 时间窗口临近    │
  └─────────────────────────────────────────────────────────────────┘

【第二层】DXY + 10Y 收益率 ——— BTC 的引力场
  ┌─────────────────────────────────────────────────────────────────┐
  │ DXY 机制:                                                        │
  │   美元走强 → 全球资本回流美元 → 新兴市场 + 风险资产流动性收紧         │
  │   美元走弱 → 美元流出寻找高收益 → 风险资产估值提升                   │
  │   BTC 与 DXY 历史负相关: -0.6~-0.8（强趋势期）                     │
  │                                                                   │
  │ 10Y 收益率机制:                                                   │
  │   10Y↑ → 无风险收益率上升 → 机构资金从 BTC 流向美债                 │
  │   10Y↓ → 债券吸引力下降 → 机构资金寻找高收益替代品                   │
  │   阈值: 4% 是心理分界线（低于4%→机构开始考虑 BTC 替代）             │
  │   当前: 10Y ~5% → 机构资金竞争激烈，BTC 估值压制                   │
  └─────────────────────────────────────────────────────────────────┘

【第三层】BTC 现货 ETF 净流 ——— 直接管道
  ┌─────────────────────────────────────────────────────────────────┐
  │ 原理: 2024年 ETF 批准后，机构通过 ETF 直接定价 BTC               │
  │       ETF 净流入 = 机构增量需求 → 边际定价权                       │
  │       周净流 >$5亿 连续 2 周 → 机构确认入场                        │
  │       周净流 <-$5亿 连续 6+ 天 → 历史可靠顶部信号                  │
  │ 时滞: 几乎即时（T+1 反映价格）                                     │
  └─────────────────────────────────────────────────────────────────┘
```

## 二、ETF 时代范式转变（2024+ 最关键认知）

### 2.1 BTC 从「滞后指标」到「领先指标」

```
ETF 前 (2013-2023):
  散户主导 → 降息才买 → BTC 滞后央行政策 6-12 个月
  策略逻辑: 等 Fed 降息 → 买 BTC → 追涨

ETF 后 (2024+):
  机构主导 → 提前 6-12 个月布局 → BTC 领先定价
  2024 案例: ETF 批准 1 月份 → 机构抢跑 → BTC 在 Fed 首次降息前已涨 +120%
  策略逻辑: 等 Fed 降息 → 卖 BTC（利好出尽）

⚠️ 核心误区: "Fed 降息 = 买 BTC" 在 ETF 时代完全失效
⚠️ 正确框架: 买 BTC 应在"市场开始预期降息"时，而非"降息落地"时
```

### 2.2 机构布局的时间窗口模型

```
降息预期形成 (T)
    → 机构开始 DCA 买入 ETF (T+1个月)
    → BTC 开始上涨趋势 (T+2~3个月)
    → 首次降息落地 (T+6~12个月)  ← 散户追涨
    → BTC 回调/"卖事实" (T+6~12个月后)
    → 散户套牢

2025 复盘:
  2024Q4 Warsh 鸽派预期 → 机构提前布局
  2025 3次降息 → 每次降息前 BTC 上涨，降息当天或后几天回调
```

### 2.3 全球 M2 与 BTC 背离规律

```
历史背离案例:
  2020.3  M2 急扩 vs BTC 短暂下跌   → 背离 2 个月 → BTC +500% (6个月)
  2021.Q4 M2 增速放缓 vs BTC 创新高  → 背离 3 个月 → BTC -75%（预示顶部）
  2022-2023 M2 收缩 vs BTC 底部      → 一致走低
  2024.Q1 M2 恢复 vs BTC ETF带动涨   → 几乎同步（ETF时代传导加快）

当前 (2026-06):
  全球 M2 +12% YoY  vs  BTC -12% YTD
  背离已持续约 6 个月 → 历史上 6-12 个月背离均以 BTC 补涨结束
  T-bill 驱动的 M2 扩张对 BTC 传导比 QE 更强（直接非银体系扩张）
```

## 三、五大指标机制详解

### 3.1 Fed 政策周期

**理论逻辑**: Fed 政策设定风险资产的折现率基准。

```
加息周期 → 无风险利率上升 → 风险资产 DCF 贴现值下降 → BTC 估值压力
降息周期 → 无风险利率下降 → 风险资产估值重新膨胀 → BTC 受益

ETF 时代修正:
  机构提前布局 → 实际影响在"预期形成"时，而非政策落地时
  点阵图（Dot Plot）比 FOMC 决议更重要（点阵图反映机构预期基础）

当前 (2026-06): HOLD 状态
  Warsh 接班预期（鸽派）→ 市场已部分定价 2026H2 宽松
  实际降息可能触发"卖事实"效应
```

**评分影响**: -10 ~ +10

| 状态 | 评分 | 说明 |
|------|------|------|
| CUTTING_MORE | +10 | 降息中 + 预期更多 |
| CUTTING_PAUSE | +5 | 降息中但预期暂停 |
| HOLD | 0 | 维持，需结合预期分析 |
| HIKING_PAUSE | -5 | 加息中但预期暂停 |
| HIKING_MORE | -10 | 加息中 + 预期更多 |

### 3.2 全球 M2（领先信号核心）

**理论逻辑**: 全球 M2 = Fed + ECB + BoJ + PBOC 合计，代表全球信用总量。

```
传导路径:
  M2 扩张 → 银行超额准备金 → 资本市场流动性提升 → 风险资产估值膨胀

传导时滞分类:
  T-bill 驱动:   ~8-10 周（非银体系扩张，传导更直接）
  央行 QE 驱动:  ~13 周（传统路径）
  信贷扩张驱动:  ~20+ 周（经济体系内生，间接传导）

当前: T-bill 驱动为主 → 传导时间可能比历史均值短
```

**评分影响**: -10 ~ +10

| M2 YoY | 评分 |
|--------|------|
| >+10% | +10（加速扩张）|
| +5~10% | +5 |
| ±5% | 0（平稳）|
| <-5% | -10（收缩）|

### 3.3 DXY（引力场之一）

**理论逻辑**: 美元指数代表全球资本的"避险-风险"倾向。

```
DXY 走强的两种情形（需区分！）:
  ① 美国基本面强 → DXY↑ 但同期股市也涨 → BTC 影响中性
  ② 全球风险规避 → DXY↑ 同期股市跌 → BTC 跟随下跌 (负面)

DXY 走弱的两种情形（需区分！）:
  ① 美国基本面弱 → DXY↓ + 降息预期 → 对 BTC 中长期利好（持续性强）
  ② 纯技术回调 → DXY↓ 短暂 → 对 BTC 影响有限（可能反转）

当前 (2026-06): DXY 从 ~108 高点回落至 ~100
  → 美元走弱原因: 关税政策不确定性 + 市场对美元储备地位再思考
  → 持续性: 结构性（非纯技术回调）→ 对 BTC 中期利好可持续
```

### 3.4 10Y 国债收益率（引力场之二）

**理论逻辑**: 10Y 收益率是机构资金的"机会成本基准"。

```
10Y = 5% 情形:
  无风险 5% 年化 vs BTC 高波动
  机构 (pension fund, insurance) 在 5% 时倾向于"安全够了"
  → 直接减少 BTC 配置需求

10Y = 3% 情形:
  传统资产收益不足 → 机构被迫寻找高收益替代品 → BTC 成为 "portfolio diversifier"

历史拐点:
  2022 10Y 从 1.5% → 4.0% → BTC -75%
  2023 10Y 高位震荡 4.0%-5.0% → BTC 反弹受抑
  2024 10Y 开始高位回落 → BTC ETF时代超越利率压制上涨
  当前: 10Y ~5% → 仍在竞争机构资金
```

### 3.5 BTC 现货 ETF 净流量

**理论逻辑**: ETF 净流量 = 机构增量意愿的直接测量。

```
重要性排序 (ETF 时代):
  ETF 资金流 >> 散户情绪指标 (Fear & Greed)
  周净流 > 日净流（日线噪音多）

信号质量分级:
  连续 ≥2 周 >$5亿流入：机构确认买入 → 强 BULL 信号
  单周 >$5亿流入：可能是一次性买入 → 弱 BULL 信号
  连续 6+ 天净流出：历史上出现在顶部区域 → 可靠 BEAR 信号
  季节性/月末调仓：暂时噪音，不代表趋势

ETF vs 链上区别:
  ETF 流入 ≠ 上链（通常托管在 Coinbase Prime/Fidelity）
  但 ETF 流入会减少市场可流通供给 → 价格效应一样
```

### Step 3 — ETF 时代四问校准

套用评分前，先回答以下问题：

**Q1: Fed 政策是否已被市场充分定价？**
- BTC 是领先指标 → 若过去 6 个月 BTC 已因降息预期上涨 → 降息本身额外效应有限
- 判断标准: 近 6 个月 BTC 相对 M2 是否已收敛 or 还在背离？

**Q2: M2 扩张的驱动质量？**
- T-bill 驱动（非银体系）→ 传导更强更快（约 8-10 周）
- 央行 QE 驱动 → 传统路径，约 13 周
- 信贷扩张驱动 → 较弱，约 20+ 周

**Q3: DXY 走弱的持续性？**
- 结构性（基本面弱、储备地位动摇）→ 持续性强，BTC 利好可持续
- 技术性回调 → 可能反转，BTC 利好短暂

**Q4: ETF 流出是否系统性？**
- 连续 6+ 天净流出 → 可靠顶部/阶段性见顶信号
- 季节性调仓（月末/季末）→ 临时噪音
- 大机构减仓 vs 小账户赎回 → 前者更悲观

## 八、注意事项与常见误区

| 误区 | 正确认知 |
|------|---------|
| "Fed 降息 = 立即买 BTC" | 降息预期形成时买，降息落地时警惕卖出 |
| "ETF 流出 = BTC 见顶" | 需要连续 6+ 天才是可靠信号，单周不确定 |
| "M2 涨 BTC 马上涨" | 传导时滞 8-13 周，背离期间需要耐心持有 |
| "DXY 跌 BTC 必涨" | 需区分结构性 vs 技术性走弱，地缘政治驱动可能同步利空 |
| "10Y 低 = BTC 牛市" | 仅当机构资金实际从债市流出寻找替代品时有效 |

- **搜索工具**: 必须使用 `mcp__tavily__tavily-search`，禁止 WebSearch/WebFetch/curl
- **调整上限**: `score_adjustment` 硬性限制 ±5
- **更新频率**: 每次 Fed FOMC 会议后必须更新；其他每周由 TeamA 定期维护
- **跨维度复用**: 本维度的 `m2_yoy_pct`、`dxy_trend`、`yield_10y_pct` 可被跨市场维度（维度F）直接引用，避免重复搜索
