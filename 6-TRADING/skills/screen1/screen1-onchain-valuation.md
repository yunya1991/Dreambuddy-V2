# /screen1-onchain-valuation

**Screen 1 — 维度D：链上估值深度研究**

链上估值 SKILL。基于 MVRV Z-Score / NUPL / RHODL Ratio / STH-MVRV 四大指标，结合 ETF 时代校准规则，输出估值定位与分数调整，写入 `screen1_onchain_annotation.json`。

> **BTC-only**: 此分析专用于 BTC。ETH/SOL 的链上估值体系不同，跳过。

---

## 一、链上估值不可替代的原因

```
传统资产估值:
  PE/PB/DCF → 依赖财务报表 → 可被操纵 → 估值有主观性

比特币链上估值:
  每笔交易永久记录在区块链上
  → 每个 UTXO（未花费交易输出）的"最后移动价格"可精确追踪
  → 全市场持有者的成本基础完全透明
  → MVRV = 当前市值 ÷ 已实现市值 = 最纯粹的估值指标

核心公式:
  已实现市值 = Σ（每个UTXO的最后移动价格 × 数量）
  MVRV = 当前市值 / 已实现市值
  含义: MVRV>1 说明平均持有者在盈利，MVRV<1 说明整体亏损
```

---

## 二、四大指标理论详解

### 2.1 MVRV Z-Score（核心估值指标）

**计算公式**：
```
MVRV Z-Score = (当前市值 - 已实现市值) / 当前市值标准差

  当前市值    = 流通量 × 当前价格
  已实现市值  = Σ(每个UTXO最后移动价格 × 数量)
  标准差      = 历史市值的滚动标准差（用于归一化）

含义:
  Z > 0: 当前市值高于已实现市值 → 平均持有者在盈利 → 偏高估
  Z < 0: 当前市值低于已实现市值 → 平均持有者亏损 → 偏低估
  Z 值越高: 偏离历史均值越大 → 过热程度越高
```

**ETF 时代阈值修订（最重要的校准）**：

| MVRV Z | 旧规则 (2017-2021) | **新规则 (ETF 时代 2024+)** | 解读 |
|--------|------------------|--------------------------|------|
| < 0 | 极度低估 → 买入 | 依然有效 | 平均持有者亏损 |
| 0~1 | 低估 | **低估** | 低于历史均值 |
| 1~2 | 公允 | **公允/偏暖** | |
| 2~3.5 | 偏高 | **公允区上沿** | ETF 托底压低阈值 |
| 3.5~5 | 高位 | **相对高位（替代旧 7+）** | 减仓区间 |
| > 5 | 高位 | **严重高估** | 强烈减仓 |
| > 7 | 泡沫/顶部 | **几乎不会再出现** | |

**历史峰值递减规律（关键证据）**：
```
2013 峰值: Z = 12
2017 峰值: Z = 10
2021 峰值: Z = 7
2025 峰值: Z = 3.5（ETF 机构托底，压低顶部阈值）

→ 每个周期 ETF/机构化程度提高 → 更多长期持有者
→ 平均成本基础被机构不断"稀释" → Z 值峰值永久性降低
→ 若未来 Z 只到 3.5-4.0 就见顶，是结构性变化，不是"没涨够"
```

### 2.2 NUPL（净未实现盈亏）

**计算公式**：
```
NUPL = (当前市值 - 已实现市值) / 当前市值

  即: 全市场未实现盈利 / 当前总市值的百分比

含义:
  NUPL = 0: 市场整体盈亏平衡
  NUPL > 0: 市场整体在盈利（越高 = 越贪婪）
  NUPL < 0: 市场整体在亏损（越低 = 越恐惧）

与 MVRV 区别:
  MVRV 是比率（相对值），NUPL 是绝对盈亏占比
  两者高度相关，但 NUPL 更直观反映"情绪温度"
```

**五段情绪周期**：

| NUPL 值 | 情绪阶段 | 市场含义 | BTC 通常位置 |
|--------|---------|---------|------------|
| < 0 | **投降（Capitulation）** | 多数人亏损，极度悲观 | 历史底部区域 |
| 0~0.25 | **希望/恐惧（Hope/Fear）** | 从底部刚恢复，情绪不稳 | 早期复苏 |
| 0.25~0.50 | **乐观（Optimism）** | 市场开始相信趋势 | 牛市中段 |
| 0.50~0.75 | **信念（Belief）** | 普遍乐观，持仓坚定 | 牛市后段 |
| > 0.75 | **贪婪/狂喜（Euphoria）** | 极度贪婪，分歧加大 | 顶部区域 |

**注意**：部分工具显示 NUPL 为 0-100（百分比），代码自动归一化处理，两种格式均可输入。

### 2.3 RHODL Ratio（持有年龄分布）

**计算公式**：
```
RHODL Ratio = 持有 1-2 年的已实现市值 / 持有 1周-1月 的已实现市值

含义:
  分子: 老手（1-2年持有者的锁定价值）
  分母: 新人（短期投机者的锁定价值）

  RHODL 高 → 老手资金远超新人 → 长期持有者主导市场 → 底部特征
  RHODL 低 → 新人资金涌入 → 投机主导 → 顶部特征

为什么有效:
  底部时: 只有坚定的长期持有者留在市场（短期投机者已割肉离场）
  → 分母（短期持有者）极小 → 比值极大
  顶部时: 大量新投机者涌入
  → 分母（短期持有者）极大 → 比值很小
```

**历史底部结构信号（三次）**：

| 时期 | RHODL 值 | 背景 | 后续 BTC 表现 |
|------|---------|------|------------|
| 2015 底 | 5.0（历史第一高）| 矿工熊市彻底清洗 | 后续 **+10000%** (30个月) |
| 2022 底 | 7.0（历史第一高更新）| FTX 崩塌，极度恐慌 | 后续 **+350%** (18个月) |
| 2026-05 | **4.5（历史第三高）** | Stagflation Lite 承压 | 等待确认 |

> RHODL > 4 = 历史上仅出现 3 次，每次均是大底。当前 RHODL=4.5 是极强的底部结构信号。

### 2.4 STH-MVRV（短期持有者成本）

**定义**：
```
STH（Short-Term Holder）= 持有 BTC ≤ 155 天的地址

STH-MVRV = 当前价格 / STH 平均持有成本（STH 实现价格）

含义:
  STH-MVRV > 1.0: 短期持有者整体盈利（持仓稳定，不急于卖出）
  STH-MVRV = 1.0: 短期持有者盈亏平衡（心理支撑线）
  STH-MVRV < 1.0: 短期持有者整体亏损（随时可能恐慌卖出）
  STH-MVRV > 1.33: 短期持有者大量盈利（可能获利了结，顶部风险）

为什么 155 天:
  经验研究表明，持有超过 155 天的比特币不再"短期投机性"
  155 天约 = 减半周期 180 天的 86%
  超过 155 天转为"长期持有者"（LTH）
```

**STH 成本线作为支撑/阻力**：
```
STH 均成本 = 价格长期强支撑（短期持有者不愿低于成本割肉）
  价格在 STH 成本以上: 健康市场，STH 盈利，抛压小
  价格跌破 STH 成本: 短期持有者进入亏损，触发止损卖出 → 价格进一步下跌

当前案例 (2026-06):
  BTC ~$73,500 | STH 均成本 ~$97,000（推测）
  STH-MVRV ~0.76（整体亏损 -24%）
  → STH 整体亏损，恐慌性卖出压力存在
  → $97K 形成强阻力（STH 解套需跨越此价格）
```

## 三、四指标联合框架

### 3.1 信号一致性判断

| 组合 | 可靠性 | 解读 |
|------|-------|------|
| MVRV↓ + NUPL投降 + RHODL高 + STH亏损 | **极强底部** | 历史上均出现在大底 |
| MVRV↑ + NUPL贪婪 + RHODL低 + STH大幅盈利 | **强顶部预警** | 分批止盈 |
| MVRV中 + NUPL乐观 + RHODL中 | **健康上涨** | 趋势延续 |
| MVRV↓ + NUPL投降 + RHODL低 + STH极度亏损 | 混合信号 | 短期恐慌但长期持有者未积累，底部不确定 |

### 3.2 指标领先性（时间先后）

```
信号出现顺序（从最早到最晚）:
  1. RHODL 率先升高（长期持有者开始主导，1-3个月领先）
  2. NUPL 转入投降区（情绪触底，与价格底部同期）
  3. STH-MVRV < 1.0（短期持有者进入亏损，价格底部信号）
  4. MVRV Z 下降（滞后 1-2 个月，确认底部完成）
  5. Hash Ribbon 金叉（矿工确认，通常是最后的底部信号）

→ RHODL 是最早的底部信号，Hash Ribbon 是最后的确认信号
→ 当 RHODL 和 NUPL 均指向底部时，可以开始分批布局
→ Hash Ribbon 金叉时，底部通常已经确认（最安全入场点）
```

## 五、ETF 时代特殊注意

**矛盾信号解读框架（Jun 2026）**:

```
技术维度 (BEAR)  ←←← 价格在 MA200 下方，月线 MACD 死叉
矿工维度 (BEAR)  ←←← 价格低于生产成本，HashRibbon 恢复中
链上维度 (BULL)  →→→ Z=1, RHODL=4.5, STH亏损，底部结构
减半周期 (BEAR)  ←←← 第6阶段去库存期，-15分
```

**这不是矛盾，这是 ETF 时代底部积累的特征标志**:
- 链上数据领先技术指标约 2-4 个月
- RHODL + NUPL 组合是历史上最早发出底部信号的指标组合
- 当链上极度乐观 vs 技术极度悲观时 → 历史上均出现在底部积累阶段

### Step 3 — ETF 时代三问校准

**Q1: ETF 净流入是否仍在持续？**
- 是 → MVRV Z 阈值校准有效（3.5 = 高位），维持新规则
- 否（大规模净流出）→ 旧规则部分恢复，MVRV Z 3.5+ 警惕性提高

**Q2: 当前 MVRV Z 与历史同期减半阶段相比如何？**
- Z 明显偏低（-30%）→ ETF 压低效应更强，BULL 信号更可靠
- Z 明显偏高（+30%）→ 可能有过热因素，谨慎

**Q3: RHODL 与 NUPL 信号方向是否一致？**
- 一致 → 可靠，confidence +0.1
- 不一致 → 矛盾信号，confidence -0.1，narrative 中解释

### Step 4 — 计算各指标分数

```
MVRV Z  = X.X  → 分: +/-Y
NUPL    = X.X  → 分: +/-Y
RHODL   = X.X  → 分: +/-Y
STH-MVRV= X.X  → 分: +/-Y
合计         = +/-Z
```

`score_adjustment` 定性因素（±10）：
- 长期持有者（LTH）是否出现异常卖出 → ±1~3
- 交易所余额是否急剧增加（卖压积累）→ -1~2
- ETF 时代校准是否失效的迹象 → ±1

`confidence`：
- 4 条精确数值 → 0.85~0.95
- 2~3 条有效 → 0.65~0.80
- 1 条有效 → 0.50~0.60
- 0 条 → 0.40，`score_adjustment=0`

- **更新频率**: 建议每周由 TeamA 更新，链上数据变化较慢但极为重要
- **注释时效**: 超过 7 天未更新的 annotation 应视为"过期"，confidence 自动降级
