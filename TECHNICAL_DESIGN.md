## 1. 架构设计原则

### 1.1 核心原则

| 原则 | 说明 | 实现方式 |
|------|------|----------|
| **模块化** | 每个策略独立为模块，可单独运行和测试 | 目录隔离，独立配置 |
| **松耦合** | 模块间通过接口通信，避免直接依赖 | 策略抽象层 + 消息传递 |
| **统一风控** | 所有策略共享统一风控引擎 | 13-通用风控模块作为 SDK |
| **状态持久化** | 进程重启不丢失状态 | JSON 文件持久化 |
| **配置分离** | 配置与代码分离，支持多环境 | .env 文件 + config_loader |
| **可观测性** | 完善的日志和监控 | 结构化日志 + 飞书告警 |

### 1.2 设计模式

| 模式 | 应用场景 | 实现位置 |
|------|----------|----------|
| **策略模式** | 多种入场/离场策略切换 | v15_signal.py, classic_exit_system.py |
| **观察者模式** | 信号订阅与分发 | 风控规则注册表 |
| **工厂模式** | 动态创建交易客户端 | okx_client.py |
| **模板方法** | 统一交易流程 | v15_trader.py |
| **状态模式** | 持仓生命周期管理 | TradingDecisionStateMachine |

## 5. API 设计

### 5.1 交易所 API

#### OKX 客户端接口

```python
class OKXClient:
    # 行情接口
    def get_candles(self, symbol, timeframe, limit):
        """获取K线数据"""
    
    def get_ticker(self, symbol):
        """获取当前行情"""
    
    def get_contract_info(self, symbol):
        """获取合约信息"""
    
    # 交易接口
    def place_order(self, symbol, side, pos_side, price, size, td_mode):
        """下单"""
    
    def cancel_order(self, order_id):
        """撤单"""
    
    def get_order(self, order_id):
        """查询订单"""
    
    # 持仓接口
    def get_positions(self):
        """获取持仓"""
    
    def get_position(self, symbol):
        """获取单个持仓"""
    
    # 账户接口
    def get_account(self):
        """获取账户信息"""
    
    def get_balance(self):
        """获取余额"""
```
