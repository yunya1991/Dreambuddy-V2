# 27-策略治理审批系统

> **端口**：8094 | **类型**：Flask 服务
> **定位**：策略治理审批 — C0-C8 流水线管理 + 变更包 + 审批 + 审计哈希链

## 能力链

1. **C0-C8 流水线状态管理** — 策略开发全流程状态机
2. **变更包草稿构建与查询** — changeset 管理
3. **审批请求** — 创建、查询、状态校验
4. **审计哈希链** — 哈希链查询与完整性验证
5. **评估门控（gate）** — 策略发布前评估

## 目录结构

```
27-策略治理审批系统/
├── app.py              # Flask 入口
├── governance/         # 治理核心
│   ├── approval/       # 审批引擎
│   └── audit/          # 审计哈希链
│       └── chain.py    # 哈希链实现
└── data/               # 数据
```

## 启动

```bash
python app.py
```

服务监听 `0.0.0.0:8094`。
