## 1. 概述

图结构上下文压缩引擎（Graph Context Compressor）是 DreamBuddy-V2 的上下文管理实验模块，通过图结构对上下文进行压缩和检索。当前处于实验状态。

## 2. 设计概述

### 2.1 核心理念（双维度编排架构）

依据 [SPEC.md](./SPEC.md) v1.0，本模块实现「双维度编排架构」：

- **思维链简化**：S/C/F 链作为固定五步思维顺序，不含具体实现
- **AI 推理动态化**：每个思维步骤是决策点，AI 动态选择技能并评估置信度
- **技能专业化**：A/C/F 系列技能为独立可调用能力单元，统一契约（输入→处理→输出+置信度）
- **交叉验证**：S/C/F 三链在关键节点投票，多源印证提升置信度，链间冲突触发深入分析
- **推理透明**：图架构记录完整思考轨迹，可追溯

### 2.2 核心能力

- 上下文压缩：将冗长会话/记忆压缩为图结构节点
- 图状态管理：维护节点关系与依赖
- 意图网关：识别用户意图，路由到合适链/技能
- 链规划器：动态编排 S/C/F 链执行顺序
