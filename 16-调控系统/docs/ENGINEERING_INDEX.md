# 调控系统 - 工程索引

## 1. 概述

调控系统（Governance & Control System）是 DreamBuddy-v2 的全局调控与治理中枢，负责协调各子系统间的资源分配、策略调度和系统行为调整。

### 1.1 核心定位

| 属性 | 说明 |
|------|------|
| 系统名称 | 调控系统 |
| 目录位置 | `16-调控系统/` |
| 主入口 | `__init__.py` |
| 核心模块 | `core/` |
| 依赖系统 | 通用风控模块（13）、知识库（2-KNOWLEDGE） |

### 1.2 功能概览

- 全局策略调度协调
- 资源分配与优先级管理
- 系统行为动态调整
- 跨系统冲突解决
