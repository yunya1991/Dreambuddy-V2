# D2/D3 评审标注指南（P1-6）

> 沿用 45-评测系统 §9 校准协议，不新建协议。

## 1. 标注目标

为 D2（架构缺口检测）/ D3（意图预测）的 AI 裁判建立校准集，验证 AI 评分与人工判断的一致性。

## 2. 标注维度

### D2 架构缺口标注

| 维度 | 好（3） | 中（2） | 差（1） |
|---|---|---|---|
| **缺口识别准确性** | 正确识别真实架构缺口，无误报 | 识别正确但有少量误报/漏报 | 大量误报或漏报 |
| **证据链完整性** | 证据可追溯到具体文件/行 | 有证据但不够具体 | 无证据或证据无效 |
| **路由正确性** | gap_type 路由到正确能力域 | 路由大致正确 | 路由错误 |

### D3 意图预测标注

| 维度 | 好（3） | 中（2） | 差（1） |
|---|---|---|---|
| **意图识别准确性** | 意图类型与用户真实意图一致 | 大致相关但不够精确 | 意图错误 |
| **预测有效性** | 预测的下一意图/动作合理 | 预测有一定道理 | 预测无意义 |
| **轨迹连贯性** | 意图轨迹符合对话逻辑 | 轨迹有小跳跃 | 轨迹断裂或矛盾 |

## 3. 标注流程

1. **抽样**：从 D2/D3 实验结果中分层抽样 ≥200 条，覆盖好/中/差三档（每档约 67 条）
2. **双盲标注**：两位标注员独立标注，互不可见对方结果
3. **顺序对调**：A/B 两位标注员的样本顺序随机对调，消除顺序偏差
4. **一致性校验**：计算 Cohen's κ ≥ 0.60、Krippendorff's α ≥ 0.67（ordinal）
5. **分歧仲裁**：差 >1 档的样本由第三位标注员仲裁
6. **锁定**：记录 judge_model_id + snapshot_date + prompt_hash + temperature(=0) + max_tokens

## 4. 偏差控制

- 长度与分数相关性 |r| < 0.2
- 双裁判取均值
- 差 >1 档记 disagreement
- 同 spec 复算差异 >5% 标记 `judge_drift`

## 5. 标注模板

见 `calibration_template.jsonl`，每条记录格式：

```json
{
  "sample_id": "D2-001",
  "experiment": "D2-A",

  "ai_output": "...",

  "annotator_b": {"accuracy": 2, "evidence": 2, "routing": 3, "overall": 2},
  "agreement": null,
  "notes": ""
}
```

## 6. 质量校验

运行 `python registry/review_calibration.py <annotation_file>` 计算 κ/α。
