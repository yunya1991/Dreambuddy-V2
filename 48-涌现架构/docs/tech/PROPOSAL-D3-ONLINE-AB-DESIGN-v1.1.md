## §1 实验设计（2×2 因子）

| 臂 | 意图预测 | 知识组合 | 说明 |
|---|---|---|---|
| A（基线） | off | off | 现状：无预测无组合 |
| B | on | off | 仅预测：展示下一意图建议 |
| C | off | on | 仅组合：展示知识组合（memory/SKILL/doc） |
| D | on | on | 预测+组合联动 |

- **随机化策略（修订后）**：**按日期分层，每层（日）内会话级随机化**——每个 session_id 在其开始日层内等概率分配到 A/B/C/D 四臂；同会话不切臂；日间波动由分层吸收，不与臂效应混杂
- **分流验证**：实验开始前跑 3 天空跑期（全臂无差异处理），验证分流均衡性（各臂会话数比例 95% CI 含 25%）

## §2 数据采集（最小埋点集）

```
intent_predicted   — 预测事件（含 top1/top3 与置信度）
combo_presented     — 组合展示事件（含组合成员 id）
user_action         — 用户动作（accept / reject / modify / ignore）
time_to_action      — 预测/展示 → 动作的时长（秒）
session_meta        — 会话元数据（arm / stratum=日期 / task_type 代理标签）
```

落盘：`48-涌现架构/events/d3_online_ab/*.jsonl`（append-only，event_id 幂等，FAIL-OPEN）

## §3 主终点操作定义（修订后）

**time-to-correct-action**：从会话开始（session_start 埋点）到**用户显式 accept 动作**（对预测建议或知识组合点击接受/采纳按钮）的时长（秒）。

| 情形 | 处理 |
|---|---|
| 用户 accept | 主终点观测值 = session_start → accept 时长 |
| 用户 modify 后接受 | 观测值 = session_start → modify 后接受时长；modify 事件单独记录 |
| 用户 reject / ignore / 直接关闭会话 | **censored**：记入样本但主终点按删失处理（Kaplan-Meier + log-rank 检验做敏感性分析） |
| 会话内多次 accept | 取**第一次** accept（预注册锁定） |

**ground truth 说明**：本实验的『正确』以用户显式 accept 为准（用户是判定主体）——这是接受率口径，不是预测准确率口径；预测准确率仍由 D3-A 离线评估承担，两者不混用。

## §4 判定标准（预注册，修订后）

**样本量（功效分析）**：双侧 t 检验，α=0.05，最小可检测效应 Cohen's d=0.3，目标功效 80% → **每臂 n=175 会话**（四臂共 700 会话）。
- 积累期按周监测：任一臂 < 175 时不做主检验；全部臂 ≥ 175 后锁定样本做主检验
- 若 8 周后仍不足 175/臂：**声明为探索性实验**，结论仅作方向参考，不产出 verdict，不进 verdict 仪表盘

**分层检验（gatekeeping）**：
1. **主检验（仅 1 次）**：D 臂 vs A 臂 time-to-correct-action，双侧 t 检验 α=0.05；censored 样本用 log-rank 敏感性分析佐证
2. **次检验（主检验通过后执行）**：B vs A、C vs A，**Holm-Bonferroni 校正**（2 次比较，校正后阈值 0.05/2 与 0.05）
3. **次终点**（接受率/纠正率/澄清轮次）：**Benjamini-Hochberg FDR 校正**（q=0.10）

**四态判定**：candidate（主检验通过且方向为正）/ falsified（主检验显著但方向为负）/ inconclusive（主检验不显著但样本充足）/ insufficient_data（任一臂 < 175 且未满 8 周）
