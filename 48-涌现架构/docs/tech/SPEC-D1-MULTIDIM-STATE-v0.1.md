## §0 Executive Summary

### 0.1 做什么

**一句话**：深度文章只用于**训练**（既产生主导因素主张，也产生组合因子 / 主次矛盾结构）；48 涌现架构才是**输出口**，输出经「反思 → 验证」后供 40 神经传递，**50 只做旁路验证**。

**主线（训练侧，离线，一次性）**：**深度文章 → 因素识别（F1）→ 单因素方向（F2）→ 主导因素主张（F3）→ 样本门控 → 训练 48 涌现架构**（详见 §2.5 / §2.7）。
目标是**深度文章的交易逻辑抽象**——抽取"文章关注哪些因素、哪个因素主导、指向哪个方向"，而非文本语义；假设只能来自深度文章，不能来自快讯事件标签（快讯无论证链，只有事实陈述）。

**辅助（服务主线，不得替代）**：
- **9 域 `DimensionContext`** → 训练侧提供历史维度特征矩阵，推理侧提供实时维度状态（§2.6）
- 39 域聚合算子 → 提供**离散度 / 事件化采样**（不产生交易逻辑）
- **快讯 × 价格** → 敏感因子探测（`sens_f`，只测显著性不判方向，§2.9.2）；快讯主题热度 → 辅助状态维 `narrative_heat`

**训练期（离线，一次性）**

```
深度文章 500 篇（正文齐备，2026-05-30→11-09）──→ F1（99.6% 覆盖，3.8 类/篇）
                                                        ↓
                               F2 单因素方向 → F3 主导因素主张（claim）
                                                        ↓
9 域 DimensionContext 历史矩阵（8 维 × 日，滚动归一，严格 t 截断）
                                                        ↓
                          样本门控（一致 / 背离但有效 / 无信号）→ 样本权重
                                                        ↓
                        三层防线验证（Holm → PBO/CSCV → SPA/DSR，代码不动）
                                                        ↓
                        训练 48 涌现架构（学"什么维度组合下、谁主导"）
```

**推理期（在线，文章不参与）**

```
9 域 DimensionContext 历史上下文
快讯 × 价格（敏感因子） / 深度文章（组合因子·主次矛盾）
        ↓
48 涌现架构 + 做梦器反思（变异 / 组合 / 筛选 → 涌现）
        ↓
验证门（三层防线）—— 50 旁路验证器（被调度，不接收涌现直接成果）
        ↓
40 周期神经网络（周期约束 + 有效因子 + 矛盾判定逻辑）
        ↓
交易执行 → 交易数据回流反思层（涌现闭环）
```

**硬约束**：48 **不向 50 直接传输成果**。50 降为**旁路验证器**——只在验证门被调度做交叉验证（影子/旁路），不是主矛盾终局；最终面向交易的是 40。

| 禁止 | 原因 |
|---|---|

| 不做维度组合全空间搜索 | 维度组合爆炸 → 多重比较必然爆表；假设必须**预注册且有 claim 来源**（§5.3） |

| **不用文章做推理证据** | 文章多为事后分析，只能进训练集；推理期输入只有 9 域实时维度状态 |

### 0.3 核心判断（三条，全部有实测依据）

1. **v0.1 失败不是"事件方法"的错，是状态表征太粗**
   3 档 regime × 5 类事件 = 15 格，格内异质性（降息 25bp vs 100bp）远大于格间差异。
   数值证据：三个 regime 桶的 cell 均值几乎相同（bull +0.30~0.39% / chop +0.37~0.39% / bear −0.02~0.06%，μ0=+0.14%），PBO 0.816~0.969 全灭。

2. **9 域的价值在 state vector 的"形状"，不在它当前的分数**
   8 维连续 + 自适应权重（flow 1.5 / valuation 1.4 / onchain 1.3 / macro 1.2 / news·sentiment·breadth 1.0 / intermarket 0.8 / narrative 0.7 / calendar 0.6）+ 贝叶斯置信 + 跨模块一致性，是**连续状态空间**的正确骨架。
   但当前分数是 mock，历史是合成的 → 只能借设计，不能借数据。

3. **39 域的价值在聚合算子，但分子层输入错位**
   它的原子层（变化驱动 `{layer,category,metric,timestamp,value,prev_value,reasons,source}`）与细胞层聚合（单因子序列 / 跨因子活跃状态 / 多因子离散度 CV）是正确的「事件→状态」转换机制。
   但它的分子层输入是 `trader.log`（系统内部判断事件），**与叙事无关** → 需换输入源为新闻/文章，不能直接复用产物。

### 0.4 最大的现实约束（先摆在前面）

**所有多维数据的真实历史都只有约 1 个月**，除了 K 线（2023-01 起）与 newsflash 文本（2018/2023-01 起）。因此本方案的第一块工作不是建模，是**回填**（§4）。回填可行性已逐维实测分级：3 维可回填、2 维需补源、2 维不可回填。

## §1 失败复盘：v0.1 事件断点为什么被证伪

### 1.1 三层防线的最终数值（6,697 事件 / 3.7 年 / 15 cell）

| 防线 | 判据 | 结果 |
|---|---|---|
| 批内 Holm | ≥3 candidate | **0**（最优 holm_p=0.256） |
| 批级 PBO/CSCV | ≤0.50 | **5/5 family 全灭**（0.816~0.969） |
| 胜出者 SPA/DSR | — | 无胜出者，未执行 |

### 1.2 根因分解（三条，互不排斥）

| # | 根因 | 证据 | 本 SPEC 的应对 |
|---|---|---|---|
| R1 | **状态表征粗**：3 档 regime 抹平了状态差异 | 三桶均值几乎相同 | §5 连续状态向量 |
| R2 | **事件标签丢强度**：同类型事件按二值等同 | 格内方差 ≫ 格间 | §5.3 因素取值按滚动分位量化 |
| R3 | **单点窗口**：只取 T+24h，丢失路径 | 未直接检验（潜在） | §5.4 多窗口（T+24h / T+72h / T+7d）+ 累积异常收益 |

### 1.3 一条必须记住的方法论

**PBO > 0.8 意味着"发现过程本身无信息"，不是"某个模式运气差"。**
v0.1 在 160 事件时曾判断"样本不足"，扩样 42 倍到 6,697 事件后结论不变且更干净 → 下次遇到高 PBO，先怀疑表征/假设空间，不要先扩样。

### 1.4 主线链路验证实测（2026-11-10，500 篇文章）

用 500 篇试爬正文跑通「文章 → C1 → NPE → 命题」全链路（首次落盘校验，非冒烟）：

| 指标 | 实测 | 判定 |
|---|---|---|
| 文章 | 500 篇 / fetch_ok 482 / 平均 3,303 字 | ✅ |
| 时间跨度 | 2026-05-30 → 2026-11-09（138 唯一日，5.4 个月） | ⚠️ 偏短 |
| C1 v0.1 | keep 487 / drop 13 | ✅ |
| 命题数 | **533 条（1.11/篇）** | ✅ 量足 |
| direction | bullish 346 / bearish 187 | ✅ |
| confidence_in_text | hedged / strong 正常 | ✅ |
| **event_type** | **other 469/533 = 88%** | ❌ **不可用** |
| **time_window** | **空 482/533 = 90%** | ❌ **不可用** |
| **condition_event** | **碎片化**（"我们深入研究了可能" / "前水平下跌 5% 至 10%"） | ❌ **不可映射谓词** |

**结论：链路是通的，瓶颈在 NPE 环节，不在文章数量。** 三个具体缺陷：

| 缺陷 | 代码位置 | 后果 |
|---|---|---|
| 触发词典仅 15 个（11 因果 + 4 条件） | `_CAUSAL_TRIGGERS` / `_CONDITIONAL_TRIGGERS` | 条件从句漏抽；非条件触发时 `_extract_condition` 取"触发词左侧全部"→ 碎片 |
| 事件类型仅 6 类 + 首个关键词命中 | `_EVENT_TYPE_RULES` | 88% 落 `other` |
| 时间窗线索仅 5 个词 | `_TIME_WINDOW_RULES` | 90% 为空 |

**方向修正**：当前优先级不是扩文章（500 篇已产 533 条），也不是先回填 3 年序列，而是**提升 NPE 命题质量（P0.5，前置门禁）**——命题的 `condition_event` 不可映射为可计算谓词时，后续所有验证都无输入。

## §2.5 文章因素抽象（Factor Abstraction）—— 训练样本构建

> 用户方法论（2026-11-10 确认）：**交易涌现不需要文本语义分析，只需要「什么因素 → 价格往哪走」**。因此放弃"句子级因果命题"（现 NPE v0.1，88% 落 `other`），改为**因素级抽象**。
>
> **本节全部位于训练侧（离线、一次性）**：产物是训练样本，不是运行时证据。文章不进入推理链路（§0.1 / §2.7）。

### 2.5.1 三层流水线（训练样本构建）

| 步骤 | 做什么 | 结合哪个域 | 输出 |
|---|---|---|---|
| **F1 因素识别** | 文章涉及哪些维度（技术 / 资金流 / 链上 / 宏观 / 事件 / 情绪） | **39 域分类体系 + 术语表** 作别名词典 | `factors: [{factor_id, evidence_spans, count}]` |
| **F2 单因素方向** | 每个因素指向多还是空 | **9 域 `DimensionContext`**（§2.6）提供同窗口客观方向做对照 | `{factor_id, direction, strength, consistency}` |
| **F3 主导因素主张（claim）** | 多因素叠加时，作者认为**哪个因素主导**、指向哪个方向、在什么时间窗 | 文章内部显著度 + 9 域实测强度分布 | `DominanceClaim`（见下） |

**F3 是主张提取，不是信号合成**（用户 2026-11-10 确认，D8）。三条理由：

1. **不与 50 抢裁决层**——最终方向裁决属于 50；48 若自己合成方向，就形成两套裁决。
2. **可验证的对象是"作者主张"**，不是"我们的权重猜得准不准"——后者正是 v0.1 的失败路径（PBO 0.816~0.969，发现过程本身无信息）。
3. **urgency / impact 是正文独有的信息增量**——恰是 50 仲裁器当前硬编码为常数的两个参数（§2.7.3）。

`DominanceClaim` schema：

```json
{
  "claim_type": "dominance",
  "dominant_factor": "flow.funding",
  "dominant_dimension": "D2",
  "direction": "short",
  "horizon": "days",
  "confidence_in_text": 0.72,
  "urgency": 0.6,
  "impact": 1.5,
  "supporting_factors": ["sentiment.cycle:long"],
  "opposing_factors": ["macro.rate:long"],
  "salience_distribution": {"D1": 0.10, "D2": 0.45, "D3": 0.05, "D4": 0.25, "C6": 0.0, "C7": 0.10, "C8": 0.0, "NEWS": 0.05},

```

- `urgency`：由 `time_window` 映射（日内 0.9 / 短期 0.6 / 中长期 0.3）
- `impact`：由因素类先验映射（flow 1.5 / onchain 1.3 / macro 1.2 / technical 1.1 / event·sentiment 1.0）
- `salience_distribution`：8 维软标签，定义见 §2.7.2

### 2.6 9 域通用能力：`DimensionContext` API（新增，D9）

**定位**：9 域补齐"逐指标历史归一 → 方向 + 强度"的对外接口，作为**通用能力**长期沉淀。这是重要工程实现项，不是本 SPEC 的临时脚手架。

**为什么不直接复用现有实现**（实测，§2.1）：

| 现有能力 | 局限 |
|---|---|
| `SignalEngine.generate_composite_signals` 的 `score_z` / `score_percentile` | 只作用于**综合分**（`_score_history` ≤200），不是逐指标 |
| `_adaptive_weight` / `_bayesian_confidence` | 需要 `update_module_performance` 回灌真实对错，当前无人调用 |
| `_pct_rank_last` / `_zscore_last_s` | 位于 embedded 生成副本，属选币风控私有特征，未对外 |
| 8 维模块分 | mock（§2.1） |
| `compute_resistance_3d(raw_score, historical_scores)` | **范式正确**（direction + 历史归一 velocity + 数据点置信），但需外部喂真实序列 |

**契约（冻结）**：

```python
@dataclass(frozen=True)
class DimensionContext:

    data_points: int
    availability: str     # long / short / none（复用 P2 分级）

def get_dimension_context(dimension: str, as_of: str, window: int = 60) -> DimensionContext
def get_dimension_matrix(as_of: str, dimensions: list[str] | None = None) -> dict[str, DimensionContext]
```

| 项 | 口径 | 依据 |

### 2.7 训练 / 推理分离与样本门控（新增，D10）

#### 2.7.1 两个阶段

| 阶段 | 输入 | 输出 | 频次 |
|---|---|---|---|
| **训练（离线）** | 500 篇文章 claim + 9 域历史 `DimensionContext` 矩阵 | 训练样本 `(X = 维度状态矩阵, y = 软标签)` → 训练 48 | 一次性，可迭代重训 |
| **推理（在线）** | 9 域实时 `DimensionContext` 矩阵（**不含文章**） | 48 预测：主导维度 + 方向 + 强度 + urgency / impact → 40 | 持续 |

**48 的预测能力来源**：训练时从文章学到"什么维度组合下、什么因素主导"；推理时只看维度状态即可判断，不依赖文章。

#### 2.7.2 训练标签：软标签（Q1 结论）

不把 claim 打成"唯一主导维度 + 方向"的硬标签，而是 **8 维显著度分布**：

```
salience[d] = Σ_{factor ∈ d} ( sign(factor) × evidence_span_len × class_weight )  →  归一化到 [0,1]
```

理由：60 细类归并到 8 维后，"唯一主导"这一假设经常不成立（实测 3.8 类因素/篇，多类并列）；硬标签会把"并列"变成错误标签。软标签还能直接作为 48 的回归目标，与连续输出同构。

#### 2.7.3 样本门控：解决"文章多为事后分析"

**问题**：深度文章常在价格走完之后撰写，作者会挑当时表现最强的维度解释——这是事后归因（hindsight / post-hoc rationalization）。直接入训会把"结果"教成"原因"。

**门控规则**（用 9 域实测做一致性检验，**只影响训练，不进 50**）：

| 档 | 判定 | 处置 | 佐证 |
|---|---|---|---|
| **一致** | 文章主导维 = 9 域实测最强维，且方向一致 | 正常入训，权重 1.0 | 事前可得的因素，作者强调合理 |
| **背离但有效** | 主导维 ≠ 实测最强维，但该维当时确实显著变化（`abs(z) ≥ 1` 且方向一致） | 入训，权重 1.5 | 作者看到了别人没看到的——**这才是 alpha 来源** |
| **无信号** | 主导维 `abs(z) < 0.5` 或方向相反 | 降权 0.3 或剔除 | 事后编故事 |

**阈值（0.5 / 1.0 / 方向一致）必须在跑门控前冻结进预注册文档**，不得按验证结果回调。

#### 2.7.4 与 50 的关系（修正原「第四类矛盾」）

- 50 **不读文章**，也不新增 `narrative_fact_conflict` 矛盾类型
- 50 `identify_primary_contradiction` 当前的 `DEFAULT_URGENCY = 0.5` / `DEFAULT_IMPACT = 1.0`（`50-NN主矛盾评估器/core/contradiction.py` L32-L33）由 **40 下传时携带**填补：48 在推理时输出 urgency / impact，经 40 进入 50 仲裁
- 一致性检验的产物是**训练样本权重**，不进入运行时

### 2.8 NEWS 维：快讯极性 + 时效对齐（P3-b，新增）

**架构定位（用户裁决 2026-11-10）— NEWS 是单一辅助维，不承担主判据**：

- 文章是**多维**主张（6 大类 60 细类），对应主链路 `48 涌现架构 → 40 周期神经网络`；
- 快讯是**单维**实时力量记录，只做两件事：①给 NEWS 维提供方向/强度 ②作为文章 claim 的时效参照（lead/lag）；
- 因此 NEWS 维的一致率**不得**用于评判文章价值、也**不得**单独否决 48 链路；NEWS 不可用时只降级该维（`availability=none`），其余 7 维不受影响。

**为什么不用文章验证 NEWS**：文章是事后解释（平均滞后事件 1-3 天），快讯是**事件时点的实时力量记录**（`od_decay_hl_hrs` 中位半衰期 6h、24h、72h 三档）。用文章去"验证"新闻维等于用结果验证原因；用快讯才能回答"那一刻市场在交易什么"。

**数据实况（2026-11-10 实测）**：

| 项 | 实测 |
|---|---|
| `backfill/newsflash_history.jsonl` | **193,300 条 / 1,410 天 / 2022-12-31 → 2026-11-09** |
| 字段 | `id · title · description · published_ms · is_important · od_event_type` |
| `od_event_type` 分布 | market_sentiment 118,108 · crypto_regulation 23,280 · token_milestone 20,157 · monetary_policy 10,096 · security_incident 7,483 · project_ecosystem 6,859 · us_policy 3,765 · geopolitics 2,638 · us_data 914 |
| `is_important` | true 96,992 / false 96,308（可用作权重） |
| 与 500 篇文章同日覆盖 | **482/500 = 96.4%** |
| DB 内 `od_attention_type`（仅 33 天 3,048 条） | neutral 2,589 · risk_on 147 · risk_off 67 · policy_tightening 48 · policy_easing 2 |
| DB 内 `od_policy_sentiment_0_1` | **退化**（mean 0.501 / stdev 0.035 / 99.5% 落在 0.3-0.7）→ **不作极性源** |

**极性口径（三源优先级，全部预注册冻结）**：

| 优先级 | 源 | 极性 `s_i` | 覆盖 |
|---|---|---|---|
| ① | `od_attention_type`（仅 DB 33 天） | risk_on / policy_easing → **+1**；risk_off / policy_tightening → **−1** | 9.3% |
| ② | 快讯标题+描述**多空词典**（中英双语，预注册 ~120 词） | 利好词命中 − 利空词命中，取符号 | 待测 |
| ③ | `od_event_type` **固定极性先验**（仅无歧义类） | security_incident → **−1**；其余歧义类 → 0 | 见下 |

`od_event_type` 固定极性只对 **security_incident（−1）** 无歧义；`crypto_regulation`（收紧/放松）、`monetary_policy`（加息/降息）、`token_milestone`（上线/解锁）方向相反，**必须留 0，不得猜**。这是 A 口径覆盖率上限只有 ~4% 的根本原因，也是必须引入 ② 词典的原因。

**日度聚合（NEWS 维序列）**：

```
score(t) = Σ_i w_i · s_i / Σ_i w_i        （i 为落在窗口内的快讯）
w_i = (1.5 if is_important else 1.0) · exp(−Δh_i · ln2 / 24)   # 24h 半衰期
```

`score(t)` 形成日度序列后，仍走 §2.6 同一契约：滚动 60 日 `z` + 分位，`direction = ±0.3` 阈值，`strength = abs(tanh(z))`。**不新增第二套归一逻辑**。

**时效对齐（用户核心要求：文章慢、快讯快）**：

| 窗口 | 区间 | 用途 |
|---|---|---|
| `pre_24h` | `(T−24h, T]` | 事件期实时力量（主对齐窗口） |
| `pre_72h` | `(T−72h, T]` | 事件期扩展（覆盖周末/低发稿日） |
| `post_24h` | `(T, T+24h]` | **文章是否领先快讯**（lead 判定） |
| `post_72h` | `(T, T+72h]` | 同上扩展 |

一致率主口径用 `pre_72h`（文章成稿前的实时力量）；`post_*` 仅用于标注 `lead_lag ∈ {lead, lag, coincident}`，**不参与一致率分母**。这样避免"文章抄快讯"被算成正确预测。

**availability 升级**：NEWS 由 `none` → **`long`（1,410 天 ≥ 900）**，这是 P3-a 报告中 296/500 不可测里最大一块缺口的直接解法。

**与 50 的关系不变**：NEWS 只在训练侧与文章 claim 比对、以及经 48→40 下传时提供维度级状态，**不直连 50**。

### 2.9 双轨因子发现：快讯敏感因子 × 文章组合因子（新增，P3-c）

> 用户裁决（2026-11-10）：「从快讯发现敏感因子，从深度文章发现组合因子。快讯实时性来评估哪些因子对价格更显著，也是区分主导因子的一个有效方法；而组合因子则更能协同验证，多空因子对比发现主矛盾和次要矛盾。」

#### 2.9.0 统一架构总览（用户裁决 2026-11-10）

三路输入各司其职，统一进入涌现框架，经反思与验证后供给 40，**50 只做旁路验证器**：

```
① 历史上下文层（9 域）
   单维历史序列 ──► DimensionContext：direction / strength / z / percentile
   回答：这个因子现在处在历史什么位置？

② 单一突变层（快讯 × 价格）
   快讯事件时刻 ──► 价格反应 ──► 敏感因子 sens_f
   回答：哪类突变真的能推动价格？

③ 组合结构层（深度文章）
   多维 claim ──► 组合因子 + 多空对比 ──► 主/次矛盾结构
   回答：因子如何协同？矛盾体长什么样？

        └──────────────┬──────────────┘
                       ▼
④ 反思涌现层（做梦器 33-REA / hermes + 48 涌现架构）
   把 ①②③ 作为上下文做变异 / 组合 / 筛选 ──► 最佳涌现
                       │
                       ▼
⑤ 验证门（三层防线 + 50 辅助验证，影子/旁路）
   50 只被调度做交叉验证，**不接收涌现架构的直接成果**
                       │  验证通过才放行
                       ▼
⑥ 神经网络层（40 周期）
   有效因子 + 矛盾判定逻辑 作为特征 / 先验
   交易结果回流 ④ 继续训练
                       └──────► 回到 ④（闭环）
```

**四条边界（冻结）**：

1. **9 域只提供历史上下文**——单维归一后的方向与强度，不做组合、不做裁决。
2. **快讯只做敏感因子探测**——用实时性区分"显著因子 vs 噪音因子"，不判多空方向（P3-b2 已证伪）。
3. **文章只做组合因子 / 主次矛盾结构**——多维协同与矛盾体识别，不作为实时信号。
4. **50 是验证器，不是终点**——涌现架构不直传 50；50 被验证门调度做旁路交叉验证，最终面向交易的是 40。

**涌现闭环**：40 的神经网络交易数据可回流 ④ 参与训练，形成「历史上下文 + 单一突变 + 矛盾结构 → 反思涌现 → 验证 → 40 → 交易数据 → 再涌现」的闭环。**涌现是结果，不是某个模块的产物**——三路输入不合成一个"总分"，而是在反思层被反复重组、筛选、验证后自然浮现。

#### 2.9.1 为什么要分两轨（P3-b2 之后的自然结论）

P3-b2 已证伪的是「快讯极性 → 文章多空主张」这条**方向映射**路径（平衡准确率 0.50），而不是快讯本身的价值。两条信息轨的物理属性不同，应承担不同职责：

| 轨 | 数据 | 频率 | 维度 | 擅长回答 | 不擅长回答 |
|---|---|---|---|---|---|
| **A 快讯** | 193,300 条 / 1,410 天 | 实时（分钟级） | **单维**（一条快讯通常只戳一个因子） | **哪些因子对价格敏感**（显著性 / 反应幅度 / 衰减速度） | 多空方向（P3-b2 已证伪）、多维协同 |
| **B 深度文章** | 500 篇（可扩 63,750 篇） | 日级（滞后） | **多维**（实测 3.8 类/篇） | **因子如何组合**、多空力量对比下的**主/次矛盾结构** | 实时性、因果方向（事后归因） |

这正是用户对「快讯只是单一维度、文章才是多维」的精确定位：**快讯不作方向判据，只作因子敏感度探针；文章不作实时信号，只作组合结构先验。**

#### 2.9.2 轨道 A：快讯敏感因子探针（Sensitivity Probe）

**定义**：对因子细类 `f`（§2.5.3 六大类约 60 细类），用命中该因子的快讯时刻作为事件时间戳，测量事件后异常收益，得到**敏感度分数** `sens_f`。**只测显著性，不测方向。**

```
S(f, Δt) = mean(r_{T→T+Δt} | 快讯命中 f) − mean(r_{T→T+Δt} | 同期非事件日)
sens_f   = |S(f, Δt*)| / se × n_f/(n_f + 100)      # 收缩，防小样本假显著
```

| 项 | 口径（预注册） |
|---|---|
| 事件源 | `newsflash_history.jsonl` 的 `od_event_type` 9 类 + 标题关键词 → 因子细类映射表（**独立预注册，禁止事后调整**） |
| 主窗口 | `Δt* = T+24h`（当前为日线，见下方数据缺口） |
| 佐证窗口 | `T+4h` / `T+72h` / `T+7d` |
| 反应变量 | 收盘对收盘收益；**对照组 = 同期非事件日**（沿用 §5.4，不用全局 μ0） |
| 显著性 | Welch t / 置换检验 + **Holm 校正**（复用 `pattern_stats.holm_adjust`） |
| 事件强度 | 复用 `news_polarity.news_density`（当日条数 / 重要条数）；P3-b2 实测密度与次日 `|return|` 相关 **+0.092**，是唯一残留弱信号 |
| 产物 | `factor_sensitivity.jsonl`：`{factor, window, n_events, n_control, mean_excess, t, p_holm, sens, stability}` |

**数据缺口（必须如实标注，不得假装实时）**：

1. **时间粒度**：当前 K 线只有 **日线**（`yfinance/BTC-USD`），因此 `Δt*` 只能取 `T+24h`，"实时性"体现为**事件触发即标记、次日收盘结算**，不是分钟级。要真正测 `15m/1h` 反应需补 **1h K 线**（列入 P1b 增量补源，不阻塞本阶段）。
2. **因子映射覆盖率（已解决）**：原 `classify_newsflash` 只映射 4/9 类 `od_event_type`（44,624 / 193,300 = 23.1%）。P0-2 新增独立映射 `EVENT_TYPE_FACTOR_DIMS`（v1），9 类全覆盖，实测 **193,300 / 193,300 = 100%**；v2 关键词优先命中 **72,291（37.4%）**，其余回落 v2 粗表，覆盖率同为 100%。映射表与 `MAPPING_VERSION = news-factor-v1` 固化于 `18-数据获取中心/backfill/p3c1/news_factor_mapping.json`。**但须警惕**：`market_sentiment` 占 **61.1%**，覆盖率高不等于信息量大，P3-c1 必须按事件族分层报告，禁止让单一宽泛类型主导 `sens_f`。

**终版测量口径（评审 T1/T2/T3/D1/D2/D5 修复，绑定）**

| 项 | 修复后口径 | 原因 |
|---|---|---|
| 超额收益 | **多因子残差化**：对同日其余已测维度的收益回归取残差，而不是只做"事件日 vs 非事件日" | 快讯高度聚集，只剥时间会把其它因子暴露混进 `sens_f`（T1） |
| 事件聚集 | 同一 UTC 日多条快讯**按日聚合为一次事件**，或使用 cluster-robust 标准误 | 窗口重叠破坏 i.i.d. 假设，p 值偏乐观（D5） |
| 多重检验 | **Holm 为主判**，FDR(BH) 为补充，并报告预计假阳性数 | 检验规模 ≈ 60×9×4 ≈ 2160（T3） |
| 时间对齐 | 快讯 `published_ms → UTC 日`；K 线 `date` 口径必须与 UTC 日**显式对齐并写单测** | 错一天会让全部结果整体偏移且不报错（D1） |
| 产物血缘 | `factor_sensitivity.jsonl` 必含 `mapping_version / data_version / code_commit / timezone` | 可复现、可回滚（D2） |
| 映射稳定性 | 至少两套独立映射，排序 Spearman ≥0.70 才采信 `sens_f` | 排除"显著性只是映射的产物"（T2） |

**用途**：`sens_f` 是区分主导因子的客观先验——高敏感因子在组合与 40 输入中获更高权重，而不是 60 细类等权。

#### 2.9.3 轨道 B：文章组合因子（Combination Factor）

**定义**：把单篇 claim 从「一个主导维」升级为「多维因子组合 + 各自方向」，再对组合做多空力量对比，识别**主矛盾 / 次要矛盾**。

```
combo   = {(f_i, dir_i)}_{i=1..k}          # k ≤ 3，实测 3.8 类/篇，截断取前 3
bull_S  = Σ_{dir_i=+} sens_{f_i} · |z_{f_i}|   # 快讯敏感度加权的多头力量
bear_S  = Σ_{dir_i=-} sens_{f_i} · |z_{f_i}|   # 空头力量
primary = 力量占比 > 0.55 的一方所在维度      # 对齐 50 SPEC-M1 §M5 三步法
secondary = 其余维度，权重封顶 0.30           # 对齐 50「重心原则」
```

| 项 | 口径（预注册） |
|---|---|
| 组合枚举 | **只枚举文章真实出现的组合**（数据驱动，非全空间搜索），阶数 ≤3；全空间搜索会组合爆炸并必然过拟合 |
| 方向来源 | `factor_extractor.extract_dominance_claim` 的 dim + direction；不一致的组合单列 `conflict` |
| 权重来源 | **轨道 A 的 `sens_f`**——这是双轨协同的核心，组合不是等权相加 |
| 主/次判定 | 多空力量占比 >0.55 为主矛盾，其余为次要矛盾（≤0.3）；对齐 50 §M5 三步法，**但产物只进训练侧** |
| 验证 | 条件收益 vs 同期非条件日（§5.4）+ 阶数受限 + Holm；样本外 walk-forward |
| 产物 | `combo_factors.jsonl`：`{combo_id, factors, bull_S, bear_S, primary, secondary, n_obs, forward_ret, p_holm}` |

**为什么组合能"协同验证"**：单因子可能噪声或不显著，但**多因子同向共振**时（如技术突破 + 资金流入 + 宏观宽松），条件收益的信噪比通常高于单因子；反之多空因子并存时，力量对比直接给出主/次矛盾结构。这也是 §6.4 U3「组合条件模式」的落地形态。

**实测可行性（500 篇，2026-11-10，复用现成 `extract_dominance_claim`）**：

| 指标 | 实测 | 含义 |
|---|---|---|
| 有主导维 | 379 / 500（75.8%） | 与 P3-a 一致 |
| **≥2 维显著（salience>0.02）** | **425 / 500（85.0%）** | 组合因子原料充足 ✅ |
| **≥3 维显著** | **326 / 500（65.2%）** | 支持阶数上限 k≤3 |
| 含 supporting_factors | 249 / 500（49.8%） | 同向协同可测 |
| 含 opposing_factors | 102 / 500（20.4%） | 反面因子较少 |
| **同时含多空因子** | **79 / 500（15.8%）** | ⚠️ **主/次矛盾的直接文章样本仅 79 篇** |

**关键结论（必须如实写进预注册）**：文章作者倾向**单向论证**——85% 有 ≥2 维同向组合，但只有 15.8% 同时提到对立因子。因此：

- **组合因子（同向共振）** 可直接从文章学，样本充足；
- **主/次矛盾（多空并存）** 在文章侧样本仅 79 篇，**不足以作为独立训练信号**，只能作为**结构先验**；其统计验证必须依赖 50 的运行时维度力量对比 + 轨道 A 的 `sens_f` 加权，而不能仅凭文章。

#### 2.9.3.1 多空力量的运行时口径（与文章解耦）

由文章学到的是「哪些因子常一起出现」，由**快讯与 9 域实测算出的是「此刻多空谁更强」**：

```
bull_S(t) = Σ_{f: dim_f 方向 up 且 sens_f 显著} sens_f · |z_f(t)|
bear_S(t) = Σ_{f: dim_f 方向 down 且 sens_f 显著} sens_f · |z_f(t)|
primary(t) = 占比 > 0.55 的一方；secondary(t) = 其余（≤0.3）
```

这样主/次矛盾是**运行时由 9 域 + 敏感度权重算出**，文章只提供组合结构先验，避免用 79 篇小样本硬拟合。

#### 2.9.4 双轨协同（架构落点，不越界）

```
9 域 ──► DimensionContext（历史上下文）
快讯 ──► sens_f（敏感因子权重）──┐
文章 ──► 组合因子 + 主/次矛盾结构 ─┴──► ④ 反思涌现（做梦器 / 48）
                                            │
                                  ⑤ 验证门（三层防线 + 50 旁路验证）
                                            │ 通过
                                  ⑥ 40 周期神经网络（有效因子 + 矛盾判定逻辑）
                                            │
                                     交易数据回流 ④
```

- **9 域 / 快讯 / 文章是三路并列输入**，不互相替代，也不在 48 之前合成总分；
- `sens_f` 是「哪些因子值得进网络」的客观筛子，同时是矛盾力量（`bull_S/bear_S`）的校准依据；
- **50 的 `DimensionForce` 已含 `long_force / short_force`**，`bull_S/bear_S` 直接映射，无需新造接口；
- **50 只做验证**：由验证门调度、影子/旁路运行，**不接收涌现架构的直接成果，也不是主矛盾终局**；
- NEWS 维**仍不提供方向判据**（P3-b2 裁决不变），只提供 `sens_f` 与 `news_density` 两个弱辅助量。

| 4 | 文章用途 | 产出事件断点标签 | 主导主张 + **组合因子 / 主次矛盾结构** | ✅ 更贴合文章"多维、滞后、单向论证"的物理属性 |
| 5 | 快讯用途 | 仅主题热度辅助 | **敏感度探针**（不判方向） | ✅ 避免 P3-b2 已证伪的方向误用 |
| 6 | 50 角色 | 主矛盾终局裁决 | 旁路验证器（被调度） | ✅ 消除两套裁决；但需保证验证独立 |
| 7 | 输出链路 | 48 → 40 → 50 | 48 → 反思 → 验证 → 40（50 旁路） | ✅ 面向交易的目标单一 |
| 8 | 验证方式 | 15 个离散 cell，PBO 0.82~0.97 全灭 | 三层防线 + 分阶段 fail-fast | ✅ 先证最小单元，不再一次性赌大空间 |

**结论：方向合理。** 三条依据：

1. **逐条命中 v0.1 的三个根因**（表征粗 / 强度丢失 / 单点窗口），不是"换个说法重做一遍"；
2. **按数据物理属性分工**：9 域给历史位置、快讯给显著性、文章给组合结构——不再要求任何一路承担它物理上做不到的事；
3. **保留了 fail-fast**：P3-c1 单因子若不显著就停，不进入组合与反思层，避免重演"扩样 42 倍仍全灭"。

**但有三处必须补硬，否则方案不成立**：

| 风险 | 问题 | 必须的补丁 |
|---|---|---|
| **高** | `sens_f` 单窗口会选到"反向敏感"因子（P3-b2 已见 24h 反转） | `pre` / `post` 双窗口同号才计显著；反向只记"反转敏感"，不入正向因子池 |
| **高** | 主/次矛盾**自证**：`bull_S/bear_S` 的 `sens_f` 与 `z` 与验证用同一批数据 | 必须 walk-forward 样本外 + 50 用独立数据源交叉验证，禁止训练集内验证 |
| **高** | "涌现"目前只是修辞：做梦器的变异算子 / 适应度 / 选择压力未定义 | P3-c1、P3-c2 未通过前**不建反思层**；届时先写清三要素再谈涌现 |
| 中 | 日线粒度使"实时性"打折 | 如实标注 `T+24h`；1h K 线另立项，不阻塞 |
| 已解决 | 快讯→因子映射仅 23.1% | P0-2 补到 100%（v1/v2），保留双映射稳定性检验 |

**一句话评估**：新方案不是"更大更全"，而是**把旧方案赌错的假设空间拆成三个可单独证伪的最小单元**；合理性成立，但成立的前提是守住上面三条补丁，尤其是"主次矛盾不得自证"。

#### 2.9.8 三条硬补丁的落地状态与涌现三要素定义

**落地状态（2026-11-10）**

| 补丁 | 落地形态 | 状态 |
|---|---|---|
| ① 双窗口同号 | `factor_sensitivity.classify_sensitivity(pre, post)` → `positive / reversal / weak`；`reversal` 一律 `eligible=False`，不进正向池 | ✅ 代码 + 10 单测 |
| ② 禁止自证 | `walk_forward_split(dates, n_folds, embargo)` + `validate_no_leakage(folds)`：train 严格早于 test 且无交集 | ✅ 代码 + 单测 |
| ③ 涌现三要素 | `REQUIRED_EMERGENCE_KEYS` + `emergence_ready(definition)` 门禁 | ✅ 门禁代码；要素定义见下，实现待 P3-c2 通过后 |

**涌现三要素的可操作定义（未齐备不得启用反思层）**

| 要素 | 定义 | 硬要求 |
|---|---|---|
| **变异算子 variation** | 对 48 输出的「因子集合 + 组合阶数 + `sens_f` 权重 + 时间窗」做结构化变异 | 可复现（固定随机种子）、可逆、每次变异有审计记录 |

| **选择压力 selection** | 每代保留固定比例 top-k，淘汰同时考虑适应度与多样性；连续 G 代无提升即停 | k 与 G 必须预注册；停止条件不得事后调整 |

**门禁**：`emergence_ready({variation, fitness, selection})` 未全绿，或 P3-c1 / P3-c2 未通过 → **不启用反思层**，避免"涌现"变成不可证伪的叙事。

### 4.2 回填设计要点

1. **统一日度粒度**（UTC 日界），与 v0.1 事件库 `ts_precision` 口径一致

**必须如实记录的三条**：

1. **判据③不通过，且是"假通过"陷阱**。实时口径 0.8306 看似高，但拆开是：多头主张 103/106（敏感度 0.97）、空头主张 **0/18**（特异度 0）。平衡准确率 0.4858 ≈ 随机——**一致率完全由多头基准率贡献，无判别力**。
2. **根因是词典多头偏置**：193,300 条中 108,833 条判多 / 32,945 条判空（bull_share **76.76%**）；日度序列 **1,410 天里 1,365 天净多头、仅 13 天净空头**（mean +0.365 / stdev 0.143）。日度分根本无法取到负值，自然无法识别空头主张。
3. **z 口径 ≠ 文章口径**：滚动 60 日 z 衡量"相对异常多头"，文章主张是"绝对多空"，两者不是同一个问题，所以 z 口径 0.178 不能解释为"文章与快讯反向"，只能说明口径不匹配。

**结论**：NEWS 维的数据地基已打通（可测率 0→100%、覆盖 1,410 天），但**极性词典本身不可用于绝对方向判定**。这不是"NEWS 维无用"，而是"朴素词典无效"。

**P3-b2（新增，必须先做）— 词典对数几率校准**：

| 项 | 设计 |
|---|---|
| 方法 | 对每个词典词 w 计算 `LO(w) = log((n_bull(w)+α)/(n_bear(w)+α)) − log((N_bull+α)/(N_bear+α))`，去掉语料基准率 |
| 训练窗 | **2022-12-31 → 2026-05-29**（严格早于 500 篇文章起点，无前视、无文章反推） |
| 应用窗 | 2026-05-30 之后，`flash_score = Σ LO(w)`，符号为极性 |
| 验收 | ①日度负值天数从 13 提升到 ≥200 ②平衡准确率 ≥0.60 ③多头敏感度与空头特异度均 >0.35 ④不达标则 NEWS 维降级为"仅强度可用，方向不可用" |

#### P3-b2 实测结论（已执行，2026-11-10）

实现落在 [news_polarity.py](../../../../18-数据获取中心/data_center/processing/news_polarity.py) 的 `learn_word_weights` / `calibrated_flash_score` / `load_calibrated_flashes`（23 单测全绿）。

**改法**：不用"朴素词典伪标签"做校准（那会循环），改用**训练窗内每条快讯之后的 BTC 次日收益**作标签，学习每个词的标准化效应量并做收缩：

```
LO(w) = ((mean_ret(w) − μ0) / sd) × n_w / (n_w + 100)
```

训练窗 2022-12-31 → 2026-05-29（**165,850 条**样本，严格早于文章起点），学习到 **120 个词**。

| 判据 | 实测 | 判定 |
|---|---|---|
| ①日度负值天数 | **891 / 1,410**（P3-b 时仅 13） | ✅ 通过 |
| ②平衡准确率 | **0.50**（多头 0/110、空头 19/19） | ❌ 未通过（≥0.60） |
| ③敏感度 / 特异度均 >0.35 | 0.00 / 1.00 | ❌ |
| ④降级 | — | 触发 |

**关键发现（必须记录）**：

1. **学出来的权重是"反向/反转"的**：`获批`、`超预期`、`涨超`、`bullish` 的次日效应为负；`加息`、`新低`、`退市`、`大跌` 的次日效应为正。即 BTC 对消息存在 **24h 反转（fade / oversold bounce）**，与"利好=看涨"的直觉相反。
2. **因此校准后方向系统性翻转为偏空**（1,410 天中 891 天为负），而文章 85% 是看多主张 → 两边基准率相反，平衡准确率仍是 **0.50**。这不是"找到了反向 alpha"，而是**双向基准率互相抵消**。
3. **朴素与校准都无判别力**：朴素（0.486）偏多、校准（0.500）偏空，平衡准确率均在随机线。说明"快讯词频极性 → 文章多空主张"这条路径**不通**。
4. **强度辅助也弱**：`|news_score|` 与次日 `|return|` 相关 **−0.031**；但**快讯条数密度**与次日 `|return|` 相关 **+0.092**（重要快讯 +0.081）——这是 NEWS 维唯一留下的可用信号。

**裁决（按 §7 判据④ Fail-open）**：

- NEWS 维**方向不可用**，`DimensionContext` 中 NEWS 不再参与 `dominant/agreement` 判定（`direction` 固定 `neutral`，`strength` 仍按 z 输出供参考）；
- 保留 **`news_density`**（当日快讯条数 / 重要快讯条数）作为**辅助强度特征**，标注"弱信号（|corr|≈0.09），不进主判据"；
- 该降级**不影响**另外 7 维，也不影响 `48 → 40` 主链路（符合 §2.8 架构定位）。

2. **v2 维度聚合曾误用 v1 静态表**：导致两套映射的维度结果完全相同、Spearman 虚高为 1.0。改为单遍 `build_counts()` 同时产出族计数与维度计数，保证同一套映射。

|---|---|---|
| ① 映射覆盖率 | 100%（v1/v2，P0-2） | ✅ |

| ③ 双映射排序稳定性 | 维度级 Spearman **0.40**（<0.70） | ❌ |
| ④ 可复现/版本化 | `news-factor-v1` + 产物落盘 | ✅ |

**关键发现**：

1. **日频事件强度对 BTC 日收益几乎没有解释力**：原始相关系数全部在 **|r| ≤ 0.061**（最大为 `us_data` 的 −0.060、`monetary_policy` 的 −0.061）；效应量约 4–17bp/1SD，而 BTC 日波动约 400bp，信噪比不足 1/20。

- 结论按实记录：**在日线粒度下，快讯事件族强度不足以构成可交易的敏感因子**。若要继续该方向，必须先解决数据粒度（1h K 线）或改用事件窗口内的方向性度量，而不是扩大样本。

| post_1h | 0.097% | 0.125% | **0.029%** | 1.07 |
| post_4h | 0.054% | 0.070% | **0.016%** | 0.59 |
| post_24h | 0.000% | 0.095% | **0.095%** | 3.57 |
| pre_24h | 0.000% | 0.107% | **0.107%** | 4.00 |

**判读**：F 值看似显著只因 n≈33,800，效应量是 0.02%–0.11% 的方差解释率；换成 HAC 标准误后族/维全部不显著（见上表）。**贡献可视为零。**

**默认关闭（硬约束）**：
- 代码开关：`factor_prior.build_factor_prior()` 默认 `enabled=False`；关闭时产出 `degraded=true, reason="newsflash_prior_disabled_by_default"`，40 侧 `load_factor_prior()` 返回 `None`。
- 重开条件：显式设置 `DREAM_ENABLE_NEWSFLASH_PRIOR=1`，且必须在 SPEC 记录新证据（否则视为违规）。
- **定位调整**：D1 的因子来源**只有深度文章**（训练侧）；快讯降级为叙事热度辅助指标（`narrative_heat`），不进入任何因子权重、不进 40。

## §5 状态表征层设计

### 5.1 状态向量定义（v0.1 冻结 8 维）

| # | 维度 | 信息族 | 计算 | 归一化 | 历史 |
|---|---|---|---|---|---|
| 1 | `sent` | 文本族 | newsflash FinBERT 日度均值 | 滚动 252 日分位 | ✅ 2023-01→今 |
| 2 | `narrative_heat` | 文本族 | 39 域主题聚类 → 当日最热主题热度 + 主题集中度 HHI（叙事是否聚焦） | 分位 | ✅ 2023-01→今 |
| 3 | `mom` | 价格族 | BTC 60 日收益率 | 滚动 252 日 z-score | ✅ 2023-01→今 |
| 4 | `vol` | 价格族 | 20 日已实现波动率 | z-score | ✅ 2023-01→今 |
| 5 | `breadth` | 价格族 | 上涨标的占比（多币 K 线；否则代理） | 分位 | ✅ 2023-01→今 |
| 6 | `macro_tight` | 宏观族 | 收益率曲线 T10Y2Y + 高收益利差 BAMLH0A0HYM2 合成 | 分位 | ✅ 1976→今 |
| 7 | `macro_risk` | 宏观族 | VIX 分位 + NASDAQ 60 日动量合成 | 分位 | ✅ 1971→今 |
| 8 | `macro_liq` | 宏观族 | RRP + WALCL + M2 同比合成 | z-score | ✅ 1959→今 |

**设计意图**：三族各占席位（文本 2 / 价格 3 / 宏观 3），使 §6.4 的 U2 真交叉验证在 v0.1 就具备可执行条件。

**降级备选（不进 v0.1 状态向量）**：`sent_disp`（日度情绪标准差，与 sent 高度相关，仅作 U1 校验）、`topic_sent`（各主题独立情绪，作 U3 组合用）、`fg`（fear_greed，41 天）、`lsr`（多空比，2 天）、`tvl_chg`（TVL，40 天）、`mvrv/sopr`（6 天）——历史不足或信息重复，不用于主检验。

**可用性降级**：任一维历史缺失时，状态向量自动降维并在产物标 `dims_effective`。**不允许用 mock 或插值补齐。**

### 5.2 归一化的前视防护

- 滚动窗口严格用 `[t-252, t-1]`，**不含 t 日**
- 分位计算用 `rank < target` 的比例（处理并列值）
- 每维落盘同时存 `raw_value` 与 `normalized`，便于审计

### 5.3 假设来源：因素 × 方向（防止维度组合爆炸的核心设计）

**不做**全空间搜索（8 维 × 若干分位档 = 组合爆炸，多重比较必然爆表）。

**只验证两类有来源的对象**：

| 类型 | 来源 | 规模 | 用途 |
|---|---|---|---|
| **H-L1 单因素方向** | P2 的 24 个可验证细类 × 2 方向 | ≤48 条，预注册冻结 | 因素是否真有预测力（**不依赖文章**） |
| **claim 方向** | 500 篇文章的 `DominanceClaim` | 每篇一条 | 作者主张是否有 alpha（**样本级评估，不构成假设空间**，不进 Holm 批内多重比较） |

```
示例（H-L1）:
  因素: flow.funding（P2 可验证）
  取值: DimensionContext.z(funding) 的滚动分位
  假设: P(forward_7d > 0 | funding 分位 > 0.8 且 direction = up)
        > P(forward_7d > 0 | 同期非条件日)
```

**数量控制**：
- H-L1 全集 = 24 × 2 = 48 条，**预注册文件冻结**，验证过程中不得增删（否则 PBO 无意义）
- claim 不产生组合爆炸：它是逐篇文章的观测，不是谓词空间
- 无可用序列的 30 个细类标 `unverifiable`，不进假设集（诚实暴露覆盖缺口）

**降级方案**：若 H-L1 全部不显著，退化为**单维极端分位**假设（8 维 × 双尾 = 16 条），作为 fallback 而非主线。

### 5.4 反应定义（事件研究 → 条件分布对比）

| 项 | 口径 |
|---|---|
| 反应变量 | 条件日的 `forward_return[T+24h]`（BTC 收盘对收盘） |
| 对照组 | 同窗口内非条件日的 forward return（**不是 μ0 全局均值**，消除 regime 漂移） |
| 检验 | 两组差异的 Welch t 检验 / 置换检验（n 小用置换） |
| 多窗口 | T+24h（主）/ T+72h（佐证）/ T+7d（佐证，不进主检验） |
| 重叠校正 | 条件日连续时 forward return 重叠 → 用 **block bootstrap**（块长 = 窗口长度） |

**关键改进 vs v0.1**：v0.1 用全局 μ0 做基准，导致 regime 漂移被误记成效应；本 SPEC 用**同期非条件日**做对照，这是正确的反事实。

### 6.4 多维交叉验证（回填的第二个用途，用户强调）

回填的价值不只是「维度更多」，更是**相互验证**。三类用途必须分开，不可混用：

| 用途 | 做法 | 产出 | 判据 |
|---|---|---|---|
| **U1 数据质量校验** | 同一构念用两个独立源计算，偏差超阈值即标记可疑 | 数据可信度报告 | 偏差 > 3σ 标 `suspect`，验证时剔除 |
| **U2 假设稳健性** | 同一命题在**不同独立信息族**内分别找代理谓词，检验是否同向 | 弱 / 中 / 强证据分级 | 三族同向=强，两族=中，单族=弱 |
| **U3 组合条件模式** | 多族状态同时极端时的条件收益 vs 单族极端 | 组合条件模式 | 需样本 n≥30 |

#### 信息族与独立性声明（**关键约束，防止虚假交叉**）

| 族 | 数据源 | 与加密行情的独立性 |
|---|---|---|
| **宏观族** | fred 20 序列（美债 / VIX / 美元 / 收益率曲线 / 高收益利差） | ✅ **真独立**（外部宏观，加密不驱动） |
| **加密价格族** | BTC K 线派生（momentum / vol / breadth） | — 基准 |
| **加密文本族** | newsflash → FinBERT sentiment | ⚠️ **非独立**（新闻被价格驱动，反向因果） |
| **事件流族** | newsflash `od_event_type` → co-occurrence | ⚠️ **与文本族同源**（同一批 newsflash） |

**结论（必须写进预注册）**：
- **U2 假设稳健性只能用「宏观族 vs 加密价格族」做真交叉**——这两族信息源独立
- **加密文本族与事件流族同源**，只能做 U1 一致性校验，**不可当作两条独立证据**（否则 n 条新闻被误算成 n 重验证）
- 情绪族与价格族同向，只能说明"价格与新闻同步"，**不构成因果证据**

#### 交叉验证是加严，不是放松

| 层级 | 原判据 | 本 SPEC 追加 |
|---|---|---|
| candidate | holm_p < 0.05（不变） | 无追加 |
| **verified** | 三层全过 + 方向稳定 ≥2 独立时间窗 | **+ 跨族一致**：宏观族与加密族同向 |

即交叉验证只用于**晋级门槛加严**，绝不用于放宽 p 值阈值。

### 6.5 四层验证（P3-a 前置门控 + L1/L2/L3，因素抽象版）

| 层 | 验证什么 | 输入 | 输出 | 依赖文章 |
|---|---|---|---|---|
| **P3-a 主导因素一致率** | 文章 claim 的主导维 vs 9 域实测最强维 | claim + 当日 `DimensionContext` | 一致率 + 三档分布（一致 / 背离但有效 / 无信号） | ✅ |
| **L1 因素预测力** | 因素客观取值 → 后续收益 | 历史维度状态序列（3 年） | 每因素每方向的胜率 / 期望收益 / p 值 | ❌ **不依赖** |
| **L2 作者方向准确度** | 文章给的因素方向 vs 因素客观方向 | 文章因素 + 当时客观取值 | 准确率矩阵（作者在哪些因素上判断更准） | ✅ |
| **L3 主张预测力** | claim 方向 → 后续收益（**不是**合成方向） | claim.direction + 价格 | 胜率 / 期望收益 vs 基准 | ✅ |

**分工**：
- **P3-a 是前置门控**——一致率接近随机说明 9 域与文章讲的不是一回事，后续不必做；成本最低（500 篇即可算，不需回测）
- **L1 是知识积累主渠道**——样本不受 500 篇限制（可用 3 年历史），产出即 E5 原语；但只覆盖长历史可验证的因素类（technical / macro / event / narrative）
- **L2 回答"作者在哪些因素上可信"**——可产出作者/来源加权先验
- **L3 回答"作者主张有没有 alpha"**——是训练样本质量的最终判据，**不是运行时信号**
- 四层**均走同一套三层防线**（Holm → PBO/CSCV → SPA/DSR），只是对象从"事件 cell"变为"因素方向 / claim"
