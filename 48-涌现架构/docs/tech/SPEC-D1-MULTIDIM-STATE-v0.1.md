## §0 Executive Summary

### 0.1 做什么

把 D1 的验证单元从「**离散事件 × 3 档 regime**」升级为「**连续多维状态向量 × 叙事命题谓词**」：

```
19.3 万条 newsflash 历史 ─┐
1,385 天 BTC 日 K ────────┤→ 真实日度多维序列（回填层）
NPE 命题库 ───────────────┘         ↓
                          连续状态向量（归一化、无前视）
                                    ↓
                          命题谓词 → 状态区域 → 反应分布
                                    ↓
                          三层防线（已建成，代码不动）
                                    ↓
                          verified 命题 → E5 原语 / E2 种群 / CBR 案例
```

### 0.2 不做什么

| 禁止 | 原因 |
|---|---|
| 不废弃 P0/P1/P2 已有产出 | 正文爬取器、C1 v0.1、NPE v0、事件库 6,697 事件全部可复用 |
| 不用 9 域现有 mock 分数 | 实测 `_generate_mock_*` 11 函数 + 130 处 `random.`，时序为随机游走合成（§2.1） |
| 不直接修 9 域服务层 | 9 域 mock 链路服务前端展示，动它牵动前端契约；改为 18 域并行建真实序列 |
| 不做维度组合全空间搜索 | 维度组合爆炸 → 多重比较必然爆表；假设必须**预注册且有命题来源**（§5.3） |
| 不放宽三层防线 | 同 v0.1：Holm → PBO/CSCV → SPA/DSR，全部预注册冻结 |
| 不产生交易信号 | 全部 shadow 只读；39 域既有定位也是"只做描述性观察"（39/SPEC.md §8.2） |

### 0.3 核心判断（三条，全部有实测依据）

1. **v0.1 失败不是"事件方法"的错，是状态表征太粗**
   3 档 regime × 5 类事件 = 15 格，格内异质性（降息 25bp vs 100bp）远大于格间差异。
   数值证据：三个 regime 桶的 cell 均值几乎相同（bull +0.30~0.39% / chop +0.37~0.39% / bear −0.02~0.06%，μ0=+0.14%），PBO 0.816~0.969 全灭。

2. **9 域的价值在 state vector 的"形状"，不在它当前的分数**
   8 维连续 + 自适应权重（flow 1.5 / valuation 1.4 / onchain 1.3 / macro 1.2 / news·sentiment·breadth 1.0 / intermarket 0.8 / narrative 0.7 / calendar 0.6）+ 贝叶斯置信 + 跨模块一致性，是**连续状态空间**的正确骨架。
   但当前分数是 mock，历史是合成的 → 只能借设计，不能借数据。

3. **39 域的价值在聚合算子，但分子层输入错位**
   它的原子层（变化驱动 `{layer,category,metric,timestamp,value,prev_value,reasons,source}`）与细胞层聚合（单因子序列 / 跨因子活跃状态 / 多因子离散度 CV）是正确的「事件→状态」转换机制。
   但它的分子层输入是 `trader.log`（系统内部判断事件），**与叙事无关** → 需换输入源为新闻/文章，不能直接复用产物。

### 0.4 最大的现实约束（先摆在前面）

**所有多维数据的真实历史都只有约 1 个月**，除了 K 线（2023-01 起）与 newsflash 文本（2018/2023-01 起）。因此本方案的第一块工作不是建模，是**回填**（§4）。回填可行性已逐维实测分级：3 维可回填、2 维需补源、2 维不可回填。

### 1.1 三层防线的最终数值（6,697 事件 / 3.7 年 / 15 cell）

### 1.2 根因分解（三条，互不排斥）

| # | 根因 | 证据 | 本 SPEC 的应对 |
|---|---|---|---|
| R1 | **状态表征粗**：3 档 regime 抹平了状态差异 | 三桶均值几乎相同 | §5 连续状态向量 |
| R2 | **事件标签丢强度**：同类型事件按二值等同 | 格内方差 ≫ 格间 | §5.3 命题谓词携带方向/阈值 |

### 1.3 一条必须记住的方法论

**PBO > 0.8 意味着"发现过程本身无信息"，不是"某个模式运气差"。**
v0.1 在 160 事件时曾判断"样本不足"，扩样 42 倍到 6,697 事件后结论不变且更干净 → 下次遇到高 PBO，先怀疑表征/假设空间，不要先扩样。

## §4 数据地基：回填可行性分级

### 4.1 分级结论（这是本 SPEC 最关键的事实基础）

| 维度 | 可回填性 | 方案 | 预期覆盖 |
|---|---|---|---|
| **sentiment** | ✅ **直接可回填** | newsflash description → `SentimentEngine.analyze_batch` → 日度均值/分位 | 2023-01 → 今，~1,400 天 |
| **momentum / volatility / breadth（自建）** | ✅ **直接可回填** | BTC 日 K 派生：20/60/252 日动量、ATR 分位、涨跌家数代理（若有多币 K 线则真实 breadth） | 2023-01 → 今 |
| **fear_greed** | ⚠️ 部分 | 现有 495 条 1.7 月；历史需外部源（alternative.me 有全历史 API，待核验） | 待 P1 核验 |
| **co-occurrence（原子→细胞）** | ✅ 可回填（需重建输入） | 用 newsflash 的 `od_event_type` + tickers_hit 作为原子事件源，套 39 域细胞层聚合公式 | 2023-01 → 今 |
| **narrative** | ⚠️ 需补正文 | 63,750 篇仅 500 篇有正文 → 需先扩爬（P0 爬虫已有，96.4% 成功率） | 视爬取进度 |
| **flow（ETF/资金流）** | ❌ 不可回填 | 只有 2026-08 起 2.2 月；历史 ETF 流向需外部源 | 只能向前累积 |
| **onchain（MVRV/SOPR/净流入）** | ❌ 不可回填 | 无任何历史源 | 只能向前累积 |
| **funding / OI** | ❌ 缺源 | 数据源本身不存在 | 需先接交易所历史接口 |

### 4.2 回填设计要点

1. **统一日度粒度**（UTC 日界），与 v0.1 事件库 `ts_precision` 口径一致
2. **每条序列落盘必须带 provenance**：`{date, value, n_inputs, source, builder_version}`
   - `n_inputs` 是防伪关键：某日只有 3 条 newsflash 时，其 sentiment 不可与 300 条的日期等同
3. **覆盖率门禁**：`n_inputs < 阈值` 的日期标 `low_coverage`，验证时降权或剔除（口径预注册）
4. **无前视**：序列在日 D 的值只能由 ≤ D 日 23:59 UTC 的输入计算
5. **FAIL-OPEN**：单日计算失败写 `null` + 原因，不中断整批，不插值（插值=伪造观测）

### 4.3 回填产物体积预算

| 序列 | 行数 | 体积估算 |
|---|---|---|
| sentiment_daily | ~1,400 | < 1 MB |
| market_state_daily | ~1,400 × 8 维 | < 2 MB |
| cooccurrence_daily | ~1,400 | < 2 MB |
| **总计** | — | **< 10 MB**（可直接入 git） |

## §5 状态表征层设计

### 5.1 状态向量定义（v0.1 冻结 8 维）

| # | 维度 | 计算 | 归一化 |
|---|---|---|---|
| 1 | `sent` | newsflash FinBERT 日度均值 | 滚动 252 日 **分位** ∈ [0,1] |
| 2 | `sent_disp` | 日度情绪标准差 | 同上 |
| 3 | `mom` | BTC 60 日收益率 | 滚动 252 日 z-score |
| 4 | `vol` | 20 日已实现波动率 | 滚动 252 日 z-score |
| 5 | `breadth` | 上涨标的占比（有多币 K 线时） | 分位 |
| 6 | `fg` | fear_greed 指数 | 分位 |
| 7 | `lsr` | 多空比 | 分位 |
| 8 | `tvl_chg` | TVL 20 日变化率 | z-score |

**可用性降级**：`breadth`/`fg`/`lsr`/`tvl_chg` 历史不足时，状态向量自动降为 4 维（`sent/sent_disp/mom/vol`），并在产物标 `dims_effective`。**不允许用 mock 或插值补齐。**

### 5.2 归一化的前视防护

- 滚动窗口严格用 `[t-252, t-1]`，**不含 t 日**
- 分位计算用 `rank < target` 的比例（处理并列值）
- 每维落盘同时存 `raw_value` 与 `normalized`，便于审计

### 5.3 假设来源：命题谓词（防止维度组合爆炸的核心设计）

**不做**全空间搜索（8 维 × 若干分位档 = 组合爆炸，多重比较必然爆表）。

**只验证有命题来源的假设**：

```
NPE 命题: "资金费率>0.1% 且 OI 创新高时，短期回调概率大"
   ↓ 人工/半自动映射（预注册，可审计）
谓词:    sent_disp > 0.9 且 mom > 0.8
   ↓
假设 H:  P(forward_24h < 0 | 谓词为真) > P(forward_24h < 0 | 谓词为假)
```

**假设数量控制**：
- 来源限定为 NPE 在 500 篇试爬文章上抽出的命题（冒烟 0.40 命题/篇 → 约 200 条，去重后约 30-60 条）
- **预注册文件冻结**假设全集，验证过程中不得增删（否则 PBO 无意义）
- 无法映射到可计算谓词的命题标 `unmappable`，不计入假设集（诚实暴露映射损失率）

**降级方案（若命题映射不可行）**：退化为**单维极端分位**假设（8 维 × 双尾 = 16 条），数量可控，但失去了叙事语义——作为 fallback 而非主线。

### 5.4 反应定义（事件研究 → 条件分布对比）

| 项 | 口径 |
|---|---|
| 反应变量 | 条件日的 `forward_return[T+24h]`（BTC 收盘对收盘） |
| 对照组 | 同窗口内非条件日的 forward return（**不是 μ0 全局均值**，消除 regime 漂移） |
| 检验 | 两组差异的 Welch t 检验 / 置换检验（n 小用置换） |
| 多窗口 | T+24h（主）/ T+72h（佐证）/ T+7d（佐证，不进主检验） |
| 重叠校正 | 条件日连续时 forward return 重叠 → 用 **block bootstrap**（块长 = 窗口长度） |

**关键改进 vs v0.1**：v0.1 用全局 μ0 做基准，导致 regime 漂移被误记成效应；本 SPEC 用**同期非条件日**做对照，这是正确的反事实。

### 6.2 新增构建器（唯一需要新写的代码）

`build_conditional_patterns(series, hypotheses, prices)`：
- 输入：日度状态序列 + 预注册假设集 + 价格
- 对每条假设 H_k：取满足谓词的日子 → 条件收益序列；所有假设的条件序列作为 CSCV 的 series_list
- 输出：与 `build_patterns` 相同的 pattern 结构（复用 status 流转口径）

### 6.3 预注册新增条款（补充到 `PATTERN-STATS-PREREG-v0.1.md`）

必须有 **v0.2 预注册文件**，冻结：
1. 状态向量维度与归一化方法（§5.1/§5.2）
2. 假设全集（§5.3 的 30-60 条命题谓词清单）
3. 对照组定义与重叠校正方法（§5.4）
4. `low_coverage` 剔除阈值
5. `dims_effective` 降级规则

**未冻结前不得跑验证**——否则 PBO 失去意义。

## §7 分阶段实施路径

| Phase | 目标 | 产出 | 验收判据 | 依赖 |
|---|---|---|---|---|
| **P1 回填地基** | 真实日度序列 | `sentiment_daily` + `market_state_daily` + `cooccurrence_daily`（或明示缺哪维） | ①≥900 天序列 ②每日带 `n_inputs` ③抽查 10 天人工核对情绪方向 ④覆盖日占比 ≥80% | 无（原料已就绪） |

## §8 风险与已识别坑

| # | 风险 | 影响 | 缓解 |
|---|---|---|---|
| K1 | `sentiment` 回填质量受 newsflash 短文本限制（无正文） | 情绪信号噪声大 | ①`n_inputs` 门禁 ②与文章级 sentiment 做一致性校验（500 篇有正文的样本） |
| K2 | 条件日样本稀疏（谓词苛刻时 n<30） | 统计功效不足 | 预注册最小样本 n≥30；不达标假设标 `insufficient_n` 不晋级 |
| K3 | 谓词映射主观性（人工映射可被事后调整） | p-hacking 风险 | ①预注册冻结 ②映射由独立于验证的人员/进程执行 |
| K4 | 8 维中 4 维历史不足 | 状态向量退化 | 降级为 4 维，如实标注 `dims_effective`，不补齐 |
| K5 | 39 域术语表仅 3 条占位 | 分子层不可用 | 本 SPEC 不走 39 分子层，改用 newsflash `od_event_type` 作原子事件源 |
| K6 | forward return 重叠 | p 值偏乐观 | block bootstrap（块长=窗口） |
| K7 | 情绪序列与价格同源（newsflash 受价格驱动） | 反向因果 | 谓词只用 t-1 及更早的状态；反应只看 t+1 之后 |
