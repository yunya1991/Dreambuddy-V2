## §1 architecture_gap（11 条）——三态处置（修订后）

**实测基础（不变）**：全仓函数跨目录重名率 27.5%（排除魔术方法，40320 函数名 / 11098 重名）。

**三态处置规则（修订后）**：

| 处置态 | 判定条件 | 动作 |
|---|---|---|
| `reclassified→closed` | 按新判据（call 边假依赖率 < 0.35）实测达标 | 关闭，notes 写明『判据从模块级重名率<0.4 改为 call 边假依赖率<0.35，原记录 78-88% 重名率不再适用』 |
| `reclassified→open` | 按新判据实测不达标 | 保持 open，按新判据跟踪 |
| `deferred` | 根治依赖 33-REA AST 精准解析 | 挂起，标注依赖项与排期归属 |

**执行要求**：11 条逐条按新判据重测后回填，禁止批量关闭；`capability_gaps.jsonl` 每条增加 `reclassified_from`（旧判据描述）与 `recalibrated_at`（时间戳）字段。

## §2 interface_mismatch（13 条）——5 域扩样实测（修订后）

**扩样数据（云端实测，2026-11-12，共 3110 个公开函数）**：

| 域 | 公开函数 | 有 docstring | docstring 率 |
|---|---:|---:|---:|
| 9-基本面分析 | 703 | 65 | **9.2%** |
| 18-数据获取中心 | 1093 | 507 | **46.4%** |
| 40-周期神经网络系统 | 163 | 62 | **38.0%** |
| 48-涌现架构 | 830 | 264 | **31.8%** |
| 50-NN主矛盾评估器 | 321 | 54 | **16.8%** |
| **5 域合计** | **3110** | **952** | **30.6%** |

**扩样结论（修正 v1.0 的抽样偏差）**：
1. v1.0 的 17 域 64% 确属高覆盖域抽样偏差——5 域扩样后均值 **30.6%**，域间差异大（9.2%~46.4%）
2. 与缺口记录的『缺注解 94-96%』对照：按 docstring 口径实测缺注解率约 69.4%（1-30.6%），仍低于记录值——记录口径可能为完整类型注解（type hints），**定义统一仍是前置条件**
3. 域间差异显著（9域 9.2% vs 18域 46.4%）支持分级判据：L1 跨域边界函数 100%（硬门槛）/ L2 模块内公开函数 docstring ≥ 60%（软门槛）/ L3 私有函数豁免——按 L2 口径当前仅 18 域达标，9/40/48/50 域均需补齐

**执行要求**：定义统一后（L1=type hints+docstring，L2=docstring），按 L1/L2 分别统计 13 条缺口对应域的达标率，逐条回填处置。

## §3 doc_debt（13 条）——内容门禁实测（修订后）

**README 五要素内容门禁**：定位（1 段）/ 入口（主要模块与脚本列表）/ 数据流（1 段或图）/ 依赖（外部库+内部域）/ 运行方式（关键命令）。

**关键子模块定义**：被 ≥2 个其他域 import 的模块，或目录下 py 文件 ≥ 5 个的模块。

**5 域实测（云端，2026-11-12）**：

| 域 | README 存在 | 门禁通过（/5） | 缺失要素 |
|---|---|---|---|
| 9-基本面分析 | ❌ 无 | 0 | 全部 |
| 18-数据获取中心 | ✅ | 3 | 定位、依赖 |
| 40-周期神经网络系统 | ❌ 无 | 0 | 全部 |
| 48-涌现架构 | ✅ | **5（全过）** | 无 |
| 50-NN主矛盾评估器 | ❌ 无 | 0 | 全部 |

**实测结论**：内容门禁口径下 5 域中仅 48 域完全达标——『有 README』≠『文档合格』的批评被实测证实（18 域有 README 但缺 2 要素）。doc_debt 缺口按内容门禁重测后**真实存在**，非判据问题，需分批补齐（先主链域 48/40/50/23）。

## §4 决策 SLA 与回填追踪（修订后）

| 项 | 规则 |
|---|---|
| **决策 SLA** | 33-REA 与 0-系统文档管理裁决后 **5 个工作日内**，48 域完成 37 条重测与回填 |
| **回填字段** | `capability_gaps.jsonl` 每条增加 `reclassified_from`（旧判据）、`recalibrated_at`（时间戳）、`resolution_note`（新判据实测值） |
| **回滚机制** | 任一类别重测后 closed 比例 > 80% 时，触发人工抽检该类别 10% 样本；抽检发现 1 条伪关闭即回滚该类别全部关闭项并冻结判据待复审 |
| **追踪方案** | 缺口清单 SPEC §0 统计表每次回填同步更新；verdict 仪表盘不纳入判据类缺口（非实验项） |
