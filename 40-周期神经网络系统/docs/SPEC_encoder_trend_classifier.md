# SPEC: 40-周期神经网络系统 — BERT 类 Encoder 趋势判别模型（P6 阶段架构选型）

> 版本：v0.2（评审修订稿）
> 日期：2026-10-24
> 状态：评审修订完成（v0.1 评审 6 项修订已合入），待终审
> 上游：40-SPEC.md 主规格（P6 神经网络深度学习阶段）
> 关联系统：21-特征工程中心（特征供给）/ 12-三屏趋势系统（三屏逻辑+基线+集成推理层宿主）/ 9-基本面分析（FinBERT 经验）/ 23-四层闭环自进化架构（决策门禁）

## 零 · 问题总结与定位声明

40 主规格 P6 阶段三要求：以 L1-L3 语义特征为输入、周期判定为目标，训练传导网络，且必须建立在阶段一/二验证基础上。本规格选定 Encoder-only（BERT 类）判别架构作为 P6 的落地架构。

**定位声明（v0.2 新增，避免职责重叠）：**
1. **层级关系**：本模型输出 trend_classification（趋势方向判别）是 40 主链路 L2 周期判定模块的语义输入，不是周期判定本身——周期判定（真实周期/理论周期状态机）仍归 40 主链路 L2 模块，本模型不替代、不绕过
2. **接入定位**：本模型作为 12-三屏趋势系统集成推理层（ml/algo_ensemble.py）的新算法候选接入，与既有 LightGBM/XGBoost 并列竞争，通过 12 系统 ensemble 接口输出，不另立独立输出通道——复用 12 系统的样本收集与标注管道，避免双头输出信号冲突
3. **前置门禁**：E0（特征管道）与 E1（基线固化）可与 40 主规格 P1-P4 并行推进；E2 及以后必须以 P1-P5 完成验证为前置门禁（继承主规格红线：神经网络训练必须建立在阶段一/二验证基础上，禁止直接跳到端到端黑箱）

**架构选型理由：**
1. 任务性质匹配：判断上涨/下跌是分类判别任务，不是生成任务。Encoder 的双向注意力 + 池化分类头是判别任务最优架构；Decoder 自回归生成能力在本场景是冗余开销
2. 金融周期性匹配：周期规律需要全局比对（当前时点与历史相似形态的关联），双向注意力允许每个 token 关注全局上下文，契合周期是中枢神经的核心认知
3. 既有先例验证：9-基本面分析已落地双 FinBERT（ProsusAI 英文 + valuesimplex/FinBERT2 中文），含 3 层 fail-open 回退设计，证明 BERT 类金融模型在本基础设施上可运行

核心认知（用户理论框架）：
1. 深度理解与判别能力：需要的不是生成，而是对基本面+技术面的深度理解，输出上涨/下跌判别
2. Token 对应交易系统实体：Transformer 的 token 在交易系统中对应基本面和技术面指标数据
3. 时序参考三屏交易逻辑：周/日/1H 三个时间框架判别先后（高级别约束低级别）
4. 每个 token 关注全局：输入向量投影成 QKV，自注意力识别市场趋势方向

## 一 · 架构设计

### 1.1 整体架构

```
输入层：三屏 token 序列（周/日/1H）
  周线 token × N_w ──┐
  日线 token × N_d ──┼──→ 拼接 + 时间框架位置编码
  1H  token × N_h ──┘
Encoder 主干（小模型，2-4 层）
  MultiHead Self-Attention（QKV 投影，全局注意力）
  + FeedForward + LayerNorm + 残差
  + 相对位置编码（周期性位置感知）
分层注意力注入（可选，阶段二）
  周线 token 输出 → 作为全局上下文约束日线/1H 判别
判别头：
  [CLS] 池化 → MLP → 三分类 {UP / DOWN / NEUTRAL}
  + 置信度输出（温度校准）
```

### 1.2 Token 设计（基本面 + 技术面指标）

特征供给方：21-特征工程中心（FeatureHub 唯一入口）。每个 token = 一个时间步的特征组嵌入：

| 特征组 | 来源模块 | 嵌入方式 |
|---|---|---|
| 技术面组 | classic_indicators / triple_screen_trend / crypto_morphology / elder_ray | 数值特征：分桶嵌入（TabTransformer 列嵌入思路）或线性投影 |
| 基本面组 | fundamental_ratios + 9-基本面 FinBERT 情感输出 + 39 系统 L1-L3 语义产出 | 情感分数线性投影；语义事件嵌入 |
| 周期组 | yijing_cycle / 40 系统 cycle_state（真实周期+理论周期） | 类别嵌入 + 数值投影 |
| 宏观组 | FRED（FEDFUNDS/DFII10/T10YIE）+ 美林时钟象限 | 数值投影 + 象限类别嵌入 |
| 技术锚点组（v0.2 新增） | MA200 距离/上下状态、MA50/MA100 多级分界（预计算特征） | 数值投影 + 布尔状态嵌入 |

Token 结构约束：
- 每个 token 内特征组独立嵌入后拼接（组内同维，组间可异维再投影到 d_model）
- 缺失特征用可学习的 ｜ 嵌入填充（对齐 21 中心血缘追踪的缺失列语义）
- 特征版本随 FeatureVector 版本号绑定，保证可复现

**MA200 锚点处理（v0.2 修订）**：MA200 等长窗口锚点不依赖模型在 token 窗口内学习（日线 token 窗口 60-120 根不足以覆盖 200），而是作为预计算特征注入技术锚点组——收盘价与 MA200 的距离百分比、上下状态布尔值、MA50/MA100 多级分界状态。特征计算在 21 中心 talib_aligned 模块基础上扩展（该模块已含 ema 类指标），随特征管道统一供给。

### 1.3 时序设计：周/日/1H 三屏判别

三屏逻辑来源：12-三屏趋势系统（Elder 三屏）

| 屏 | 时间框架 | 角色 | token 数建议 |
|---|---|---|---|
| 第一屏 | 周线 | 定方向（全局上下文，对应 40 系统长周期约束） | 52-104 |
| 第二屏 | 日线 | 找时机（中期确认，MA200 锚点经预计算特征注入） | 60-120 |
| 第三屏 | 1H | 确认入场（局部细节，短周期信号） | 72-168 |

判别先后机制（高级别弹性约束低级别）：
- 阶段一（拼接式）：三屏 token 拼接 + 时间框架位置编码（周/日/1H 各自可学习编码），全局自注意力自动学习跨屏依赖
- 阶段二（分层式）：周线 Encoder 输出作为 KV 上下文，注入日线/1H 的交叉注意力——显式实现周线约束日线、日线约束 1H
- 与 40 主规格 L5 高级别弹性约束低级别同构：低级别判别与高级别冲突时，输出降级为 NEUTRAL

**1H 屏实现边界（v0.2 新增）**：12 系统 compute_trend_signal_from_dataframes 当前仅支持周/日双屏；1H 第三屏的数据获取与重采样在本模块内独立实现（可复用 12 系统 data/market_data.py 的 resample_candles 函数），不改动 12 系统既有接口，降低耦合。

### 1.4 QKV 全局注意力

- 标准 MultiHead Self-Attention：输入投影 Q/K/V，注意力捕捉跨周期、跨特征组依赖（如 BTC 周线趋势 token 对 1H 信号 token 的全局影响）——这是 LightGBM 等树模型做不到的显式全局交互
- 相对位置编码：金融时序存在周期性（周/月/季），使用相对位置编码而非绝对位置，支持外推
- 注意力温度校准：防止注意力过度集中于近期 token（注意力稀释/分布漂移），训练时加注意力熵正则

### 1.5 模型规模约束（小模型红线）

| 项 | 约束 | 理由 |
|---|---|---|
| 层数 | 2-4 层 Encoder | 金融样本少（周线一年仅 52 token），防过拟合 |
| d_model | 64-128 | 同上 |
| 注意力头 | 4-8 | 同上 |
| 总参数量 | ≤ 1M（百万级以内） | 轻量服务器 CPU 推理可行（FinBERT 已验证 CPU 可行，本模型应远小于它） |
| 初始化 | 从 FinBERT 蒸馏初始化（可选）或随机小模型 | 迁移金融先验 |

## 二 · 数据与标签

### 2.1 训练数据
- 特征：21-特征工程中心 FeatureHub（回测/实盘共用唯一入口，带血缘追踪）
- K线：18-数据获取中心（OKX/ccxt 轨）
- 语义：39 系统 l3_synthesis.json / semantic_events.jsonl
- 情感：9-基本面 FinBERT 输出

### 2.2 标签设计（防噪声，v0.2 对齐既有工具）
- 判别目标：未来 N 期收益方向 + 波动率调整阈值（三分类 UP/DOWN/NEUTRAL，NEUTRAL 为波动率带内的震荡区）
- 标注工具：直接复用 12 系统 ml/label_samples.py（默认 lookahead 7 日），日线标签窗口对齐 7 日（v0.2 修订：原 10 日改为 7 日，与既有标注工具及已收集样本完全兼容）
- 标签窗口：周线 N=4 周 / 日线 N=7 日 / 1H N=24 小时（预注册，禁止事后调参；周线/1H 窗口需在标注工具中扩展参数，扩展不改默认行为）

### 2.3 训练验证
- Walk-Forward 5 折（对齐 11 系统回测引擎范式），禁止随机打乱时序
- 验证窗口留出：最近 20% 时间段作为纯验证，不参与任何调参

## 三 · 实施阶段（Shadow 渐进路线）

| 阶段 | 内容 | 通过标准 | 前置依赖 |
|---|---|---|---|
| E0 | 特征管道打通：FeatureHub → token 序列生成器（含 MA200 预计算特征） | 三屏 token 序列可复现生成，血缘完整 | 可与 P1-P4 并行 |
| E1 | 基线对照：12 系统 LightGBM 46 维特征基线固化 | 基线指标（准确率/IC）落表 | 可与 P1-P4 并行 |
| E2 | 小模型训练：拼接式 Encoder（阶段一架构） | Walk-Forward 指标 ≥ LightGBM 基线 | **P1-P5 完成验证（硬门禁）** |
| E3 | Shadow 运行：实盘旁路并行，不产生交易影响 | Shadow 运行 ≥ 4 周，输出分布稳定 | E2 通过 |
| E4 | 分层式升级：周→日→1H 交叉注意力注入 | 分层式 ≥ 拼接式，且高级别约束生效可解释 | E3 通过 |
| E5 | 接入 40 主链路：输出作为 L2 周期判定的语义输入 | 40 主规格 P6 验收标准满足 | E4 通过 |

**接入方式（v0.2 明确）**：E3-E5 期间模型经 12 系统 ensemble 接口（algo_ensemble）以候选算法身份参与集成，与 LightGBM/XGBoost 权重竞争；E5 接入 40 主链路时，trend_classification 作为 L2 周期判定模块的语义输入之一，不替代周期判定状态机。

红线（继承 40 主规格）：
1. 本模型输出为周期判定/趋势判别的语义输入与建议，不产生交易信号
2. 所有交易决策归 23 系统三步门禁（回测→影子→灰度）
3. E2 未超基线则不进入 E3；E3 未稳定则不进入 E5
4. 禁止跳过 E1 基线直接宣称模型有效
5. E2 及以后必须以 40 主规格 P1-P5 完成验证为前置门禁，禁止提前训练（v0.2 新增）

## 六 · 风险与注意事项

1. 样本量风险：周线 token 稀少，小模型 + 数据增强（跨币种共享训练）+ 正则化三管齐下
2. 注意力漂移：近期 token 注意力过集中 → 注意力熵正则 + 温度校准
3. 分布漂移：市场 regime 切换导致特征分布变化 → 接入 11 系统市态标签做条件训练或分组评估
4. 过拟合红线：所有标签窗口/超参预注册，验证窗口封板，禁止事后调整
5. 算力约束：轻量服务器 CPU 推理（小模型可行）；训练任务走 31-分布式计算部署或云端按需资源
6. 扩展性：早期以加密市场（BTC/ETH/SOL）为例验证；架构按资产类设计 token 组，后期扩展美股/贵金属时新增特征组嵌入即可，模型结构不变
7. 职责边界（v0.2 新增）：趋势判别经 12 系统 ensemble 输出，周期判定归 40 主链路 L2，两者信号冲突时以 40 L2 周期判定为高级别约束（高级别弹性约束低级别）

## 七 · 验收标准

1. E0：token 序列生成可复现（同特征版本输入 → 字节级一致输出），MA200 预计算特征与 12 系统指标计算结果一致
2. E2：Walk-Forward 5 折三分类准确率与方向 IC 均 ≥ LightGBM 基线
3. E3：Shadow ≥ 4 周无中断，判别输出分布稳定（PSI < 0.1）
4. E4：分层式在历史牛熊段（2020-2022、2024 Q4）判别与 40 主规格 P1-P4 周期判定结论一致性 ≥ 70%
5. E5：接入后 40 系统 cycle_state.json 的周期判定置信度提升可量化
