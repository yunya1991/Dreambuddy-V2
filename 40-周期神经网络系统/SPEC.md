# SPEC: 40-周期神经网络系统 — 周期中枢驱动的分层传导与策略映射

> 版本：v0.7（跨市场传导与传统金融方法融合稿）
> 日期：2026-10-20（v0.7 更新于 2026-10-26）
> 状态：跨市场定位+传统金融方法融合（v0.7），待评审
> 上游：39-金融语义蒸馏系统（L1-L3 描述性产出）
> 下游：23-四层闭环自进化交易架构（决策门禁）

## 零 · 问题总结

39 系统已形成完整的描述性骨架（L1 原子事件 → L2 事件线 → L3 多因子矛盾综合），但缺乏『灵魂』——即从描述到推理的传导机制。本系统以**周期为中枢神经**，构建从宏观周期判定 → 资产轮动 → 板块传导 → 策略映射的分层推理链路，将 39 系统的描述性产出转化为周期理论服务下的结构化推理输入。

**市场覆盖定位（v0.7）**：加密市场主体兼具金融与科技双重属性，本身即宏观金融的组成部分。本系统覆盖**加密与传统金融两个市场**，传导链为跨市场结构：传统金融（股/债/汇/金）↔ 加密市场（内部层级传导），资金流动识别横跨两大市场。

**核心认知（用户理论框架）：**

1. **周期是金融的中枢神经**
   - 真实周期（现在时）：美联储加减息周期——资金成本的真实锚
   - 理论周期：短周期（数周-数月）/ 中周期（数月-数年）/ 长周期（数年-数十年）
   - 两者关系类似预期与真实：互为印证、互为修正

2. **周期调控资金在大池子内的流动与顺序**
   - 避险资产：黄金为代表
   - 大宗商品：石油、矿产等
   - 债券/现金：美债、美元
   - 风险资产：股票、加密货币
   - 美林时钟提供**预期管理**框架；资产表现反映**真实资金动态**；预期与现状互为印证修正

3. **板块内层级传导**
   - 股票：龙头 → 蓝筹 → 增长型 → 泡沫型
   - 加密：BTC（龙头）→ ETH 等（主流）→ UNI 等（增长型）→ meme（炒作型）
   - 资金沿风险偏好梯度传导，龙头先行、炒作型殿后

4. **技术确定性锚点**
   - 日线 MA200 等技术分界线为模糊周期提供确定性信息（牛熊分界）
   - 作用：为周期判定的不确定性提供硬边界

5. **策略映射（简单原则）**
   - 顺势（周期上行）→ 趋势追涨策略
   - 逆势（周期下行）→ 趋势做空策略
   - 不确定（周期模糊）→ 高抛低吸策略
   - **高级别弹性约束低级别**：长周期方向约束中短周期操作

6. **描述性服务于周期理论**
   - 大周期表现由基本面数据综合决定（如美国 CPI 对美联储政策的重要性）
   - 39 系统 L1-L3 的描述性产出正是周期判定的语义输入
   - 顶层逻辑并非臆测，而是由低层神经（L1-L3）逆向深度学习获得

7. **矛盾论方法支持**
   - 自进化系统的矛盾论方法为多数据冲突下的主要矛盾识别提供算法支持
   - 用于识别真正的周期趋势，过滤噪声

## 三 · 核心模块设计

### 3.1 周期判定模块（L2 层）
- **真实周期状态机**：基于 FEDFUNDS 变化序列判定加息周期/降息周期/平台期
- **理论周期估计**：短/中/长周期的趋势分解（待评估：可用 HP 滤波/小波分解等经典方法，避免过拟合）
- **印证修正机制**：理论周期与真实周期背离时，以矛盾论方法识别主要矛盾（哪个是主要趋势）

### 3.2 资产轮动模块（L3 层）
- 美林时钟四象限定位：增长/通胀二维映射（预期管理）
- 资产表现印证：各大类资产动量/相对强弱（真实资金动态）
- 背离检测：预期象限 vs 真实资金流向不一致时输出修正信号

### 3.3 板块传导检测模块（L4 层，v0.5 重构）

板块轮动并非必然发生，传导是**检测对象**而非假设。三维度交叉验证共同形成周期下神经传导的真实方向；分歧较大时移交 23 矛盾论框架识别主要矛盾（不在本系统内强行裁决）。

**维度一 · 板块传导检测**（已实现，scripts/p3_sector_transmission.py）
- 加密板块层级：BTC → ETH/SOL 主流 → 增长型 → meme 层
- **meme 层观测方式（v0.6 调整）**：meme 热点更替快，固定代币清单（DOGE/PEPE/WIF）会滞后，改为 **Pump 平台指标观测**（scripts/p3_meme_platform_monitor.py，产出 meme_platform.json）：
  - 新代币毕业率：新池样本中 pumpswap 毕业池占比（毕业=从 bonding curve 迁移到 AMM）；毕业率上升=meme 热度健康，下降=热度退潮
  - 新池热度：新池数量、FDV 分布中位数、买卖人数比、24h 价格变化分布
  - 回购费用指标：需链上数据（Pump 程序手续费分配事件），列为后续扩展
  - 数据源：GeckoTerminal 公开 API（已验证可用，无需鉴权；Pump 官方前端 API 被 Cloudflare 拦截不可用）
- 传导健康度：龙头先行、板块跟涨为健康传导（expanding）；炒作型独涨为末端信号；资金收缩回主流层（contracting）为周期晚期预警
- 层级动量梯度：各层级相对 BTC 的强弱变化（层中位数动量梯度，联动 MA200 牛熊锚点输出 regime）
- **传统金融方法融合（v0.7）**：
  - Stovall 板块轮动映射表：宏观周期四阶段（复苏→扩张→放缓→衰退）→ 超额收益板块预注册先验（复苏：科技/工业；扩张：能源/材料；放缓：必需消费/医疗；衰退：公用事业/金融），作为 L4/L5 的预注册规则表
  - 市场广度指标：站上 MA200 的传导链资产占比（加密版广度），配合 meme 平台毕业率构成双层广度观测

**维度二 · 洗盘识别**（复用 11-易经推理系统 bcrm2 洗盘模块，不复制代码）
- 接口契约：WashoutDetector.run(coin, df, macro_data) → WashoutVerdict（washout 持有 / weakness 真弱势加速离场 / unknown 维持现状，含置信度与特征快照）
- 多因子判定：缩量 + OI 温和下降 + CVD 与价格背离 → 洗盘；缩量 + OI 上升 + CVD 同步下行 → 真弱势；funding 深度负值辅助判定
- 回测指标：准确率 77.5%（vs volume-only 32.5%），有判定准确率 96.9%
- FAIL-OPEN 铁律：任何异常 → unknown()，绝不阻塞主链路
- 用途：识别各类别资产中龙头的真实形态（洗盘回调 vs 真弱势），修正传导检测的层级动量读数

**维度三 · 资金流动识别**（已实现，scripts/p3_fund_flow.py，v0.7 扩展传统金融方法）
- 板块内资金流动：板块内部龙头/跟风轮动检测（龙头动量衰减 + 跟风补涨 = 板块内资金扩散末期）
- 跨资产类别流动：加密/黄金/债券/股票/美元间的资金流动矩阵（动量轮动 + 相对强弱迁移）
- **传统金融方法融合（v0.7，John Murphy 跨市场分析体系）**：
  - 60 日滚动相关性矩阵：SPX vs 10Y、黄金 vs 美元、BTC vs SPX——核心观测相关性的**结构性变化**（如股债相关性由负转正为宏观体制切换经典信号）
  - 跨资产 RS 比率线：黄金/股票、加密/股票比率趋势及均线方向（传统金融板块轮动标配方法）
  - 利差指标：T10Y2Y 期限利差（衰退预警）+ BAMLH0A0HYM2 高收益信用利差（风险偏好温度计）——传统金融跨资产观测标配
  - 资金流代理（后续扩展）：CFTC 持仓报告（商业/非商业头寸，聪明钱方向）、交易所稳定币余额变化（加密资金流入代理）
- 数据依赖：18 中心价格序列 + ccxt 量能数据 + FRED 扩展序列（T10Y2Y/BAMLH0A0HYM2）；产出 fund_flow.json

**三维度融合**：传导检测（方向）× 洗盘识别（真伪）× 资金流动（来源去向）→ 神经传导真实方向

### 3.4 策略映射模块（L5 层）
- 输入：周期判定（顺/逆/不确定）+ 技术锚点（MA200 上下）
- 输出：策略映射建议（追涨/做空/高抛低吸）+ 资产类别偏好
- **弹性约束**：长周期方向约束中短周期；中周期约束短周期；低级别与高级别冲突时降级为高抛低吸

### 3.5 神经网络深度学习（演进方向，分阶段）
- **阶段一（规则引擎）**：上述模块以预注册规则实现，验证传导逻辑有效性
- **阶段二（统计学习）**：积累事件流后，对周期判定与资产表现做统计关联学习
- **阶段三（神经网络）**：在既有知识基础上深度学习——以 L1-L3 语义特征为输入，周期判定为目标，训练传导网络；顶层逻辑由低层数据逆向学习获得，非人工臆测
- **约束**：神经网络阶段前必须完成阶段一/二验证；训练数据依赖事件流积累

## 七 · 风险与缓解机制（v0.2 完善）

1. **周期判定滞后性**
   - 风险：宏观数据（CPI/利率决议）天然滞后，周期状态确认时行情往往已走一段
   - 缓解机制：
     a) 双轨信号源：硬数据轨（FRED 序列，滞后但权威）+ 软语义轨（39 系统快讯语义事件，前瞻但噪声高），互为印证
     b) 前瞻-确认两阶段状态：周期状态变更先进入前瞻预警（软语义轨触发），硬数据确认期数按数据轨预注册（FEDFUNDS 月频 2 期、CPI 月频 2 期、快讯语义轨按事件数计 3 件），确认延迟上限 ≤ 60 天，两阶段分别标注置信度
     c) 发布日历事件窗口：FOMC/CPI 发布日前后 ±2 日为事件窗口，窗口内周期状态冻结（预注册选定：冻结），避免数据跳变引发状态抖动
     d) 状态去抖动：周期状态切换需连续 2 期同向证据，单期反向证据仅降置信度不切状态

2. **美林时钟失效场景**
   - 风险：滞胀等非典型周期下，增长/通胀二维象限映射失真
   - 缓解机制：
     a) 象限置信度分级：每象限输出置信度，历史映射失真频发象限（如滞胀象限）默认降一级置信度
     b) 印证权重动态化：预期象限与真实资金流向（资产动量）背离持续 ≥3 期触发失效检测，资产表现印证权重上调、时钟定位权重下调
     c) 失效降级路径：失效检测触发后，L3 资产轮动输出从象限定位降级为纯动量排序，asset_rotation.json 标注 clock_degraded=true
     d) 滞胀特殊规则：预注册滞胀象限资产偏好修正表（现金/商品优先）作为象限映射的先验覆盖

3. **过拟合与端点偏差**
   - 风险：HP 滤波等趋势分解存在端点偏差；参数事后调整导致过拟合
   - 缓解机制：
     a) 参数预注册：滤波窗口/lambda/分解层级全部预注册并版本化，禁止运行时调整
     b) 端点处理：分解结果末端 6 期标记为低置信端点，仅作参考不进入周期判定主证据（预注册选定：末端低置信标记方案，不采用单向滤波）
     c) Walk-Forward 滚动验证：禁止随机打乱时序
     d) 验证窗口封板：最近 20% 时间段为纯验证，任何参数不得依据该段表现调整
     e) 最小复杂度原则：优先规则引擎与简单统计，复杂模型必须证明相对简单基线的增量收益

4. **数据扩展依赖**
   - 风险：石油（CL=F）、meme 代币清单等数据源未就绪，L3/L4 层覆盖不全
   - 缓解机制：
     a) 扩展优先级：优先级一 原油 CL=F（L3 大宗维度）→ 优先级二 meme 代币 Top10（L4 传导末端）→ 优先级三 周线锚点数据
     b) 扩展流程：18 中心 sources.yaml 新增 → 数据质量验证（≥90 天连续）→ 回归验证（既有产出不因扩展漂移）→ 灰度接入
     c) 缺失降级：数据未就绪维度在产出物标注 data_coverage=partial，对应结论降一级置信度，不阻塞其他维度输出
     d) 扩展不改结构：资产池扩展只加条目不改判定逻辑，与按资产类独立设计一致

5. **与 23 系统职责划分**
   - 风险：23 的美国宏观事件驱动交易策略做事件级交易，与 40 周期级状态判定边界模糊，可能双头决策
   - 缓解机制：
     a) 接口契约固化：40 向 23 提供周期状态上下文的 schema 固化（cycle_state.json 字段冻结，新增字段只增不改）
     b) 冲突裁决规则：事件级信号与周期级状态冲突时，23 门禁以 40 周期状态为高级别约束（与高级别弹性约束低级别同构）；40 不做事件级交易，23 不做周期级判定
     c) 单向依赖：40→23 仅提供上下文输入，23 门禁决策不回写 40 周期状态，避免循环依赖

6. **单点数据源故障（v0.2 新增）**
   - 风险：FRED/yfinance/ccxt 单一数据源故障或字段变更导致周期判定中断
   - 缓解机制：
     a) fail-open 降级：数据源故障时周期状态保持上一确认状态并标注 stale=true，置信度随停滞时长衰减（预注册四档：高/中/低/失效，每 24h 降一档；降至失效档时 cycle_state 标注 unavailable=true，23 门禁按无周期上下文处理）
     b) 数据新鲜度校验：每次判定前检查数据时间戳，超过数据固有频率 2 倍未更新即触发降级
     c) 关键锚点冗余：FEDFUNDS 为主锚，利率期货隐含预期（39 语义轨）为备用印证源

7. **样本量不足（统计学习/神经网络阶段，v0.2 新增）**
   - 风险：周期级样本天然稀少（一轮完整周期数年），P5/P6 阶段样本不足
   - 缓解机制：
     a) 跨资产共享样本：同类周期机制下多资产（BTC/ETH/SOL/黄金/标普）共享训练样本
     b) 事件流积累前置：P5 前持续积累 contradiction_events/semantic_events 事件流，预注册样本量门槛（矛盾事件 ≥ 200 条、语义事件 ≥ 1000 条）未达标不进入模型训练
     c) 小模型约束：对齐 Encoder 架构选型规格（docs/SPEC_encoder_trend_classifier.md）的小模型红线（参数量 ≤ 1M），复杂度与样本量匹配
