# SPEC: 40-周期神经网络系统 — 周期中枢驱动的分层传导与策略映射

> 版本：v0.1（评估调研稿）
> 日期：2026-10-20
> 状态：评估调研完成，待评审
> 上游：39-金融语义蒸馏系统（L1-L3 描述性产出）
> 下游：23-四层闭环自进化交易架构（决策门禁）

## 零 · 问题总结

39 系统已形成完整的描述性骨架（L1 原子事件 → L2 事件线 → L3 多因子矛盾综合），但缺乏『灵魂』——即从描述到推理的传导机制。本系统以**周期为中枢神经**，构建从宏观周期判定 → 资产轮动 → 板块传导 → 策略映射的分层推理链路，将 39 系统的描述性产出转化为周期理论服务下的结构化推理输入。

**核心认知（用户理论框架）：**

1. **周期是金融的中枢神经**
   - 真实周期（现在时）：美联储加减息周期——资金成本的真实锚
   - 理论周期：短周期（数周-数月）/ 中周期（数月-数年）/ 长周期（数年-数十年）
   - 两者关系类似预期与真实：互为印证、互为修正

2. **周期调控资金在大池子内的流动与顺序**
   - 避险资产：黄金为代表
   - 大宗商品：石油、矿产等
   - 债券/现金：美债、美元
   - 风险资产：股票、加密货币
   - 美林时钟提供**预期管理**框架；资产表现反映**真实资金动态**；预期与现状互为印证修正

3. **板块内层级传导**
   - 股票：龙头 → 蓝筹 → 增长型 → 泡沫型
   - 加密：BTC（龙头）→ ETH 等（主流）→ UNI 等（增长型）→ meme（炒作型）
   - 资金沿风险偏好梯度传导，龙头先行、炒作型殿后

4. **技术确定性锚点**
   - 日线 MA200 等技术分界线为模糊周期提供确定性信息（牛熊分界）
   - 作用：为周期判定的不确定性提供硬边界

5. **策略映射（简单原则）**
   - 顺势（周期上行）→ 趋势追涨策略
   - 逆势（周期下行）→ 趋势做空策略
   - 不确定（周期模糊）→ 高抛低吸策略
   - **高级别弹性约束低级别**：长周期方向约束中短周期操作

6. **描述性服务于周期理论**
   - 大周期表现由基本面数据综合决定（如美国 CPI 对美联储政策的重要性）
   - 39 系统 L1-L3 的描述性产出正是周期判定的语义输入
   - 顶层逻辑并非臆测，而是由低层神经（L1-L3）逆向深度学习获得

7. **矛盾论方法支持**
   - 自进化系统的矛盾论方法为多数据冲突下的主要矛盾识别提供算法支持
   - 用于识别真正的周期趋势，过滤噪声

## 一 · 架构设计

### 1.1 分层传导架构（五层）

```
┌─────────────────────────────────────────────┐
│ L5 策略映射层：顺势追涨 / 逆势做空 / 不确定高抛低吸 │
│     高级别弹性约束低级别（长→中→短）              │
├─────────────────────────────────────────────┤
│ L4 板块传导层：BTC→ETH→增长型→meme 风险梯度       │
├─────────────────────────────────────────────┤
│ L3 资产轮动层：黄金/大宗/债券/股票/加密 大池子     │
│     美林时钟（预期）vs 资产表现（真实）互为印证     │
├─────────────────────────────────────────────┤
│ L2 周期判定层：真实周期（美联储加减息）            │
│     + 理论周期（短/中/长）互为印证修正            │
├─────────────────────────────────────────────┤
│ L1 语义输入层：39 系统 L1-L3 描述性产出           │
│     + 宏观数据（CPI/利率/通胀预期）+ 技术锚点(MA200)│
└─────────────────────────────────────────────┘
```

## 三 · 核心模块设计

### 3.1 周期判定模块（L2 层）
- **真实周期状态机**：基于 FEDFUNDS 变化序列判定加息周期/降息周期/平台期
- **理论周期估计**：短/中/长周期的趋势分解（待评估：可用 HP 滤波/小波分解等经典方法，避免过拟合）
- **印证修正机制**：理论周期与真实周期背离时，以矛盾论方法识别主要矛盾（哪个是主要趋势）

### 3.2 资产轮动模块（L3 层）
- 美林时钟四象限定位：增长/通胀二维映射（预期管理）
- 资产表现印证：各大类资产动量/相对强弱（真实资金动态）
- 背离检测：预期象限 vs 真实资金流向不一致时输出修正信号

### 3.3 板块传导模块（L4 层）
- 加密板块层级：BTC → ETH/SOL 主流 → UNI 等增长型 → meme 炒作型
- 传导健康度：龙头先行、板块跟涨为健康传导；炒作型独涨为末端信号
- 层级动量梯度：各层级相对 BTC 的强弱变化

### 3.4 策略映射模块（L5 层）
- 输入：周期判定（顺/逆/不确定）+ 技术锚点（MA200 上下）
- 输出：策略映射建议（追涨/做空/高抛低吸）+ 资产类别偏好
- **弹性约束**：长周期方向约束中短周期；中周期约束短周期；低级别与高级别冲突时降级为高抛低吸

### 3.5 神经网络深度学习（演进方向，分阶段）
- **阶段一（规则引擎）**：上述模块以预注册规则实现，验证传导逻辑有效性
- **阶段二（统计学习）**：积累事件流后，对周期判定与资产表现做统计关联学习
- **阶段三（神经网络）**：在既有知识基础上深度学习——以 L1-L3 语义特征为输入，周期判定为目标，训练传导网络；顶层逻辑由低层数据逆向学习获得，非人工臆测
- **约束**：神经网络阶段前必须完成阶段一/二验证；训练数据依赖事件流积累

## 四 · 产出物定义

- `cycle_state.json`：周期判定状态（真实周期/理论周期/印证状态/主要矛盾）
- `asset_rotation.json`：资产轮动分析（美林时钟定位/资产动量/背离信号）
- `sector_conduction.json`：板块传导分析（层级动量梯度/传导健康度）
- `strategy_mapping.json`：策略映射建议（周期状态→策略类型+资产类别偏好，仅建议不决策）

## 五 · 边界红线（强制）

1. 40 系统产出周期判定与策略映射**建议**，不产生交易信号
2. 所有交易决策归 23 系统三步门禁（回测 → 影子 → 灰度）
3. 神经网络训练必须建立在阶段一/二验证基础上，禁止直接跳到端到端黑箱
4. 周期判定为概率性描述，必须标注不确定性；MA200 等技术锚点作为硬边界参考
5. 复用不新建：数据源用 18 中心，语义输入用 39 系统，矛盾识别用 23 矛盾论框架

## 七 · 风险与注意事项

1. **周期判定滞后性**：宏观数据（CPI/利率决议）天然滞后，需结合 39 系统快讯语义做前瞻
2. **美林时钟失效场景**：滞胀等非典型周期下时钟象限映射失真，需资产表现印证修正
3. **过拟合风险**：理论周期分解方法（HP 滤波等）存在端点偏差，预注册参数并留验证窗口
4. **数据扩展依赖**：石油（CL=F）、meme 代币清单等需扩展 18 中心 sources.yaml
5. **与 23 系统既有宏观 SPEC 的职责划分**：23 的『美国宏观事件驱动交易策略』做事件级交易，40 做周期级状态判定，接口为 40 向 23 提供周期状态上下文

## 八 · 验收标准（P1-P4 阶段）

1. cycle_state.json 能正确输出真实周期状态（以 FEDFUNDS 历史序列回测验证状态机）
2. MA200 锚点与历史牛熊段对照，分界准确率可量化
3. 资产轮动输出与美林时钟经典周期案例（如 2020-2022）回测对照
4. 板块传导梯度在历史风险偏好切换期（如 2024 Q4）可复现
5. 策略映射建议仅作为 23 门禁输入，不绕过门禁直接执行
