### 3.2 app.py 结构（参考 ml_trade_service_v2.py）

```python
"""经典指标系统 C0-C8 模块化 API 服务"""
from flask import Flask
from .c0_env_scan import blueprint as c0_bp
from .c1_universe import blueprint as c1_bp
# ... c2-c8 + agents

def create_app() -> Flask:
    app = Flask(__name__)
    # 注册横切 hooks（CORS/before_request/after_request）
    from .core.http import register_hooks
    register_hooks(app)
    # 注册各阶段 Blueprint
    app.register_blueprint(c0_bp)
    app.register_blueprint(c1_bp)
    # ... c2-c8 + agents
    return app

app = create_app()
```

## 6. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 全局锁耦合 | 高 | Phase 0 先集中抽取 locks.py，各模块 import 同一实例 |
| 函数跨阶段调用 | 高 | 允许 `from classic_pipeline.c0_env_scan import xxx`，不强制零依赖 |
| 187K 行一次性拆分风险 | 高 | Strangler Fig 逐阶段迁移，每阶段独立验证 |
| 回归测试覆盖不足 | 中 | 每个 Phase 必须有路由级回归 + 核心函数单测 |
| 前端 API 契约变更 | 高 | Blueprint 路由前缀与旧路由完全一致，零破坏 |
| 全局变量副作用 | 中 | `_RUNTIME_CTX` (threading.local) 放入 core/runtime.py 统一管理 |

## 7. 验收标准

1. **零破坏**：431 个路由 URL + 方法 + 返回结构 100% 不变
2. **模块化**：`classic_pipeline/` 下 10 个子包（core + C0-C8 + agents），每个子包 < 5000 行
3. **可测试**：每个阶段有独立单元测试，覆盖率 ≥ 80%
4. **可启动**：`python -m classic_pipeline.app` 启动成功，健康检查通过
5. **可回滚**：每个 Phase 可单独 revert，不影响其他阶段
6. **文档对齐**：前端 `classic/` 模块与后端 C0-C8 Blueprint 一一对应
