V3系统产品使用指南

版本：2025-11-20 • 适用环境：macOS，本地运行 • 输出渠道：Web 与本地文件

概览与受众

  • 目标用户：量化交易使用者、运维/平台管理员、策略与风控工程师、ML/数据工程师。
  • 使用场景：统一启动/监控数据采集、浏览指标与决策、调用 ML3 优化与训练、联动执行与反馈学习、对接交易日志与所需外部接口。

系统总览与分层架构

V3 是分层架构的交易研究与执行系统，包含数据采集与特征、指标分析、综合决策与风控、机器学习三层优化、强化学习执行、反馈学习与监控。Web 端入口与 API 由 web_server.py 提供，默认端口由环境变量 PORT 控制，缺省为 8080（web_server.py:15566-15571）。主要目录位于 v3_system/：

  • base_layer：data_layer（采集/流/Sink）、indicator_layer、analysis_layer、attention_layer
  • decision_layer：综合决策、策略与风控
  • ml_system：三层优化与在线学习
  • execution_rl：PPO 执行策略
  • feedback_learning_layer：在线学习、日志反馈、回测与优化
  • consoles：控制台入口与交易控制台

架构与数据流

数据层（采集→处理→流→落地→服务）

  • 入口编排：v3_system/base_layer/data_layer/main.py:33-35,170-181 将组件注册到 COMPONENTS_TO_RUN 并并发启动。
  • 采集器：Binance WebSocket 默认 BTCUSDT（main.py:51-53），可通过 BINANCE_STREAMS 指定多流。
  • 处理器/特征：日志与特征计算器在流上叠加（main.py:85-99），输出到 features_stream。
  • 可选 Sink：Redis/TimescaleDB/MinIO/Parquet 按开关启用（main.py:105-149）。
  • 风控消费者：消费信号流执行风险规则（main.py:120-123）。

指标/分析/注意力

  • 指标层：LSTM+Attention 风格选择与指标计算，如 indicator_selector_nn.py、indicator_calculator.py。
  • 分析层：趋势强度、加权评分与多时间框架 ML 模型（analysis_layer/）。
  • 注意力层：动态权重调整，影响信号置信度（在 BTC 卡片中集成，btc_position_api.py:127-168）。

决策与风控

  • 综合决策 API 封装在 decision_layer/__init__.py（__init__.py:8-19），对外提供交易决策。
  • 策略示例：4H 入场价评估（strategies/entry_4h.py:2-4），止盈分析（profit_stop_analysis.py:2-4）。

ML3 三层优化

  • 协调器 MLSystem 负责指标→决策→执行的优化闭环（ml_system/ml_system.py:21-23）。
  • 状态与模块指标查询（ml_system/ml_system.py:208-210,500-562），暴露到 Web API（web_server.py:3390-3397,4019-4204）。

执行与反馈

  • 强化学习执行：状态/训练/动作与指标在 execution_rl/（Web API：web_server.py:5583-5732）。
  • 反馈学习记录与监控在 feedback_learning_layer/（日志读取 log_feedback.py:18-20、在线学习指标 online_learning.py:46-48）。

控制台

  • 交易控制台封装配置管理、决策获取、信号与绩效（consoles/trading_console.py:12,129,149,155,169,213）。

执行 RL

配置与特性开关

快速开始

  • 依赖：Python 3.11+、Node 18+、Docker（TimescaleDB/MinIO 可选）。
  • 安装 Python 依赖：pip install -r requirements.txt（requirements.txt）。
  • 环境变量：复制 .env.template 为 .env，关键：ACTIVE_SYSTEM=v3、PYTHONPATH、PORT、REDIS_HOST/PORT、TIMESCALE_DSN、MINIO_ENDPOINT（.env.template:33-91）。
  • Docker 可选服务：docker compose up -d timescaledb minio（docker-compose.yml:14-49）。
  • 启动 Web：python web_server.py（监听 0.0.0.0:${PORT}）。
  • 启动采集：POST /api/start_collectors；查状态 GET /api/data_layer/status。

典型使用流程

  • 浏览与诊断：进入 /navigation，按分层查看页面与指标；/api/btc/position-signals 返回图表与买卖档位。
  • 策略与决策：POST /api/trade_decision 获取综合决策；查看 /api/performance_stats 与 /api/trade_execution_log。
  • ML3 优化：查询 /api/v1/ml3/status 与 /api/v1/ml3/module_metrics；触发训练 POST /api/v1/ml3/train。
  • 执行与反馈：强化学习 POST /api/execution_rl/act；监控反馈学习与日志。

配置管理与 Feature 开关

  • 读取与更新配置（落盘到 user_data/config.json）：/api/get_config、/api/update_config。
  • Feature toggles：/api/features 与单项读写，启用 Timescale/Parquet 等选择性能力。

安全与权限

  • .env 含交易所密钥、JWT、WebUI 认证：禁止入库、定期轮换、最小权限、配置 IP 白名单（.env.template:41-47）。
  • 对外暴露 API 建议前置反向代理与鉴权中间件。

运维与排错

  • 采集器异常：/api/data_layer/status 查看组件状态；必要时停止/重启。
  • 路由与健康：GET /api/debug/routes；文本指标 GET /metrics（Prometheus 兼容）。
  • 端口冲突：Docker freqtrade 占用 8080（docker-compose.yml:8-13）；将 PORT 改为 8002 或停用容器。
